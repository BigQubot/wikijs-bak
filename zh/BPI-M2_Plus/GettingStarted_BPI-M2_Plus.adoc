= 简介

香蕉派M2+ 是迷你尺寸开发板，以超便携的外形提供出色的计算性能。它的尺寸为 65mm*65mm 梦幻迷你尺寸板 Allwinner H系列芯片。它有不同的版本，但共享相同的接口。

TIP: 更多信息： link:/en/BPI-M2_Plus/BananaPi_BPI-M2_Plus[香蕉派 BPI-M2 Plus]

== 规格参数

- 四核 1.2GHz Cortex-A7 H3
- 1GB DDR3
- 8GB eMMC 船上
- 机载 WiFi 和蓝牙
- 10/100/1000Mbps Ethernet 端口

=== 将映像安装到 SD 卡

**Windows 电脑**

使用 Balena Etcher 安装映像。 +
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

. 点击“**从文件闪存**”来选择镜像。 
. 点击“**选择目标**”来选择 USB 设备。 
. 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**有两种方法供您选择。**

. 使用 dd 命令安装镜像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2_plus-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 安装镜像 bpi-tools 上 Linux，插入SD卡 Linux 电脑并运行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2_plus-xxx.img.zip /dev/sdX
```

 
=== 安装镜像到 eMMC

. 复制“xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img“给你的 USB 磁盘
. 插入你的 USB M2P 磁盘
. 执行(如果是自动挂载的则跳过此步骤)
+
```sh
mont /dev/sda1 /mnt
```
. 有两种方法可以将镜像刻录到 eMMC.
- 使用 bpi-copy 用于燃烧。
+
```sh
bpi-copy xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img
```
- 使用dd命令进行刻录。
+
```sh
sudo dd if=/mnt/sda1/xxx-sd-emmc-xxx.img of=/dev/mmcblk0
```

. 然后关闭M2P电源，取出TF卡，打开M2P电源 EMMC

=== 更新图片
例如，更新您的映像以支持新的 emmc5.1
```sh
  * execute “bpi-tools”, to update your bpi tools;
  * execute “bpi-update -c bpi-m2p.conf”, to download new driver to update your image
  * execute “file *.tgz”, to check download files’ type is compressed data
  * execute “bpi-bootsel”, you will see the bootloader path, “/usr/lib/u-boot/bananapi/bpi-m2p/BPI_M2P_720P.img.gz”
  * execute “bpi-bootsel /usr/lib/u-boot/bananapi/bpi-m2p/BPI_M2P_720P.img.gz”, to update your bootloader
  * reboot
```

=== 如何创建图像
. 准备一张已安装好系统的SD卡(Ubuntu/Raspbian/..)
. 用M2P启动SD卡，M2P启动完成后，复制文件并配置系统，然后关闭M2P。 [如果您不想配置系统，可以跳过此步骤]
. 将 SD 卡插入 PC(正在运行 Linux)
+
```sh
cd /media
ln -s <your account> pi
```
. 执行
+
```sh
bpi-migrate -c bpi-m2p.conf -c ubuntu-mate-from-sd.conf -d /dev/sdx
```
. 那么你现在就可以得到你自己的图像了

=== GPIO 控制
- 要访问一个 GPIO 您首先需要将其导出
+
```sh
 echo XX > /sys/class/gpio/export
```
- XX 是所需引脚的编号。要获得正确的数字，您必须根据引脚名称进行计算 (像PH18) 
+
(字母在字母表中的位置 - 1) * 32 + 引脚号 
+
对于 PH18 这将是 ( 8 - 1) * 32 + 18 = 224 + 18 = 242 (因为 'h' 是第 8 个字母)
+
```sh  
echo "out/in" > /sys/class/gpio/gpio*NUMBER*/direction
 echo "0/1" > /sys/class/gpio/gpio*NUMBER*/value
```

=== OTG
. 在 M2P 控制台上：
+
执行 
+
```sh

```

. PC端：

- 如果adbd设置成功，插入OTG-USB M2P 和 PC 接口(与 Ubuntu 系统)

- 执行
+
```sh
adb devices
```
查看PC是否已识别M2P OTG。
+
- 如果是的话，我们可以执行
+
```sh
adb shell
```
现在通过 adb 连接 M2P。
