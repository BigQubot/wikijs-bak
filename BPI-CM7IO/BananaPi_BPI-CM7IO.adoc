= BPI-CM7IO Introduction

Banana Pi BPI-CM7IO is the carrier board for link:/en/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7]. It converts the CM7 module's board-to-board signals into standard development interfaces, including HDMI, USB, Fast Ethernet, microSD, a 40-pin GPIO header, and a USB-based cellular-module socket.

[WARNING]
====
BPI-CM7IO is designed around the BPI-CM7 V00 signal assignment. Its CM4-style module connectors do *not* make it a universal Raspberry Pi CM4 or BPI-CM4 carrier. Confirm electrical compatibility before installing any other compute module.
====

== Key Features

* Two 100-pin high-density connectors for BPI-CM7
* USB-C connector for regulated 5 V input and USB 2.0 OTG data
* 2 x USB 2.0 Type-A host ports
* Full-size HDMI Type-A output
* 10/100M Ethernet RJ45 port
* microSD card socket
* 40-pin GPIO header
* mini-PCIe-style socket for USB-based 4G/LTE modems
* micro-SIM socket connected to the cellular-module socket
* 3-pin 3.3 V TTL debug UART header
* Reset and FEL/MaskROM recovery buttons
* 4-pin composite-video/stereo-line-output header
* Blue and green status/user LEDs
* Carrier identification EEPROM at TWI/I2C address `0x56`

== Hardware

=== Interface Specification

[cols="1,3", options="header"]
|===
| Interface | BPI-CM7IO V00 implementation

| Compute module
| 2 x Hirose DF40C-series 100-pin board-to-board connectors for BPI-CM7

| Power input
| Regulated 5 V through USB-C. The USB-C CC pins use sink pull-down resistors and there is no USB-PD voltage-negotiation controller in the schematic.

| USB OTG
| 1 x USB 2.0 OTG through the USB-C connector

| USB host
| 2 x USB 2.0 Type-A ports. A third USB 2.0 host link is routed to the cellular-module socket.

| Display
| 1 x full-size HDMI Type-A output from CM7 HDMI0

| Ethernet
| 1 x RJ45, 10/100M Fast Ethernet. The carrier magnetics use two Ethernet pairs, not four-pair Gigabit Ethernet.

| Removable storage
| 1 x microSD card socket

| GPIO
| 1 x 40-pin header with 3.3 V GPIO, UART, TWI/I2C, SPI, PWM, I2S/DMIC, SPDIF, IR, 5 V, 3.3 V, and ground

| Cellular expansion
| 1 x 52-pin mini-PCIe-style socket and 1 x micro-SIM socket. The data connection is USB 2.0; PCIe clock and data lanes are not connected.

| Debug
| 1 x 3-pin 3.3 V TTL debug UART header

| Buttons
| Reset and FEL/MaskROM recovery

| Analog A/V
| 1 x 4-pin header: composite video, ground, line-out left, and line-out right

| Indicators
| 1 x blue LED and 1 x green LED

| Carrier EEPROM
| 24C02-compatible EEPROM, TWI/I2C address `0x56`

| Hardware revision used for this page
| BPI-CM7 Carrier V00 schematic, dated July 16, 2026
|===

=== Power and USB-C Notes

Use a stable regulated 5 V supply with enough current for the CM7 module and all attached USB or cellular devices. The USB-C connector carries both the 5 V input and the CM7 USB0 OTG data pair.

[CAUTION]
====
The carrier schematic does not contain a USB-PD controller. Do not apply 9 V, 12 V, or another negotiated USB-PD voltage to the 5 V input rail.
====

=== Cellular-Module Socket

The 52-pin connector has the mechanical form commonly called mini-PCIe, but BPI-CM7IO routes USB 2.0 D+/D-, SIM signals, control signals, and power to it. PCIe transmit, receive, and reference-clock lanes are not present.

[IMPORTANT]
====
Use a USB-interface 4G/LTE modem. A PCIe-only mini-PCIe card will not work in this socket.
====

[CAUTION]
====
The GPIO header uses 3.3 V logic and is not 5 V tolerant. Pins 22 and 36 are level-shifted GPIO signals, not 3.3 V power pins. Alternate functions require matching pinctrl/device-tree configuration and cannot all be enabled simultaneously.
====

== Board Differences

=== BPI-CM7 vs BPI-CM7IO

[cols="1,2,2", options="header"]
|===
| Function | BPI-CM7 | BPI-CM7IO

| Role
| Compute module containing the processor, memory, storage, PMIC, and wireless module
| Carrier that turns module signals into connectors

| User-facing ports
| None
| HDMI, USB-C, USB Type-A, RJ45, microSD, GPIO, UART, audio/CVBS, cellular socket, and SIM

| Ethernet
| Exposes H618 Fast Ethernet PHY pairs
| Adds magnetics and 10/100M RJ45

| Storage
| Onboard eMMC
| Adds removable microSD

| Power
| Receives 5 V through module connectors
| Receives 5 V through USB-C and supplies the module
|===

=== BPI-CM7IO vs BPI-CM4IO

[cols="1,2,2", options="header"]
|===
| Item | BPI-CM7IO | BPI-CM4IO reference board

| Intended module
| BPI-CM7 (Allwinner H618)
| BPI-CM4 / Raspberry Pi CM4-style module

| Ethernet
| 10/100M Fast Ethernet
| Gigabit Ethernet is listed for BPI-CM4IO

| GPIO header
| 40 pins
| 26 pins

| MIPI camera/display connectors
| Not implemented on BPI-CM7IO V00
| MIPI CSI and DSI are listed for BPI-CM4IO

| Cellular expansion
| mini-PCIe-style socket using USB 2.0 data, plus micro-SIM
| mini-PCIe and SIM interfaces are listed for BPI-CM4IO

| Electrical interchangeability
| Do not assume CM4 compatibility
| Designed for its own documented CM4-family signal assignment
|===

== Development

Operating-system images must include the BPI-CM7 device tree so that the CM7IO USB, Ethernet, HDMI, microSD, LEDs, and 40-pin pinmux are configured correctly.
