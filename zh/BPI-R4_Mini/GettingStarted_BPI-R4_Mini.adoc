= 概述

香蕉派 BPI-R4 Mini Wifi7智能路由器板设计与 MediaTek MT7987A 四核 Arm Cortex-A53，支持 2GB DDR4 和 8G eMMC 船上闪光。 2 x 2.5G RJ45，板载 Wifi7，迷你尺寸。 

= 开发
== 准备工作
* USB 磁盘 +
* USB C型数据线 +
* CAT6A/Cat5e Ethernet 电缆 +
* 12V/5A 电源适配器（无任何外设和网线插入时，功耗 BPI-R4MINI 主板大约10W，所以 12V/2A 会起作用的。
但您需要根据自己的配件使用情况来确定是否需要更高功率的电源适配器，12V/5A 推荐） +
* Windows/unbuntu 系统 +
* link:https://docs.banana-pi.org/en/BPI-R4_Mini/BananaPi_BPI-R4_Mini#_system_image[BPI-R4Mini 镜像] +

=== 如何将镜像闪烁到 NAND 闪光灯
TIP: 工厂形象信息：OpenWrt 24.10-快照架构：aarch64_皮质-a53


将镜像闪烁之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r4mini-NAND-20260721.img) 例如，步骤如下：

1.	格式化 USB 磁盘到 FAT32。

2.	复制 Nand 启动 OpenWrt 镜像(mtk-bpi-r4mini-NAND-20260721.img) 到 USB 磁盘。
3.	将引导程序更改为 eMMC 启动，然后给开发板上电。
4.	插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```SH

cd /mnt
```
5.	执行以下命令即可全部擦除 Nand 闪存并将镜像复制到 nand 设备：

== 读写EEPROM
WARNING:  注意：我们发布的映像文件在每次启动时使用随机 MAC 地址，并且不使用 EEPROM。如果您希望使用 EEPROM，则需要编写脚本来读取数据并更新端口。

=== 读取EEPROM +

```sh

hexdump -C /sys/bus/i2c/devices/0-0057/eeprom 
```


=== 将内容写入EEPROM

```sh
printf '\x01\x02\x03\x04\x05\x06' | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=32 conv=notrunc
```

"**\x01\x02\x03\x04\x05\x06**" 是你要写入的内容，可以是MAC地址、序列号或者其他信息。 +
"**废话=1**" 表示块大小为 1。 +
"**寻找=32**" 表示偏移量 (要跳过多少个块). +
**“废话=1 次寻找=32**"表示跳过32个字节，相当于从0x00到0x1F跳过字节，从0x20开始写入内容。 +
"**转化次数=不截断**“不截断EEPROM，保留原始数据。

比如我想向地址中写入两组MAC地址 **0x20** 和 **0x30** 分别：

```
printf '\x12\x41\x89\x7F\x64\xD3' | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=32 conv=notrunc
printf '\x7E\xF5\x56\x36\x4C\xD1'  | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=48 conv=notrunc
```

WARNING:  **PS：由于V1.2版本后续批次计划向EEPROM写入数据，因此必须避免0x00到0x1F范围内的地址。**

== M.2键(B+M) 插槽(为了 4G/5G 模块或 NVMe SSD)

=== 4G/5G 模块
的 BPI-R4Pro 拥有1个M.2 B-KEY插槽，全部用于 4G/5G蜂窝模块。

它支持一对 USB2.0 和 USB3.0 信号，均通过扩展 USB 3.0 枢纽。

此外，CN8h 还具有额外的 PCIe3.0 1lane 信号。

image::/bpi-r4_mini_en/m.2_key_b_slot.png[m.2_key_b_slot.png]

=== NVMe SSD

M.2按键插槽只能安装一种类型的M.2按键模块。

所以 4G/5G 模块和 NvMe SSD 只能安装一个。


== NANO SimSlot
SIM1可以使用板载NANO SIM插槽

== FPC连接器
这是一个 16 针连接器。

通常用于连接 spi lcd 或 i2c 电容式触摸屏。

image::/bpi-r4_mini_en/fpc.png[fpc.png]


== 调试 UART 
的 BPI-R4Mini 机载有 USB-到-UART 芯片(HT42B534-2)，连接到MT7988A的调试 UART.

连接时 USB Type-c连接器(CN41) 到 PC，一个 USB就会出现-to-serial设备，可以用来调试。

终端设置：波特率=115200，数据位：8位，奇偶校验：无，停止位：1位，流控制：无。

== 嵌入式SIM卡
PIN42/44/46/48 M.2 B-KEY Slot 是第二组SIM 卡信号。

注意：这需要您的模块支持，并且需要额外安装 eSIM 模块。

image::/bpi-r4_mini_en/esim.png[esim.png]

== EEPROM
内置1颗EEPROM芯片 (P24C02A)，可用于存储少量数据。

GPIO0连接有复位按钮，用于新设备快速连接路由器。

== LED
BPI-R4Mini有 LED 来指示各种操作状态，包括电源、WiFi、 Ethernet, 4G/5G 蜂窝等

* 1x 动力绿 LED，PCB上丝印“PWR”，上电时亮起，无法通过软件控制。
* 1x 蓝色状态 LED，PCB上丝印“B”，由控制 GPIO "PCA_A_IO1_6/SYS_LEDB".
* 2x WiFi 状态蓝色 LED，丝印“W2G”、“W5G”。
* 1x 5G 蜂窝状态蓝色 LED，丝印 
* 每个 2.5G RJ45 有 2 个 LED，每个 1G RJ45 有 1 个 LED LED 以指示网络状态。

== DCIN
BPI-R4Pro 需要一个单一的 +12V供电，并具有多种电源，包括直流电源适配器， USB PD， POE等

电源电压范围为9~建议使用24V、12V或20V，超过25.3V会自动关机。

=== DCIN(5521)

但如果同时存在其他电源，则会切换到其他电源。

== USB C型PD
的 USB Type-C PD连接器连接有CH224Q芯片，用于与设备通信 USB 适配器并允许适配器输出20V电压。 +

BPI-R4Mini 有一个 USB2.0 Type-A 连接器，可用于连接 USB 闪存驱动器或其他 USB 设备。 +
USB2.0连接器的电源输出 (CN12) 是 5V/1300mA，可以通过“PCA_A_IO1_3/VBUS_AB_PDN” 输出低。 +

== 散热片

MTK OpwnWRT MP4.0 风扇带 PWM 控制参考。
```bash
root@OpenWrt:~# cat /sbin/fan-speed 
#!/bin/sh /etc/rc.common

if [ ! -f /sys/class/pwm/pwmchip0/export ]; then
        exit 0
fi

### enable fan ###
echo 2 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm2/period
echo 7000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm2/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm2/enable

while :
do
        sleep 20
        result=`cat /sys/class/thermal/thermal_zone0/temp`

        temperature=$((result))
        #echo $temperature
        if [ ${temperature} -ge 53000 ]; then
                echo 7000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -ge 62000 ]; then
                echo 10000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -le 4800 ]; then
                echo 5000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -le 4000 ]; then
                echo 3000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi
done
root@OpenWrt:~#
```
