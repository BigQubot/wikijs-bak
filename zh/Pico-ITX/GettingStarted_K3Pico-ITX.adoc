= 简介

K3 Pico-ITX 是一款单板计算机，可提供高达 60 TOPS 的 AI 性能。它具有统一的内存架构，8 CPU 核心和8个AI加速核心，以及板载高速UFS存储和10Gb光纤网络接口。这种设计最大限度地提高了科学计算和人工智能等应用的计算能力并提高了效率。

K3 Pico-ITX 采用 2.5 英寸 Pico-ITX Plus 外形，针对空间有限的部署进行了优化。该板支持双M.2扩展插槽，并提供实时运动控制和系统管理接口。

与丰富的 I/O K3 Pico-ITX 具有可扩展性和工业级架构，可实现快速评估和系统集成，从而加快上市时间。
