= 简介

Banana Pi M2 Zero 是一款超紧凑型单板计算机，尺寸仅 60 mm × 30 mm。它搭载 Allwinner H2+ 四核 Cortex-A7 处理器和 512 MB RAM，适合空间受限的轻量级系统应用。与其他 Banana Pi 产品一样，它同时支持 Linux 和 Android 操作系统。

TIP: 更多信息：link:/zh/BPI-M2_Zero/BananaPi_BPI-M2_Zero[Banana Pi BPI-M2_Zero]

== 规格参数

- 四核 ARM Cortex A7 CPU H2+
- 512 MB SDRAM
- 板载 WiFi（AP6212）和蓝牙
- Mini HDMI

== Linux
=== 准备

. 建议使用 A1 等级、容量至少 8 GB 的存储卡。
. 在 Linux PC 上安装 bpi-tools（如果使用其他工具烧录镜像，可跳过此步）。如果无法访问安装地址或遇到其他安装问题，请前往 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源代码仓库，手动下载并安装。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验和正确。
. 默认登录账号/密码：pi/bananapi 或 root/bananapi

=== 将镜像安装到 SD 卡
**Windows PC**

使用 balenaEtcher 安装镜像。 +
link:https://balena.io/etcher[balenaEtcher] 是 Balena 开发的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux PC**

**有两种方法供您选择。**

. 在 Linux 上使用 dd 命令写入镜像。如果系统自动挂载了 SD 卡设备 /dev/sdX 的分区，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2_zero-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 在 Linux 上使用 bpi-tools 安装镜像：将 SD 卡插入 Linux PC，然后执行以下命令。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2_zero-xxx.img.zip /dev/sdX
```

== 高级开发
=== 如何创建镜像
- 准备一张已安装系统（Ubuntu/Raspbian 等）的 SD 卡。
- 从 SD 卡启动。启动完成后，复制所需文件并配置系统，然后关闭 M2 Zero。（如果无须配置系统，可跳过此步。）
- 将 SD 卡插入运行 Linux 的 PC。
+
```sh
cd /media
```
然后执行：
+
```sh
ln -s <your account> pi
```
- 执行
+
```sh
bpi-migrate -c bpi-m2z.conf -c ubuntu-mate-from-sd.conf -d /dev/sdx
```
- 此时即可得到自定义镜像。

=== OTG
. 在 M2 Zero 控制台上：
+
执行
+
```sh
./adbd.sh
```
然后执行
+
```sh
ps -ax | grep adbd
```
检查 adbd 是否已启动。

. 在 PC 终端上：
+
如果 adbd 已成功启动，请通过 OTG-USB 线将 M2 Zero 连接到运行 Ubuntu 的 PC。
执行
+
```sh
adb devices
```
检查 PC 是否已识别 M2 Zero 的 OTG 设备。
如果已经识别，可执行：
+
```sh
adb shell
```
此时已通过 adb 连接到 M2 Zero。

=== 显示
**如何更改显示分辨率**

以下以将 M2Z 的 HDMI 输出改为 1080P 为例。

. 执行
+
```sh
mount /dev/mmcblk0p1 /mnt
cd /mnt/bananapi/bpi-m2z/linux
```
找到“**sys_config.fex**”。

. 执行
+
```sh
vim sys_config.fex
```
将
+
```sh
screen0_output_mode = 5
```
改为
+
```sh
screen0_output_mode = 10
```
+
image::/picture/display_output.png[display_output.png]

. 保存修改后，使用
+
```sh
fex2bin
```
命令“**fex2bin sys_config.fex script.bin**”将 sys_config.fex 转换为 bin 文件，然后重新启动。
+
参数含义：
