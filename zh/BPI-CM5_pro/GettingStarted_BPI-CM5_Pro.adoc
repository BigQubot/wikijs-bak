= 简介

Banana Pi BPI-CM5 Pro 是一款基于 Rockchip RK3576 第二代 8 nm 高性能 AIoT 平台的计算模块。它集成四核 Cortex-A72（2.2 GHz）和四核 Cortex-A53（1.8 GHz）、专用 NEON 协处理器及 6 TOPS NPU，最高支持 16 GB 内存；同时支持 4K 视频编解码、丰富的扩展接口和多种操作系统。

TIP: Rockchip RK3576设计 link:/en/BPI-CM5_Pro/BananaPi_BPI-CM5_Pro[香蕉派 BPI-CM5 Pro] AI计算机模块设计

== 将镜像写入 eMMC：方法一

NOTE: 请准备一张已写入镜像的 SD 卡，以及一个存有镜像文件的 U 盘。

. 将 SD 卡插入 BPI-CM5 Pro I/O 板，连接电源并启动，然后插入 U 盘。

. 查看存储设备：
+
```sh
lsblk
```
检查 U 盘是否已挂载（如果已经挂载，可跳过第三步）。

. 将 U 盘挂载到 /mnt 目录。
+
```sh
sudo mount /dev/sda1 /mnt
cd /mnt
```

. 将镜像写入 eMMC：
+
```sh
sudo dd if=bpi-cm5-Pro-xxx.img of=/dev/mmcblk0 bs=10M
```

. 断开电源并取出 SD 卡，再次通电后从 eMMC 启动。

== 将镜像写入 eMMC：方法二
NOTE: Maskrom：当 Flash 中没有固件时，芯片会进入 Maskrom 模式，可用于首次烧录。在开发调试过程中，如果 Loader 无法正常启动，也可进入 Maskrom 模式烧录固件。     

NOTE: Loader：U-Boot 启动时检测到对应按键被按下，设备便会进入 Loader 模式。此模式支持烧录和升级固件，也可通过工具单独写入某个分区镜像，便于调试。

BPI-CM5 Pro 套件启动后，可通过以下三种方式查看 IP 地址：

* 连接 HDMI 显示器并登录系统，在终端中输入 ip a 命令查看 IP 地址。
* 连接 [调试串口](#Debugging Serial Port)，在终端中输入 ip a 命令查看 IP 地址。
* 如果没有调试串口或 HDMI 显示器，也可通过路由器管理界面查看 CM5 套件以太网接口的 IP 地址。但路由器有时可能不显示该地址；遇到这种情况时，请按以下步骤排查：
** 首先确认 Linux 系统已正常启动。CM5 套件上的绿灯常亮时，通常表示启动正常。
** 检查网线是否连接牢固，或更换一根网线。
** 尝试使用其他路由器，因为遇到了路由器无法正确分配 IP 地址或分配的 IP 地址未显示在路由器上的问题。
** 如果没有其他可用的路由器，则需连接 HDMI 显示器或使用调试串口查看 IP 地址。

TIP: 请注意，CM5 套件上的 DHCP 自动 IP 分配不需要任何配置。

== RGB LED

BPI-M5 Pro 配有绿色和红色两个用户 LED。

* 绿色用户 LED 默认常亮，表示内核正在运行。

== WiFi

BPI-CM5 Pro 套件配有板载 WiFi 模块，无需外接无线网卡，并使用标准第四代天线。

=== 在服务器版镜像中通过命令行连接 WiFi

1、首先登录 Linux 系统，可使用以下三种方式之一：

* CM5 套件已连接网线时，可通过 SSH 远程登录。
* CM5 套件已连接调试串口时，可通过串口终端登录。
* CM5 套件已连接 HDMI 显示器时，可使用屏幕上显示的终端登录。

2、使用 nmcli dev wifi 命令扫描附近的 WiFi 热点。

```sh
# 1. 启用 WiFi
root@armsom-cm5:/# nmcli r wifi on
# 2. 扫描 WiFi
root@armsom-cm5:/# nmcli dev wifi
# 3. 连接 WiFi 网络
root@armsom-cm5:/# nmcli dev wifi connect "wifi_name" password "wifi_password"
```

=== 在服务器版镜像中通过图形界面连接 WiFi

1、登录 Linux 系统，可使用以下三种方式之一：

* CM5 套件已连接网线时，可通过 SSH 远程登录。
* CM5 套件已连接调试串口时，可通过串口终端登录；请使用 MobaXterm，因为 Minicom 无法显示图形界面。

== RTC

* CM5 套件配备 LK8563S RTC 芯片。
* 首先将 RTC 电池插入 2 针接口，为 RTC 芯片供电。

TIP: RTC 电池应保持连接，并确认系统已经创建 LK8563S RTC 设备。

```sh
root@armsom-cm5:/# dmesg | grep rtc
[    3.476710] rtc-hym8563 2-0051: rtc information is valid
[    3.488534] rtc-hym8563 2-0051: registered as rtc0
[    3.490109] rtc-hym8563 2-0051: setting system clock to 2024-06-16T09:45:52 UTC (1718531152)
```

* 找到 rtc0 后，使用以下命令设置系统时间并同步到 rtc0。

```sh
root@armsom-cm5:/# hwclock -r
2023-11-03 10:32:40.461910+00:00
root@armsom-cm5:/# date
2023年11月03日 星期五 10:33:12 UTC
root@armsom-cm5:/# hwclock -w
root@armsom-cm5:/# hwclock -r
root@armsom-cm5:/# poweroff
```

* 取出 RTC 电池，等待至少 10 分钟后重新装入并启动设备，检查 RTC 时间是否与系统时钟同步。

```sh
root@armsom-cm5:/# hwclock -r
2023-11-03 10:35:40.461910+00:00
root@armsom-cm5:/# date
2023年11月03日 星期五 10:36:01 UTC

== MIPI DSI

BPI-CM5 Pro 套件的 MIPI DSI 最高支持 2K@60Hz 分辨率。

* 按照下图连接排线：

image::/bpi-cm5_pro/banana_pi_bpi-cm5_pro_mipi_dsi_setting.jpg[banana_pi_bpi-cm5_pro_mipi_dsi_setting.jpg]

* 配置 10.1 英寸 MIPI LCD 屏幕：

// 根据所用产品选择
overlays=armsom-cm5-io-display-10hd // cm5-kit
```
