= 简介

香蕉派 BPI-R4 路由器板带有 MediaTek MT7988A (Filogic 880) 四核ARM Corex-A73设计，4GB DDR4 RAM,8GB eMMC,128MB SPI-NAND 板载闪存，还有 2x 10Gbe SFP, 4x Gbe网口,带USB3.2接口,M.2支持 4G/5G/NVME SSD.2x miniPCIe 插槽，带 PCIe3.0 2lane 接口，用于 Wi-Fi 7 NIC (网络接口卡)。它是一款非常高性能的开源路由器开发板。

TIP: 更多信息： link:/en/BPI-R4/BananaPi_BPI-R4[香蕉派 BPI-R4]

== 如何将镜像刻录到板上 Nand
NOTE: **NAND 有在工厂刻录的镜像。如果要使用，只需切换到相应的启动，然后上电即可启动。**

NOTE: 当你想更新的时候 Nand 设备，首先将启动开关更改为从 SD 设备启动，并插入一张带有 SD boot Image 的 SD，然后启动后，您需要 flash 一张 Nand 镜像进入 Nand 设备。最后你将 bootstrap 更改为 boot from Nand 设备。

在将镜像刻录到之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r4-NAND-20231030.img) 例如，步骤如下：

. 复制 Nand 启动 OpenWrt 镜像(**mtk-bpi-r4-NAND-20231030.img**) 到 USB 磁盘。 
. 更改启动开关跳线，板子从SD设备启动，然后给板子上电。
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
. 执行以下命令即可全部擦除 Nand 闪存并将镜像复制到 nand 设备：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r4-NAND-20231030.img of=/dev/mtdblock0
```
. 关闭电源 BPI-R4 板子，拔掉U盘驱动，修改bootstrap为启动 Nand 设备。

== 如何将镜像刻录到板上 eMMC
NOTE: 因为SD卡和 EMMC 设备共享一个SOC的控制器，需要切换到 NAND 启动然后刻录 EMMC 镜像进入 EMMC。最后，您将更改启动方式 EMMC.

将镜像刻录到之前 eMMC，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (bl2_emmc-r4.img, mtk-bpi-r4-EMMC-20231030.img) 例如，步骤如下：

. 复制 EMMC 启动 OpenWrt 镜像(**bl2_emmc-r4.img**,**mtk-bpi-r4-EMMC-20231030.img**) 到 USB 磁盘，如果镜像被压缩，请在复制到之前解压 USB 磁盘。

. 将开关跳线更改为 Nand 并从主板启动 Nand.
 
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```

. 执行：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc-r4.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4-EMMC-20231030.img of=/dev/mmcblk0
 mmc bootpart enable 1 1 /dev/mmcblk0
```
 
. 关闭R4板电源，删除U盘驱动，更改引导程序以从 emmc 设备。

== 读写EEPROM
WARNING: **我们发布的映像文件在每次启动时使用随机 MAC 地址，并且不使用 EEPROM。如果您希望使用 EEPROM，则需要编写脚本来读取数据并更新端口。**

1、读取EEPROM
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom
```
2、写入内容到EEPROM
```
printf '\x01\x02\x03\x04\x05\x06' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=32 conv=notrunc
```
"**\x01\x02\x03\x04\x05\x06**" 是你要写入的内容，可以是MAC地址、序列号或者其他信息。 +
"**废话=1**" 表示块大小为 1。 +
"**寻找=32**" 表示偏移量 (要跳过多少个块). +
**“废话=1 次寻找=32**"表示跳过32个字节，相当于从0x00到0x1F跳过字节，从0x20开始写入内容。 +
"**转化次数=不截断**“不截断EEPROM，保留原始数据。

比如我想向地址中写入两组MAC地址 **0x20** 和 **0x30** 分别：
```
printf '\x12\x41\x89\x7F\x64\xD3' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=32 conv=notrunc
printf '\x7E\xF5\x56\x36\x4C\xD1' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=48 conv=notrunc

```
WARNING:  **PS：由于V1.2版本后续批次计划向EEPROM写入数据，因此必须避免0x00到0x1F范围内的地址。**

3、读取EEPROM全部内容。
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom
```
读取EEPROM中指定位置的内容。
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom | tail -n +3
```
"**尾部-n +3**"表示只显示从第三行开始的数据，即0x20。



= 配件

== 10G SFP 模块
的 SFP 串行解串器速度 BPI-R4 固定为 10Gbps，因此仅 SFP 支持这个就可以用了！

一般是10G的PIN6 SFP+ 模块为GND。插入模块后，SFP_模组_DEF0将被拉低，从而开启 SFP 电源。

因此，如果模块的这个PIN不是GND，则3.3V_将不提供 SFP 电源！

=== M.2 4G/5G 模块(USB 接口)
BPI-R4 支持M.2 USB 接口4G LTE/5G 模块： **移远EM05, RM500U-CN,RM500Q-GL& RM520N-GL ** 

如果您想在以下设备上使用 M.2 蜂窝模块 BPI-R4:

. 安装 4G/5G 蜂窝模块插入 CN16 插槽(M.2 键盘)
. 将 NANOSIM 卡插入 SIMSlot(卡1) 带卡托盘(注意方向)
. 在模块上安装天线
. 开机后会自动拨号

NOTE: 的可用性 4G/5G 取决于本地载波频段。

root@R4RN:/# cat /sbin/fan-speed 
#!/bin/sh /etc/rc.common

if [ ! -f /sys/class/pwm/pwmchip0/export ]; then
        exit 0
fi

### enable fan ###
echo 0 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm0/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable

while :
do
        sleep 20
        result=`cat /sys/class/thermal/thermal_zone0/temp`

        temperature=$((result))
        #echo $temperature
        if [ ${temperature} -ge 53000 ]; then
                echo 5000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -ge 62000 ]; then
                echo 1000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4800 ]; then
                echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4000 ]; then
                echo 10000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi
done
