== Linux
=== 准备

. Linux 镜像支持从 SD 卡或 eMMC 启动。
. 建议使用 A1 等级、容量至少 8 GB 的存储卡。
. M2 Ultra 与 M2 Berry 使用相同的 Linux 镜像。
. 在 Linux PC 上安装 bpi-tools（如果使用其他工具烧录镜像，可跳过此步）。如果无法访问安装地址或遇到其他安装问题，请前往 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源代码仓库，手动下载并安装。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验和正确。
. 默认登录账号/密码：pi/bananapi 或 root/bananapi
. 确保 SW4 切换到“1”以进行 SD 启动。

image::/picture/w2-sw4-1.jpg[w2-sw4-1.jpg]

=== 使用 SD 卡安装镜像

**Windows PC**

使用 balenaEtcher 安装镜像。 +
link:https://balena.io/etcher[balenaEtcher] 是 Balena 开发的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux PC**

**有两种方法供您选择。**


. 在 Linux 上使用 dd 命令写入镜像。如果系统自动挂载了 SD 卡设备 /dev/sdX 的分区，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
sudo apt-get install pv unzip
sudo unzip -p xxx-bpi-w2-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 在 Linux 上使用 bpi-tools 安装镜像：将 SD 卡插入 Linux PC，然后执行以下命令。
+
```sh
sudo apt-get install pv unzip
sudo bpi-copy xxx-bpi-w2-xxx.img.zip /dev/sdX
```

=== 安装镜像到 eMMC

. 准备一张已烧录 Linux 镜像的 SD 卡，并使用该卡启动开发板。
. 解压镜像并复制到 USB 存储设备，将 U 盘插入开发板后挂载。（如果系统已自动挂载，可跳过此步。）
+
```sh
mount /dev/sdx /mnt
```
. 可通过两种方式将 Linux 镜像安装到开发板。
- 使用 dd 命令安装。
+
```sh
sudo dd if=/mnt/xxx.bpi-w2-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 使用 bpi-tools 命令安装 U 盘中的 Linux 镜像。
+
```sh
sudo bpi-copy xxx-bpi-w2-xxx.img.zip /dev/mmcblk0
```
. 写入完成后安全关机，然后取出 SD 卡。

== 高级开发
=== SATA

. 在 W2 上挂载设备

- 接入 SATA 设备后，执行以下命令：
+
```sh
fdisk -l
mount /dev/sdx /mnt/xxx
```
+
image::/picture/w2_sata.jpg[w2_sata.jpg]

. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：

- 创建新分区
+
```SH
fdisk /dev/sdx
```
设置分区数量和大小。创建分区后，输入“**wq**”保存并退出。

- 格式化 SATA 设备
+
```SH
mkfs.ext2 /dev/sdx
```
- 挂载 SATA 设备
+
```sh
mount /dev/sdx /mnt/xxx
```

==== SSD
. 成功接入 SATA 设备后，可使用以下命令测试 SATA 接口：
+
--
测试读取速度
```sh
time dd if=/dev/xxx of=/dev/null bs=1M count=1000
```
测试写入速度
```sh
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
--
+
