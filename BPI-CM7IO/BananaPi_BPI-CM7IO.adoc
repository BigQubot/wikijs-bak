= BPI-CM7IO Introduction

Banana Pi BPI-CM7IO board is designed for link:/en/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7].

TIP: Allwinner H618 design : link:/en/BPI-M4_Zero/BananaPi_BPI-M4_Zero[Banana Pi BPI-M4 Zero] single board computer +
Allwinner H618 design : link:/en/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7] computer module

== Key Features

* 2 x 100-pin board-to-board connectors
* USB Type-C power input and USB 2.0 OTG
* 2 x USB 2.0 Type-A
* HDMI output
* 10/100M Ethernet RJ45
* microSD card slot
* 40-pin GPIO header
* mini-PCIe-style socket with USB 2.0 interface
* SIM card slot
* UART debug interface
* Reset and FEL buttons
* Composite video and stereo line output

= Hardware

== BPI-CM7 module base board interface

[options="header",cols="1,3"]
|===
| Interface | Specification

| Compute module
| 2 x 100-pin board-to-board connectors for BPI-CM7

| Power input
| 5 V through USB Type-C

| USB OTG
| 1 x USB 2.0 OTG through USB Type-C

| USB Host
| 2 x USB 2.0 Type-A; 1 x USB 2.0 routed to the cellular-module socket

| Display
| 1 x HDMI Type-A

| Ethernet
| 1 x 10/100M Ethernet RJ45

| Storage
| 1 x microSD card slot

| GPIO
| 1 x 40-pin GPIO header

| Cellular
| 1 x mini-PCIe-style socket with USB 2.0 interface and 1 x SIM card slot

| Debug
| 1 x 3-pin UART debug header

| Buttons
| Reset and FEL

| Analog A/V
| 1 x 4-pin composite video and stereo line-output header
|===
