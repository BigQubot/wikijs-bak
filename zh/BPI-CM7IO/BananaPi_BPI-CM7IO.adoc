= BPI-CM7IO 简介

香蕉派 BPI-CM7IO 板设计用于 link:/en/BPI-CM7/BananaPi_BPI-CM7[香蕉派 BPI-CM7].

TIP: Allwinner H618设计： link:/en/BPI-M4_Zero/BananaPi_BPI-M4_Zero[香蕉派 BPI-M4 Zero] 单板计算机 +
Allwinner H618设计： link:/en/BPI-CM7/BananaPi_BPI-CM7[香蕉派 BPI-CM7] 电脑模块

== 主要特性

* 2 个 100 针板对板连接器
* USB Type-C电源输入和 USB 2.0OTG
* 2 x USB 2.0 A型
* HDMI输出
* 10/100M Ethernet RJ45
* microSD 卡插槽
* 40针 GPIO 标头
* 迷你PCIe式插座 USB 2.0接口
* SIM卡槽
* UART 调试接口
* 重置和 FEL 按钮
* 复合视频和立体声线路输出
