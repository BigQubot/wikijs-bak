= 简介

Banana Pi BPI-R3 Mini 路由器开发板采用 MediaTek MT7986A（Filogic 830）四核 ARM Cortex-A53 芯片，板载 2 GB DDR 内存和 8 GB eMMC。它是一款高性能开源路由器开发板，采用 MT7976C 支持 2.4 GHz/5 GHz Wi-Fi 6，并提供两个 2.5GbE 以太网端口。

TIP: 更多信息：link:/zh/BPI-R3_Mini/BananaPi_BPI-R3_Mini[Banana Pi BPI-R3_Mini]

=== MediaTek MT7986(Filogic 830)
MT7986（Filogic 830）集成四个最高 2 GHz 的 Arm Cortex-A53 内核，处理能力最高可达 18,000 DMIPS，并支持总速率达 6 Gbps 的双频 4×4 Wi-Fi 6 连接。它提供两个 2.5G 以太网接口和串行外设接口（SPI）。Filogic 830 内置的硬件加速引擎可实现快速、可靠的 Wi-Fi 卸载和无线网络连接。此外，该芯片还支持 MediaTek FastPath™ 技术，适用于游戏、AR/VR 等低延迟应用。

与上一代技术相比，Wi-Fi 6 具有更低的延迟、更大的带宽容量和更快的传输速率。支持 6 GHz 频段的无线设备主要利用 160 MHz 宽信道和较少拥塞的 6 GHz 频谱，提供多千兆传输及低延迟 Wi-Fi 连接，为流媒体、游戏、AR/VR 等应用提供可靠的无线网络。

== 规格参数

- MediaTek MT7986A（Filogic 830）四核 ARM Cortex-A53
- WiFi 6 2.4G/5G（MT7976C）
- 2 GB DDR 内存
- 8 GB eMMC 闪存
- 128 MB NAND 闪存
- 2 个 2.5GbE 以太网端口
- 1 个 M.2 Key B USB 接口
- 1 个 M.2 Key M PCIe 接口
- 1 个 USB 2.0 接口

== Linux
=== 将镜像烧录到板载 eMMC

WARNING: 更新 eMMC 时，首先将启动开关切换为从 NAND 启动。系统启动后，将 eMMC 镜像烧录到 eMMC，最后再把启动方式切换为从 eMMC 启动。

向 eMMC 烧录镜像前，请准备一个 U 盘。下面以 OpenWrt 镜像（mtk-bpi-r3mini-EMMC-20230719.img、bl2_emmc-r3mini.img）为例：

. 将 eMMC 启动用 OpenWrt 镜像（mtk-bpi-r3mini-EMMC-20230719.img、bl2_emmc.img）复制到 U 盘。
. 调整启动开关跳线，使开发板从 NAND 启动，然后上电。
. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）
+
```sh
mount -t vfat /dev/sda1 /mnt 
```
切换到挂载点，本例为：
+
```sh
cd /mnt
```

. 执行以下命令，启用 eMMC 并将镜像写入 eMMC：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc-r3mini.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r3mini-EMMC-20230719.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
```
 . 关闭 R3 Mini 开发板电源，拔出 U 盘，并将启动方式切换为从 eMMC 启动。
+
WARNING: 启用 eMMC 设备，并将启动方式设为从 eMMC 启动。

=== 将镜像烧录到板载 NAND

WARNING: 更新 NAND 时，首先将启动开关切换为从 eMMC 启动。系统启动后，将 NAND 镜像烧录到 NAND，最后再把启动方式切换为从 NAND 启动。

向 NAND 烧录镜像前，请准备一个 U 盘。下面以 OpenWrt 镜像（mtk-bpi-r3mini-NAND-20230719-single-image.bin）为例：

. 将 NAND 启动用 OpenWrt 镜像（mtk-bpi-r3mini-NAND-20230719-single-image.bin）复制到 U 盘。
 . 调整启动开关跳线，使开发板从 eMMC 启动，然后上电。
 . 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）
+
```sh
mount -t vfat /dev/sda1 /mnt
```
切换到挂载点，本例为：
+
```sh
cd /mnt
```
. 执行以下命令，擦除整个 NAND 闪存并将镜像写入 NAND：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r3mini-NAND-20230719-single-image.bin of=/dev/mtdblock0
```
. 关闭 BPI-R3 Mini 开发板电源，拔出 U 盘，并将启动方式切换为从 NAND 启动。
+
WARNING: 启用 NAND 设备，并将启动方式设为从 NAND 启动。

=== jffs2 错误解决方法

烧录 eMMC 后，如果切换为从 eMMC 启动时串口持续输出 jffs2 错误，可使用以下方法解决。

. 首先切换回 NAND 启动，执行以下命令向 eMMC 写入零数据。
+
```sh
dd if=/dev/zero of=/dev/mmcblk0
```
. 然后按照 link:/zh/BPI-R3_Mini/GettingStarted_BPI-R3_Mini#_将镜像烧录到板载_emmc[文档]重新烧录 eMMC。

. 可以在系统的 /etc/config/wireless 文件中修改 WiFi 配置。

        option type 'mac80211'
        option path 'platform/18000000.wbsys'
        option channel '1'
        option band '2g'
        option htmode 'HE20'
        option cell_density '0'

config wifi-iface 'default_radio0'
        option device 'radio0'
        option network 'lan'
        option mode 'ap'
        option encryption 'none'

== 进阶开发
=== GPIO 控制
```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
查看 GPIO 基准编号，本例中为 411



例如，如果要将 GPIO 22 配置为高电平输出，需要输入以下命令：
```sh
echo 433（22+411） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio433/direction
echo 1 > /sys/class/gpio/gpio433/value
```

=== 4G/5G 模块
BPI-R3mini 支持使用 **M.2 Key B USB 接口** 的蜂窝网络模块，包括 4G LTE EM05，以及 5G Quectel RM500U-CN/RG200U-CN 和 RM520N-GL/RM500Q-GL 系列。

2023-09-12 及以后发布的镜像默认支持 RM500U-CN 和 RM520N-GL，安装其中任一模块即可直接使用。

如果使用 EM05 或其他模块，通常需要修改驱动程序。

. 将 4G/5G 蜂窝模块安装到 CN4 插槽（M.2 Key B）
. 插入 NANOSIM 卡
. 在模块上安装天线
. 开机后会自动拨号

WARNING: 4G/5G 是否可用取决于当地运营商使用的频段。

=== BPI-R3mini 的 WiFi AP 模式
* ra0 是 MT7986A 的 2.4 GHz WiFi 接口
* rax0 是 MT7986A 的 5 GHz WiFi 接口

=== 串口线
由于调试接口的 UART0_TXD 同时也是 WiFi 启动配置引脚，上电时需要将该引脚拉低。

部分串口线（如 PL2303）带有较强的上拉。如果在上电前插入，可能导致 WiFi 芯片识别错误，使 WiFi 功能失效。

CP2102、CH340、FTDI 等其他型号均可使用；串口线必须符合 3.3 V TTL 电平标准。

可在此处购买串口线：https://www.aliexpress.us/item/3256805457599756.html

image::/picture/r3mini-usbc2uart.png[r3mini-usbc2uart.png]

如果电脑配有 USB Type-C 接口并支持 PD 12 V/1.5 A（20 W）或更高功率，也可以直接用电脑为 BPI-R3mini 供电。

此外，BPI-R3mini 内置 CH340E USB 转串口芯片，无需额外的串口线。

WARNING: 如果电脑不支持 USB PD，R3mini 很可能会反复重启。

这是因为 R3mini 功耗较高；连接所有外设时，运行功耗接近 20 W。
