= 简介

Hello World 是最著名的程序之一。对于每个程序员来说，这个程序是几乎所有编程语言中的第一个示例程序。事实上，它所做的只是告诉计算机说 Hello World。传统上，这个程序一直被程序员用来测试新的系统或编程语言。对于程序员来说，在计算机屏幕上看到这两个词通常表明他们的代码已经准备好编译、加载和运行，而这个输出就是为了证明这一点，所以以此为例。

= 运行程序通过 main.py
创建一个新的 main.py 文件并写入以下内容。
```sh
print('Hello, World!')
```
如果要使用MpfShell执行该文件，请将其放在与MpfShell相同的目录中。

image::/bpi-bit/main.png[main.png]

然后切换到MpfShell的程序区，输入runfile main.py，或射频 main.py，运行文件 rf 的缩写。

image::/bpi-bit/main_result.png[main_result.png]

可以看到有hello world的回显，说明程序运行成功。

有用的提示：最新的 mpfshell 指令有一个 lexecfile，如果您需要与之交互，可以使用它 python 输入，因为runfile只能接收board输出而不能接收输入。
