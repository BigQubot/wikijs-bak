以MG90S舵机为例。对于其他舵机，请参阅他们的
对应的用户手册并修改相应的参数
下面的代码。

[arabic]
. MG90S伺服关键参数：
* 控制角，0°~ 180°
* PWM 工作时间控制，500us ~ 2500us对应0° ~ 180°
* 工作电压：4.8V至6V (5V典型值)
* 堵转扭矩：1.8 kg/cm (4.8V)
* 最大堵转扭矩：2.2 kg/cm (6V)
* 运行速度为0.1s/60° (4.8V)
. 找到任意旋转角度所需的工作时间表达式
是：
+
```
Let y be the duty time and x be the rotation angle
y=(2500-500)/180*x+500
y=(100*x+4500)/9
```

. 根据参数可以确定角度
舵机由高电平持续时间控制
PWM 波。并且由于必须控制舵机的控制
通过周期性的 PWM 波形，一个周期的持续时间必须超过
控制舵机达到180°所需的工作时间，即
如果超过2500us， PWM 频率应低于400hz。
. 设置 PWM 频率为200hz，则周期持续时间为5000us，并且
控制舵机从0°开始旋转对应的占空比
至 180° 为 10% 至 50%。
. 的 PWM 占空比控制精度 CircuitPython 是16位，100%
占空比用二进制表示为 1111 1111 1111 1111，FFFF 为
十六进制和十进制 65535。
. 用于查找任何旋转所需的占空比的表达式
角度为：
+
```
Let y be the duty cycle and x the rotation angle
y=((50-10)/180*x+10)/100*65535
y=(4369*x+196605)/30
```
. 伺服的接线方法及 BPI-PicoW-S3: 
+
> VBUS 引脚
BPI-PicoW-S3 可以输出 +5V；除 GP0 外，所有 GP 引脚均可用于
输出 PWM，只需修改程序中对应的引脚即可。
+
[cols=",",options="header",]
|===
|MG90S |BPI-PicoW-S3
|GND 棕色 |接地
|+5V红 |总线总线
|PWM 橙色 |GP0
|===

. 根据上面的表达式和参数，设计一个程序
可以任意控制这个舵机的旋转角度： 
+
```py
import board
import pwmio
import time
servo_1 = pwmio.PWMOut(board.GP0, frequency=200, duty_cycle=0)#200hz, one cycle 5000us

def get_duty_cycle(x):
    return int((4369*x+196605)/30)

servo_1.duty_cycle = get_duty_cycle(90)# 90 degrees
```

. 使用列表来设计一组连续的伺服动作：
+
```py
import board
import pwmio
import time
servo_1 = pwmio.PWMOut(board.GP0, frequency=200, duty_cycle=0)#200hz, one cycle 5000us

def get_duty_cycle(x):
    return int((4369*x+196605)/30) 

action_list1 = [0,45,90,135,180,0,180,45,135,90]

while True:
    for i in action_list1:
        servo_1.duty_cycle = get_duty_cycle(i)
        time.sleep(0.5)
```
