= 简介

Banana Pi M1+ 板载 WiFi 802.11g/b/n。得益于板载 WiFi 芯片，该开发板既支持经典项目，也能拓展更多应用。与其他 Banana Pi 产品一样，它可运行 Android、Lubuntu、Ubuntu、Debian 和 Raspbian 等操作系统。

Banana Pi M1+ 是 M1 的升级版。板载 WiFi 为开发板增加了更多功能，也让用户能更方便地搭建 Linux 桌面或路由器项目。

TIP: 更多信息：link:/zh/BPI-M1_Plus/BananaPi_BPI-M1_Plus[Banana Pi BPI-M1_Plus]

== 规格参数

- 双核 1.0 GHz CPU
- 1 GB DDR3 内存
- Mali-400 MP2，支持 OpenGL ES 2.0/1.1
- 板载 WiFi

== 高级开发
=== SATA
. 在 M1P 上挂载 SATA 设备

- 接入 SATA 设备后，执行：
+
```sh
fdisk -l
```
- 然后 
+
```sh
mount /dev/sdx /mnt/xxx
```
+
image::/picture/m1p_sata.png[m1p_sata.png]

. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：

- 创建新分区
+
```sh
fdisk /dev/sdx
```
设置分区数量和大小。创建分区后，输入“**wq**”保存并退出。
- 格式化 SATA 设备
+
```sh
mkfs.ext2 /dev/sdx
```
- 执行
+
```sh
mount /dev/sdx /mnt/xxx
```

. 成功接入 SATA 设备后，可使用以下命令测试 SATA 接口：

- 测试读取速度
+
```SH
time dd if=/dev/xxx of=/dev/null bs=1M count=1000 
```
- 测试写入速度
+
```SH
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+

=== A20 CAN 总线
要将 can4linux 移植到 Banana Pi，需要参考 A20 硬件手册中的 CAN 模块说明。can4linux 是基于字符设备驱动的 Linux 驱动，已用于桌面 PC 和多种嵌入式平台，例如 Freescale FlexCAN（i.MX 系列微控制器）和 Xilinx Zynq。

A20 CAN 的详细文档：https://dl.linux-sunxi.org/A20/CAN%20Bus1.pdf

以下教程介绍如何在运行 Bananian 15-01 的 Banana Pi 上使用 CAN 总线。

感谢 selqcir 分享此示例：

- 下载“bananian-1501.img”并将其安装到 8 GB SD 卡。
- 使用“bananian-config”扩展根文件系统
- 安装缺少的软件包：
+
```sh
apt-get install git
apt-get update
apt-get upgrade
reboot
```
- 获取最新可用的 Bananian，并继续安装缺少的软件包：
+
```sh
git clone https://github.com/Bananian/linux-bananapi
apt-get install build-essential u-boot-tools uboot-mkimage 
apt-get install libusb-1.0-0 libusb-1.0-0-dev git wget fakeroot kernel-package zlib1g-dev libncurses5-dev
apt-get install subversion
```
- 构建内核：
+
```sh
cd linux-bananapi
make menuconfig
```
- 菜单出现时，不保存并退出。
+
```sh
zcat /proc/config.gz > /root/linux-bananapi/.config
make uImage modules
make INSTALL_MOD_PATH=output modules_install
```
- 此步骤完成后，内核应已编译，且“Module.symvers”文件可用。
- 然后重命名 Bananian 提供的模块和固件，并替换为新版本。
+
```sh
mv /lib/modules /lib/modules.old
mv /lib/firmware /lib/firmware.old
mv /root/linux-bananapi/output/lib/modules /lib/modules
mv /root/linux-bananapi/output/lib/firmware /lib/firmware
```
- 对 uImage 执行同样操作：
+
```sh
mount /dev/mmcblk0p1 /mnt
cd /mnt
mv uImage uImage.old
mv /root/linux-bananapi/arch/arm/boot/uImage /mnt
reboot
```
- 创建供后续构建使用的链接：
+
```sh
cd /lib/modules/3.4.104/
ln -s /root/linux-bananapi build
cd ~
```
- 获取 Can4Linux 并构建它：
+
```sh
svn checkout https://svn.code.sf.net/p/can4linux/code/trunk can4linux-code
cd /root/can4linux-code/can4linux/
make TARGET=BANANAPI
```
- 配置开发板每次启动时自动加载模块：
+
```sh
insmod can4linux.ko
cp can4linux.ko /lib/modules/3.4.104/kernel/net/can/
depmod -A -v
modprobe -v can4linux
echo "" >> /etc/modules ; echo "can4linux" >> /etc/modules
reboot
```
- 构建 CAN 示例
+
```sh
apt-get install swig
apt-get install python-dev
cd can4linux-code/can4linux-examples/
```
- 在“pyCan-example.py”文件中更新 CAN 速率和设备。
+
```sh
# setting the device number
device = 0
defaultBaudrate = '250'
```
- 连接 CAN 收发器与 CAN 总线，并使用以下示例进行检查：
+
```sh
python pyCan-example.py
```

操作完成。

使用此方法时，内核版本为“Linux bananapi 3.4.104”，而不是“Linux bananapi 3.4.104+”。这是因为未能找到与 Bananian 15-01 完全相同的源代码，但 CAN 总线可以正常工作。
