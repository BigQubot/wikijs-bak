= 简介

Banana Pi BPI-M64 是一款 64 位四核迷你单板计算机，配备 2 GB 内存和 8 GB eMMC，并集成 WiFi 与蓝牙。接口包括两个 USB 2.0 Type-A、一个 USB OTG、一个 HDMI、一个音频插孔和一个直流电源接口。其处理器与 R18 引脚兼容，因此产品分为 M64 和 M64-R18 两个版本。

TIP: 更多信息：link:/en/BPI-M64/BananaPi_BPI-M64[Banana Pi BPI-M64]

== 规格参数

**A64**

- 1.2 GHz 四核 64 位 ARM Cortex-A53 处理器（A64）
- 2 GB DDR3 SDRAM
- 8 GB eMMC
- 10/100/1000 Mbps 以太网
- WiFi（AP6212）及蓝牙

**R18**

- 1.2 GHz 四核 64 位 ARM Cortex-A53 处理器（R18）
- 2 GB DDR3 SDRAM
- 8 GB eMMC
- 10/100/1000 Mbps 以太网
- WiFi（AP6212）及蓝牙

= 开发

== Android
=== 准备

. 准备一根 USB 转串口线、一根 Micro-USB 线，以及一台运行 Linux 或 Windows 7/10 的电脑。
. USB 转串口线用于控制台调试，Micro-USB 线用于下载镜像和 ADB 调试。
. M64 开发板只能通过直流电源启动。
. 如果要将 SD 卡用作 Android 存储，而该卡曾烧录过 Linux 镜像或其他 Allwinner 可启动镜像，请从第 0 个块开始格式化 SD 卡。
. 下载并安装 Allwinner 镜像下载工具：Windows 使用 PhoenixSuit，Linux 使用 LiveSuit。

== Linux
=== 准备

. 准备一张至少 8 GB 的 TF 卡、一个 USB 转串口适配器，以及一台运行 Ubuntu 的电脑。
. 使用 USB 转串口适配器连接 M64 的调试控制台。
. M64 开发板只能通过直流电源启动。
. 在 Linux 电脑上安装 bpi-tools。如果无法访问该网址或遇到其他问题，请前往 bpi-tools 仓库手动安装该工具。
+
```sh
  $ apt-get install pv
  $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 BPI 镜像。
. 登录用户名/密码：pi/bananapi 或 root/bananapi

=== 将镜像烧录到 SD 卡
**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**可以选择以下两种方法。**

. 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m64-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 使用 Linux 上的 bpi-tools 烧录镜像。将 SD 卡插入 Linux 电脑并执行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m64-xxx.img.zip /dev/sdX
```

=== 将镜像烧录到 eMMC
. 准备一张已烧录 Linux 镜像的 SD 卡，并用该卡启动开发板。
. 解压镜像并复制到 U 盘，将 U 盘插入开发板并挂载。（如果已自动挂载，可跳过此步）
+
```sh
mount /dev/sdx /mnt
```
. 可通过以下两种方式将 Linux 镜像安装到开发板。
- 使用 dd 命令烧录。
+
```sh
sudo dd if=/mnt/xxx.bpi-p2_zero-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 使用 bpi-tools 命令烧录 U 盘中的 Linux 镜像
+
```sh
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/mmcblk0
```
. 烧录完成后，安全关机并取出 SD 卡。

=== 切换为 LCD 启动模式
. 默认发布镜像使用 HDMI 启动模式。首次启动后，可以切换为 LCD 启动模式，以支持 BPI 7 英寸 LCD。
+
```sh
 $ sudo bpi-bootsel /usr/lib/u-boot/bananapi/bpi-m64/BPI-M64-LCD7-linux4.4-8k.img.gz
 $ reboot
```
. 如需使用触摸面板（TP），请加载触摸屏驱动程序
+
```sh
 $ sudo modprobe gt9xxnew_ts.ko
```

=== GPIO 控制
. 要访问 GPIO 引脚，首先需要使用以下命令将其导出
+
```sh
 echo XX > /sys/class/gpio/export
```

. XX 是目标引脚的编号。要得到正确编号，需要根据引脚名称（如 PH18）进行计算。
+
NOTE: （字母在字母表中的序号 - 1）× 32 + 引脚号。+
以 PH18 为例：（8 - 1）× 32 + 18 = 224 + 18 = 242，因为 h 是第 8 个字母。
+
```sh
echo "out/in" > /sys/class/gpio/gpio*NUMBER*/direction
echo "0/1" > /sys/class/gpio/gpio*NUMBER*/value
```
