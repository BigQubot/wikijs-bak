= 简介

Banana Pi BPI-R3 路由器开发板采用 MediaTek MT7986（Filogic 830）四核 ARM Cortex-A53 芯片，板载 2 GB DDR 内存和 8 GB eMMC。它是一款高性能开源路由器开发板，支持 Wi-Fi 6：2.4 GHz WiFi 使用 MT7975N，5 GHz WiFi 使用 MT7975P；同时提供两个 2.5GbE 网络端口。

=== MediaTek MT7986(Filogic 830)
MT7986（Filogic 830）集成四个最高 2 GHz 的 Arm Cortex-A53 内核，处理能力最高可达 18,000 DMIPS，并支持总速率达 6 Gbps 的双频 4×4 Wi-Fi 6 连接。它提供两个 2.5G 以太网接口和串行外设接口（SPI）。Filogic 830 内置的硬件加速引擎可实现快速、可靠的 Wi-Fi 卸载和无线网络连接。此外，该芯片还支持 MediaTek FastPath™ 技术，适用于游戏、AR/VR 等低延迟应用。

与上一代技术相比，Wi-Fi 6 具有更低的延迟、更大的带宽容量和更快的传输速率。支持 6 GHz 频段的无线设备主要利用 160 MHz 宽信道和较少拥塞的 6 GHz 频谱，提供多千兆传输及低延迟 Wi-Fi 连接，为流媒体、游戏、AR/VR 等应用提供可靠的无线网络。

TIP: 更多信息：link:/en/BPI-R3/BananaPi_BPI-R3[Banana Pi BPI-R3]

== 规格参数

- MediaTek MT7986（Filogic 830）四核 ARM Cortex-A53
- WiFi 6 2.4G/5G（MT7976C）
- 2 GB DDR 内存
- 8 GB eMMC 闪存
- 128 MB NAND 闪存
- 2 个 2.5GbE 网络端口
- 1 个 M.2 Key B USB 接口
- 1 个 M.2 Key M PCIe 接口
- 1 个 USB 2.0 接口

== 将镜像烧录到 SD 卡
NOTE: **请对 SD 卡进行低级格式化并清除其中的所有数据，这一点非常重要。
否则，在启动过程中会遇到“jffs2”错误。**

**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

- 单击“**Flash from file**”选择镜像。 
- 单击“**Select target**”选择目标设备。 
- 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]
 
**Linux 电脑**

. 安装 bpi-tools。如果无法访问该网址或遇到其他问题，请前往 bpi-tools 仓库手动安装该工具。
+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
``` 
. 下载镜像后，将 TF 卡插入 Ubuntu 电脑。+
执行 
+
```sh
bpi-copy xxx.img /dev/sdx
```
以便将镜像烧录到 TF 卡。
 
. 将 TF 卡插入 R3，把跳线切换到正确的启动位置，然后上电启动 R3。

TIP: 将启动跳线切换为从 SD 卡启动，并启用 SD 卡设备。

== 将镜像烧录到 NAND

以 OpenWrt 镜像（mtk-bpi-r3-SD-WAN1-SFP1-20220619-single-image.img、mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin）为例，操作步骤如下：

. 插入已烧录镜像的 SD 卡，上电启动开发板。（SD 卡上的镜像“**mtk-bpi-r3-SD-WAN1-SFP1-20220619-single-image.img**”可以是 OpenWrt，也可以是 Ubuntu 等其他 Linux 系统。）
. 将可从 NAND 启动的 OpenWrt 镜像（**mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin**）复制到 U 盘。如果镜像已压缩，请先解压再复制到 U 盘。
. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）
+
```sh
mount -t vfat /dev/sda1 /mnt 
```
切换到挂载点，本例为：
+
```sh
cd /mnt
```
. 执行以下命令，启用 NAND 并将镜像写入 NAND 闪存：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin of=/dev/mtdblock0
```
. 取出 SD 卡，将启动开关切换为从 NAND 启动，然后重新启动开发板。
+
TIP: 启用 NAND 设备，并将启动方式设为从 NAND 启动。
+
image::/picture/bpi-r3-jumper-flash-nand.png[bpi-r3-jumper-flash-nand.png]

== 将镜像烧录到 eMMC
WARNING: SD 卡和 eMMC 设备共用同一个 SoC 接口。

NOTE: 将启动开关切换到 NAND，然后启动 BPI-R3。

. 将存有 **bl2_emmc.img** 和 **mtk-bpi-r3-EMMC-xxx.img** 的 U 盘插入 BPI-R3。
. 将 U 盘挂载到 /mnt，然后执行以下命令把镜像烧录到 eMMC：
+
```sh
mount -t vfat /dev/sda1 /mnt
cd /mnt
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r3-EMMC-WAN1-SFP1-20220619-single-image.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
```
. 关闭 R3 开发板电源，拔出 U 盘，并将启动方式切换为从 eMMC 设备启动。
+
TIP: 启用 eMMC 设备，并将启动方式设为从 eMMC 启动。
+
image::/picture/bpi-r3-jumper-boot-emmc.png[bpi-r3-jumper-boot-emmc.png]



. 执行以下命令，启用 NOR 并将镜像写入 NOR 闪存：


**GPIO 控制**

```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
查看 GPIO 基准编号，本例中为 411

image::/picture/bpi-r3-gpio-base.jpg[bpi-r3-gpio-base.jpg]

例如，如果要将 GPIO 22 配置为高电平输出，需要输入以下命令：
```sh
echo 433（22+411） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio433/direction
echo 1 > /sys/class/gpio/gpio433/value
```

== PWM 风扇控制
```sh
echo 0 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 5000 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm0/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
```

== 4G&5G

BPI-R3 支持 4G LTE EC25。

如需在 BPI-R3 上使用 5G：

. 将 5G 上网卡插入 USB 3.0 接口。
. 将 RG200U-CN 连接到 Mini PCIe 插槽，通过 USB 2.0 与 SoC 通信（速率受限）。
. 制作 RG200U-CN LGA 转接板，并将其插入 M.2 Key M 插槽。

WARNING: 4G/5G 是否可用取决于当地运营商使用的频段。

== BPI-R3 的 AP 模式

ra0 是 MT7986A 的 2.4 GHz WiFi 接口

rax0 是 MT7986A 的 5 GHz WiFi 接口

=== WiFi 与串口线

如果串口线采用 PL2303 芯片，驱动程序可能无法加载固件，进而导致 WiFi 无法工作。

CP2102、CH340、FTDI 等其他型号均可使用；串口线必须符合 3.3 V LVTTL 电平标准。

UART_TX0 是启动配置引脚，上电期间必须保持低电平。
