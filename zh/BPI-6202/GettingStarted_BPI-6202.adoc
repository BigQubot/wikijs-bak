BPI-6202 是一款通用嵌入式控制器软硬件开发平台，为应用开发者提供功能完整的硬件方案，并支持 BSP + Docker 开发环境和强大的边缘计算能力。开发者可利用该平台快速完成开发和产品化。

TIP: link:/zh/BPI-6202/BananaPi_BPI-6202[Banana Pi BPI-6202 嵌入式单板工业计算机]

= 开发

== 准备
. 一张容量至少为 8 GB 的 TF 卡
. 读卡器
. 3.3 V TTL 串口线，波特率：115200
. 24 V 电源

== 将镜像写入 TF 卡
可根据电脑操作系统选择方法 1 或方法 2。

**方法一**：（Windows 主机环境）

. 使用 Balena Etcher 写入镜像。 +
link:https://balena.io/etcher[Balena Etcher] 是 Balena 开发的开源 GUI 烧录工具，可将操作系统镜像写入 SD 卡或 U 盘。
+
- 单击 “**Flash from file（从文件烧录）**”选择镜像。

- 单击 “**Select target（选择目标）**”选择 USB 设备。

- 单击 “**Flash!（烧录）**”开始写入。
+
image::/picture/etcher.jpg[etcher.jpg]

**方法二**：（x86/64 Linux 主机环境）

. 在 x86/64 Linux 主机中插入 TF 卡。假设 TF 卡对应的块设备为 /dev/sdz，cs6202-xxx.img 文件的完整路径为 /home/foobar/cs6202-xxx.img，执行以下命令制作 TF 卡。
+
```sh
sudo dd if=/home/foobar/ cs6202-xxx.img of=/dev/sdz bs=16M status=progress
sync && sleep 2 && sync && sudo udisksctl power-off -b /dev/sdz
```
. 如果 TF 卡上已有有效的文件系统分区，插入后可能会自动挂载；运行上述命令前，请使用 umount 卸载 /dev/sdzN 分区。

== 将镜像安装到 eMMC
NOTE: 请根据所使用的镜像选择对应方法。

=== cs6202-starter-install-tfcard.img
. 将 TF 卡插入 CS6202，然后接通电源启动。
. 如果启动正常，上电后 5 秒内 RUN 指示灯会常亮。
+
image::/picture/cs6202-starter-install-tfcard_1.jpg[cs6202-starter-install-tfcard_1.jpg]
. 当 RUN 指示灯由常亮变为心跳闪烁时，TF 卡中的 eMMC 镜像正在写入板载 eMMC。此时 Fn 指示灯会由熄灭变为常亮。
+
image::/picture/cs6202-starter-install-tfcard_2.jpg[cs6202-starter-install-tfcard_2.jpg]
. 等待约 6～8 分钟。烧录成功后，Fn 指示灯会呈心跳式闪烁（与 RUN 指示灯类似）。
+
**LED 灯：**
+
image::/picture/cs6202-starter-install-tfcard_3.jpg[cs6202-starter-install-tfcard_3.jpg]
+
**显示屏幕：**
+
image::/picture/cs6202-starter-install-tfcard.jpg[cs6202-starter-install-tfcard.jpg]
. 烧录过程中，如果 Fn 指示灯由常亮变为熄灭，表示烧录失败。可能有两个原因：TF 卡中的 eMMC 镜像校验失败，或写入 eMMC 时发生错误。
. 完成步骤 4（即烧录成功）后，关闭电源并取出 TF 卡，否则会再次开始安装。重新上电后，CS6202 将从 eMMC 启动。

=== cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img
. 将 TF 卡插入 CS6202，然后接通电源启动。
. CS6202 启动后，可通过以下两种方法将 cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz 烧录到 eMMC。
+
**方法一**：使用 U 盘

a. 将 cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz 文件复制到 U 盘，然后把 U 盘插入 CS6202。
b. 通常 CS6202 会自动挂载 U 盘。如果未自动挂载，也可以使用 mount 命令手动挂载。
+
```sh
mount /dev/sda1 /mnt/media/foobar
```
c. 假设 U 盘中 cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz 文件的完整路径为 **/mnt/media/foobar/ cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz**。
d. 在 CS6202 中运行以下命令，将镜像烧录到 eMMC。
+
```sh
gunzip -c /mnt/media/foobar/cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz | sudo dd of=/dev/mmcblk1 bs=16M status=progress
sync && sleep 2 && sync
```

+
**方法二**：使用网络
a. 将镜像文件复制到 Web 发布目录。
b. 假设完整 URL 为：“http://a.b.c/pub/ cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz”。
c. 在 CS6202 中运行以下命令，将镜像烧录到 eMMC。
+
```sh
curl -fsSL "http://a.b.c/pub/cs6202-ubuntu-mate-20.04.1-desktop-armhf-docker-sd-emmc.img.gz" | gunzip -c | sudo dd of=/dev/mmcblk1 bs=16M status=progress
sync && sleep 2 && sync
```
. 按上述步骤完成 eMMC 烧录后，拔出 TF 卡并重新上电，CS6202 将从 eMMC 启动。
