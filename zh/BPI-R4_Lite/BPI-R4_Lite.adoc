= 简介

香蕉派 BPI-R4 Lite 路由器板带有 MediaTek MT7987A 四核 Arm Cortex-A53 设计,2GB DDR4,8GB eMMC 闪存，256MB SPI-NAND 闪存，32MB SPI-板载NOR Flash和Micro SD卡插槽，还有1x 2.5G SFP, 1x 2.5G RJ45 WAN,4x 1G RJ45 LAN,带 USB3.0 端口,1x M.2 KEY-B 插槽，带 USB3.0 用于 5G 模块。1x miniPCIe 插槽，带 PCIe3.0 2lane 接口，用于 Wi-Fi 7 NIC (选项：2x miniPCIe 插槽，带 PCIe3.0 1lane),1x miniPCIe 插槽，带 USB2.0 接口It 和 1x USB TypeC 调试控制台。它是一款非常高性能的开源路由器开发板。

== 如何将镜像烧录到板载NOR
> 当您想要更新Nor设备时，首先将启动开关更改为从SD设备启动，然后插入一张带有SD启动映像的SD，然后启动后，您需要将一张Nor映像闪存到Nor设备中。最后，将引导程序更改为从 Nor 设备引导。
{.is-info}

在将镜像刻录到之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r4lite-NOR.img ) 例如，步骤如下：

1. 复制 Nand 启动 OpenWrt 镜像(**mtk-bpi-r4lite-NOR.img**) 到 USB 磁盘。 
2. 更改启动开关跳线，板子从SD设备启动，然后给板子上电。
3. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
4. 执行以下命令擦除整个 Nor 闪存并将映像复制到 Nor 设备：

+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r4lite-NOR.img of=/dev/mtdblock0
```
5. 关闭电源 BPI-R4_Lite 板子，拔掉U盘驱动，修改bootstrap为启动 Nand 设备。

== 如何将镜像刻录到板上 Nand
> **NAND 有在工厂刻录的镜像。如果要使用，只需切换到相应的启动，然后上电即可启动。**
{.is-info}


>  当你想更新的时候 Nand 设备，首先将启动开关更改为从 SD 设备启动，并插入一张带有 SD boot Image 的 SD，然后启动后，您需要 flash 一张 Nand 镜像进入 Nand 设备。最后你将 bootstrap 更改为 boot from Nand 设备。
{.is-info}


在将镜像刻录到之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r4lite-NAND-2PCIe-1L.img) 例如，步骤如下：

1. 复制 Nand 启动 OpenWrt 镜像(**mtk-bpi-r4lite-NAND-2PCIe-1L.img**) 到 USB 磁盘。 
2. 更改启动开关跳线，板子从SD设备启动，然后给板子上电。
3. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```
4. 执行以下命令即可全部擦除 Nand 闪存并将镜像复制到 nand 设备：

+
```sh
mtd erase /dev/mtd0
mtd write mtk-bpi-r4lite-NAND-2PCIe-1L.img /dev/mtd0
```
5. 关闭电源 BPI-R4_Lite 板子，拔掉U盘驱动，修改bootstrap为启动 Nand 设备。


== 如何将镜像刻录到板上 eMMC
> 因为SD卡和 EMMC 设备共享一个SOC的控制器，需要切换到 NAND 启动然后刻录 EMMC 镜像进入 EMMC。最后，您将更改启动方式 EMMC.
{.is-info}


将镜像刻录到之前 eMMC，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (bl2_emmc.img, mtk-bpi-r4lite-EMMC-NAND.img) 例如，步骤如下：

1. 复制 EMMC 启动 OpenWrt 镜像(**bl2_emmc-r4.img**,**mtk-bpi-r4-EMMC-20231030.img**) 到 USB 磁盘，如果镜像被压缩，请在复制到之前解压 USB 磁盘。

2. 将开关跳线更改为 Nand 并从主板启动 Nand.
 
3. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)

+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```

4. 执行：

+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4lite-EMMC-NAND.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
sync
sync
```
 
5. 关闭R4电源_Lite板，删除u盘驱动，更改bootstrap从 emmc 设备。

== Wi-Fi7网卡
您可以插入 BPI-R4-NIC 底部分为 CN12 和 CN14 BPI-R4-Main，然后用两颗M2螺丝固定。

的 BPI-R4-NIC 模块需要12V供电，所以电源上 BPI-R4-Main 上电前必须先开机 (将SW4拨至“ON”位置，12V LED 通电时会亮起)

IMPORTANT:  12V电源将提供给 BPI-R4-NIC 通过PIN6/28/48 miniPCI 插槽。 
插接其他模块时，如果无法确认模块是否能承受12V，请务必关闭SW4。

当所有功能正常后，我们可以检测到三个SSID，BE14上的三个蓝色LED灯也会亮起。
     
==== 如何开启WiFi热点

打开web并在config中配置相应的STA热点。
然后点击连接进行连接。
