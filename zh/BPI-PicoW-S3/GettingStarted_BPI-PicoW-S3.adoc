== 首次使用

使用一根同时支持供电和数据传输的 USB-C 线，将
BPI-PicoW-S3 开发板连接到计算机。

计算机的文件管理器中会重新出现一个 `CIRCUITPY` 磁盘。

> BPI-PicoW-S3 出厂时已预装 **tinyUF2** 和 **CircuitPython** 固件。CircuitPython 是对初学者非常友好的平台，建议使用它快速上手 BPI-PicoW-S3 开发板。
