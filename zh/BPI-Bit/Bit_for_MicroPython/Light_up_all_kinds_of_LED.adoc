= 点亮各种 LED

如果说 Hello World 是软件编程的起点，那么 Blink LED 就是硬件编程的起点：一切从点亮 LED 开始。

所以我们开始准备我们的硬件，我使用的是 beta 版本 1.3。它足以满足本章的目的，并且对于后续板来说是通用的。所以，我们讲究循序渐进，先一盏灯，再一排灯。

== 使用 main.py
将以下代码准备到 main.py 文件。与前一种不同，这种效果是连续的。它将使灯亮起并等待一秒钟然后熄灭。
```sh
from machine import Pin
import time
led = Pin(18, Pin.OUT) # get a led on gpio 18.
print('turn on')
led.value(1) # turn on
print('sleep 1s')
time.sleep(1) # sleep 1s
print('turn off')
led.value(0) # turn off
```

image::/bpi-bit/mian_light.png[mian_light.png]

如果效果不明显，可编写无限循环观察。按 Ctrl+C 停止，否则无法继续操作。
```sh
from machine import Pin
import time
led = Pin(18, Pin.OUT) # get a led on gpio 18.
while True:
   print('turn on')
   led.value(1) # turn on
   print('sleep 1s')
   time.sleep(1) # sleep 1s
   print('turn off')
   led.value(0) # turn off
   print('sleep 1s')
   time.sleep(1) # sleep 1s
```

== 学习灯板上的 LED 阵列（NeoPixel）
将以下代码写入 main.py（\HowToCode\ 01.leds \rgb_lattice.py）
```sh
from pixel import Pixel
View = Pixel()
RGB = (10, 10, 10)
View.LoadXY(2, 2, RGB)
View.Show()
```
