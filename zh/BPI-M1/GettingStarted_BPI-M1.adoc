= 简介

Banana Pi M1 是我们为建设开源开发板社区推出的首款产品。我们希望你通过 Banana Pi 探索和体验 DIY 项目与便携式计算的世界。欢迎企业、DIY 爱好者和技术爱好者加入社区；大家可以共同探索兴趣、启发他人，并构建实用项目。

TIP: 更多信息：link:/en/BPI-M1/BananaPi_BPI-M1[Banana Pi BPI-M1]

== 主要特性

- Allwinner A20 双核 1.0 GHz CPU
- Mali-400 MP2，支持 OpenGL ES 2.0/1.1
- 1 GB DDR3 内存。
- 1 个 SATA 接口。
- 1 个千兆以太网接口
- 1 个 USB OTG 和 2 个 USB 2.0 接口
- 1 个麦克风
- AV 视频输出
- HDMI 输出
- 红外
- CSI 摄像头接口
- DSI 显示接口
- 26 针 GPIO 排针

= 开发
== Armbian
=== 基本要求

需要一台 x86_64 或 aarch64 计算机，至少配备 2 GB 内存和约 35 GB 磁盘空间。原生构建可使用虚拟机、容器或裸机安装的 Ubuntu Jammy 22.04.x amd64/aarch64；容器化构建可使用任何支持 Docker 的 amd64/aarch64 Linux。

```bash
apt-get -y install git
 git clone https://github.com/armbian/build
 cd build
 ./compile.sh
```

=== 如何构建 M1 BSP 代码

```sh
准备一台运行 Ubuntu 的电脑
在电脑上安装 Docker CE：https://docs.docker.com/install/linux/docker-ce/ubuntu/#install-docker-ce
安装 Docker 后，执行 "docker pull sinovoip/bpi-build-android:a20_01" 拉取镜像
镜像拉取完成后，执行 "docker run --privileged -d -p 2223:22 -v /media:/media sinovoip/bpi-build-android:a20_01"
"ssh -p 2223 root@127.0.0.1 # 默认密码为 root"
在 Ubuntu 终端中执行 "git clone https://github.com/BPI-SINOVOIP/BPI-M1-bsp.git"
执行 "./build.sh" 构建 M1 BSP 代码
构建完成后打开新终端，执行 "docker cp xxxxx（容器 ID）:xxxxx（项目路径） xxxxx（电脑路径）"
```

== Linux
=== 为 M1 烧录 Linux 镜像

. 从论坛下载最新的镜像。
. 将 TF 卡插入读卡器，再把读卡器接入电脑的 USB 接口。
. 下载刷机工具“BalenaEtcher”并启动。
. 单击“Flash from file”以选择您的镜像文件。(.img 或 .zip)
. 单击 “Select target” 选择目标 USB 设备。
. 开始烧录并等待操作完成。

=== 为 M1 烧录第一个镜像

. 可以从论坛下载最新镜像。
. 在系统中安装 bpi-tools。如果无法访问该 URL 或遇到其他问题，请前往 bpi-tools 仓库手动安装。
+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载镜像后，将 TF 卡插入 Ubuntu 电脑。
+
```sh
执行 "bpi-copy xxx.img /dev/sdx" 将镜像写入 TF 卡。
```
. 完成步骤 3 后，将 TF 卡插入 M1，然后按下电源按钮启动 M1。

=== 更新镜像

. 更新 bpi-tools
+
```sh
bpi-tools
```
. 下载新驱动以更新镜像
+
```sh
bpi-update -c bpi-m1.conf
```
. 检查下载文件的类型是否为压缩数据
+
```sh
file *.tgz
```
. 执行
+
```SH
bpi-bootsel
```
您将看到引导加载程序路径，“/usr/lib/u-boot/bananapi/u-boot-2018.01/u-boot-2018.01-bpi-m1-8k.img.gz”
. 更新您的引导加载程序
+
```sh
bpi-bootsel /usr/lib/u-boot/bananapi/u-boot-2018.01/u-boot-2018.01-bpi-m1-8k.img.gz
```
. 重新启动
