= 简介

香蕉派 M5是新一代单板计算机设计、使用 Amlogic S905X3 四核 Cortex-A55 (2.0xxGHz) 处理器。马里-G31 MP2 GPU 带有 4 个执行引擎 (650兆赫)。支持4GB LPDDR4和16G eMMC 闪光。它有 4 个 USB 3.0 端口、1GbE LAN 端口、红外接收器、音频插孔、1 个 HDMI 输出和 USB C型电源。

香蕉派M2Pro同款 SOC 与M5，但电路板布局不同。 2GB LPDDR4 和 16G eMMC 闪光灯, 2 USB 3.0端口，1GbE LAN端口，rtl8821cu usb wifi/bt 板载、红外接收器、1 个 HDMI 输出、1 个 MicroUSB 端口、直流电源。

TIP: 更多信息： link:/en/BPI-M5/BananaPi_BPI-M5[香蕉派 BPI-M5] +
更多信息： link:/en/BPI-M2_Pro/BananaPi_BPI-M2_Pro[香蕉派 BPI-M2_Pro]

== 规格参数

- SoC – Amlogic S905X3 四核 Cortex-A55 处理器 @ 高达 2.0 GHz
马里-G31 MP2 GPU @650Mhz
- 系统内存 – 4GB LPDDR4
- 存储空间 – 16GB eMMC 闪光 (选项高达 64GB), MicroSD 插槽高达 2TB
- 视频输出 – HDMI 2.1 高达 4Kp60，带 HDR、CEC、EDID
- 音频 – 3.5 毫米音频插孔、数字 HDMI 音频
- 连接性 – 千兆位 Ethernet
- USB – 4x USB 通过 VL817 集线器控制器的 3.0 端口，1x USB-C端口 (只为了权力？)
- 扩展 – 40 针 Raspberry Pi 接头，具有 28x GPIO, UART, I2C, SPI, PWM，和功率信号 (+5V, +3.3V，接地).
- 调试 – 3 针调试接头
- 其他 – 重置、电源和 U-boot 按钮；功率和活动 LED的；红外接收器
- 电源 – 5V @3A 通过 USB Type-C接口
- 尺寸 – 92x60mm (与 Raspberry Pi PCB 尺寸不同，但测量时可能包含连接器)
- 重量 – 48克

= 开发
== 准备

. 准备一个 usb-串行电缆，一个 5V/3A 适配器 type-c 电源。串口线用于控制台调试，type-c线用于 android 镜像下载和ADB调试。 M2pro采用的是Micro-usb 端口用于 android 镜像下载和ADB调试。
. 准备一张至少8GB的SD卡 linux 开发, android 只支持 emmc 启动。
. 的 SOC ROM 第一启动媒体是 emmc，因此板无法从 SD 卡启动，如果 emmc 可以使用任何闪现的映像启动，更多信息请参阅板启动顺序。
. 在 Android SD卡是mmc0， emmc 是 mmc1，但在 Linux SD卡是mmc1， emmc 是mmc0。

> 使用 Balena Etcher 安装映像 Windows, Linux 和 MacOS.

link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

- 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

> 使用 Balena Cli 安装镜像 Windows, Linux 和 MacOS.

link:https://github.com/balena-io/balena-cli[巴莱纳 CLI] 是 balenaCloud 或 openBalena 的命令行界面。可以用来闪光 linux 镜像。从以下位置下载安装程序或独立包 link:https://github.com/balena-io/balena-cli/releases[巴莱纳-io] 和 link:https://github.com/balena-io/balena-cli/blob/master/INSTALL.md[安装 ]正确连接到您的 PC，然后您就可以使用“link:https://docs.balena.io/reference/balena-cli/#local-flash-image[本地闪存]" balena 的命令选项闪现 linux 镜像到 SD 卡或usb 开车。

```sh
 $ sudo balena local flash path/to/xxx-bpi-m5-xxx.img.zip
 $ sudo balena local flash path/to/xxx-bpi-m5-xxx.img.zip --drive /dev/disk2
 $ sudo balena local flash path/to/xxx-bpi-m5-xxx.img.zip --drive /dev/disk2 --yes
```

> 使用 dd 命令安装镜像 Linux

挂载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m5-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
> 安装镜像 bpi-tools 上 Linux

将 SD 卡插入 Linux 电脑并运行
```sh
 $ sudo apt-get install pv unzip
```

=== 开机 Linux 来自 USB 开车

S905x3 不支持 usb 启动 soc rom，所以启动的唯一方法 linux 来自 usb 驱动器是创建可启动的 SD 卡或 emmc 刷入 bootloader，然后加载 boot 和 rootfs usb 开车。启动后，一切都会从 usb 开车。

. 简单的方法是 link:/en/BPI-M5_M2_Pro/GettingStarted_BPI-M5_M2_Pro#_install_image_to_sdcard[闪光 M5/M2Pro Linux 镜像到 SD 卡或emmc] 可启动并将其闪存到 usb 用于加载 boot 和 rootfs 的驱动器。
. 启动 M5/M2pro 董事会与 link:/en/BPI-M5_M2_Pro/GettingStarted_BPI-M5_M2_Pro#_boot_sequence[SD 卡或 emmc], 复制 /boot/boot.ini 到 /boot/boot.ini.org 以便引导加载程序加载 boot.ini 失败，然后尝试从 usb 驱动器引导分区。
. 重新启动系统，bootscript 和 rootfs 将从中加载 usb 开车。
+

**Linux 无线AP模式**

. 准备正确设置 wifi 适配器。
. 获取 WiFi 适配器频段、频率、频道、HT 能力、VHT 能力或其他属性
+
```sh
$ iw list
```
. 使用 Netplan 和 Network-Manager 管理 wifi 接入点模式。
安装 NetworkManager，因为 ap 仅受 NetworkManager 渲染器支持
+
```sh
$ sudo apt install network-manager
```
示例 2.4G wifi ap 模式 netplan 配置文件， 01-wlan0-ap-2.4g.yaml
+
```sh
network:
version: 2
renderer: NetworkManager
wifis:
  wlan0:
    dhcp4: no
    access-points:
      "bananapi":
         mode: ap
         band: 2.4GHz
         channel: 6
         auth:
           key-management: psk
           password: "123456789"
```
5G wifi ap 模式 netplan 配置文件示例， 01-wlan0-ap-5g.yaml
+
```sh
network:
version: 2
renderer: NetworkManager
wifis:
  wlan0:
    dhcp4: no
    access-points:
      "bananapi":
         mode: ap
         band: 5GHz
         channel: 36
         auth:
           key-management: psk
           password: "123456789"
```
. 使用 Netplan 和 Hostapd 管理 wifi 接入点模式。
- 创建一个netplan配置文件， 01-wlan0-ap-hostapd.yaml
+
```sh
network:
version: 2
renderer: networkd
ethernets:
  wlan0:
    dhcp4: no
    addresses:
      - 192.168.11.1/24
```
- 安装hostapd
+
```sh
$ sudo apt install hostapd
```
创建hostapd配置文件 /etc/hostapd/hostapd.conf，例如
+
```sh
interface=wlan0
ssid=bananapi

driver=nl80211

auth_algs=1
wpa=2
wpa_passphrase=123456789
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP

#bridge=br0
beacon_int=500
#SSID not hidden
ignore_broadcast_ssid=0

hw_mode=a
channel=36
max_num_sta=8

### IEEE 802.11n
ieee80211n=1
#require_vht=0
ht_capab=[HT20][HT40+][SHORT-GI-20][SHORT-GI-40][SHORT-GI-80][DSSS_CCK-40]

### IEEE 802.11ac
ieee80211ac=1
#require_vht=0
#vht_capab=[MAX-MPDU-3895][SHORT-GI-80][SU-BEAMFORMEE]
#vht_oper_chwidth=1
#vht_oper_centr_freq_seg0_idx=42

### WMM
wmm_enabled=1
```
- 要支持 80MHz 通道宽度，您需要加载驱动程序 **实时_伏特_启用=2** 选项，或者您可以创建 /etc/modprobe.d/8822cs.conf 有内容
+
```sh
options 88x2cs rtw_vht_enable=2
```
- 安装并配置dhcp服务器服务，例如使用isc-dhcp-server
+
```sh
$ sudo apt install isc-dhcp-server
```
配置 dhcp 服务器接口 /etc/default/isc-dhcp-server
+
```sh
# On what interfaces should the DHCP server (dhcpd) serve DHCP requests?
#       Separate multiple interfaces with spaces, e.g. "eth0 eth1".
INTERFACESv4="wlan0"
```
配置 dhcp 子网和 dns /etc/dhcp/dhcpd.conf
+
```sh
...
option domain-name "example.org";
option domain-name-servers 8.8.8.8, 114.114.114.114;
...
# No service will be given on this subnet, but declaring it helps the 
# DHCP server to understand the network topology.
subnet 192.168.11.0 netmask 255.255.255.0 {
  range dynamic-bootp 192.168.11.1 192.168.11.100;
  option broadcast-address 192.168.11.255;
  option routers 192.168.11.1;
}
```
- 启动服务
+
```sh
$ sudo hostapd /etc/hostapd/hostapd.conf -B
$ sudo systemctl restart isc-dhcp-server
```
- 路由配置。
+
```sh
sysctl net.ipv4.ip_forward=1
iptables -t nat -A POSTROUTING -s 192.168.11.0/24 -o eth0 -j MASQUERADE
```

=== 禁用Cloud-init&Snap
Cloud-init 和 Snap 服务默认启用，您可以禁用或删除它们。

. 禁用或删除 cloud-init
+
```sh
 $ sudo touch /etc/cloud/cloud-init.disabled
```
或
+
```sh
 $ sudo apt purge cloud-init
```
. 禁用或删除快照
+
```sh
 $ sudo apt purge snapd
```

=== 启用 rc-local
systemd 服务 rc-local.service 已存在于发布映像中，但没有 [安装] 单元文件中的一部分。因此，Systemd 无法启用它。首先，我们必须更新文件。
```sh
 $ sudo nano /lib/systemd/system/rc-local.service
```
```sh
 [Unit]
 Description=/etc/rc.local Compatibility
 Documentation=man:systemd-rc-local-generator(8)
 ConditionFileIsExecutable=/etc/rc.local
 After=network.target
 
 [Service]
 Type=forking
 ExecStart=/etc/rc.local start
 TimeoutSec=0
 RemainAfterExit=yes
 GuessMainPID=no
 
 [Install]
 WantedBy=multi-user.target
 Alias=rc-local.service
```
创建 /etc/rc.local 文件。
```sh
 sudo nano /etc/rc.local
```
```sh
 #!/bin/sh
 #
 # rc.local
 #
 # This script is executed at the end of each multiuser runlevel.
 # Make sure that the script will "exit 0" on success or any other
 # value on error.
 #
 # In order to enable or disable this script just change the execution
 # bits.
 #
 # By default this script does nothing.
 
 exit 0
```
添加可执行权限 /etc/rc.local
```sh
 $ sudo chmod +x /etc/rc.local
```
启用 rc-local.service 并重新启动
```sh
 $ sudo systemctl enable rc-local.service
 $ sudo reboot
```

=== 启用 sudo Debian

发布 Debian image默认不安装sudo，使用“su -”命令，用户可以更改为root。如果你喜欢sudo，可以安装它。
```sh
 $ su root
 Password:(enter bananapi)
 
 # apt-get update
 # apt-get install sudo
 # adduser pi sudo
```
然后请注销并重新登录。

=== 安装 Docker发动机
安装 Docker 发动机开启 Ubuntu 20.04 服务器

. 设置存储库
更新 apt 软件包索引并安装软件包以允许 apt 通过 HTTPS 使用存储库：
+
```sh
 $ sudo apt-get update
 $ sudo apt-get install apt-transport-https ca-certificates curl gnupg lsb-release
```
添加 Docker官方GPG密钥：
+
```sh
 $ curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
```
设置稳定存储库
+
```sh
 $  echo \
    "deb [arch=arm64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu \
    $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```
. 安装 Docker发动机
+
```sh
 $ sudo apt-get update
 $ sudo apt-get install docker-ce docker-ce-cli containerd.io
```
. 验证 Docker 通过运行 hello-world 映像正确安装引擎。
+
```sh
 $ sudo docker run hello-world
```
