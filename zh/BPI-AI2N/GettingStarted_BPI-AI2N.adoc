= 简介

香蕉派 BPI-AI2N 模块系统 (索姆) 和 BPI-AI2N 载板是开源硬件解决方案，旨在利用 RZ/V2N 视觉AI MPU。支持8GB内存、32GB emmc, 双千兆 ethernet 端口，2 个 USB3 接口。

== 规格参数

- SoC – 瑞萨 RZ/V2N 四核 64 位 Arm Cortex-A55 处理器 @ 高达 1.8 GHz，配备 Mali-G31 GPU
- 系统内存 – 8GB LPDDR4
- 存储空间 – 32GB eMMC 闪存、MicroSD 插槽
- 视频输出 – MIPI DSI 至 hdmi 连接器，高达 1080p
- 连接性 – 双千兆位 Ethernet
- USB – 2x USB 3.0端口，1x USB-C端口
- 扩展 – 28x 40 针接头 GPIO, UART, I2C, SPI, PWM，和功率信号 (+5V, +3.3V，接地).
- 调试—— USB Type-C 调试头
- 电源 – 12V @3A 直流适配器

= 阿姆比安 Linux
== 准备

- Linux 镜像支持SD卡或 EMMC 启动。
- 建议使用A1级卡，至少16GB。
- 下载最新的 Linux 镜像，并确认校验和正确。
- 默认登录： pi/bananapi 或 root/bananapi

== 将映像安装到 SD 卡

- 使用 Balena Etcher 安装映像 Windows, Linux 和 MacOS.
+
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

1. 点击“**从文件闪存**”来选择镜像。 
2. 点击“**选择目标**”来选择 USB 设备。 
3. 点击“**快闪！**“开始燃烧。
+
image::/picture/etcher.jpg[etcher.jpg]

- 使用 Balena Cli 安装镜像 Windows, Linux 和 MacOS.
+
link:https://github.com/balena-io/balena-cli[巴莱纳 CLI] 是 balenaCloud 或 openBalena 的命令行界面。可以用来闪光 linux 镜像。从以下位置下载安装程序或独立包 link:https://github.com/balena-io/balena-cli/releases[巴莱纳-io] 和 link:https://github.com/balena-io/balena-cli/blob/master/INSTALL.md[安装 ]正确连接到您的 PC，然后您就可以使用“link:https://docs.balena.io/reference/balena-cli/#local-flash-image[本地闪存]" balena 的命令选项闪现 linux 镜像到 SD 卡或usb 开车。

```sh

$ sudo balena local flash xxx-bpi-ai2n-xxx.img.xz --drive /dev/sdX
```

+
link:https://imager.armbian.com[Armbian 成像仪] 是一个用于安装 Armbian OS 的开源映像工具。
+

- 使用 dd 命令安装镜像 Linux
+

+

== 安装镜像到 eMMC

1. 准备一张SD卡 Linux 镜像闪存和启动板与此 SD 卡。
2. 将目标镜像复制到udisk，将udisk插入主板并安装。
3. 将映像安装到 emmc.
- 使用dd命令写入，umount mmcblk0p1和mmcblk0p2分区（如果自动安装）。 
+
```sh
$ sudo apt-get install xz-utils pv
$ sudo sh -c 'xzcat xxx-bpi-ai2n-xxx.img.xz | pv | dd of=/dev/sdX bs=1M status=progress && sync'
```

- 另一种方法是将实时运行的 Armbian 系统从 SD 卡转移到内部存储设备，例如 eMMC。它准备目标存储、复制活动系统、调整引导加载程序设置，并确保系统可以独立引导而无需重新安装。
+
```sh
$ sudo armbian-config --cmd STO001
```

- 网络计划
+
桌面和 CLI 映像附带一个默认的 Netplan YAML 文件，位于 etc/netplan/00-default-use-network-manager.yaml. 这些图像默认使用 NetworkManager 后端。全部 Ethernet 接口已配置为 DHCP，并将自动从路由器获取 IP 地址。
+
```sh
# Added by Armbian
#
# Reference: https://netplan.readthedocs.io/en/stable/netplan-yaml/
#
# Let NetworkManager manage all devices on this system.
# Any device will come up with DHCP, once carrier is detected.
# This is basically Netplan passing control over to NetworkManager at boot time.

network:
  version: 2
  renderer: NetworkManager
```
如果在首次启动期间成功建立 Wi-Fi 连接，将在以下位置创建 Wi-Fi Netplan YAML 文件 /etc/netplan/30-wifis-dhcp.yaml. 如果首次启动时没有连接Wi-Fi，也可以在启动后手动创建该文件。
+
```sh
# Created by Armbian firstlogin script
network:
  wifis:
    wlan0:
      dhcp4: yes
      dhcp6: yes
      access-points:
        "NETWORK":
         password: "password"
```
+
更多Netplan配置信息，请参考 link:https://netplan.readthedocs.io/en/latest/using-static-ip-addresses[网络计划文档]

+
YAML 文件更改后，您应该应用配置
+
```sh
$ sudo chmod 600 /etc/netplan/xxx.yaml
$ sudo netplan apply
```

== RGB LED
该板有两个 RGB LED 供用户控制

- 黄色 LED 载板上，默认状态为heatbeat触发
+
```sh
$ sudo sh -c 'echo timer > /sys/class/leds/carrier-led/trigger'
```
- 蓝色 LED 在核心板上，默认状态为默认触发
+
```sh
$ sudo sh -c 'echo none > /sys/class/leds/core-led/trigger'
```

== 风扇

控制风扇的 on/off 通过 hwmon sysfs 接口获取状态。

- 启用风扇

```sh
$ sudo sh -c 'echo 1 > /sys/class/hwmon/hwmon3/fan1_target'
```

- 禁用风扇

```sh
$ sudo sh -c 'echo 0 > /sys/class/hwmon/hwmon3/fan1_target'
```

== ADC
有3个12位单元 adc 在 RZV2N 中，每个单元最多 8 个通道。董事会 adc CN3 排针连接到 adc1。

阅读 adc 来自 iio sysfs 的数据

```sh
$ cat /sys/bus/iio/devices/iio:device1/in_voltage0_raw
```

```sh
  GPIO.setmode(GPIO.BOARD)
  GPIO.setup(phyledpin, GPIO.OUT)

def blink_bcm():

    time.sleep(1)  
    GPIO.output(bcmledpin, GPIO.LOW)

def blink_board():
  while True:
    GPIO.output(phyledpin, GPIO.HIGH)

    time.sleep(1)  
    GPIO.output(phyledpin, GPIO.LOW)
    print("********set phy pin ", phyledpin, " Low********")
```

```sh
#!/usr/bin/env python

import wiringpi as wpi
```

```sh
WantedBy=multi-user.target
```

== 闪光灯 Spi 引导装载程序

的 SPI bootloader由三部分组成：Flash Writer文件、ATF固件和U-Boot。共有三个文件： Flash_作家*.mot, bl2_BP_spi.srec(bl2_bp_spi.bin)和 fip.srec(fip.bin)，可以在 /boot 的目录 Linux 镜像。

- 通过串行端口的闪存引导加载程序

1. 复制闪存_作家*.mot, bl2_BP_spi.srec 和 fip.srec 到您的 Windows 电脑。
2. 连接 Windows PC 到板通过 usb 开往 usb 类型 uart 端口波纹管核心板。
3. 将 Bootsel Switch 更改为 SCIF 下载模式。
+
image::/picture/ai2n-boot-scidownload.png[ai2n-boot-scidownload.png]

4. 开 Windows PC，打开终端模拟器。在这里，我们使用 link:https://github.com/TeraTermProject/teraterm/releases/tag/v4.108[太拉术语 4.108] 举个例子。
+
Note: 如果使用 Tera Term 5.x 版本，请在发送文件窗口中选择“以与 Tera Term 4 相同的方式发送”。
+
image::/picture/ai2n-spiflash-teraterm5.png[ai2n-spiflash-teraterm5.png]
5. 选择“文件”>“新建连接”，然后选择“串行”端口，如下所示。
+
image::/picture/ai2n-spiflash-serial1.png[ai2n-spiflash-serial1.png]
6. 从“设置”>“终端”打开配置窗口并按如下方式更改设置。
+
image::/picture/ai2n-spiflash-serial2.png[ai2n-spiflash-serial2.png]
7. 从“设置”>“串行端口”打开配置窗口，并按如下方式更改设置。

image::/picture/ai2n-spiflash-serial3.png[ai2n-spiflash-serial3.png]

```sh
  Please Input : H'
```

```sh
Writes to any of SPI address.
Program size & Qspi Save Address
```
