= 简介

“OpenWrt One/AP-24.XY”路由器开发板基于 MediaTek MT7981B（Filogic 820）SoC 和 MediaTek MT7976C 双频 Wi-Fi 6 芯片组，是 OpenWrt 开源社区推出的首款官方开发板。

OpenWrt One 基于 MediaTek Filogic 820 SoC，支持双频 Wi-Fi 6（3×3/2×2），提供 1 个 2.5 Gbit WAN 口和 1 个 1 Gbit LAN 口，配备 1GB DDR4 RAM、256 MiB NAND、16 MiB NOR、M.2 SSD 接口和 USB 2.0 接口。

OpenWrt One 采用 MediaTek MT7981B SoC，集成主频 1.3 GHz 的双核 Arm Cortex-A53、1GB DDR4 RAM 和 256 MiB SPI NAND 存储。另有 16 MiB 受保护存储用于系统备份，双存储设计可避免板载系统因刷写失败而无法恢复。M.2 2230/2242 NVMe PCIe 2.0 x1 插槽可扩展外部存储；开发板还提供实时时钟电池座、USB 2.0 Type-A 接口和 mikroBUS 扩展接口。

OpenWrt One 是 OpenWrt 开源社区设计的首款开发板，由 Banana Pi 参与协作并负责生产和销售。OpenWrt One/AP-24.XY 的销售可为项目提供收入，用于承担托管服务和 OpenWrt 大会等费用。Banana Pi 通过其分销网络销售开发板，并从每台设备的销售收入中向 Software Freedom Conservancy（SFC）捐款，款项专用于 OpenWrt 项目。

== 烧录镜像
NOTE: 出厂镜像版本：openwrt-24.10.0-rc2


TIP: link:https://firmware-selector.openwrt.org/?version=SNAPSHOT&target=mediatek%2Ffilogic&id=openwrt_one[也可以单击此处选择所需的 OpenWrt 版本]

. 准备一个 FAT32 格式的 USB 存储设备，并放入以下文件：
+
link:https://downloads.openwrt.org/snapshots//targets/mediatek/filogic/openwrt-mediatek-filogic-openwrt_one-snand-preloader.bin[openwrt-mediatek-filogic-openwrt_one-snand-preloader.bin]
+
link:https://downloads.openwrt.org/snapshots//targets/mediatek/filogic/openwrt-mediatek-filogic-openwrt_one-factory.ubi[openwrt-mediatek-filogic-openwrt_one-factory.ubi]

. 请关闭设备电源。

. 把包含上述两个文件的 USB 存储设备插入 Type-A 接口。

. 将启动介质开关设为 NOR。

. 按住正面的 USER 按键（位于 Type-A 接口一侧）。

. 连接电源并启动设备。

. 等待 LED 变绿。

. LED 变绿后松开 USER 按键，烧录过程即完成。

WARNING: 如果上述操作无效，请尝试更换已格式化的 USB 存储设备，并把文件重命名为：

openwrt-mediatek-filogic-openwrt_one-snand-preloader.bin

openwrt-mediatek-filogic-openwrt_one-factory.ubi
