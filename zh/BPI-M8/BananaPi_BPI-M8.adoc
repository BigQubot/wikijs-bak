= BPI-M8 简介

的 BPI-M8 基于高性能八核AI平台芯片A733构建，该芯片结合了双核Arm® Cortex®-A76和六核Arm Cortex-A55。它支持 Imagination PowerVR BXM-4-64 MC1 GPU, 3TOPS NPU、LPDDR4、LPDDR4x、LPDDR5 DRAM 和 UFS/eMMC 记忆。

的 BPI-M8 拥有丰富的外围设备，包括 USB、DP、UFS、HDMI、MIPI CSI、MIPI DSI、FAN、RTC 和 1 个千兆位 Ethernet 端口 (支持 PoE)。它还支持 SD 卡启动，并具有板载 KEIIOT K038 WiFi/Bluetooth 芯片。配备4GB LPDDR5 RAM, 32GB eMMC 存储和两个 12x12mm 单天线模块。

== 主要特性

* 双核 Arm Cortex-A76 + 六核 Arm Cortex-A55，高达 2.0GHz
* 想象PowerVR BXM-4-64 MC1
* 4GB LPDDR5 RAM
* 32GB eMMC 闪光
* 支持MIPI DSI显示接口
* 支持MIPI CSI相机接口
* 支持 PCIE/DP 接口
* 支持UFS模块
* HDMI输出
* 40针 GPIO 
* POE
