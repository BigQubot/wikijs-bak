= 安装 VS Code

Visual Studio Code 是轻量而强大的桌面源代码编辑器，支持 Windows、macOS 和 Linux。它内置 JavaScript、TypeScript 和 Node.js 支持，并提供丰富的扩展，可支持 C++、C#、Java、Python、PHP、Go 等语言以及 .NET、Unity 等运行环境。

下载 VS Code：https://code.visualstudio.com/

安装很简单，这里不再赘述

= 在 VS Code 中安装 PlatformIO 插件

. 打开 VS Code 扩展列表，单击左侧栏中的第五个图标。
+
image::/picture/vscode_1.jpeg[vscode_1.jpeg]

. 在搜索框中输入 PlatformIO，然后在结果列表中选择第一个 PlatformIO IDE。
+
image::/picture/vscode_2.jpeg[vscode_2.jpeg]

. 在插件界面点击安装
+
image::/picture/vscode_3.jpeg[vscode_3.jpeg]

. 安装过程可能需要约 40 分钟，请耐心等待。如果提示找不到 Python 2.7，可暂时忽略；PlatformIO 安装过程中会自动安装。
+
image::/picture/vscode_4.png[vscode_4.png]

. 安装成功后，左侧列表中会出现一个图标，左下角会出现一个小日志
+
image::/picture/vscode_5.jpeg[vscode_5.jpeg]

= 创建新项目
. 单击左下角的主页图标进入 PlatformIO Home，再单击 New Project。
+
image::/picture/vscode_6.jpeg[vscode_6.jpeg]

. 填写项目名称、开发板和框架。项目名可自行设定；本例使用 BPI:bit，因此选择 bpibit 开发板，框架会自动选定。项目保存位置通常保持默认；取消勾选后也可自定义路径。
+
image::/picture/vscode_7.png[vscode_7.png]

. 单击“完成”即可成功设置项目
+
image::/picture/vscode_8.jpeg[vscode_8.jpeg]

. 左侧的资源管理器显示项目文件夹

- platformio.ini（配置文件）
- lib（自动生成的库目录）
- src（程序源文件目录）

+
image::/picture/vscode_9.jpeg[vscode_9.jpeg]

= 编译并上传程序
进入 src 目录，打开 main.cpp 进行编程。用数据线将开发板连接到计算机后，单击下方箭头，PlatformIO 会自动识别串口并上传程序。

image::/picture/vscode_10.jpeg[vscode_10.jpeg]
