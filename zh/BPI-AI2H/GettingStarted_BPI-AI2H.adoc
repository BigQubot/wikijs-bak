= 简介

Banana Pi BPI-AI2H 系统模块（SoM）及其载板是充分发挥 RZ/V2H 视觉 AI MPU 能力的开源硬件方案。它支持 8 GB 内存、32 GB eMMC、双千兆网口和 USB 3.0/2.0 接口。

== 规格参数

- SoC：瑞萨 RZ/V2H 四核 64 位 Arm Cortex-A55 处理器，主频最高 1.8 GHz，搭配 Mali-G31 GPU
- 系统内存：8 GB LPDDR4
- 存储：32 GB eMMC、MicroSD 卡槽
- 视频输出：通过 MIPI DSI 转 HDMI 接口输出，最高支持 1080p
- 网络：双千兆以太网
- USB：3 个 USB 3.0 端口、1 个 USB 2.0 端口、1 个 USB-C 端口
- 扩展：40 Pin 排针，提供 28 路 GPIO、UART、I2C、SPI、PWM 以及 +5 V、+3.3 V 和 GND 电源信号
- 调试：USB Type-C 调试接口
- 电源：12 V/3 A 直流适配器

= Armbian Linux
== 准备

- Linux 镜像支持从 SD 卡或 eMMC 启动。
- 建议使用容量至少为 16 GB 的 A1 等级存储卡。
- 下载最新的 Linux 镜像，并确认校验和正确。
- 默认登录： pi/bananapi 或 root/bananapi

== 将镜像写入 SD 卡

- 使用 Balena Etcher 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化镜像写入工具，可将操作系统镜像写入 SD 卡或 U 盘。

1. 单击“**Flash from file**”选择镜像。 
2. 单击“**Select target**”选择目标设备。 
3. 单击“**Flash!**”开始写入。
+
image::/picture/etcher.jpg[etcher.jpg]

- 使用 Balena CLI 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://github.com/balena-io/balena-cli[Balena CLI] 是 balenaCloud/openBalena 的命令行工具，可用于写入 Linux 镜像。从 link:https://github.com/balena-io/balena-cli/releases[balena-io Releases] 下载安装程序或独立软件包，并按照 link:https://github.com/balena-io/balena-cli/blob/master/INSTALL.md[安装说明]正确安装到 PC。随后可使用 Balena 的“link:https://docs.balena.io/reference/balena-cli/#local-flash-image[local flash]”命令将 Linux 镜像写入 SD 卡或 U 盘。
+
```sh
$ sudo balena local flash xxx-bpi-ai2h-xxx.img.xz
$ sudo balena local flash xxx-bpi-ai2h-xxx.img.xz --drive /dev/sdX
$ sudo balena local flash xxx-bpi-ai2h-xxx.img.xz --drive /dev/sdX --yes
```

- 使用 Armbian Imager 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://imager.armbian.com[Armbian Imager] 是用于安装 Armbian OS 的开源镜像写入工具。
+
对于非官方开发板镜像，请依次选择 Use Custom Image -> Browse，选择本地镜像文件和目标存储设备，再选择 Erase & Flash。
+
image::/picture/armbian-imager-tool.png[armbian-imager-tool.png]

- 在 Linux 中使用 dd 命令写入镜像
+
如果 SD 卡设备 /dev/sdX 的分区已自动挂载，请先将其卸载。 
+
```sh
$ sudo apt-get install xz-utils pv
$ sudo sh -c 'xzcat xxx-bpi-ai2h-xxx.img.xz | pv | dd of=/dev/sdX bs=1M status=progress && sync'
```

== 安装镜像到 eMMC

1. 准备一张已写入 Linux 镜像的 SD 卡，并用该 SD 卡启动开发板。
2. 将目标镜像复制到 U 盘，将 U 盘插入开发板并挂载。
3. 将镜像安装到 eMMC。
- 使用 dd 命令写入。如果 mmcblk0p1 和 mmcblk0p2 分区已自动挂载，请先卸载。 
+
```sh
$ sudo apt-get install xz-utils pv
$ sudo sh -c 'xzcat xxx-bpi-ai2h-xxx.img.xz | pv | dd of=/dev/sdX bs=1M status=progress && sync'
```

- 另一种方法是将 SD 卡上正在运行的 Armbian 系统迁移到 eMMC 等内部存储设备。该工具会准备目标存储、复制当前系统、调整引导加载程序设置，并确保系统无需重新安装即可独立启动。
+
```sh
$ sudo armbian-config --cmd STO001
```
+
image::/picture/ai2n-armbian-install-emmc.png[ai2n-armbian-install-emmc.png]

== 调试串口

开发板提供两个调试串口：

- Type-C 接口：使用普通 USB Type-C 线即可连接 PC，无需在 Linux 或 Windows 中安装专用驱动；波特率为 115200。

- 3 Pin 排针接口：标准 3.3 V TTL 电平 UART，需要 USB 转 TTL 串口线（如 CP2102、PL2303、CH340 等）连接 PC；波特率为 115200。
+

== 网络

Armbian 使用 link:https://netplan.io/[Netplan.io] 描述网络配置。Netplan 通过声明式配置简化 Linux 网络设置；如需手动配置网络，只需创建或编辑 Netplan YAML 文件（语法请参阅 link:https://netplan.readthedocs.io/en/stable/netplan-yaml/[Netplan 文档]）。

- NetworkManager Applet 图形界面
+
对于桌面镜像，右键单击系统托盘中的 NetworkManager Applet 图标，再选择“Edit Connections”配置网络。
+
image::/picture/ai2n-eth.png[ai2n-eth.png]
+
要连接无线网络，可左键单击系统托盘中的 NetworkManager Applet 图标，再选择可用网络项，显示无线网络列表。 
+
image::/picture/ai2n-wifi-list.png[ai2n-wifi-list.png]
+
单击您要连接的网络。如果网络是安全的，则会出现一个对话框提示您输入网络密钥：
+
image::/picture/ai2n-wifi-passwd.png[ai2n-wifi-passwd.png]


- Netplan
+
桌面和 CLI 镜像均附带默认 Netplan YAML 文件 /etc/netplan/00-default-use-network-manager.yaml。这些镜像默认使用 NetworkManager 后端；所有以太网接口均配置为 DHCP，会自动从路由器获取 IP 地址。
+
```sh
# Added by Armbian
#
# Reference: https://netplan.readthedocs.io/en/stable/netplan-yaml/
#
# Let NetworkManager manage all devices on this system.
# Any device will come up with DHCP, once carrier is detected.
# This is basically Netplan passing control over to NetworkManager at boot time.

network:
  version: 2
  renderer: NetworkManager
```
如果首次启动时成功建立 Wi-Fi 连接，系统会创建 /etc/netplan/30-wifis-dhcp.yaml。若首次启动时未连接 Wi-Fi，也可在启动后手动创建该文件。
+
```sh
# Created by Armbian firstlogin script
network:
  wifis:
    wlan0:
      dhcp4: yes
      dhcp6: yes
      access-points:
        "NETWORK":
         password: "password"
```
+
有关 Netplan 配置的更多信息，请参阅 link:https://netplan.readthedocs.io/en/latest/using-static-ip-addresses[Netplan 文档]。

+
修改 YAML 文件后，需要应用配置：
+
```sh
$ sudo chmod 600 /etc/netplan/xxx.yaml
$ sudo netplan apply
```

== RGB LED
开发板提供两个可由用户控制的 RGB LED。

- 载板上的黄色 LED，默认使用 heartbeat 触发器
+
```sh
$ sudo sh -c 'echo timer > /sys/class/leds/carrier-led/trigger'
```
- 核心板上的蓝色 LED，默认使用 default-on 触发器
+
```sh
$ sudo sh -c 'echo none > /sys/class/leds/core-led/trigger'
```

== 风扇

通过 hwmon sysfs 接口控制风扇的开关状态。

- 启用风扇

```sh
$ sudo sh -c 'echo 1 > /sys/class/hwmon/hwmon3/fan1_target'
```

- 禁用风扇

```sh
$ sudo sh -c 'echo 0 > /sys/class/hwmon/hwmon3/fan1_target'
```

== ADC
RZ/V2H 内置 3 个 12 位 ADC 单元，每个单元最多支持 8 个通道。开发板的 ADC 排针 CN3 连接到 adc1。

通过 IIO sysfs 读取 ADC 数据：

```sh
$ cat /sys/bus/iio/devices/iio:device1/in_voltage0_raw
```

```sh
$ sudo armbian-config --cmd DTO001
```

== GPIO
过去，Linux 内核通过 /sys/class/gpio 命名空间公开 GPIO 引脚，但该接口自 4.8 版本起已弃用。替代方案是名为 link:https://libgpiod.readthedocs.io/en/latest/index.html[libgpiod] 的 C 库及一组名为 gpiod 的用户空间工具。

- 安装 gpiod
+
```sh
$ sudo apt install gpiod
```

- 列出 GPIO 芯片
+
输出各芯片的标签和 GPIO 线数量。芯片可通过编号、名称或路径标识，例如“0”“gpiochip0”和“/dev/gpiochip0”均指向同一个芯片。
+
```sh
$ sudo gpiodetect
gpiochip0 [10410000.pinctrl] (96 lines)
```

- 列出 GPIO 线
+
输出 GPIO 线信息。GPIO 线可按名称指定；提供芯片选项时，也可按偏移量指定。每条 GPIO 线对应一个 GPIO 引脚，该引脚的全局 GPIO 编号为线偏移量加 416。

+
```sh
$ sudo gpioinfo
gpiochip0 - 96 lines:
        line   0:        "P00" "carrier-led" output active-high [used]
        line   1:        "P01"   "core-led"  output  active-high [used]
        line   2:        "P02"       unused   input  active-high 
        line   3:        "P03"  "interrupt"   input  active-high [used]
        ...
        line  93:        "PB5"       unused   input  active-high 
        line  94:        "PB6"       unused   input  active-high 
        line  95:        "PB7"       unused   input  active-high
```

- 根据 GPIO 名称获取线偏移量。例如，40 Pin 排针的物理 Pin 31 名为 P9_5。
+
```sh
$ sudo gpiofind P9_5
77
```

- 读取 40 Pin 排针物理 Pin 31 的值
+
```sh
$ sudo gpioget gpiochip0 77

```

- 将 40 Pin 排针物理 Pin 31 设置为低电平
+
```sh
$ sudo gpioset gpiochip0 77=0
```

- 监视 GPIO 电平变化事件。使用 -r 监视上升沿，或使用 -f 监视下降沿，但两者不能同时指定。
+
```sh
$ sudo gpiomon -r gpiochip0 77
```

```sh
import RPi.GPIO as GPIO  
import time  
import sys

# phy pin.31, bcm pin.6
bcmledpin = 6
phyledpin = 31    

def setup_bcm():
  GPIO.setmode(GPIO.BCM)
  GPIO.setup(bcmledpin, GPIO.OUT)
  
def setup_board():
  GPIO.setmode(GPIO.BOARD)
  GPIO.setup(phyledpin, GPIO.OUT)

def blink_bcm():  
  while True:  
    GPIO.output(bcmledpin, GPIO.HIGH)
    print("********set bcm pin ", bcmledpin, " High********")
    time.sleep(1)  
    GPIO.output(bcmledpin, GPIO.LOW)
    print("********set bcm pin ", bcmledpin, " Low********")
    time.sleep(1)

def blink_board():
  while True:
    GPIO.output(phyledpin, GPIO.HIGH)
    print("********set phy pin ", phyledpin, " High********")
    time.sleep(1)  
    GPIO.output(phyledpin, GPIO.LOW)
    print("********set phy pin ", phyledpin, " Low********")
    time.sleep(1)

def shutdown():
    GPIO.cleanup()
  
if __name__ == '__main__':     # Program start
```

```sh
    time.sleep(1)
    wpi.digitalWrite(PIN, 0)
    time.sleep(1)
```

=== VNC

. 安装 x11vnc


. 创建密码文件
+
```sh
 $ x11vnc -storepasswd
 Enter VNC password:

 Write password to /home/pi/.vnc/passwd?  [y]/n y
 Password written to: /home/pi/.vnc/passwd
```

. 创建服务文件 /lib/systemd/system/x11-vnc.service
+
```sh
[Unit]
Description="x11vnc"
Requires=display-manager.service
After=lightdm.service

[Service]
ExecStart=/usr/bin/x11vnc -auth guess -loop -forever -safer -shared -ultrafilexfer -bg -o /var/log/x11vnc.log
ExecStop=/usr/bin/killall x11vnc

[Install]
WantedBy=multi-user.target
```

. 启用服务
+
```sh
sudo systemctl daemon-reload
sudo systemctl enable x11-vnc
sudo systemctl start x11-vnc
```

+

== 准备
- Yocto 镜像支持从 SD 卡或 eMMC 启动。
- 建议使用容量至少为 16 GB 的 A1 等级存储卡。

- 下载最新的 Yocto 镜像，并确认校验值正确。
- root 登录无需密码。

== 将 Yocto 镜像写入 SD 卡

- 使用 Balena Etcher 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化镜像写入工具，可将操作系统镜像写入 SD 卡或 U 盘。

1. 单击“**Flash from file**”选择镜像。 
2. 单击“**Select target**”选择目标设备。 
3. 单击“**Flash!**”开始写入。
+
image::/picture/etcher.jpg[etcher.jpg]

- 使用 Balena CLI 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://github.com/balena-io/balena-cli[Balena CLI] 是 balenaCloud/openBalena 的命令行工具，可用于写入 Linux 镜像。从 link:https://github.com/balena-io/balena-cli/releases[balena-io Releases] 下载安装程序或独立软件包，并按照 link:https://github.com/balena-io/balena-cli/blob/master/INSTALL.md[安装说明]正确安装到 PC。随后可使用 Balena 的“link:https://docs.balena.io/reference/balena-cli/#local-flash-image[local flash]”命令将 Linux 镜像写入 SD 卡或 U 盘。
+
```sh
  $ sudo balena local flash core-image-weston-bananapi-ai2h-xxx.rootfs.wic.gz
  $ sudo balena local flash core-image-weston-bananapi-ai2h-xxx.rootfs.wic.gz --drive /dev/sdX
  $ sudo balena local flash core-image-weston-bananapi-ai2h-xxx.rootfs.wic.gz --drive /dev/sdX --yes
```

- 使用 Armbian Imager 写入镜像，支持 Windows、Linux 和 macOS。
+
link:https://imager.armbian.com[Armbian Imager] 是用于安装 Armbian OS 的开源镜像写入工具。
+
对于非官方开发板镜像，请依次选择 Use Custom Image -> Browse，选择本地镜像文件和目标存储设备，再选择 Erase & Flash。
+
image::/picture/armbian-imager-tool.png[armbian-imager-tool.png]

- 在 Linux 中使用 dd 命令写入镜像
+
如果 SD 卡设备 /dev/sdX 的分区已自动挂载，请先将其卸载。 
+
```sh
 $ sudo apt-get install gunzip pv
 $ sudo sh -c 'gunzip -c core-image-weston-bananapi-ai2h-xxx.rootfs.wic.gz | pv | dd of=/dev/sdX bs=1M status=progress && sync'
```

== 将 Yocto 镜像安装到 eMMC

1. 准备一张已写入 Linux 镜像的 SD 卡，并用该 SD 卡启动开发板。
2. 将 Linux 镜像复制到 U 盘，将 U 盘插入开发板并挂载。
3. 使用 dd 命令安装。如果 mmcblk0p1 和 mmcblk0p2 分区已自动挂载，请先卸载。

```sh

 $ sudo sh -c 'gunzip -c core-image-weston-bananapi-ai2h-xxx.rootfs.wic.gz | pv | dd of=/dev/sdX bs=1M status=progress && sync'
```

== 写入 SPI 引导加载程序

SPI 引导加载程序由三部分组成：Flash Writer 文件、ATF 固件和 U-Boot。对应文件为 Flash_Writer*.mot、bl2_bp_spi.srec（bl2_bp_spi.bin）和 fip.srec（fip.bin），可在 Linux 镜像的 /boot 目录中找到。

- 在 Windows PC 上通过串口写入引导加载程序

1. 将 Flash_Writer*.mot、bl2_bp_spi.srec 和 fip.srec 复制到 Windows PC。
2. 使用 USB 线将 Windows PC 连接到核心板下方的 USB Type-C UART 端口。
3. 将 Bootsel 开关切换到 SCIF 下载模式。
+
image::/picture/ai2n-boot-scidownload.png[ai2n-boot-scidownload.png]

4. 在 Windows PC 上打开终端模拟器。以下以 link:https://github.com/TeraTermProject/teraterm/releases/tag/v4.108[Tera Term 4.108] 为例。
+
NOTE: 如果使用 Tera Term 5.x，请在 Send file 窗口中选择“Send in same way as Tera Term 4”。
+
image::/picture/ai2n-spiflash-teraterm5.png[ai2n-spiflash-teraterm5.png]
5. 选择“文件”>“新建连接”，然后选择“串行”端口，如下所示。
+
image::/picture/ai2n-spiflash-serial1.png[ai2n-spiflash-serial1.png]
6. 从“设置”>“终端”打开配置窗口并按如下方式更改设置。
+
image::/picture/ai2n-spiflash-serial2.png[ai2n-spiflash-serial2.png]
7. 从“设置”>“串行端口”打开配置窗口，并按如下方式更改设置。
+
image::/picture/ai2n-spiflash-serial3.png[ai2n-spiflash-serial3.png]
8. 连接电源线给开发板上电，终端上会显示以下信息。

```sh
Program size & Qspi Save Address

  Please Input : H'
```

```sh

  Please Input : H'
```

+
```sh

please send ! ('.' & CR stop load)
```

```sh
SpiFlashMemory End Address  : H'00036D17
```

```sh
Load Program to Spiflash
Writes to any of SPI address.
Program size & Qspi Save Address
===== Please Input Program Top Address ============
  Please Input : H'
```

17. 输入“00000”。日志继续。
+

```sh
  Please Input : H'
```
18. 输入“60000”。日志继续。

```sh
please send ! ('.' & CR stop load)
```
