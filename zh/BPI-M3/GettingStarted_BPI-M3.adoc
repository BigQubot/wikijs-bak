= 简介

Banana Pi M3 是一款高性能单板计算机，配备八核处理器和 2 GB 内存，并提供千兆以太网、两个 USB、SATA、WiFi、蓝牙和 HDMI 接口。它可运行 Android、Lubuntu、Ubuntu、Debian 和 Raspbian 等多种操作系统。

TIP: 更多信息：link:/zh/BPI-M3/BananaPi_BPI-M3[Banana Pi BPI-M3]

== 规格参数

- 八核 1.8 GHz 高性能 CPU
- 2 GB LPDDR3 内存
- 8 GB eMMC 存储
- 板载 WiFi 和蓝牙

=== 构建 M3 BSP 源代码
. 准备一台运行 Ubuntu 的电脑。
. 在电脑上安装 Docker CE：https://docs.docker.com/install/linux/docker-ce/ubuntu/#install-docker-ce （配置 Docker 环境）
. 安装 Docker 后，执行以下命令拉取 Docker 镜像
+
```sh
docker pull sinovoip/bpi-build:ubuntu12.04
```
. 镜像拉取完成后，创建并进入 Docker 容器，执行
+
```sh
docker run --privileged -d -p 2222:22 -v /media:/media sinovoip/bpi-build:ubuntu12.04
```
. 登录 Docker 容器
+
```sh
ssh -p 2222 root@127.0.0.1 # 默认密码为 root
```
. 克隆 M3 BSP 源代码，执行
+
```sh
git clone https://github.com/BPI-SINOVOIP/BPI-M3-bsp.git
```
. 构建 M3 BSP 源代码，执行
+
```sh
./build.sh
```
. 构建完成后，打开新终端，执行以下命令将编译结果从 Docker 容器中复制出来
+
```sh
docker cp <your container id>:<your project path> <your pc path>
```

== Linux
=== 准备

. 准备一张至少 8 GB 的 TF 卡和一个 USB 转串口适配器。
. 使用 USB 转串口适配器连接 M3 的调试控制台。
. 登录用户名/密码：pi/bananapi 或 root/bananapi。

=== 将镜像烧录到 SD 卡

**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**可以选择以下两种方法。**

. 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m3-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 使用 Linux 上的 bpi-tools 烧录镜像。将 SD 卡插入 Linux 电脑并执行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m3-xxx.img.zip /dev/sdX
```

 
=== 将镜像烧录到 eMMC

. 将“xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img”复制到 U 盘。
. 将 U 盘插入 M3。
. 执行以下命令（如果已自动挂载，可跳过此步）
+
```sh
mont /dev/sda1 /mnt
```
. 可以使用以下两种方法将镜像烧录到 eMMC。
- 使用 bpi-copy 烧录。
+
```sh
bpi-copy xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img
```
- 使用 dd 命令烧录。
+
```sh
sudo dd if=/mnt/sda1/xxx-sd-emmc-xxx.img of=/dev/mmcblk0
```

. 关闭 M3 电源，取出 TF 卡，再次上电后从 eMMC 启动。


=== 更新镜像
例如，将现有镜像更新为支持新版 eMMC 5.1。

```sh
bpi-tools
bpi-update -c bpi-m3.conf
file *.tgz
bpi-bootsel
bpi-bootsel /usr/lib/u-boot/bananapi/bpi-m3/BPI_M3_720P.img.gz
reboot
```

=== 制作自己的镜像

- 制作一个 Raspbian 镜像

- 准备一张已安装 Raspbian 系统的 SD 卡

- 使用该 SD 卡启动 M3。M3 启动完成后，复制所需文件并配置 Raspbian，然后关闭 M3。

- 将 SD 卡插入 Linux 电脑
+
```sh
cd /media
ln -s <your account> pi
```

- 执行 
+
```sh
bpi-migrate -c bpi-m3.conf -c raspbian-jessie-from-sd.conf -d /dev/sdx
```

- 完成后即可得到自己的镜像

=== SATA
. 在 M3 上挂载 SATA 硬盘
+
```sh
fdisk -l
mount /dev/sdx /mnt/xxx
```
+
image::/picture/m3_sata.png[m3_sata.png]

. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：
+
```sh
fdisk /dev/sdx
```
创建新分区，设置分区数量和大小，创建分区后，输入“wq”保存并退出。
+
```sh
mkfs.ext2 /dev/sdx
mount /dev/sdx /mnt/xxx
```
. 成功连接 SATA 硬盘后，可以输入以下命令测试 SATA 接口：

- 测试读取速度
+
```SH
time dd if=/dev/xxx of=/dev/null bs=1M count=1000
```
- 测试写入速度
+
```sh
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+
image::/picture/sata_test.png[sata_test.png]

. 在电脑终端中：

- 如果 adbd 已成功启动，请用 OTG-USB 线连接 M3 和运行 Ubuntu 的电脑。
- 执行
+
```sh
adb devices
```
检查电脑是否已识别 M3 的 OTG 设备
- 如果已经识别，可以执行
+
```sh
adb shell
```
