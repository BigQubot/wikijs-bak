= 简介

Banana Pi BPI-R4 路由器开发板采用 MediaTek MT7988A（Filogic 880）四核 ARM Cortex-A73 处理器，配备 4GB DDR4 内存、8GB eMMC 和板载 128MB SPI-NAND 闪存；同时提供 2 个 10GbE SFP 接口、4 个千兆以太网口和 USB 3.2 接口。M.2 插槽支持 4G/5G 模块和 NVMe SSD，另有 2 个采用 PCIe 3.0 双通道接口的 miniPCIe 插槽，可安装 Wi-Fi 7 网卡（NIC）。这是一款高性能开源路由器开发板。

TIP: 更多信息：link:/zh/BPI-R4/BananaPi_BPI-R4[Banana Pi BPI-R4]

== 如何将镜像烧录到板载 NAND
NOTE: **NAND 出厂时已经烧录镜像。如需使用，只需切换到相应的启动模式，然后上电启动。**

NOTE: 更新 NAND 时，先将启动开关切换为从 SD 卡启动，并插入一张带有可启动镜像的 SD 卡。系统启动后，将 NAND 镜像写入 NAND，最后再切换为从 NAND 启动。

烧录 NAND 镜像前请准备一个 USB 驱动器。以下以 OpenWrt 镜像（mtk-bpi-r4-NAND-20231030.img）为例：

. 将用于 NAND 启动的 OpenWrt 镜像（**mtk-bpi-r4-NAND-20231030.img**）复制到 USB 驱动器。
. 调整启动跳线，使开发板从 SD 卡启动，然后给开发板上电。
. 将 USB 驱动器插入开发板，并按如下方式挂载到 /mnt 或其他目录（若系统已自动挂载，可跳过此步）：
+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
. 执行以下命令擦除整个 NAND，并将镜像写入 NAND 设备：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r4-NAND-20231030.img of=/dev/mtdblock0
```
. 关闭 BPI-R4，拔出 USB 驱动器，然后切换为从 NAND 启动。

== 如何将镜像烧录到板载 eMMC
NOTE: 由于 SD 卡与 eMMC 共用 SoC 的同一个控制器，需要先切换为从 NAND 启动，再将 eMMC 镜像写入 eMMC，最后切换为从 eMMC 启动。

烧录 eMMC 镜像前请准备一个 USB 驱动器。以下以 OpenWrt 镜像（bl2_emmc-r4.img、mtk-bpi-r4-EMMC-20231030.img）为例：

. 将用于 eMMC 启动的 OpenWrt 镜像（**bl2_emmc-r4.img**、**mtk-bpi-r4-EMMC-20231030.img**）复制到 USB 驱动器；如果镜像已压缩，请先解压再复制。

. 将启动跳线切换为 NAND，并从 NAND 启动开发板。
 
. 将 USB 驱动器插入开发板，并按如下方式挂载到 /mnt 或其他目录（若系统已自动挂载，可跳过此步）：
+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```

. 执行：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc-r4.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4-EMMC-20231030.img of=/dev/mmcblk0
 mmc bootpart enable 1 1 /dev/mmcblk0
```
 
. 关闭 R4，拔出 USB 驱动器，然后切换为从 eMMC 启动。

== 读写 EEPROM
WARNING: **我们发布的镜像在每次启动时都会使用随机 MAC 地址，不会使用 EEPROM。如需使用 EEPROM，需要自行编写脚本读取其中的数据并更新端口配置。**

1、读取 EEPROM
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom
```
2、向 EEPROM 写入内容
```
printf '\x01\x02\x03\x04\x05\x06' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=32 conv=notrunc
```
“**\x01\x02\x03\x04\x05\x06**”是要写入的内容，可以是 MAC 地址、序列号或其他信息。+
“**bs=1**”表示块大小为 1。+
“**seek=32**”表示偏移量（跳过的块数）。+
**“bs=1 seek=32”**表示跳过 32 字节，即跳过 0x00 至 0x1F，从 0x20 开始写入。+
“**conv=notrunc**”表示不截断 EEPROM，保留原有数据。

例如，要分别向地址 **0x20** 和 **0x30** 写入两组 MAC 地址：
```
printf '\x12\x41\x89\x7F\x64\xD3' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=32 conv=notrunc
printf '\x7E\xF5\x56\x36\x4C\xD1' | dd of=/sys/bus/i2c/devices/3-0057/eeprom bs=1 seek=48 conv=notrunc

```
WARNING: **注意：后续批次的 V1.2 版本计划向 EEPROM 写入数据，因此必须避开 0x00 至 0x1F 的地址范围。**

3、读取 EEPROM 的全部内容
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom
```
读取 EEPROM 指定位置的内容。
```
hexdump -C /sys/bus/i2c/devices/3-0057/eeprom | tail -n +3
```
“**tail -n +3**”表示只显示从第 3 行开始的数据，即从 0x20 开始。



= 配件

== 10G SFP 模块
BPI-R4 的 SFP SerDes 速率固定为 10Gbps，因此只能使用支持该速率的 SFP 模块！

通常，10G SFP+ 模块的 PIN6 为 GND。插入模块后，SFP_MOD_DEF0 会被拉低，从而接通 SFP 电源。

因此，如果模块的该引脚不是 GND，就不会提供 3.3V_SFP 电源！

image::/picture/r4_sfp_power.png[r4_sfp_power.png]

=== M.2 4G/5G 模块（USB 接口）
BPI-R4 支持以下采用 M.2 USB 接口的 4G LTE/5G 模块：**Quectel EM05、RM500U-CN、RM500Q-GL 和 RM520N-GL**。

如需在 BPI-R4 上使用 M.2 蜂窝网络模块：

. 将 4G/5G 蜂窝网络模块安装到 CN16 插槽（M.2 Key B）。
. 使用卡托将 Nano SIM 卡插入 SIM 卡槽（SIM1），注意插入方向。
. 将天线安装到模块上。
. 上电后，系统会自动拨号。

NOTE: 能否使用 4G/5G 取决于当地运营商采用的频段。

=== miniPCIe 4G/5G 模块（USB 接口）
BPI-R4 支持采用 miniPCIe USB 接口的 4G LTE 模块：**Quectel EC25**。

如需在 BPI-R4 上使用 miniPCIe 蜂窝网络模块：

. 将 4G 蜂窝网络模块安装到 CN12 插槽。
. 使用卡托将 Nano SIM 卡插入 SIM 卡槽（SIM2），注意插入方向。

```bash


root@R4RN:/# cat /sbin/fan-speed 
#!/bin/sh /etc/rc.common

if [ ! -f /sys/class/pwm/pwmchip0/export ]; then
        exit 0
fi

### enable fan ###
echo 0 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm0/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable

while :
do
        sleep 20
        result=`cat /sys/class/thermal/thermal_zone0/temp`

        temperature=$((result))
        #echo $temperature
        if [ ${temperature} -ge 53000 ]; then
                echo 5000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -ge 62000 ]; then
                echo 1000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4800 ]; then
                echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4000 ]; then
                echo 10000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi
done
```
