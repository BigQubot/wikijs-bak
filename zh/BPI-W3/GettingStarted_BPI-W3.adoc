= 简介

香蕉派 BPI-W3 单板计算机的设计和开发 bananapi 专业和企业用户团队，由 Rockchip RK3588 SoC 四核 ARM Cortex-A76 和四核 Cortex-A55 由一个八核组成 CPU 处理器的动态频率可扩展至 2.4GHz。嵌入式高性能3D和2D图像加速模块、AI加速器 NPU 内置6TOPS算力。

TIP: 更多信息： link:/en/BPI-W3/BananaPi_BPI-W3[香蕉派 BPI-W3]

= 开发准备

== 工具准备
* BPI-W3 主板
* 电源 (三选一)
** USB Type-C PD 2.0支持 9V/2A, 12V/2A, 15V/2A 和 20V/2A
** 直流 12V 适配器，2.5 毫米
** PoE 12V
* 系统安装 (选择两个之一)
** 微型SD卡 /TF 卡启动
*** 微型SD卡 card/TF 卡，Class 10 或以上，至少 8GB SDHC，以及读卡器
*** 以下是一些经过 ArmSoM 团队测试和验证的高速 TF 卡：
**** 闪迪 32GB TF (微型SD卡) (开发商推荐)
**** 闪迪 32GB TF (微型SD卡) 行车记录仪&安防监控专用存储卡 (建议长期运行)
**** 闪迪 TF 8G Class10 microSD
**** 闪迪 TF 128G Class10 microSD XC TF 128G 48MB/S
** 机上 eMMC 启动
*** USB A to C数据线，用于将镜像写入ArmSoM-W3 eMMC 或使用 fastboot/adb 通过 C 型端口执行命令。你需要一个 USB 连接 ArmSoM-W3 和 PC 的 A 转 C 型数据线。

== 可选配件
* USB 键盘和鼠标
* HDMI 显示器和 HDMI 电缆
** 的 BPI-W3 配备全尺寸HDMI接口，最大支持8K@60显示。
** HDMI EDID 用于确定最佳显示分辨率。在支持 1080p 的显示器和电视上将选择此分辨率 (或 4K/8K)。如果不是 1080p，EDID 将查找下一个可用的分辨率。
* Ethernet 电缆
** 的 BPI-W3 支持 ethernet 互联网接入，最高可达2.5G。
** 网线用于连接 BPI-W3 到本地网络和互联网。
* 摄像头模组
** 的 BPI-W3 支持相机功能。
** 建议使用imx415模块，可通过Baanana Pi官方商店购买。
* LCD 显示
** 的 BPI-W3 支持 LCD 显示功能。
** 建议使用 Display 10.1 HD，可通过官方商店购买。
* 音频线
** 标准 3.5 毫米插孔可用于通过扬声器或耳机播放音频。
* WiFi/Bluetooth 卡
** 支持市场上常见的无线模块，请查看支持列表的无线部分。
** 推荐使用RTL8852be、AP6256
* USB-A 至 USB-C数据线

== 2.5G Ethernet

如果您使用有线 ethernet 上网时，请将网线插入ArmSoM-W3上的RJ45端口，系统桌面上会弹出有线连接提示。

如何手动配置 ethernet?

* 切换到root用户
```sh
sudo su
```
使用命令-ifconfig检查是否 ethernet 工作正常，然后显示 eth0 或 enP4p65s0 网卡并且 ethernet IP 地址。还可以使用 ping 工具来测试网络连接。
```sh
ifconfig
ping www.baidu.com
```

* 如果无法 ping 通，请尝试：

```sh
$ sudo dhclient eth0
```
或 
```sh
$ sudo dhclient enP4p65s0
```

== USB 接口

的 BPI-W3 提供两个 USB 2.0和两个 USB 3.0端口。

== C型

的 BPI-W3 具有功能齐全的 USB Type-C 3.0 端口，最高支持 8K@30fps DP 显示。

== HDMI

的 BPI-W3 具有两个HDMI输出端口，均支持CEC和HDMI 2.1，最高分辨率分别为8Kp60和4Kp60。

NOTE: 使用前请确认HDMI线的接口规格。

== RGB LED
的 BPI-W3 有权力 LED 和用户 LED.

* 电源指示灯 LED： 电源 LED 是绿色的。在 ArmSoM-W3 上，通电后它默认常亮。
* 用户指示器 LED：用户 LED 是蓝色的。默认情况下，其闪烁状态显示正在运行的内核。

用户可以通过命令进行控制：

```sh
armsom@armsom-w3:/# sudo su
root@armsom-w3:/# echo timer > /sys/class/leds/blue:status/trigger
root@armsom-w3:/# echo activity > /sys/clas
```
== 实时时钟

* 的 BPI-W3 配备RTC IC hym8563。
* 首先，插入 RTC 电池为 RTC IC 供电。

NOTE: 我们应该将 RTC 电池保留在 RTC 连接器中并确认 rtc hym8563 设备已创建

```sh
armsom@armsom-w3:/#  dmesg | grep rtc
[    6.407133] rtc-hym8563 6-0051: rtc information is valid
[    6.412731] rtc-hym8563 6-0051: registered as rtc0
[    6.413779] rtc-hym8563 6-0051: setting system clock to 2022-06-22T01:22:26 UTC (1655860946)
```

找到rtc0，然后使用以下命令设置系统时间并同步到rtc0。

```sh
armsom@armsom-w3:/# hwclock -r
2023-11-03 10:32:40.461910+00:00
armsom@armsom-w3:/# date
11/03/2023 Friday 10:33:12 UTC
armsom@armsom-w3:/# hwclock -w
armsom@armsom-w3:/# hwclock -r
armsom@armsom-w3:/# poweroff
```

取出 RTC 电池，10 分钟或更长时间后插入电池并启动 ArmSoM-W3，检查 RTC 是否与系统时钟同步

```sh
armsom@armsom-w3:/# hwclock -r
2023-11-03 10:35:40.461910+00:00
armsom@armsom-w3:/# date
11/03/2023 Friday 10:36:01 UTC
```

== M.2接口

的 BPI-W3 提供两个 M.2 连接器：

板正面有一个M.2 E Key连接器，带有2230安装孔，提供 PCIe 2.1单声道， USB、SATA、SDIO、PCM 和 UART 信号，支持标准工业M.2 WiFi 6模块。

香蕉派推荐使用RTL8852BE、AP6256。安装在 BPI-W3 M.2 E插槽，设置wifi后即可上网。

```sh
# Load driver  
armsom@armsom-w3:/# insmod system/lib/modules/rtkm.ko
armsom@armsom-w3:/# insmod system/lib/modules/rtkm.ko
armsom@armsom-w3:/# insmod /usr/lib/modules/rtk_btusb.ko
armsom@armsom-w3:/# lsmod

Module                  Size  Used by
8852be               4030464  0
rtkm                   16384  1 8852be
rtk_btusb              57344  0
```

== LED
- 开 BPI-W3 三色 LED 配置为 LED 类设备。当蓝色 LED 未激活 绿色 LED 将显示表明板已通电。您可以控制蓝色的行为模式 LED 通过写信给 /sys/class/leds/blue:status/trigger. 默认情况下，只有 root 用户可以写入设备。默认模式为蓝色 LED 是心跳。
+
```sh
linaro@linaro-alip:/home/linaro# sudo su // linaro password
root@linaro-alip:/home/linaro# echo timer > /sys/class/leds/blue:status/trigger
root@linaro-alip:/home/linaro# echo activity > /sys/class/leds/blue:status/trigger
```

- 您可以在触发器属性上使用 cat 来列出所有可用的 LED 模式。括号中的值是当前活动模式。
+
```sh
root@linaro-alip:/home/linaro# cat /sys/class/leds/blue:status/trigger
none rfkill-any rfkill-none kbd-scrolllock kbd-numlock kbd-capslock kbd-kanalock kbd-shiftlock kbd-altgrlock kbd-ctrllock kbd-altlock kbd-shiftllock kbd-shiftrlock kbd-ctrlllock kbd-ctrlrlock tcpm-source-psy-4-0022-online mmc2 mmc1 timer oneshot disk-activity disk-read disk-write ide-disk mtd nand-disk heartbeat backlight gpio cpu cpu0 cpu1 cpu2 cpu3 cpu4 cpu5 cpu6 cpu7 mmc0 [activity] default-on transient flash torch panic netdev rfkill0
```
- 在无模式下，写入 /sys/class/leds/blue:status/brightness 可以手动控制蓝色的状态 LED.
+
```sh
root@linaro-alip:/home/linaro# echo none > /sys/class/leds/blue:status/trigger
root@linaro-alip:/home/linaro# echo 1 > /sys/class/leds/blue:status/brightness
root@linaro-alip:/home/linaro# echo 0 > /sys/class/leds/blue:status/brightness
```
- 红灯相同，类设备 /sys/class/leds/red:status/trigger

== 实时时钟设备
BPI-W3 配备1个RTC IC hym8563

. 首先，插入RTC电池，给RTC IC供电。请注意，我们应将 RTC 电池保留在 RTC 连接器中。

. 其次，检查驱动是否加载成功。
+
```sh
root@linaro-alip:~# dmesg | grep rtc
[    3.149263] rtc-hym8563 6-0051: rtc information is valid
[    3.154624] rtc-hym8563 6-0051: registered as rtc0
[    3.155646] rtc-hym8563 6-0051: setting system clock to 2021-01-01T12:00:05 UTC (1609502405)
```
. 最后检查是否可以查看和设置时间。
+
```sh
root@linaro-alip:~# hwclock -r
2022-08-07 13:38:24.370866+00:00
root@linaro-alip:~# date
2022年 08月 07日 星期日 13:38:41 UTC
root@linaro-alip:~# hwclock -w
```
