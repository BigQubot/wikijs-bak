= 简介

香蕉派 BPI-P2 Zero 是一款超紧凑型单板计算机，尺寸仅为 65 毫米*52.5毫米。它采用四核 Cortex A7 allwinner H2+ 处理器(选项：H3 和 H5), 512MB RAM 内存.8G eMMC 闪存,100M LAN,添加 PoE 功能支持，非常适合一些空间有限的应用的轻量级系统。与 香蕉派 的其他成员一样，它支持 linux 和 android 操作系统。

TIP: 更多信息： link:/en/BPI-P2_Zero/BananaPi_BPI-P2_Zero[香蕉派 BPI-P2 Zero]

== 规格参数

- CPU: Allwinner H2+, 四核 Cortex-A7
- 512MB DDR 3 SDRAM
- 无线网络 (AP6212) & 板载蓝牙
- 迷你 HDMI
- 40针 GPIO，它包括 UART, SPI, I2C、IO等
- 100M局域网
- IEEE 802.3af PoE 标准 PoE 模块支持
- 8G eMMC 板载闪存

== Linux
=== 准备
. Linux 镜像支持SD卡或 EMMC 启动
. 建议使用A1级卡，至少8GB。
. 安装 bpi-tools 在你的 Linux 电脑(如果使用其他工具刷入镜像，请忽略此步骤)。如果您无法访问此 URL 或出现任何其他安装问题，请转至 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源存储库，手动下载并安装此工具。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认md5校验和正确。
. 默认登录： pi/bananapi 或 root/bananapi

=== 将映像安装到 SD 卡
**Windows 电脑**

使用 Balena Etcher 安装映像。 +
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

. 点击“**从文件闪存**”来选择镜像。 
. 点击“**选择目标**”来选择 USB 设备。 
. 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**有两种方法供您选择。**

. 使用 dd 命令安装镜像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-p2_zero-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 安装镜像 bpi-tools 上 Linux，插入SD卡 Linux 电脑并运行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/sdX
```

=== 安装镜像到 eMMC

. 准备一张SD卡 Linux 镜像闪存和启动板与此 SD 卡。
. 解压镜像并将其复制到 USB 驱动器，将U盘插入板上并安装。（如果自动安装，请忽略此步骤）
+
```sh
mount /dev/sdx /mnt
```
. 有两种安装方式linux镜像到板上。

IMPORTANT: 请检查您的 EMMC 分区为mmcblk0，以下只是使用示例，重点关注实际分区。

- 使用dd命令安装。
+
```sh
sudo dd if=/mnt/xxx.bpi-p2_zero-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 安装 linux 乌磁盘中的镜像 bpi-tools 命令
+
```sh
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/mmcblk0
```
. 下载完成后，安全关闭电源并弹出 SD 卡。

== 高级开发
=== 如何创建图像
- 准备一张已安装好系统的SD卡(Ubuntu/Raspbian/..)
- 使用 M2 Zero 启动 SD 卡，M2 Zero 启动完成后，复制文件并配置系统，然后关闭 M2 Zero 电源。 [如果您不想配置系统，可以跳过此步骤]
- 将 SD 卡插入 PC(正在运行 Linux)
+
```sh
cd /media
ln -s <your account> pi
```
- 执行 
+
```sh
bpi-migrate -c bpi-m2z.conf -c ubuntu-mate-from-sd.conf -d /dev/sdx
```
- 那么你现在就可以得到你自己的图像了
