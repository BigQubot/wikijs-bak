= 香蕉派（Banana Pi）开源硬件社区开发者文档中心

image::/wiki_home.jpg[wiki_home.jpg]

link:http://www.banana-pi.org/[Banana Pi] 是由 link:https://wiki.banana-pi.org/About_BPI[广东比派科技有限公司] 主导的开源硬件项目，专注于 ARM、RISC-V 与 MCU 系列开源硬件开发板，为开发者提供开放的软件与硬件平台，并打造基础技术开发平台。香蕉派产品完整整合语音、数据和视频系统平台，开发者可以在此基础上灵活构建物联网、人工智能、工业互联网控制和 STEAM 教育等应用，并形成 link:https://wiki.banana-pi.org/Banana_Pi_open_source_community_ecology_and_Internet_of_things_overall_technical_solutions[香蕉派开源社区生态与物联网整体技术解决方案]。

欢迎前往 link:http://forum.banana-pi.org/[Banana Pi 论坛]交流。由于 Google 安全策略更新，如果旧链接中的镜像无法下载，请改用新的 link:https://drive.google.com/drive/folders/0B4PAo2nW2Kfndjh6SW9MS2xKSWs?resourcekey=0-qXGFXKmd7AVy0S81OXM1RA&usp=sharing[文档] 与 link:https://drive.google.com/drive/folders/0B_YnvHgh2rwjVjNyS2pheEtWQlk?resourcekey=0-U4TI84zIBdId7bHHjf2qKA[镜像] 链接。
