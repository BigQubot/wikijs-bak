= 简介

香蕉派 M1+ 配备机载 WiFi g/b/n.由于板载 WIFI 芯片，该板支持所有经典项目，甚至更多。与它的兄弟姐妹一样，它可以运行操作系统，包括 Android, 卢本图, Ubuntu, Debian和树莓派。

香蕉派 M1+ 是我们升级后的M1板。我们觉得板载 WiFi 为主板添加了更多功能，让用户更方便地设置他们的 linx 桌面或路由器项目。 

TIP: 更多信息： link:/en/BPI-M1_Plus/BananaPi_BPI-M1_Plus[香蕉派 BPI-M1_Plus]

== 规格参数

- 双核1.0GHz CPU
- 1 GB DDR3 内存
- 带 Open GL ES 的 Mali-400 MP2 2.0/1.1
- 机载WiFi

== 高级开发
=== SATA
. 在M1P上安装SATA

- 插入sata接口后，执行
+
```sh
fdisk -l
```
- 然后 
+
```sh
mount /dev/sdx /mnt/xxx
```
+
image::/picture/m1p_sata.png[m1p_sata.png]

. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：

- 创建新分区
+
```sh
fdisk /dev/sdx
```
设置分区数量和大小，创建分区后，输入“**瓦克**” 保存并退出。
- 格式化SATA
+
```sh
mkfs.ext2 /dev/sdx
```
- 执行
+
```sh
mount /dev/sdx /mnt/xxx
```

. 成功插入SATA后，我们可以输入以下命令来测试SATA接口：

- 测试读取速度
+
```SH
time dd if=/dev/xxx of=/dev/null bs=1M count=1000 
```
- 测试写入速度
+
```SH
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+

=== A20 CAN总线
为了将can4linux移植到 BananaPi，CAN模块描述需要从A20硬件手册中获取。 can4linux是一个基于字符驱动的 Linux 驱动程序已在台式 PC 和嵌入式平台（例如 Freescale FlexCAN）上使用 (i.MX 系列微控制器) 或 Xiliny Zynq。

有关 A20 上的 CAN 的更详细文档位于： https://dl.linux-sunxi.org/A20/CAN%20Bus1.pdf

这是一个使用 CAN BUS 的教程 bananapi 与香蕉 15-01

感谢 selqcir 分享这个例子：

- 下载并安装“bananian-1501.img” 插入 8 GB SD 卡。
- 使用“bananian-config”扩展根文件系统
- 安装缺少的包：
+
```sh
apt-get install git
apt-get update
apt-get upgrade
reboot
```
- 获取最后一个可用的 bananian，并继续安装缺少的软件包：
+
```sh
git clone https://github.com/Bananian/linux-bananapi
apt-get install build-essential u-boot-tools uboot-mkimage 
apt-get install libusb-1.0-0 libusb-1.0-0-dev git wget fakeroot kernel-package zlib1g-dev libncurses5-dev
apt-get install subversion
```
- 构建内核：
+
```sh
cd linux-bananapi
make menuconfig
```
- 菜单出现时退出而不保存
+
```sh
zcat /proc/config.gz > /root/linux-bananapi/.config
make uImage modules
make INSTALL_MOD_PATH=output modules_install
```
- 在此步骤中，应该编译内核并且“Module.symvers”应该可用
- 然后重命名Bananian提供的模块和固件，并替换为新的。
+
```sh
mv /lib/modules /lib/modules.old
mv /lib/firmware /lib/firmware.old
mv /root/linux-bananapi/output/lib/modules /lib/modules
mv /root/linux-bananapi/output/lib/firmware /lib/firmware
```
- uImage 也一样：
+
```sh
mount /dev/mmcblk0p1 /mnt
cd /mnt
mv uImage uImage.old
mv /root/linux-bananapi/arch/arm/boot/uImage /mnt
reboot
```
- 创建进一步构建的链接：
+
```sh
cd /lib/modules/3.4.104/
ln -s /root/linux-bananapi build
cd ~
```
- 获取 Can4Linux 并构建它：
+
```sh
svn checkout https://svn.code.sf.net/p/can4linux/code/trunk can4linux-code
cd /root/can4linux-code/can4linux/
make TARGET=BANANAPI
```
- 为板的每次启动安装模块：
+
```sh
insmod can4linux.ko
cp can4linux.ko /lib/modules/3.4.104/kernel/net/can/
depmod -A -v
modprobe -v can4linux
echo "" >> /etc/modules ; echo "can4linux" >> /etc/modules
reboot
```
- 构建 CAN 示例
+
```sh
apt-get install swig
apt-get install python-dev
cd can4linux-code/can4linux-examples/
```
- 更新文件中的 CAN 速度和设备”pyCan-example.py"
+
```sh
# setting the device number
device = 0
defaultBaudrate = '250'
```
- 连接 CAN 收发器和 CAN 总线，并检查例如：
+
```sh
python pyCan-example.py
```

仅此而已

使用这种方法，内核版本是“Linux bananapi 3.4.104" 代替 "Linux bananapi 3.4.104+”，因为我无法找到与 Bananian 15-01 相同的来源，但 CAN 总线可以工作！
