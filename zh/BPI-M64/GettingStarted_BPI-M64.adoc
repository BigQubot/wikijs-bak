= 简介

香蕉派 BPI-M64 是一款64位四核迷你单板计算机。它具有 2GB RAM 和8GB eMMC。它还具有板载 WiFi 和 BT。在端口方面， BPI-M64 有 2 USB A 2.0端口，1个 USB OTG 端口、1 个 HDMI 端口、1 个音频插孔，最后是一个直流电源端口。该处理器与R18引脚兼容，因此有两个版本：M64和M64-R18。

TIP: 更多信息： link:/en/BPI-M64/BananaPi_BPI-M64[香蕉派 BPI-M64]

== 规格参数

**A64**

- 1.2 Ghz 四核 ARM Cortex A53 64 位处理器-A64
- 2GB DDR3 内存
- 8G EMMC
- 10/100/1000Mbps Ethernet
- 无线网络 (AP6212) & 蓝牙

**R18**

- 1.2 Ghz 四核 ARM Cortex A53 64 位处理器-R18
- 2GB DDR3 内存
- 8G EMMC
- 10/100/1000Mbps Ethernet
- 无线网络 (AP6212) & 蓝牙

=== 将映像安装到 SD 卡
**Windows 电脑**

使用 Balena Etcher 安装映像。 +
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

. 点击“**从文件闪存**”来选择镜像。 
. 点击“**选择目标**”来选择 USB 设备。 
. 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**有两种方法供您选择。**

. 使用 dd 命令安装镜像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m64-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 安装镜像 bpi-tools 上 Linux，插入SD卡 Linux 电脑并运行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m64-xxx.img.zip /dev/sdX
```

=== 安装镜像到 EMMC
. 准备一张SD卡 Linux 镜像闪存和启动板与此 SD 卡。
. 解压镜像并将其复制到 USB 驱动器，将U盘插入板上并安装。（如果自动安装，请忽略此步骤）
+
```sh
mount /dev/sdx /mnt
```
. 有两种安装方式linux镜像到板上。
- 使用dd命令安装。
+
```sh
sudo dd if=/mnt/xxx.bpi-p2_zero-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 安装 linux 乌磁盘中的镜像 bpi-tools 命令
+
```sh
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/mmcblk0
```
. 下载完成后，安全关闭电源并弹出 SD 卡。

=== 切换到 LCD 引导类型
. 默认发布镜像为HDMI启动类型，您可以切换为 LCD BPI 7" 的引导类型 LCD 首次启动后支持。
+
```sh
 $ sudo bpi-bootsel /usr/lib/u-boot/bananapi/bpi-m64/BPI-M64-LCD7-linux4.4-8k.img.gz
 $ reboot
```
. 如果您想使用TP，请加载触摸屏驱动程序
+
```sh
 $ sudo modprobe gt9xxnew_ts.ko
```

=== GPIO 控制
. 要访问一个 GPIO 您首先需要将其导出
+
```sh
 echo XX > /sys/class/gpio/export
```

. XX 是所需引脚的编号。要获得正确的数字，您必须根据引脚名称进行计算 (像PH18)
+
NOTE: (字母在字母表中的位置 - 1) * 32 + 引脚号 +
对于 PH18 这将是 ( 8 - 1) * 32 + 18 = 224 + 18 = 242 (因为 'h' 是第 8 个字母)
+
```sh
echo "out/in" > /sys/class/gpio/gpio*NUMBER*/direction
echo "0/1" > /sys/class/gpio/gpio*NUMBER*/value
```
