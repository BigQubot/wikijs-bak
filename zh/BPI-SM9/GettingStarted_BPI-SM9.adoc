= 简介

Banana Pi BPI-SM9 16-ENC-A3 深度学习计算模块搭载高度集成的 BM1688 处理器，配备八核 Arm Cortex-A53 1.6 GHz CPU、8 GB LPDDR4 内存和 32 GB 板载 eMMC。它提供一个 RJ45 千兆网口、一个 M.2 Key E、一个 M.2 Key M、四个 USB 3.2 接口、一个 Type-C（USB 3.0）接口及多种功能接口。

== 规格参数
* 支持 HDMI 2.0 输出；
* 支持双千兆 RJ45 以太网；
* 支持双层 USB 3.0 接口；
* 支持 WiFi/蓝牙功能；
* 支持 TF 卡或 M.2 SSD 扩展；
* 支持两路 MIPI 摄像头输入；
* 支持 GPIO 扩展；
* 支持 CAN 功能；
* 支持通过 USB-C 接口升级（NVIDIA 核心板方案）。

= 开发

== 准备

* 12 V/3 A 电源适配器（允许电压范围为 11～13 V，推荐使用 12 V 适配器）

* 一根 USB 转串口线（3.3 V TTL，波特率 115200），用于连接 BPI-SM9 调试控制台

* 一张 TF 卡（如果要从 TF 卡启动系统）

* 一根 Type-C 数据线（用于升级和烧录）

== UART1

image::/bpi-sm9/bpi-sm9-gettingstart/bananapi-pi_sm9_uart1.jpg[bananapi-pi_sm9_uart1.jpg]

=== 发送
使用脚本发送
```bash
admin@sophon:~/storage-hot-sda1$ cat uart_send.sh
#!/bin/bash

# 检查传入的参数数量是否正确
if [ $# -ne 2 ]; then
    echo "用法: $0 <串口设备名称> <波特率>"
    echo "示例: $0 /dev/ttyS1 9600"
    exit 1
fi

# 获取传入的串口设备名称和波特率
serial_device=$1
baud_rate=$2

# 配置串口设备
sudo stty -F $serial_device $baud_rate raw

# 要发送的数据
data="hello, hdzk!\r\n"

# 无限循环发送数据
while true; do
    echo -e "$data" | sudo tee $serial_device > /dev/null
    if [ $? -ne 0 ]; then
        echo "数据发送失败。"
        break
    fi
    sleep 1
done
```

== 实时时钟

使用前请在 SM9 中安装 CR1220 纽扣电池。

. 查看当前时钟使用命令： 
+
`sudo hwclock -r --show`

. 设置时钟： 
+
`sudo date -s "20xx-xx-xx 09:09:55"`

. 同步到硬件时钟： 
+
`sudo hwclock --systohc`


. 断电重启，然后检查时钟： 
+
`sudo hwclock -r --show`

. 如果重启后时间保持正确，则 RTC 工作正常。

== 摄像头

WARNING: 两个摄像头接口不能同时使用。

=== CAM1

TIP: 接口位于 JP7 附近。 

如果您使用其他 MIPI 摄像头，请先卸载该摄像头的驱动程序： 
`rmmod /mnt/system/ko/v4l2_csi0_ov5647.ko`

. 将 I2C 切换到 CSI2：
+
`echo 8 > /proc/zkwl/gpio`

. 安装驱动程序： 
+
`sudo insmod /mnt/system/ko/v4l2_csi2_ov5647.ko`

. 创建视频流：
+
`cd /opt/sophon/sophon-soc-libisp-dev_1.0.0/bin/`
+
`sudo ./CviIspTool.sh`

. 使用 VLC 等视频软件拉取该视频流。

image::/bpi-sm9/bpi-sm9-gettingstart/bananapi-pi_sm9_csi1.jpg[bananapi-pi_sm9_csi1.jpg]
