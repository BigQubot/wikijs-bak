== 第一件事

使用一个 USB-C 电缆具有电源和数据功能，用于连接
BPI-Centi-S3 开发板连接到您的计算机。

A `CIRCUITPY` 电脑文件管理页面会重新出现磁盘。

> BPI-PicoW-S3 预装了 **微小UF2** 和 **CircuitPython** 开箱即用的固件。推荐使用 CircuitPython 快速开始使用 BPI-PicoW-S3 开发板，因为它被认为是对初学者最友好的平台。
