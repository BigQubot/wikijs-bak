== 外部硬件要求

USB 转 UART 模块（CH340、CP2102 等）。

== 软件要求

串口调试软件（例如 https://putty.org/[PuTTY]），以及 USB 转 UART 模块所需的驱动程序。

== 接线参考

通过 USB 将 BPI-Leaf-S3 连接到计算机；将 USB 转 UART 模块的 RX 接到 GPIO17（BPI-Leaf-S3 的 TX），TX 接到 GPIO18（BPI-Leaf-S3 的 RX），GND 接到 GND（共地）。再将 USB 转 UART 模块的 USB 接口连接到计算机；可以使用连接 BPI-Leaf-S3 的同一台计算机，也可以使用另一台计算机。

== 运行结果

在连接 BPI-Leaf-S3 的计算机上，MicroPython REPL 每秒输出一次从 USB 转 UART 模块接收到的数据。

在连接 USB 转 UART 模块的计算机上，串口调试软件窗口会每秒显示一次 BPI-Leaf-S3 发出的 `Hello World!`。

== 代码
```
from machine import UART
import time

uart1 = UART(1, tx=17, rx=18)
# Select the UART interface and specify the pins used by TX and RX

uart1.init(115200, bits=8, parity=None, stop=1)
# Initialization, set the baud rate, set the number of characters, set the parity, set the stop bit


def test():
     for i in range(50):
         uart1.write('Hello World!') # write data
         time. sleep(0.5)
         print(uart1. read()) # read data
         time. sleep(0.5)


test()

```
