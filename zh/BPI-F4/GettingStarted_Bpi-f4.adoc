= BPI-F4 简介

Banana Pi BPI-F4 工业控制板采用凌阳 SP7350 四核 Arm Cortex-A55 处理器，并集成 4.1 TOPS NPU。它提供丰富的 I/O 接口，可连接多种外部设备，为用户开发 AI 软件和应用提供紧凑、稳定的平台。

BPI-F4 是 Banana Pi 开源社区与凌阳科技联合开发的官方开源硬件开发板。

TIP: 更多信息：link:/en/BPI-F4/BananaPi_BPI-F4[ 香蕉派 BPI-F4]

= 准备 

== 工具准备
* BPI-F4 核心板和底板
* 电源：DC 插头直径为 5.5 mm
** 电源适配器的输出电流必须大于 1 A。
* 系统安装介质（任选一种）
** MicroSD/TF 卡启动
*** 一张 Class 10 或更高等级、容量至少为 8 GB 的 MicroSD/TF（SDHC）卡，以及一个读卡器
*** 以下高速 TF 卡已经 ArmSoM 团队测试：
**** SanDisk 32 GB TF（MicroSD）卡（推荐开发使用）
**** SanDisk 32 GB TF（MicroSD）行车记录仪/监控摄像机存储卡（推荐长期运行使用）
**** 闪迪 TF 8G Class10 microSD
**** 闪迪 TF 128G Class10 microSD XC TF 128G 48MB/S：
** 板载 eMMC 启动


== 可选配件
* USB 键盘和鼠标
* HDMI 显示器和 HDMI 线缆
** BPI-F4 支持 1080p、720p 和 480p 分辨率
* 以太网线
** BPI-F4 支持 10M/100M/1000M 传输
** 网线用于将 BPI-F4 连接到本地网络和互联网
* 摄像头模组
** BPI-F4 支持摄像头功能
** 推荐使用 OV5647 摄像头
* LCD 显示屏

== 将镜像写入 SD 卡
NOTE: 此方法适用于 **Ubuntu** 镜像。
使用 Balena Etcher 写入镜像。 +
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化镜像写入工具，可将操作系统镜像写入 SD 卡或 U 盘。
 
. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标存储设备。 
. 单击“**Flash!**”开始写入。

image::/bpi-f4/bpi-f4-img_photor.png[bpi-f4-img_photor.png,width=80%,height=80%]

. 要从 SD 卡启动，请将启动开关调整为 [1 1 0 0]

. 将 SD 卡插入微型 SD 卡插槽。 

. 插上跳线帽后，开发板会在通电时自动开机；否则需要按住 Wake-up 键 1 秒开机。

image::/bpi-f4/bpi-f4_sdburn.png.png[bpi-f4_sdburn.png.png,width=50%,height=50%]

== 安装镜像到 eMMC

NOTE: link:https://docs.banana-pi.org/en/BPI-F4/BananaPi_BPI-F4#_ubuntu[下载 eMMC 镜像]

首先检查 U 盘的文件系统是否为 FAT32 或 FAT16。 

image::/bpi-f4/bpi-f4_fatr.png[bpi-f4_fatr.png,width=80%,height=80%]

如果不是，可使用以下命令将其格式化为 FAT32；如果已经是 FAT32 或 FAT16，则跳过此步骤。
```sh
sudo umount /dev/sdb1
sudo mkfs.vfat -F 32 -n "DATA" /dev/sdb1
```
将下载的 eMMC 镜像文件解压到 U 盘。

将启动选择开关拨到 USB 模式。

image::/bpi-f4/bpi-f4_usbbootr.png[bpi-f4_usbbootr.png,width=30%,height=30%]

U 盘插入 USB 3.0 Type-A、USB 3.0 Type-C 或 USB 2.0 Type-A 接口时均可用于升级。

将 U 盘插入 USB 3.0 Type-A 接口（无需短接跳线）。

image::/bpi-f4/bpi-f4_typea3.png[bpi-f4_typea3.png,width=30%,height=30%]

将 U 盘插入 USB 3.0 Type-C 接口（使用此接口时必须短接跳线）。

image::/bpi-f4/bpi-f4_typyc.png[bpi-f4_typyc.png,width=30%,height=30%]

将 U 盘插入 USB 2.0 Type-A 接口。

image::/bpi-f4/bpi-f4_typea2.png[bpi-f4_typea2.png,width=30%,height=30%]

上电后，会自动进入升级过程。升级完成后日志如下：

image::/bpi-f4/bpi-f4_emmc_successr.png[bpi-f4_emmc_successr.png,width=60%,height=60%]

烧录完成后关闭电源，将拨码开关设为 1111；再次上电后，开发板将从 eMMC 启动。

image::/bpi-f4/bpi-f4_emmcbootr.jpg[bpi-f4_emmcbootr.jpg,width=60%,height=30%]

= 安装并使用 smzf AI 模型框架
* 1. 首先确认有足够的存储空间
```sh
df -h
```

* 2. 从 GitHub 获取代码
```sh
git clone https://github.com/sunplus-plus1/smzf.git -b master
cd smzf
```

* 3. 子模块默认通过 SSH 拉取。如果尚未配置 SSH 密钥，需要将地址改为 HTTPS
```sh
nano .gitmodules
```
将其中两个 URL 修改为：
```sh
url = https://github.com/sunplus-plus1/nnthirdparty.git
url = https://github.com/sunplus-plus1/model-zoo.git
```

* 4. 拉取子模块
```sh
git submodule sync --recursive
git submodule update --init --recursive --remote
```

* 5. 修改 DNS
```sh
sudo nano /etc/resolv.conf

# 添加以下内容：
nameserver 8.8.8.8
```

* 6. 安装 CMake
```sh
sudo apt update
sudo apt install cmake
```

* 7. 解压以下三个文件
```sh
cd ./nnthirdparty/libtorch
tar -xzf libtorch.tar.gz

cd ..
cd ffmpeg/
tar -xzf 9.2.tar.gz

cd ..
cd opencv/
tar -xzf 4.2.tar.gz
```

* 8. 解压完成后编译项目
```sh
cd ..
cd ..
./build.sh --c3v
```

* 9. 进入 release 目录，并使用 ldd 检查缺少的依赖
```sh
export LD_LIBRARY_PATH=$(pwd)/lib:$(pwd)/nnthirdparty/jsoncpp/lib:$(pwd)/nnthirdparty/NADKLogger/lib:$(pwd)/nnthirdparty/NADKRoutines/lib:$(pwd)/nnthirdparty/nnbase/lib:$(pwd)/nnthirdparty/libtorch/lib:$LD_LIBRARY_PATH
```

* 10. 运行 AI 模型；以下以摄像头图像检测为例
```sh
./bin/nnModel -m Yolo11sDetectionHybridI8 -v /dev/video42
```

== WiFi
=== 在服务器版镜像中通过命令行连接 WiFi

1. 首先，打开终端。

2. 使用 nmcli dev wifi 命令扫描可用的 WiFi 热点：

1. 启用 WiFi
```sh
nmcli r wifi on
```
2. 扫描 WiFi
```sh
nmcli dev wifi
```

3. 连接 WiFi 网络
```sh
nmcli dev wifi connect "wifi_name" password "wifi_password"
```

=== 桌面版镜像测试方法
1. 单击桌面上的网络配置图标（测试 WiFi 时请勿连接网线）。

2. 连接 WiFi 后，打开浏览器检查能否访问互联网。

== USB
BPI-F4 提供一个 USB 3.0 Type-A 接口、一个 USB 3.0 Type-C 接口和一个 USB 2.0 Type-A 接口。

image::/bpi-f4/bpi-f4_usb.png[bpi-f4_usb.png,width=40%,height=40%]

NOTE: USB 3.0 Type-A 与 Type-C 共用 SP7350 的同一个 USB 3.0 端口，不能同时使用。插上跳线帽时选择 Type-C 接口；不安装跳线帽时选择 Type-A 接口。 

=== 使用 USB 鼠标或键盘

* 1. 将 USB 键盘或鼠标插入开发板的 USB 接口。
* 2. 将开发板连接到 HDMI 显示器。
* 3. 如果键盘或鼠标能正常操作系统，则 USB 接口工作正常（鼠标仅适用于桌面版系统）。

=== 使用 USB 存储设备
* 1. 将 U 盘或 USB 移动硬盘插入开发板的 USB 接口。

* 2. 运行以下命令；如果输出中出现 sdX 设备，则表示 USB 存储设备已被识别：
```sh
sunplus@ubuntu:~$ cat /proc/partitions | grep "sd*"
major minor  #blocks  name
   8        0    3932160 sda
```
* 3. 使用 mount 命令将 USB 存储设备挂载到 /test，然后即可查看其中的文件：
```sh
sunplus@ubuntu:/dev$ sudo mkdir /test
sunplus@ubuntu:/dev$ sudo mount /dev/sda /test/
```

* 4. 挂载后，使用 df -h 命令查看设备容量使用情况和挂载点：
```sh
sunplus@ubuntu:/dev$ df -h | grep "sd"
/dev/sda        3.8G   16K  3.8G   1% /test
```

=== 使用 OV5647 摄像头模块显示实时视频
TIP: link:https://forum.banana-pi.org/t/banana-pi-bpi-f4-sunpuls-sp7350-ov5647-camera-test/24277[视频工作流程]

首先，将 OV5647 摄像头连接到 BPI-F4 开发板。

然后通电启动系统。首次使用 OV5647 摄像头时，请执行以下命令安装工具；已经安装过则跳过此步骤。
```sh
sudo apt update
sudo apt install v4l-utils
```
image::/bpi-f4/5fe0af92368088a2b91ded6dde61c4a1.png[5fe0af92368088a2b91ded6dde61c4a1.png,width=70%,height=70%]

连接 HDMI 显示器，在 Ubuntu 桌面环境中打开终端，然后输入以下命令显示 OV5647 摄像头的实时画面：
```sh
ffplay -f v4l2 -i /dev/video42
```
