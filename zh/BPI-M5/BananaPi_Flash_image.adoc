== 将读卡器烧录至 microSD

=== 通过 Etcher 将操作系统映像闪存到 microSD

该方法适合将系统烧录到SD卡上，可用于 Windows, MacOS, 和 Linux x64 操作系统。

准备工作：

 1. 一张 microSD 卡
 2. SD卡读卡器
 3. 下载 Ubuntu / 阿姆比安 / Openwrt 对应产品的系统镜像
 4. 将SD卡插入SD读卡器，然后将SD卡读卡器插入 USB 计算机端口
 
=== 通过 Etcher 将操作系统映像闪存到 microSD

* 从链接下载 balenaEtcher： https://etcher.balena.io/[巴莱纳官方网站] 并选择指定的主机系统进行下载。程序格式为 Linux 这是应用程序图像。
* 将需要烧录的MicroSD卡插入MicroSD读卡器
* 打开etcher窗口，首先从文件中选择Flash，找到您的镜像下载位置，然后双击选择它。

image::/bpi-m5pro/flash_imae_1.png[flash_imae_1.png]

* 然后单击选择目标并选择您要刻录的 MicroSD 卡。
* 点击Flash，等待刻录成功，需要一些时间。
* 如果烧录成功，会显示如图所示。

image::/bpi-m5pro/flash_imae_2.png[flash_imae_2.png]

NOTE: 燃烧失败
 1. 的 windows 刻录镜像需要“以管理员身份运行”。一些 Linux 用户可能需要通过 chmod 命令修改它以作为可执行文件运行。
 2. 如果刷新操作系统映像时出现错误，请重试。
 
=== 通过 Win32DiskImager 将操作系统映像闪存到 microSD

* link:https://win32diskimager.org/[下载] 闪存工具 Win32DiskImager
* 打开 Win32DiskImager
* 单击文件夹图标按钮并选择要闪烁的镜像
* 完成以上操作后，点击写入按钮开始烧写镜像，然后等待镜像写入完成。

该软件主要有三个部分，分别是下载镜像 (根据地址即可烧录镜像)、升级固件和高级功能。

=== 刻录图像 MASKROM/Loader 模式
该模式适用于未烧录到系统或烧录后的系统损坏无法运行的产品 (适应所有条件)

我们打开RKDevTool烧录工具并将产品设置为进入烧录模式。

请参考产品相关说明进行操作。不同产品进入Maskrom模式的方法基本相同。

1. 准备用于图像刻录的 Type-C 电缆
2. 断开可能为产品供电的所有连接，例如电源线、USB电缆等
3. 使用一根Type-C线，一端连接产品的OTG接口，另一端连接电脑的OTG接口 USB 界面，然后打开软件RKDevTool
4. 按住 MASKROM/Recovery 按钮，然后使用直流电为产品供电
5. 等待软件提示找到 MASKROM/LOADER 装置 (如下图所示)，然后松开按钮
6. 如果不成功，请重复步骤 2-5。

开始烧录系统

NOTE: 编程失败分析
如果烧录过程中出现Download Boot Fail，或者烧录过程中出现错误，如下图所示，一般是由于烧录器接触不良造成的 USB 使用的电缆、线材劣质或计算机驱动能力不足 USB 端口。请更换 USB 电缆或计算机故障排除 USB 端口。

MASKROM 模式编程和加载器模式编程之间有什么区别？

* Maskrom：当Flash固件没有烧录时，芯片会启动进入Maskrom模式，可以烧录初始固件；如果开发调试过程中Loader无法正常启动，也可以进入Maskrom模式烧录固件。
* Loader：原理是uboot启动时检测到该引脚被按下。在Loader模式下，可以对固件进行编程和升级。您可以使用工具单独刻录分区镜像文件，以方便调试。
