= RK神经网络 SDK 快速入门指南

* 开发板：ArmSoM-W3、ArmSoM-Sige7、ArmSoM-Sige5、ArmSoM-AIM7

* 操作系统： Debian11/12

* 目的：本文介绍如何使用RK的 NPU SDK.

作为高性能8nm AIOT平台 Rockchip, 的 RK3576/RK3588 NPU 拥有强大的能力，其设计能够实现高达6TOPS的高效神经网络推理计算。这使得 RK3576/RK3588 擅长图像识别、语音识别、自然语言处理等人工智能领域。

此外， NPU 的 RK3576/RK3588 支持各种学习框架，包括TensorFlow、PyTorch、Caffe、MXNet等人工智能开发中流行的学习框架。这为开发者提供了丰富的工具和库，使他们能够轻松地进行模型训练和推理，有效解决各种大数据计算场景。

= 典型应用 RK3576/RK3588 NPU

计算机视觉： NPU 可用于图像识别、物体检测、人脸识别等任务。它在安全监控、自动驾驶、医学图像分析等领域有着广泛的应用。

自然语言处理 (自然语言处理): 的NPU加速文本分类、情感分析、机器翻译等任务，使处理大规模文本数据更加高效。

语音识别和处理：在语音识别、语音合成和相关任务中， NPU 提高处理速度和准确性，应用于智能语音助手、语音交互系统等。

智能家居和物联网： NPU低功耗特性使其适合智能家居设备、智能监控摄像头、可穿戴设备等物联网应用，实现设备智能化和自动化。

医疗保健：在医学图像分析、疾病诊断、基因组学等领域， NPU 加速大规模数据的处理和分析，协助医疗专业人员更准确的疾病诊断和治疗方案制定。

智能交通：在智能交通系统中， NPU 可用于车辆识别、交通流量监控、智能交通信号控制等任务，提高交通系统的效率和安全性。


= Rockchip NPU SDK

Rockchip's NPU SDK 包括两部分：PC端工具rknn-toolkit2，用于PC端的模型转换、推理和性能评估。具体来说，它将Caffe、TensorFlow、TensorFlow Lite、ONNX、DarkNet、PyTorch等主流模型转换为RKNN模型。这些RKNN模型可以用于PC端的推理模拟，计算时间和内存开销。在板卡端，有rknn运行环境，其中包括一套C API 库，用于与通信的驱动程序模块 NPU、可执行程序等

RKNN软件堆栈帮助用户快速部署AI模型 Rockchip 筹码。整体框架如下：

image::/bpi-m5pro/bpi-m7_rkllm.png[bpi-m7_rkllm.png]

要使用RKNPU，用户需要首先在计算机上运行RKNN-Toolkit2工具，将训练好的模型转换为RKNN格式的模型，然后使用RKNN C API 或 Python API 用于开发板上的推理。

* RKNN-Toolkit2是一款用于在PC和PC上进行模型转换、推理和性能评估的软件开发套件 Rockchip NPU 平台。

* RKNN-Toolkit-Lite2 提供了 Python 编程接口 Rockchip NPU 平台，帮助用户部署RKNN模型，加速AI应用落地。

* RKNN 运行时提供 C/C++ 编程接口 Rockchip NPU 平台，帮助用户部署RKNN模型，加速AI应用落地。

* RKNPU 内核驱动程序负责与 NPU 硬件。它是开源的，可以在 Rockchip 内核代码。

== 注意事项

* 1.使用rknn-toolkit2版本大于或等于1.4.0。
* 2.切换到自己训练的模型时，注意对齐anchor等后处理参数，否则可能会导致后处理解析错误。
* 3.官方网站及Rockchip预训练模型可检测 80 类物体。如果使用自己训练的模型，则需要更改OBJ_等级_NUM 和 NMS_THRESH 后处理参数 include/postprocess.h.
* 4.演示需要支持 librga.so。编译和使用请参考 https://github.com/airockchip/librga.
* 5.由于硬件限制，本demo中yolov5模型的后处理部分移至 CPU 默认情况下。本演示中提供的模型使用 ReLU 作为激活函数。与Silu激活函数相比，精度略有下降，但性能显着提高。

== Android 演示

1.编译：

一、导入ANDROID_NDK_PATH，例如导出ANDROID_NDK_路径=~/opts/ndk/android-ndk-r18b，然后执行以下命令：

```sh
./build-android.sh -t <target> -a <arch> [-b <build_type>]
Example:
./build-android.sh -t rk3568 -a arm64-v8a -b Release

```

2.推送可执行文件到开发板

连接 USB 将开发板的端口连接到PC上，并将整个demo目录复制到 /data:
```sh
adb root
adb remount
adb push install/rknn_yolov5_demo /data/
```

3.跑步
```sh
adb shell
cd /data/rknn_yolov5_demo/
export LD_LIBRARY_PATH=./lib
./rknn_yolov5_demo model/<TARGET_PLATFORM>/yolov5s-640-640.rknn model/bus.jpg
```

Note: 尝试搜索位置 librga.so 并将其添加到LD_图书馆_路径如果 librga.so 在 lib 文件夹中找不到。使用以下命令添加到LD_图书馆_路径。 +

```sh
export LD_LIBRARY_PATH=./lib:<LOCATION_LIBRGA.SO>
```

== 视频流演示运行命令

* h264 视频
```sh
./rknn_yolov5_video_demo model/<TARGET_PLATFORM>/yolov5s-640-640.rknn xxx.h264 264
```
Note: 需要 H264 视频流。可以使用以下命令进行转换：
```sh
ffmpeg -i xxx.mp4 -vcodec h264 xxx.h264
```

* H265 视频
```sh
./rknn_yolov5_video_demo model/<TARGET_PLATFORM>/yolov5s-640-640.rknn xxx.hevc 265
```
Note: 需要 H265 视频流。可以使用以下命令进行转换：
```sh
ffmpeg -i xxx.mp4 -vcodec hevc xxx.hevc
```

* RTSP 视频流
```sh
./rknn_yolov5_video_demo model/<TARGET_PLATFORM>/yolov5s-640-640.rknn <RTSP_URL> 265
```
