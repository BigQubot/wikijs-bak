== 关于 香蕉派 开源项目
image::/website.jpg[website.jpg]

link:http://www.banana-pi.org/[香蕉派] 是一个开源硬件项目，由 link:https://wiki.banana-pi.org/About_BPI[广东必派科技有限公司]。专注于ARM及MCU系列开源硬件开发板，提供开放的软硬件平台，打造基础技术开发平台。全系列开源硬件产品，完整集成的语音、数据、视频系统平台。开发者可以在开源硬件基础平台上灵活构建各种应用平台。可应用于物联网、AI人工智能、工业互联网控制、STEAM教育等方面。 link:https://wiki.banana-pi.org/Banana_Pi_open_source_community_ecology_and_Internet_of_things_overall_technical_solutions[香蕉派开源社区生态及物联网整体技术解决方案].

欢迎自由讨论 link:http://forum.banana-pi.org/[香蕉派论坛], 由于 Google 安全更新，如果您要使用的图像无法从新链接下载，某些旧链接将无法使用 link:https://drive.google.com/drive/folders/0B4PAo2nW2Kfndjh6SW9MS2xKSWs?resourcekey=0-qXGFXKmd7AVy0S81OXM1RA&usp=sharing[文件] 和 link:https://drive.google.com/drive/folders/0B_YnvHgh2rwjVjNyS2pheEtWQlk?resourcekey=0-U4TI84zIBdId7bHHjf2qKA[图片]

轻松购买样品 link:https://pt.aliexpress.com/store/302756[inoVoip 速卖通网上商店] 和 link:https://www.aliexpress.com/store/1101951077[BPI 速卖通网上商店]

link:https://wiki.banana-pi.org/BPI_4.0_Server[BPI 4.0服务器] 已服务超过200家 link:https://wiki.banana-pi.org/Successful_case[成功案例] 遍布全球，为客户提供研发、生产、供应链管理、产品认证一站式服务。
