= 简介

BPI-4G 模块扩展板带1个非标微型 USB 端口，可以通过此端口连接香蕉pi板，使用4G功能开发。还支持PIN定义，并连接到 BPI-R2。用户还可以选择板载4G模块，使用市场上通用的4G模块。
