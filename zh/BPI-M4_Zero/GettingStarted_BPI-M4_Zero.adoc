= Linux
== 准备

. Linux 镜像支持SD卡或 EMMC 启动时，会先从SD卡启动。
. 建议使用A1级卡，至少8GB。
. 确保可启动 EMMC 如果您想从 SD 卡启动，请格式化。
. 确保 SD 卡已格式化 Linux 如果您想从以下位置启动，镜像会闪烁 EMMC 并使用Sd卡作为存储。
. 下载最新的 [Linux Linux 图片]，并确认md5校验和正确。
. 默认登录： pi/bananapi 或 root/bananapi
. 维基指南仅适用于 [bananapi 4.9 桶 ubuntu/debian 图片].

. 准备好网线和路由器。
. 使用网线将路由器的LAN口连接到路由器的LAN口 BPI-M4 Zero，并将 PC 连接到另一个 LAN 端口。
. 检查 IP 地址 BPI-M4 Zero 在路由器管理界面上，或者在路由器上使用以下命令 BPI-M4 Zero UART 终端检查IP地址。

== 设置静态IP、DNS
. 要设置静态IP，您需要先保持连接。如果您想设置一个 Ethernet 静态IP，您必须首先维护 Ethernet 连接；如果要设置无线网络静态IP，首先必须保持WIFI连接。
. 如果上级路由器已将您要设置的IP地址分配给其他设备，请将其更改为空闲IP，或者要求其他设备放弃该IP。
. 使用 nmcli connection show 命令显示所有连接，例如：
+
```sh
  pi@bpi-m4zero:~$ nmcli connection show
  NAME UUID TYPE DEVICE
  TP-LINK_5G_7747 e4a49726-adf1-44d7-a621-0e3af96cc390 wifi wlx2cc3e6acd5d7
  Wired connection 1 612eda94-55dc-3c85-b05e-f16c41775b4e ethernet --
```
. 使用 nmcli 连接显示 [姓名] 命令显示特定连接的所有属性，例如：
+
```sh
  nmcli connection show TP-LINK_5G_7747
```
 If you want to see Ethernet, change to Wired connection 1
+
只列出三个常见的项目
+
```sh
  ipv4.dns: 192.168.3.1
  ipv4.addresses: 192.168.3.10/24
  ipv4.gateway: 192.168.3.1
```
- 默认为网关地址
- 默认为路由器DHCP分配的IP地址
- 网关地址，默认为路由器的IP地址

. 设置静态IP：
+
```sh
  nmcli connection modify TP-LINK_5G_7747 ipv4.addresses 192.168.3.2
```
. 设置DNS：
+
```sh
  nmcli connection modify TP-LINK_5G_7747 ipv4.dns 8.8.8.8
```
. 重置：
+
```sh
  reboot
```
. 重启后查看是否修改成功：
+
```sh
  ifconfig
  nmcli connection show TP-LINK_5G_7747
```

== 传输文件
**SCP**

SCP (安全副本) 命令输入Linux系统用于复制文件(s) 以安全的方式在服务器之间进行。

SCP 命令或安全复制允许在本地主机和远程主机之间或两个远程主机之间安全地传输文件。

它使用与 Secure Shell 中使用的相同的身份验证和安全性 (SSH) 协议。

您可以从以下位置复制文件 Windows 终端到一个 Linux 同一 LAN 上的系统。只需确保 Open SSH 客户端已打开并且可以在“设置”>“应用程序”>“可选功能”中查看。

如果您想从以下位置复制文件 Windows 系统到 Linux 系统中，您还需要启用 Open SSH 服务器。

image::/picture/bpi_m4_berry_mobaxterm_6.jpg[bpi_m4_berry_mobaxterm_6.jpg]
scp命令格式为：
```sh
scp [optionals] file_source file_target
```
. [optionals] is an optional parameter, such as -r, which can be used to copy the entire directory recursively.
. 文件_source 要复制的文件或目录。
. 文件_如果最后输入了特定的文件名，target 将复制过去的路径并重命名它。

采取从复制本地文件 Windows 系统到一个 Linux 系统为例。在 Windows 终端，输入：
```sh
PS D:\temp\temp_4> scp ".\hello.txt" pi@192.168.3.12:"/home/pi/Downloads/"
```
您还可以将文件复制到 Linux 系统到本地计算机 Windows 终端：
```sh
PS D:\temp\temp_4> scp pi@192.168.3.12:"/home/pi/Downloads/hello.txt" "D:\temp\temp_4"
```
- 其中 pi@192.168.3.12 是中的用户名 Linux 系统和 IP 地址 BPI-M4 Zero 在局域网中。
- 哪里：”/home/pi/Downloads/hello.txt" 是文件路径 Linux 系统。
- 哪里“D:\temp\temp_4“ 是路径 Windows 系统。
link:https://www.geeksforgeeks.org/scp-command-in-linux-with-examples/[scp参考文档]
