= 简介

BPI-4G 模块扩展板带有一个非标准 Micro-USB 接口，可通过该接口连接 Banana Pi 开发板进行 4G 功能开发；也可通过引脚连接 BPI-R2。用户还可以选择板载 4G 模块，或使用市面上的通用 4G 模块。
