= BPI-M7 显示10高清

image::/bpi-m7/banana_pi_bpi-m7_touch_screen_5.jpg[banana_pi_bpi-m7_touch_screen_5.jpg]

TIP: 更多信息： link:/en/BPI-M7/BananaPi_BPI-M7[香蕉派 BPI-M7]

显示器型号 香蕉派 Display 10 HD1 是一款 ALL O‘clock TFT LCD (薄膜晶体管液晶显示器) 模块。该模型由 TFT 组成 LCD 面板、驱动电路和背光，还具有 10.1 英寸对角线测量的 FHD 有效显示区域(1200 水平 x 1920 垂直像素) 条纹排列的分辨率。通过8位R.G.B信号输入显示16.7M颜色。

image::/bpi-m7/banana_pi_bpi-m7_touch_screen_4.jpg[banana_pi_bpi-m7_touch_screen_4.jpg]

== 一般信息

* 外形尺寸：143×228.70×2.25 (典型值。) 毫米
* 显示面积：135.36(H)×216.58(V) 毫米
* 像素数：1200RGB(H)×1920(V) 像素
* 像素间距：0.1128 (H)×0.1128(V) 毫米
* 像素排列：RGB竖条纹
* 显示模式：IPS
* 表面处理：AG
* 背光：白色 LED
* 系统接口：4通道MIPI
* NTSC: 72（类型） %
* 观看方向：全部观看
* 功耗：待定 mW

= 启用显示叠加

== Ubuntu22.04镜像启用显示覆盖
使用nano打开 /boot/firmware/ubuntuEnv.txt 文件：

```sh
sudo nano /boot/firmware/ubuntuEnv.txt
```
找到“叠加层”=文件中的“关键字，并添加以下内容：

```sh
overlays=armsom-sige7-display-10hd
```
快捷键：Ctrl + S 保存，Ctrl + X 退出

编辑后，重新启动设备以更改 Overlays 设置以支持 Display 10 HD。

== 用于启用显示覆盖的 Armbian 图像

使用nano打开 /boot/armbianEnv.txt 文件：

```sh
sudo nano /boot/armbianEnv.txt
```

查找或添加“叠加层=文件中的“关键字。

```sh
overlays=armsom-sige7-display-10hd
```

快捷键：Ctrl + S 保存，Ctrl + X 退出

编辑后，重新启动设备以更改 Overlays 设置以支持 Display 10 HD。
