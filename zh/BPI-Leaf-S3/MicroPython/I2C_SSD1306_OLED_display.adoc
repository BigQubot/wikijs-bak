SSD1306 OLED 是一种常见的屏幕模块，可使用 I²C 通信协议。它最高支持 128 × 64 像素的单色图像，不支持灰度，每个像素只有亮和灭两种状态。其控制逻辑较为简单，非常适合作为学习单片机驱动屏幕显示的入门项目。

== 外部硬件要求

一个带 I²C 接口的 SSD1306 OLED 屏幕模块，建议选择 128 × 64 像素型号。

== 驱动库下载

TIP: https://github.com/micropython/micropython-lib/blob/master/micropython/drivers/display/ssd1306/ssd1306.py[MicroPython ssd1306.py 驱动程序]

将 ssd1306.py 下载到本地，然后上传至 MicroPython 设备。

== 接线参考
[options="header"]
|=====================
| SSD1306 OLED | 开发板
| GND          | GND  
| VCC          | 3V3  
| SCL          | 16   
| SDA          | 15   
|=====================


== 扫描 I²C 地址

```py
from machine import I2C,Pin

sda_pin=Pin(15,Pin. PULL_UP)
scl_pin=Pin(16,Pin. PULL_UP)

i2c = I2C(1,sda=sda_pin, scl=scl_pin, freq=400_000)
i2c_list = i2c.scan()
i2c_total=len(i2c_list)
print("Total num:",i2c_total)
j=0
for i in i2c_list:
     j=j+1
     print("NO.{0},address:{1}".format(j,hex(i)))
```

SSD1306 的地址通常为 0x3c。

== 显示字符

TIP:  https://docs.micropython.org/en/latest/library/framebuf.html#module-framebuf[MicroPython 帧缓冲区文档]

```py
from machine import I2C, Pin
from ssd1306 import SSD1306_I2C

sda_pin = Pin(15, Pin.PULL_UP)
scl_pin = Pin(16, Pin.PULL_UP)

i2c = I2C(1, sda=sda_pin, scl=scl_pin, freq=800_000)
print(i2c. scan())
oled = SSD1306_I2C(128, 64, i2c, addr=0x3c)


def display():
     # framebuf 库仅支持编码为 32～126 的 ASCII 可打印字符
     oled.text(" !\"#$%&'()*+,-./", 0, 0)
     oled.text("0123456789:;<=>?", 0, 8)
     oled.text("@ABCDEFGHIJKLMNO", 0, 16)
     oled.text("PQRSTUVWXYZ[\]^_", 0, 24)
     oled.text("`abcdefghijklmno", 0, 32)
     oled.text("pqrstuvwxyz{|}~", 0, 40)
     oled. show()


def testAscii():
     # chr() 的返回值是与当前整数对应的 ASCII 字符
     Ascii = ''
     for i in range(32, 127):
         Ascii = Ascii + chr(i)
     for i in range(128, 256):
         Ascii = Ascii + chr(i)
     return Ascii


def display_Ascii():
     # framebuf 库仅支持编码为 32～126 的 ASCII 可打印字符
     oled.text(testAscii()[0:16], 0, 0)
     oled.text(testAscii()[16:32], 0, 8)
     oled.text(testAscii()[32:48], 0, 16)
     oled.text(testAscii()[48:64], 0, 24)
     oled.text(testAscii()[64:80], 0, 32)
     oled.text(testAscii()[80:95], 0, 40)
     oled. show()


if __name__ == "__main__":
     display()
     # print(testAscii())
     # display_Ascii()

# ASCII 可打印字符（字符编码：32～127）
# 32～126 共 95 个字符：32 是空格，其中 48～57 是数字 0～9，
# 65～90 是 26 个大写英文字母，
# 97～122 是 26 个小写英文字母，
# 其余是标点符号、运算符号等。
# 第 127 个字符表示键盘上的 Delete 命令。
# ASCII 扩展码（字符编码：128～255）
# 后 128 个字符称为扩展 ASCII 码。
# 许多基于 x86 的系统支持扩展（或“高位”）ASCII。
# 扩展 ASCII 码允许使用每个字符的第 8 位，
# 从而表示另外 128 个特殊符号、外文字母和图形符号。

```
