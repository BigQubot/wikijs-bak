= 简介

Banana Pi BPI-M6 是新一代单板计算机，采用 Synaptics VS680 四核 Cortex-A73（2.1 GHz）和一个 Cortex-M3 处理器，配备 Imagination GE9920 GPU 及最高 6.75 TOPS 的 NPU。板载 4GB LPDDR4 内存和 16GB eMMC 存储，提供 4 个 USB 3.0 接口、1 个千兆以太网口、1 个 HDMI-RX 端口和 1 个 HDMI-TX 端口。

TIP: 更多信息：link:/zh/BPI-M6/BananaPi_BPI-M6[Banana Pi BPI-M6]

== 规格参数

- Synaptics VideoSmart VS680 四核 Cortex-A73（2.1 GHz）和一个 Cortex-M3 处理器
- Imagination GE9920 GPU
- AI NPU 性能最高 6.75 TOPS
- 系统内存 – 4GB LPDDR4
- 存储 – 16GB eMMC 闪存
- 视频输出 – 1 个 HDMI 输入和 1 个 HDMI 输出
- 网络 – 千兆以太网
- USB – 通过 VL817 Hub 控制器提供 4 个 USB 3.0 端口，另有 1 个仅供电的 USB-C 端口
- 扩展 – 40 针
- 调试 – 3 针调试排针
- 其他 – Reset、Power 和 U-Boot 按键；电源及活动状态 LED
- 电源 – 通过 USB Type-C 端口输入 5 V/3 A
- M.2 Key E（PCIe + MIPI CSI）


= 开发
== 准备

. 准备一条 USB 串口线和一个 5 V/3 A USB Type-C 电源适配器。串口线用于控制台调试，Type-C 线用于下载 Android 镜像。
. Linux 开发需要准备一张至少 8GB 的 SD 卡；Android 仅支持从 eMMC 启动。

== Android
=== 准备

. 下载并安装 SenarySocSystemTool，用于通过 M6 的 USB Type-C 接口写入 Android 镜像；该工具仅支持 Windows。
. 下载最新的 Android 镜像，并确认 MD5 校验值正确。

下载 SenarySocSystemTool：link:https://download.banana-pi.dev/d/ca025d76afd448aabc63/files/?p=%2FTools%2Fimage_download_tools%2FSenarySocSystemToolSetupV1.3.2.1.rar[下载链接]

=== 使用 USB 烧录工具安装镜像

. 打开 SenarySocSystemTool.exe，单击“Browse”，选择镜像所在的 eMMCimg 目录。
+
image::/picture/m6_android_install_1.png[m6_android_install_1.png]

. 按住 Type-C 接口旁边的 USB 按键，并使用 Type-C 线连接计算机。
+
image::/picture/m6_android_install_2.png[m6_android_install_2.png]

. 单击开始烧录，然后等待烧录完成。
+
image::/picture/m6_android_install_3.png[m6_android_install_3.png]
. 烧录成功后按 RST 键，拔下 USB 线，再连接电源适配器启动开发板。
+
image::/picture/m6_android_install_4.png[m6_android_install_4.png]
. 如需擦除 eMMC，可重复上述步骤，但应单击“Erase eMMC”，而不是开始烧录。


== Linux
=== 将镜像写入 SD 卡


使用 Balena Etcher 安装镜像。 +
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

单击“**Flash from file**”选择镜像文件。 

单击“**Select target**”选择目标设备。 

单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

镜像烧录完成后，将 SD 卡插入 BPI-M6；接通电源时按住 SPI 键。

=== 将镜像安装到 eMMC
NOTE: 将镜像烧录到 eMMC 前，建议先擦除 eMMC。操作方法可 link:https://docs.banana-pi.org/zh/BPI-M6/GettingStarted_BPI-M6#_使用_usb_烧录工具安装镜像[参考这里]。

. 首先准备一张可启动的 SD 卡和一个 link:https://docs.banana-pi.org/zh/BPI-M6/BananaPi_BPI-M6[新的 SPI 文件]。
. 打开 SenarySocSystemTool，并切换到“Spi Flash”。

. 把路径改为已下载 SPI 文件所在的位置。

. 按住 Type-C 接口旁边的 USB 按键，使用 Type-C 线连接计算机，然后单击开始烧录。

. 把镜像复制到 USB 存储设备并插入 M6，再插入 SD 卡并上电。

. 挂载 USB 存储设备。
+
```sh
mount /dev/sda1 /mnt
cd /mnt
```

. 然后使用 dd 命令把镜像写入 eMMC。
+
```sh
dd if=Armbian-bpi-senarytech-trunk_Bananapim6-xxx.img of=/dev/mmcblk0
```

. 等待烧录完成后关闭电源并取出 SD 卡（插入 SD 卡时会优先从 SD 卡启动），然后按住 SPI 键并重新上电，即可从 eMMC 启动。

== HDMI
VS680 HDMI TX 功能特性：

- 支持 HDMI v2.1
- 最高支持 2160p@60 YUV444
- 最高支持 1080p@60、12 位色深
- 最高支持 HDCP 2.2
- 支持 HBR 输出
- 支持 HDR10 和 HLG

=== HDMI TX 软件配置
VS680 目前使用 FB 和 DRM 两种显示框架。

FB 方案源代码文件： +
**syna-release/linux_5_4/drivers/video/syna/source/**

DRM 方案源代码文件： +
**syna-release/linux_5_4/drivers/soc/berlin/modules/drm/**

在配置文件中启用 HDMI TX 功能。配置文件位于 SDK 的 **syna-release/configs/product/vs680_a0_android_baseline_evk/vs680_a0_android_baseline_evk_defconfig**，配置如下：

image::/picture/bpi-m6_hdmi_tx_software_configuration.png[bpi-m6_hdmi_tx_software_configuration.png]

=== 启用 HDCP
```sh
test_disp enable/disable hdcp
test_disp setVersion 1 //set hdcp 1.4
test_disp setVersion 2 //set hdcp 2.2
```

=== 分辨率配置
支持标准：CEA-861-E 视频格式

支持的分辨率： +
**3840x2160p60Hz/30Hz//24Hz** +
**1920x1200@60Hz** +
**1920x1080p@60** +
**1280x700p@60**
	
在命令行上配置分辨率和格式：

test_disp setformat[显示 ID] [分辨率 ID] [位深度] [颜色格式] [宽高比][tgID][vout_mode]

示例：
```sh
test_disp setformat 0 64 2 0
```


== GPIO

=== PWM

BPI-M6 提供三个 PWM 引脚，对应的 GPIO 分别为 GPIO53、GPIO36 和 GPIO37。

image::/bpi-m6/bpi-m6_pwm1.jpg[bpi-m6_pwm1.jpg]

您可以使用以下命令来启用它。

```sh
echo 1 |sudo tee /sys/class/pwm/pwmchip0/export
```

然后可使用以下命令检查 PWM 是否已启用。

```sh
ls /sys/class/pwm/pwmchip0
```

== Wi-Fi 与蓝牙
Wi-Fi 和蓝牙有以下两种使用方式：

. 购买 BPI-M6 CSI · Wi-Fi 扩展板，将其插入 M.2 Key E 接口，再把网卡安装到扩展板上。

. 使用 USB 接口的 Wi-Fi/蓝牙适配器。
