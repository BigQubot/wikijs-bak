= 简介

的“OpenWrt One/AP-24.XY” 路由器板基于 MediaTek MT7981B (Filogic 820) SoC 和 MediaTek MT7976C双频WiFi 6芯片组，首款正式开发板 OpenWRT 开源社区

OpenWrt 一种是基于 MediaTek Filogic 820 SoC 具有 WiFi 6、双频、3×3/2×2、1 个 2.5Gbit 广域网、1 个 1Gbit 局域网、1GB DDR4 RAM, 256 MiB NAND, 16 MiB NOR, M.2 SSD 和 USB 2.0.

OpenWrt 一用 Mediatek的MT7981B SoC 具有 1.3 GHz 双臂 Cortex-a53 内核、1 GB DDR4 RAM 和 256 MiB SPI NAND 存储。它还集成了16 MiB的额外受保护存储作为系统备份，双存储硬件以确保板载系统坚不可摧，最后还集成了M.2。 2230/2242 NVMe PCIe 2 个 X1 端口可用于添加外部存储。并配有用于内部时钟的电池座， OpenWrt 其中一个提供了 USB 2.0 Type-A 和 mikroBUS 扩展端口，为多种技术可能性提供更多接口

OpenWrt 一个是第一个电路板设计OpenWrt开源社区。与 香蕉派 合作设计，该社区还将处理路由器板的制造和分销。的 OpenWrt One/AP-24.XY 路由器应该为项目提供收入来源，例如，用于支付托管和 OpenWrt 会议，香蕉派 通过其分销网络销售该开发板，每售出一台设备，就会向软件自由保护协会捐款 (南达科他州) 专项资金用于 OpenWrt.

== 引导程序设置

NOTE: 请选择 NAND 供经常使用。 NOR适用于“恢复”。

该开关使系统能够从以下任一位置启动 NAND 或或非。

拨码开关向上的位置指示 NAND，而向下的位置表示NOR。

+
link:https://downloads.openwrt.org/snapshots//targets/mediatek/filogic/openwrt-mediatek-filogic-openwrt_one-snand-preloader.bin[openwrt-mediatek-filogic-openwrt_one-snand-preloader.bin]

. 插入 USB 包含 TypeA 两个文件的驱动器。

. 将引导程序设置为 NOR。

. 按住前面的 USER 按钮(Type A接口侧面的按键).

. 等待 LED 变绿。
