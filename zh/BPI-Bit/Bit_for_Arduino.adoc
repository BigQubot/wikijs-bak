= 关于BPI：比特

该产品采用esp-wroom-32模块为核心进行设计，支持wi-fi、蓝牙、BLE等无线通信方式。

BPI 位 (也称为 BPI-bit，风格化为 bpi:bit) 是一款基于 ESP32 32 位 Xtensa LX6 双核处理器的嵌入式系统。它支持Webduino， Arduino, MicroPython 以及 Scratch X 编程环境。

== 使用 Arduino IDE 开发板管理器 (首选)
- 稳定版发布链接： https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

- 开发发布链接： https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_dev_index.json

从 1.6.4 开始， Arduino 允许使用 Boards Manager 安装第三方平台软件包。我们有可用的套餐 Windows、Mac 操作系统和 Linux (32 位、64 位和 ARM).

安装当前上游 Arduino IDE 1.8 或更高级别。当前版本位于 Arduino 网站。开始 Arduino 并打开首选项窗口。在“其他开发板管理器 URL”字段中输入上面的发布链接之一。您可以添加多个 URL，并用逗号分隔。从 Tools > Board 菜单打开 Boards Manager 并安装 esp32 平台(安装后不要忘记从“工具”>“开发板”菜单中选择您的 ESP32 开发板).
