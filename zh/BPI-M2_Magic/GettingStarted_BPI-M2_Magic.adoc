= 产品简介

Banana Pi M2M 是一款采用 ARM SoC 的开发板，在非常小巧的外形中提供了出色的计算性能。板体为 51 mm 见方，搭载 Allwinner A33 四核 Cortex-A7 SoC 和 512 MB DDR3 内存。

TIP: 更多信息：link:/en/BPI-M2_Magic/BananaPi_BPI-M2_Magic[Banana Pi BPI-M2_Magic]

== 规格参数

- 四核 ARM Cortex-A7 CPU，R16
- 512 MB DDR3 SDRAM
- WiFi（AP6212）及板载蓝牙

== Linux
=== 准备

. 准备一张至少 8 GB 的 TF 卡和一根 USB 转串口线。
. 将 USB 转串口线连接到 40 针排针的 UART2，用于内核控制台调试。
+
NOTE: USB 接口旁的三针 UART0 在 BPI 发布的默认镜像中不能用作调试串口，因为 SD 卡与 UART0 复用相同的引脚，而默认镜像需要同时支持 SD 卡和 eMMC。如果只从 eMMC 启动，并希望启用 UART0 作为调试串口且不需要 SD 卡支持，请参阅 link:/en/BPI-M2_Magic/GettingStarted_BPI-M2_Magic#_enable_uart0_for_emmc_only_image_debug[为仅使用 eMMC 的镜像启用 UART0 调试]。
+
image::/picture/m2m_debug_console.jpg[m2m_debug_console.jpg]
image::/picture/m2m_pin_define.png[m2m_pin_define.png]

. 在 **Linux 电脑**上安装 bpi-tools。如果无法访问该网址或遇到其他问题，请前往 link:https://github.com/BPI-SINOVOIP/bpi-tools[bpi-tools 仓库] 手动下载该工具。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验值正确。
. 默认登录账号：pi/bananapi 或 root/bananapi。

=== 使用 SD 卡安装镜像

**Windows**

使用 Balena Etcher 烧录镜像。 +
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux**

可以选择以下两种方法。

- 使用 Linux 上的 bpi-tools 烧录镜像。先将 SD 卡插入 Linux 电脑
+
```sh
$ sudo bpi-copy  xxx-bpi-m2m-xxx.img.zip /dev/sdX
```
- 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先将其卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
$ sudo apt-get install pv
$ sudo unzip -p xxx-bpi-m2m-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```

=== 安装镜像 eMMC

. 准备一张已烧录 Linux 镜像的 SD 卡，并用该卡启动开发板。
. 将 eMMC 镜像复制到 U 盘，把 U 盘插入开发板并挂载。
. 使用 bpi-tools 命令烧录
+
```sh
$ sudo bpi-copy xxx-bpi-m2m-xxx.img.zip /dev/mmcblk1
```
. 也可以使用 dd 命令烧录。如果 mmcblk1p1 和 mmcblk1p2 分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同
+
```sh
   $ sudo apt-get install pv
   $ sudo unzip -p xxxb-bpi-m2m-xxx.img.zip | pv | dd of=/dev/mmcblk1 bs=10M status=noxfer
```
. 烧录完成后，安全关机并取出 SD 卡。

NOTE: 如果 eMMC 以前烧录过 Android 镜像，必须先擦除 Android 的启动分区，再执行步骤 3 或步骤 4。

```sh
   root@bpi-iot-ros-ai:/# echo 0 > /sys/block/mmcblk1/mmcblk1boot0/force_ro                              
   root@bpi-iot-ros-ai:/# echo 0 > /sys/block/mmcblk1/mmcblk1boot1/force_ro                              
   root@bpi-iot-ros-ai:/# 
   root@bpi-iot-ros-ai:/# dd if=/dev/zero of=/dev/mmcblk1boot0 bs=4096 count=1024                        
   1024+0 records in
   1024+0 records out
   4194304 bytes (4.2 MB, 4.0 MiB) copied, 0.421164 s, 10.0 MB/s
   root@bpi-iot-ros-ai:/# dd if=/dev/zero of=/dev/mmcblk1boot1 bs=4096 count=1024                        
   1024+0 records in
   1024+0 records out
   4194304 bytes (4.2 MB, 4.0 MiB) copied, 0.428427 s, 9.8 MB/s
```

== 进阶开发
=== 为仅使用 eMMC 的镜像启用 UART0 调试
. 在 sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex 中启用 UART0 节点并禁用 SDC0 节点。
+
```sh
    --- a/sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex
    +++ b/sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex
   @@ -262,7 +262,7 @@ twi_sda         = port:PE13<3><default><default><default>
    ;uart_type       = 2:2 wire,4:4 wire,8:8 wire, full function
    ;----------------------------------------------------------------------------------
    [uart0]
   -uart_used       = 0
   +uart_used       = 1
    uart_port       = 0
    uart_type       = 2
    uart_tx         = port:PF02<3><1><default><default>
   @@ -803,7 +803,7 @@ led3_active_low             = 1
    ;     that supports SD3.0 cards and eMMC4.4+ flashes
    ;-------------------------------------------------------------------------------
    [mmc0_para]
   -sdc_used          = 1
   +sdc_used          = 0
    sdc_detmode       = 3
    sdc_buswidth      = 4
    sdc_d1            = port:PF00<2><1><2><default>
```

. 构建 BSP 源代码。
. 将引导加载程序文件 SD/bpi-m2m/100MB/BPI-M2M-LCD7-8k.img.gz 复制到 U 盘。BPI 也为这一用途提供了 link:https://download.banana-pi.dev/d/ca025d76afd448aabc63/files/?p=%2FImages%2FBPI-M2M%2FUbuntu16.04%2FBPI-M2M-LCD7-eMMC-only-uart0-debug-8k.img.gz[预构建引导加载程序]。
. 从 eMMC 启动 M2M 开发板，插入 U 盘并将其挂载。
. 将引导加载程序烧录到 eMMC
+
```sh
   $ sudo bpi-bootsel BPI-M2M-LCD7-8k.img.gz /dev/mmcblk0
```
或者
+
```sh
   $ sudo gunzip -c BPI-M2M-LCD7-8k.img.gz | dd of=/dev/mmcblk0 bs=1024 seek=8
   $ sync
   $ sudo umount /dev/sda1
```
. 挂载启动分区，并在 uEnv.txt 中设置内核调试控制台
+
```sh
   $ sudo mount -t vfat /dev/mmcblk0p1 /mnt
```
在 /mnt/bananapi/bpi-m2m/linux/lcd7/uEnv.txt 中将 console=ttyS2,115200 改为 console=ttyS0,115200
+
```sh
   $ sudo umount /dev/mmcblk0p1
```
. 安全关闭开发板电源，并将调试串口连接到 UART0 三针排针。
