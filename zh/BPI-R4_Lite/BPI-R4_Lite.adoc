= 简介

Banana Pi BPI-R4 Lite 路由器开发板采用 MediaTek MT7987A 四核 Arm Cortex-A53 处理器，板载 2 GB DDR4、8 GB eMMC、256 MB SPI-NAND、32 MB SPI-NOR 和 MicroSD 卡槽。网络接口包括 1 个 2.5G SFP、1 个 2.5G RJ45 WAN 和 4 个千兆 RJ45 LAN；另有 USB 3.0 接口、1 个通过 USB 3.0 连接 5G 模块的 M.2 Key B 插槽、1 个供 Wi-Fi 7 网卡使用的 PCIe 3.0 双通道 Mini PCIe 插槽（可选两个 PCIe 3.0 单通道 Mini PCIe 插槽）、1 个 USB 2.0 Mini PCIe 插槽，以及 1 个 USB Type-C 调试控制台。它是一款高性能开源路由器开发板。

TIP: 更多信息：link:/en/BPI-R4_Lite/BananaPi_BPI-R4_Lite[Banana Pi BPI-R4_Lite]

== 将镜像烧录到板载 NOR
> 更新 NOR 时，首先将启动开关切换为从 SD 卡启动，并插入一张带有可启动镜像的 SD 卡。系统启动后，将 NOR 镜像烧录到 NOR，最后再把启动方式切换为从 NOR 启动。
{.is-info}

向 NOR 烧录镜像前，请准备一个 U 盘。下面以 OpenWrt 镜像（mtk-bpi-r4lite-NOR.img）为例：

1. 将 NOR 启动用 OpenWrt 镜像（**mtk-bpi-r4lite-NOR.img**）复制到 U 盘。
2. 调整启动开关跳线，使开发板从 SD 卡启动，然后上电。
3. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
4. 执行以下命令，擦除整个 NOR 闪存并将镜像写入 NOR：

+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r4lite-NOR.img of=/dev/mtdblock0
```
5. 关闭 BPI-R4_Lite 开发板电源，拔出 U 盘，并将启动方式切换为从 NOR 启动。

== 将镜像烧录到板载 NAND
> **NAND 中已在出厂时烧录镜像。如需使用，只需切换到相应的启动方式，然后上电。**
{.is-info}


> 更新 NAND 时，首先将启动开关切换为从 SD 卡启动，并插入一张带有可启动镜像的 SD 卡。系统启动后，将 NAND 镜像烧录到 NAND，最后再把启动方式切换为从 NAND 启动。
{.is-info}


向 NAND 烧录镜像前，请准备一个 U 盘。下面以 OpenWrt 镜像（mtk-bpi-r4lite-NAND-2PCIe-1L.img）为例：

1. 将 NAND 启动用 OpenWrt 镜像（**mtk-bpi-r4lite-NAND-2PCIe-1L.img**）复制到 U 盘。
2. 调整启动开关跳线，使开发板从 SD 卡启动，然后上电。
3. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```
4. 执行以下命令，擦除整个 NAND 闪存并将镜像写入 NAND：

+
```sh
mtd erase /dev/mtd0
mtd write mtk-bpi-r4lite-NAND-2PCIe-1L.img /dev/mtd0
```
5. 关闭 BPI-R4_Lite 开发板电源，拔出 U 盘，并将启动方式切换为从 NAND 启动。


== 将镜像烧录到板载 eMMC
> SD 卡和 eMMC 共用同一个 SoC 控制器，因此需要先切换为从 NAND 启动，再将 eMMC 镜像烧录到 eMMC，最后把启动方式切换为从 eMMC 启动。
{.is-info}


向 eMMC 烧录镜像前，请准备一个 U 盘。下面以 OpenWrt 镜像（bl2_emmc.img、mtk-bpi-r4lite-EMMC-NAND.img）为例：

1. 将 eMMC 启动用 OpenWrt 镜像（**bl2_emmc-r4.img**、**mtk-bpi-r4-EMMC-20231030.img**）复制到 U 盘。如果镜像已压缩，请先解压再复制。

2. 将启动开关跳线切换到 NAND，使开发板从 NAND 启动。
 
3. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）

+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```

4. 执行：

+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4lite-EMMC-NAND.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
sync
sync
```
 
5. 关闭 R4_Lite 开发板电源，拔出 U 盘，并将启动方式切换为从 eMMC 启动。

=== Mini PCIe 4G/5G 模块（USB 接口）
BPI-R4_Lite 支持采用 Mini PCIe USB 接口的 4G LTE 模块：**Quectel EC25**

如需在 BPI-R4_Lite 上使用 Mini PCIe 蜂窝模块：

1. 将 4G 蜂窝模块安装到 CN11 插槽中
2. 使用卡托将 Nano-SIM 卡插入 SIM 卡槽（SIM2），注意插卡方向
3. 在模块上安装天线
4. 开机后会自动拨号

> 4G 是否可用取决于当地运营商使用的频段。

== Wi-Fi 7 网卡
将 BPI-R4-NIC 插入 BPI-R4-Main 底部的 CN12 和 CN14，然后用两颗 M2 螺丝固定。

BPI-R4-NIC 模块需要 12 V 供电，因此给 BPI-R4-Main 上电前必须先启用该电源（将 SW4 拨到“ON”位置，上电后 12 V LED 会亮起）。

IMPORTANT: 12 V 电源会通过 Mini PCIe 插槽的 PIN6/28/48 提供给 BPI-R4-NIC。
插接其他模块时，如果无法确认模块能否承受 12 V，请务必关闭 SW4。

=== OpenWrt
OpenWRT MTK MP4.0 WiFi 设置：

所有功能正常后，可以检测到三个 SSID，BE14 上的三个蓝色 LED 也会亮起。
     
==== 启用 WiFi 热点

打开 Web 管理界面，在 config 中配置相应的 STA 热点。
然后单击 Connect 建立连接。
