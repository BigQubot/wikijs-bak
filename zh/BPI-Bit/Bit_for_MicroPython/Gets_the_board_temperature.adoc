= 热敏电阻
该模块用于测量环境温度。由于开发板工作时自身会发热，建议在开发板尚未升温时采集；否则读数会受板载热源影响，最终更接近板温而非环境温度。

因此，开发板开始发热前的初始读数可视为环境温度，随后读数会逐渐接近板温。

= 示例代码
```SH
from microbit import *
while True:
   sleep(100)
   temp = temperature() # get temperature ℃
   print(temp)
   display.show(str(temp))
```
