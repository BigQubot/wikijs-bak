= 简介
Banana Pi R1 是一款路由器开发板，采用与经典版 Banana Pi M1 相同的 SoC。

R1 是一款开放硬件路由器，可运行 OpenWrt、Android 和 Bananian 等多种开源操作系统。R1 采用纤薄的路由器外形，带有 2.5 英寸硬盘仓，并配备 4 个千兆 LAN 端口、1 个千兆 WAN 端口和 300 Mb/s 802.11n 无线网络。

TIP: 更多信息：link:/en/BPI-R1/BananaPi_BPI-R1[Banana Pi BPI-R1]

== 主要特性
- 双核 1.0 GHz CPU
- 1 GB DDR3 内存
- Mali-400 MP2 GPU，支持 OpenGL ES 2.0/1.1
- 4 个千兆 LAN 1 个千兆 WAN

=== 为 R1 烧录首个系统镜像
. 可从官方论坛下载最新系统镜像
. 在 Ubuntu 中安装 bpi-tools。如果无法访问此网址或遇到其他问题，请前往 bpi-tools 代码仓库手动安装。
+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
``` 
. 下载镜像后，将 TF 卡插入 Ubuntu 计算机并执行：
+
```sh
bpi-copy xxx.img /dev/sdx
```
. 完成步骤 3 后，将 TF 卡插入 R1，再按下电源按钮启动 R1。
