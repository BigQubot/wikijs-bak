= 简介

Banana Pi BPI-CM7 是一款基于 Allwinner H618 的计算模块，搭配 BPI-CM7IO 载板使用。

TIP: 更多信息：link:/zh/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7 主页]

== 规格参数

* 主控：Allwinner H618，四核 Cortex‑A53，主频最高 1.5GHz
* GPU：ARM Mali G31
* 内存：板载 LPDDR4
* 存储：板载 eMMC
* 无线：K019-CW43-Dw Wi-Fi 5 和蓝牙 5.0
* USB：1 路 USB2.0 OTG，3 路 USB2.0 Host
* 显示：HDMI 输出、CVBS 复合视频输出
* 网口：1 路 10/100M 以太网
* 扩展：microSD 卡槽、2 组 100pin 板对板连接器

= Linux 开发

== 准备
. Linux 镜像支持 SD 卡或 eMMC 两种启动方式；插入 SD 卡时，板子优先从 SD 卡启动。
. SD 卡推荐：容量≥8GB，A1 等级存储卡。
. 若从 SD 卡启动：建议提前格式化 eMMC，清除原有系统。
. 若从 eMMC 启动，SD 卡仅作存储使用：SD 卡需提前格式化，不要写入系统镜像。
. 下载最新的 link:/zh/BPI-CM7/BananaPi_BPI-CM7#_linux_2[Linux 镜像] 。下载后务必校验 MD5 值，保证镜像完整。
. 镜像烧录工具： link:https://etcher.balena.io/[balenaEtcher] 。
. 默认账号密码： pi/bananapi 或 root/1234。
. 本 Wiki 指南仅适用于 Ubuntu/Debian 类镜像。

== 擦除 eMMC
. 确保 Linux 镜像已烧录到 SD 卡中并插入 SD 卡。插入 SD 卡默认优先 SD 卡启动。
. 终端执行下列命令，列出系统中的硬盘、分区等块设备信息。
+
```bash
lsblk
```

. mmcblk0 是 eMMC，mmcblk1 是 SD 卡。在终端中输入以下命令擦除 eMMC。此过程需要二十多分钟且不可逆，请事先备份重要数据。
+
```bash
sudo dd if=/dev/zero of=/dev/mmcblk0  #向 eMMC 全盘持续写入 0，覆盖所有分区与数据
```

== SSH
. 准备网线和路由器。
. 用网线将路由器的一个 LAN 口连接到 BPI-CM7，并将 PC 连接到另一个 LAN 口，保持在同一局域网下。
. 在 BPI-CM7 上打开终端
+
```bash
ip a                     # 查看 ip 地址
systemctl is-active ssh  # 查看 ssh 服务当前运行状态
```

== 传输文件
**SCP（secure copy，安全复制）**是 Linux 系统中用于在服务器之间安全复制文件的命令。

. 在 Windows 安装 **OpenSSH**。
. 安装成功后，以管理员身份运行 **PowerShell**。
. 输入被控设备的 **用户名** 和 **IP**。

+
```bash
scp C:\BPI\1.wav pi@10.0.35.168:~/Music  # 从 Windows 发送 1.wav 文件到 BPI-CM7
pi@10.0.35.168:~/Documents/1.txt .\      # 从 BPI-CM7 发送 1.txt 文件到 Windows
```

. 如果板子重刷系统、重装 ssh、换了同 IP 的另一块开发板，远程主机密钥变更，Windows OpenSSH 的 `known_hosts` 里还存着这台 `10.0.35.168` 旧的指纹，校验失败，scp 直接断开连接。
+
```bash
ssh-keygen -R 10.0.35.168  # 删除 ip 的旧记录
```

== 查看 BPI-CM7 开发板硬件与系统信息
这一组命令用来**一次性读取开发板的系统版本、硬件型号、CPU、内存、存储分区、根文件系统挂载信息**，方便确认板子硬件、内核、启动介质（SD 卡 /eMMC）。
```bash
hostnamectl                                  # 查看操作系统版本、主机名、内核版本、架构
tr '\0' '\n' < /proc/device-tree/model       # 读取设备树里的硬件型号，输出**板子型号**
tr '\0' '\n' < /proc/device-tree/compatible  # 查看设备树兼容型号，用于确认芯片平台
uname -a                                     # 查看完整内核信息、架构、编译时间
lscpu                                        # 查看CPU 核心数、架构、频率等处理器信息
free -h  # 查看内存与 swap 大小，`-h` 自动用 GB/MB 友好单位展示
lsblk    # **列出块存储设备**（eMMC、SD 卡、U 盘等）
findmnt -no SOURCE,FSTYPE,SIZE,USED,AVAIL,USE%,TARGET /  # 查看**根分区 /**：磁盘来源、文件系统、总容量、已用 / 剩余空间、占用率
```

== 无线网络

=== WiFi 连接
```bash
nmcli device                                           # 查看网口硬件状态
nmcli device wifi list                                 # 列出可用的无线网络接入点
nmcli device wifi connection R4Pro-5G password ******  # 连接 WiFi
nmcli device disconnect wlan0                          # 断开WiFi
```

=== 创建 AP 热点
. 建立 AP
+
```bash
nmcli device wifi hotspot con-name AP1 ifname wlan0 ssid Annick password 88888888
```

. 确认主机热点转发与 NAT 规则。
+
```bash
ip a show wlan0                          # 查看 wlan0 的地址（10.42.0.1）
cat /proc/sys/net/ipv4/ip_forward        # 确认 IP 转发开启（如果是0，临时开启 sudo sysctl -w net.ipv4.ip_forward=1）
sudo iptables -t nat -L POSTROUTING -nv  # 查看 nat 表中 POSTROUTING 链的规则
```

. 连接热点 Annick，把手机的 ipv4 地址配置为固定 IP：10.42.0.100（网段：10.42.0.x），还要配置 DNS：223.5.5.5
+
```bash
ip neigh show dev wlan0  # 确认是否连接上热点
```

. 连通性验证
+
（1）手机 ping 网关：ping 10.42.0.1，能通代表手机到板子 WiFi 链路正常。

+
（2）手机 ping 外网：ping 223.5.5.5，通则上网正常。

. 断开创建的 AP 热点
+
```bash
nmcli connection down AP1  # 停止热点
nmcli connection show      # 查看当前所有连接（-- 代表已经停止）
```

. 如果想重新启动 AP1
+
```bash
nmcli connection up AP1
```

. 彻底删除 AP1 的配置（一定要先停止 AP1 再删除 AP1 的配置，否则直接删除 AP1 的配置会连同 wlan0 一起删除！）
+
```bash
nmcli connection delete AP1
```

=== WiFi 射频模块开关
. 关闭 WiFi 射频模块，wlan0 直接断电，创建的 AP 热点立刻消失，所有 WiFi 功能全部停用，如果没删除 AP1 的配置文件，就还保留在系统里。
+
```bash
nmcli radio wifi off
nmcli radio # 查看无线射频开关
```

. 打开 WiFi 射频模块，WiFi 硬件恢复供电
+
```bash
nmcli radio wifi on
nmcli radio  # 查看无线射频开关
```

== 设置静态 IP 和 DNS
设置静态 IP 前，需要先建立并保持相应的网络连接，以设置以太网静态 IP 为例。
```bash
nmcli connection show                       # 显示所有连接
nmcli connection show "Wired connection 1"  # 显示指定连接的全部属性
nmcli connection modify "Wired connection 1" ipv4.addresses 10.0.35.4/24  # 设置静态 ip 和子网掩码
nmcli connection modify "Wired connection 1" ipv4.dns8.8.8.8              # 设置 dns
reboot  # 重启
```
测试连通性。

. ping 网关：板子和路由器之间物理 / 内网链路正常，IP 配置没问题。
+
```bash
ping 10.35.0.1
```

. ping 公网 IP：内网正常，路由器已经可以访问互联网，路由没问题。
+
```bash
ping 223.5.5.5
```

. ping 域名：DNS 解析工作正常。
+
```bash
ping baidu.com
```

== 网络时间同步

测试所用镜像通过 Chrony 进行网络时间同步。

使用以下命令检查系统时钟、同步状态、Chrony 服务和时间源。

```bash
timedatectl status       # 查看系统全局时间、时区、RTC 硬件时钟、NTP 自动同步开关状态
systemctl status chrony  # 查看 chrony 服务本身
chronyc tracking         # 查看时间同步跟踪详情
chronyc sources -v       # 列出所有 NTP 时间源
date                     # 打印系统当前日期时间
```

使用以下命令管理 Chrony 服务。

```bash
sudo systemctl start chrony    # 启动 chrony 服务
sudo systemctl enable chrony   # 设置 chrony **开机自启动**
sudo systemctl restart chrony  # 重启 chrony 服务
```

使用以下命令列出或更改时区。

== 查看硬件温度

使用以下命令识别 4 个 thermal zone。

```bash
cat /sys/class/thermal/thermal_zone0/type
cat /sys/class/thermal/thermal_zone1/type
cat /sys/class/thermal/thermal_zone2/type
cat /sys/class/thermal/thermal_zone3/type
```

使用以下命令读取温度。

```bash
cat /sys/class/thermal/thermal_zone0/temp
cat /sys/class/thermal/thermal_zone1/temp
cat /sys/class/thermal/thermal_zone2/temp
cat /sys/class/thermal/thermal_zone3/temp
```

将每个返回值除以 1000，即可得到摄氏温度。

测试结果：

```text
cpu_thermal_zone: 50.2 °C
ddr_thermal_zone: 51.4 °C
gpu_thermal_zone: 53.4 °C
ve_thermal_zone: 50.8 °C
```

== 使用 U 盘
准备一个已正常分区的 U 盘，并将其插入 BPI-CM7 的 USB 接口。系统识别 U 盘之后，可以在桌面双击打开 U 盘。 

image::/bpi_cm7/bananapi_bpicm7_usb_flash_driver1.jpg[bananapi_bpicm7_usb_flash_driver1.jpg]
在用户的主目录下创建一个单独的目录用于挂载，以便于管理。
```bash
mkdir test_u
```
内核导出的块设备分区表。
```bash
cat /proc/partitions | grep "sd*"
```
将/dev/sda1设备挂载到~/test_u/目录下,如果在你挂载的目录下看不到文件，那就退出目录，再重新进入。
```bash
sudo mount /dev/sda1 ~/test_u/
ls
```
移除 U 盘。
```bash
sudo umount -v /dev/sda1
```
**注意**： U 盘挂载后，如果没有 umount 卸载就直接拔掉。 再次插入，内核就会给新编号 sdb。 卸载完成之后，才可以物理拔掉 U 盘，防止文件损坏。

== Audio-板载
=== 准备
. 一个 **2mm-4p-直针座**。
. 一条 **3.5四极音频母头对PH2.0端子线**。
. 一条 **3.5一分三音视频AV线**。
. 一条 **双头 HDMI 接口** 的线。
. 一个 **AV 转 HDMI 高清转换器**。
. 一台 **带有音频插孔和 HDMI 接口的显示器**。
. 板子上的 4pin 引脚从 **+ ** 开始，定义依次为 **TV_OUT、GND、R、L**。**3.5一分三音视频AV线** 的引脚定义为 **R、L、TV_OUT、GND**。

=== 3.5 mm 音频插孔
. 把 **2mm-4p-直针座** 焊接到板子上。
. **3.5四极音频母头对PH2.0端子线** 的 **PH2.0端子** 按照引脚定义连接主板，另一端的 **3.5四级音频母头** 可以直接插耳机线。
. 打开终端播放音频。
+
```bash
aplay 1.wav
```

=== HDMI 音频
. 把 **2mm-4p-直针座** 焊接至主板。
. **3.5四极音频母头对PH2.0端子线** 的 **PH2.0端子** 按照引脚定义连接主板，另一端的 **3.5四级音频母头** 可以直接插 **3.5一分三音视频AV线** 的 **3.5四级音频公头**。
. **3.5一分三音视频AV线** 的红白黄三根信号线接到 **AV 转 HDMI 高清转换器** 上，**AV 转 HDMI 高清转换器** 需单独供电。
. 把 HDMI 线一端接 **AV 转 HDMI 高清转换器**，另一端接显示屏。
. 打开终端播放音频，仅支持 `.wav` 格式文件。
+
```bash
pactl list short sinks            # 查看 PulseAudio 所有音频输出设备
pactl set-default-sink 0          # 设置默认音频输出设备为编号0 (HDMI Audio)
pactl info I grep "Default Sink"  # 查看当前 PulseAudio 信息
ffmpəg -i 1.ogg -c:a pcm_s16le -ar 48000 -ac 2 1.wav  # 如果音乐文件后缀是.ogg. 需要转换为.wav 才能播放
aplay 1.wav                       # 播放音乐（如果设置好了还是不能听见声音，可以重启一下板子）
speaker-test -D plughw:1,0 -c 2 -r 48000 -t sine      # 没有音乐也可以直接播放正弦波
pactl set-sink-volume 0 100%                          # 控制音量
```
**注意**：硬件链路搭建完成后画面清晰度有限，输出分辨率为 720P。
