= BPI-F4 简介

香蕉派 BPI-F4 采用凌阳 SP7350 Quad ARM Cortex-A55 和 4.1 Tops 的工业控制板设计 NPU,形成了4.1 TOPS AI平台，具有广泛的 I/O 与外部设备连接的选项。它提供了一个紧凑而强大的环境，使客户能够开发自己的人工智能软件和应用程序

BPI-F4 是香蕉派开源社区与凌阳科技联合开发的官方开源硬件开发板

TIP: 更多信息：link:/en/BPI-F4/BananaPi_BPI-F4[ 香蕉派 BPI-F4]

= 准备 

== 工具准备
* BPI-F4 core 板和基板
* 电源：DC Jack插头直径5.5mm
** 适配器供电电流必须大于1A。
* 系统安装 (选择一个)
** 微型SD卡 /TF 卡启动
*** 微型SD卡 card/TF, Class 10 或以上，至少 8GB SDHC 和读卡器
*** 经ArmSoM团队测试的高速TF卡：
**** 闪迪 32GB TF (微型SD卡) (开发商推荐)
**** 闪迪 32GB TF (微型SD卡) 行车记录仪和安全摄像头存储卡 (建议长期运行)
**** 闪迪 TF 8G Class10 microSD
**** 闪迪 TF 128G Class10 microSD XC TF 128G 48MB/S：
** 机上 eMMC 启动


== 可选配件
* USB 键盘和鼠标
* HDMI 显示器和 HDMI 电缆
** BPI-F4 支持1080p、720p、480p分辨率
* Ethernet 电缆
** BPI-F4 支持 10M/100M/1000M 传输
** 网线用于连接 BPI-F4 到本地网络和互联网
* 摄像头模组
** BPI-F4 支持拍照功能
** 我们建议使用 ov5647
* LCD 显示

= 安装并使用smzf AI模型框架
* 1.首先确认您有足够的存储空间
```sh
df -h
```

* 2. 检索内容 Github
```sh
git clone https://github.com/sunplus-plus1/smzf.git -b master
cd smzf
```

* 3.拉取子模块默认使用SSH。我还没有配置密钥，所以需要将其更改为HTTPS
```sh
nano .gitmodules
```
修改两个网址：
```sh
url = https://github.com/sunplus-plus1/nnthirdparty.git
url = https://github.com/sunplus-plus1/model-zoo.git
```

* 4.接下来，拉取子模块
```sh
git submodule sync --recursive
git submodule update --init --recursive --remote
```

* 5.修改DNS
```sh
sudo nano /etc/resolv.conf

#Add the following content:
nameserver 8.8.8.8
```

* 6.安装CMake
```sh
sudo apt update
sudo apt install cmake
```

* 7.解压三个文件
```sh
cd ./nnthirdparty/libtorch
tar -xzf libtorch.tar.gz

cd ..
cd ffmpeg/
tar -xzf 9.2.tar.gz

cd ..
cd opencv/
tar -xzf 4.2.tar.gz
```

* 8.解压后
```sh
cd ..
cd ..
./build.sh --c3v
```

* 9.进入release目录，使用ldd查找缺少的依赖
```sh
export LD_LIBRARY_PATH=$(pwd)/lib:$(pwd)/nnthirdparty/jsoncpp/lib:$(pwd)/nnthirdparty/NADKLogger/lib:$(pwd)/nnthirdparty/NADKRoutines/lib:$(pwd)/nnthirdparty/nnbase/lib:$(pwd)/nnthirdparty/libtorch/lib:$LD_LIBRARY_PATH
```

* 10.开始使用AI模型。这里我们以摄像头图像检测为例
```sh
./bin/nnModel -m Yolo11sDetectionHybridI8 -v /dev/video42
```

=== 使用OV5647摄像头模块启动实时视频录制
TIP: link:https://forum.banana-pi.org/t/banana-pi-bpi-f4-sunpuls-sp7350-ov5647-camera-test/24277[视频工作流程]

首先，将OV5647摄像头连接到F4板

然后通电并启动系统。如果这是您第一次使用OV5647相机，请执行以下命令；否则，您可以跳过此步骤。
```sh
sudo apt update
sudo apt install v4l-utils
```
image::/bpi-f4/5fe0af92368088a2b91ded6dde61c4a1.png[5fe0af92368088a2b91ded6dde61c4a1.png,width=70%,height=70%]

通过 HDMI 连接，启动终端 Ubuntu 桌面模式，输入以下命令激活OV5647摄像头
```sh
ffplay -f v4l2 -i /dev/video42
```
