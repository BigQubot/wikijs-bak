= 关于 BPI:bit

该产品以 ESP-WROOM-32 模块为核心设计，支持 Wi-Fi、Bluetooth、BLE 等无线通信方式。

BPI:bit（也称 BPI-bit，风格化写作 bpi:bit）是一款基于 ESP32 的嵌入式系统，搭载 32 位 Xtensa LX6 双核处理器。它支持 Webduino、Arduino、MicroPython 和 Scratch X 编程环境。

== 通过数据线连接开发板
使用 Micro USB 数据线将开发板连接到计算机，连接方式与使用 BPI:bit MicroPython 时相同。

请参阅本文档第 2 节“通过数据线连接开发板”。

以下说明介绍如何使用 Arduino IDE 开发板管理器进行安装。

== 使用 Arduino IDE 开发板管理器 (首选)
- 稳定版发布链接： https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

- 开发版链接： https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_dev_index.json

从 1.6.4 版开始，Arduino 支持使用 Boards Manager 安装第三方平台软件包。现有软件包支持 Windows、macOS 和 Linux（32 位、64 位及 ARM）。

安装 Arduino IDE 1.8 或更高版本，当前版本可从 Arduino 官网获取。启动 Arduino IDE 并打开 Preferences（首选项）窗口，在 Additional Board Manager URLs（附加开发板管理器网址）字段中填入上面的一个发布链接。可以添加多个 URL，并用逗号分隔。通过 Tools > Board 菜单打开 Boards Manager，安装 esp32 平台；安装完成后，记得在 Tools > Board 菜单中选择你的 ESP32 开发板。
