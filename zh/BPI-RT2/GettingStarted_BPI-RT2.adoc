= 简介

BPI-RT2 路由器采用 Realtek RTL8198D 方案，是一款适用于小微企业、家庭等网络环境的高性能无线路由器。

BPI-RT2 是一款双频无线路由器，2.4 GHz 2T2R 与 5 GHz 2T2R 可同时工作。四根全向高增益天线提供较强的信号穿透能力和更广的覆盖范围，使数据传输更加顺畅。MU-MIMO 多设备收发技术延迟低，可让多台设备同时稳定连接。

== TFTP


1. 连接串口工具。上电后持续按住 ESC 键，进入启动模式。

image::/bpi-rt2/rt2-uboot.png[rt2-uboot.png]

2. 下载 TFTPD64 工具。

image::/bpi-rt2/rt2-tftp.png[rt2-tftp.png]

3. 使用以太网线连接计算机与开发板，然后在启动模式中查看开发板的 IP 地址。
执行 `printenv`。

image::/bpi-rt2/rt2-printip.png[rt2-printip.png]

然后修改计算机的 IP 地址，使其与开发板处于同一子网；计算机 IP 的最后一个主机号必须为 66。配置如下：

image::/bpi-rt2/rt2-ip.png[rt2-ip.png]

4. 启动 TFTPD64，并把要传输的文件放入 E:\tftp-root。
如果该目录不存在，请在 E 盘新建名为 tftp-root 的目录。
在“Server interfaces”中选择 192.168.1.66。
“Host”输入 192.168.1.6（开发板的 IP 地址）。
“Local File”单击旁边的“...”或“Browse”按钮。
在弹出窗口中进入 E:\tftp-root 目录。
选择要传输的文件并单击“打开”。
保留其余设置不变。

image::/bpi-rt2/rt2-tftp2.png[rt2-tftp2.png]

5. 在串口执行以下命令：tftpboot 0x82000000 ubi_device_img.ubi
（文件名 98D_ubi_device.ubi 必须与“Local File”中选择的文件完全一致。）
串口出现“Loading...”或“TFTP from server...”提示后，立即单击 TFTPD64 中的“Put”按钮。

image::/bpi-rt2/rt2-tftp4.png[rt2-tftp4.png]
image::/bpi-rt2/rt2-tftp5.png[rt2-tftp5.png]

在开发板串口中输入：run updev

6. 再次上传 img.tar，操作过程与上述步骤相同。 

image::/bpi-rt2/rt2-tftp3.png[rt2-tftp3.png]
在开发板串口中输入：run upt
最后，只需重新启动即可。

image::/bpi-rt2/rt2-reboot.png[rt2-reboot.png]

= 双系统备份
== 双备份分区结构

image::/bpi-rt2/bpt-rt2-dualbackup4.png[bpt-rt2-dualbackup4.png]

== 变量含义
`sw_tryactive=0`：尝试启动系统 0（ubi_k0 + ubi_r0）

`sw_tryactive=1`：尝试启动系统 1（ubi_k1 + ubi_r1）

`sw_tryactive=2`：本次启动使用默认系统（由 `sw_commit` 决定）

`sw_commit=0`：默认系统为系统0

`sw_commit=1`：默认系统为系统1

== 启动流程
U-Boot 读取 `sw_tryactive`：

如果 `sw_tryactive`=0 或 1：尝试加载对应的系统。

如果启动成功，U-Boot 会自动把 `sw_tryactive` 设为 2，下次启动默认系统。

如果启动失败（例如内核崩溃或挂载失败），则执行 4.2 故障切换。

如果 `sw_tryactive`=2：直接读取 `sw_commit`，并按其值切换系统。

== 双备份手动切换
在 U-Boot 模式下执行：
```bash
setenv sw_tryactive 0
saveenv
Boot
```
image::/bpi-rt2/bpt-rt2-dualbackup1.png[bpt-rt2-dualbackup1.png]

可以看到系统切换到系统 0（root=31:7）。

image::/bpi-rt2/bpt-rt2-dualbackup2.png[bpt-rt2-dualbackup2.png]

在 U-Boot 模式下执行：

```bash
setenv sw_tryactive 1
saveenv
Boot
```
可以看到系统切换到系统 1（root=31:9）。

image::/bpi-rt2/bpt-rt2-dualbackup3.png[bpt-rt2-dualbackup3.png]

查看当前设置
```bash
printenv sw_tryactive
printenv sw_commit
```
