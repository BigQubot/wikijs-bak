= Linux
== 准备

. Linux 镜像支持从 SD 卡或 eMMC 启动，并优先从 SD 卡启动。
. 建议使用 A1 等级、容量至少为 8 GB 的存储卡。
. 如果要从 SD 卡启动，请确保已格式化可启动的 eMMC。
. 如果要从 eMMC 启动并将 SD 卡用作存储，请确保 SD 卡已格式化且未烧录 Linux 镜像。
. 下载最新的 [Linux 镜像]，并确认 MD5 校验值正确。
. 默认登录账号：pi/bananapi 或 root/bananapi
. 本 Wiki 指南仅适用于 [Banana Pi 4.9 BSP Ubuntu/Debian 镜像]。

== SSH
. 准备好网线和路由器。
. 使用网线将路由器的一个 LAN 口连接到 BPI-M4 Zero，并将电脑连接到另一个 LAN 口。
. 在路由器管理界面中查看 BPI-M4 Zero 的 IP 地址，或在 BPI-M4 Zero 的 UART 终端中使用以下命令查询。
+
```sh
  ifconfig
```
+
```sh
  eth0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST> mtu 1500
        inet 192.168.3.10 netmask 255.255.255.0 broadcast 192.168.3.255
        inet6 fe80::3e1f:688f:81ab:d8b7 prefixlen 64 scopeid 0x20<link>
        ether 02:00:54:a0:d6:a6 txqueuelen 1000 (Ethernet)
        RX packets 553 bytes 92549 (92.5 KB)
        RX errors 0 dropped 0 overruns 0 frame 0
        TX packets 329 bytes 26023 (26.0 KB)
        TX errors 0 dropped 0 overruns 0 carrier 0 collisions 0
        device interrupt 42
```
. 在电脑上打开 SSH 终端软件，例如 link:https://mobaxterm.mobatek.net/[MobaXterm] 或 link:https://www.putty.org/[PuTTY]。
. 以 MobaXterm 为例，在 IP 地址栏中填入获取到的地址（如上例中的 192.168.3.10），在 Port 栏中填入 22。
+
image::/picture/bpi_m4_berry_mobaxterm_3.jpg[bpi_m4_berry_mobaxterm_3.jpg]

. 打开 SSH 终端，输入用户名/密码：pi/bananapi 或 root/bananapi。输入密码时不会显示字符，正常输入并按 Enter 即可。
+
image::/picture/bpi_m4_berry_mobaxterm_4.jpg[bpi_m4_berry_mobaxterm_4.jpg]

== NoMachine 远程桌面
. 确保 BPI-M4 Zero 已连接互联网，然后使用以下命令下载 NoMachine DEB 安装包。
+
```sh
  wget https://download.nomachine.com/download/8.9/Arm/nomachine_8.9.1_1_arm64.deb
```
. 也可以在电脑浏览器中打开 link:https://downloads.nomachine.com/download/?id=117&distro=ARM[NoMachine for ARM - arm64 下载页面]，下载 DEB 安装包，再通过 SSH 或 U 盘复制到 BPI-M4 Zero 的用户目录。
. 下载完成后，通过以下命令进行安装。请注意，文件名以实际下载的文件名为准。
+
```sh
  sudo dpkg -i nomachine_8.9.1_1_arm64.deb
```
. 电脑端也需要下载并安装 NoMachine。在 link:https://download.nomachine.com/[NoMachine 下载页面]中选择适合电脑操作系统的安装包，下载并完成安装。
. 确保电脑和 BPI-M4 Zero 位于同一局域网。可以先尝试建立 SSH 连接，以确认局域网通信正常。
. 在电脑上打开 NoMachine，单击 Add，在新窗口的 Host 栏中输入 BPI-M4 Zero 的 IP 地址，然后再次单击 Add。
+

== 设置静态 IP 和 DNS
. 设置静态 IP 前，需要先建立相应连接：设置以太网静态 IP 时先建立以太网连接；设置无线网络静态 IP 时先连接到 WiFi。
. 如果上级路由器已将目标 IP 地址分配给其他设备，请改用空闲 IP，或让其他设备释放该地址。
. 使用 nmcli connection show 命令显示所有连接，例如：
+
```sh
  pi@bpi-m4zero:~$ nmcli connection show
  NAME UUID TYPE DEVICE
  TP-LINK_5G_7747 e4a49726-adf1-44d7-a621-0e3af96cc390 wifi wlx2cc3e6acd5d7
  Wired connection 1 612eda94-55dc-3c85-b05e-f16c41775b4e ethernet --
```
. 使用 nmcli connection show [NAME] 命令显示指定连接的所有属性，例如：
+
```sh
  nmcli connection show TP-LINK_5G_7747
```
 如需查看以太网连接，请将名称改为 Wired connection 1
+
下面只列出三个常用项目
+
```sh
  ipv4.dns: 192.168.3.1
  ipv4.addresses: 192.168.3.10/24
  ipv4.gateway: 192.168.3.1
```
- 默认值为网关地址
- 默认值为路由器通过 DHCP 分配的 IP 地址
- 网关地址，默认值为路由器的 IP 地址

. 设置静态 IP：
+
```sh
  nmcli connection modify TP-LINK_5G_7747 ipv4.addresses 192.168.3.2
```
. 设置 DNS：
+
```sh
  nmcli connection modify TP-LINK_5G_7747 ipv4.dns 8.8.8.8
```
. 重置：
+
```sh
  reboot
```
. 重启后查看是否修改成功：
+
```sh
  ifconfig
  nmcli connection show TP-LINK_5G_7747
```

== 传输文件
**scp**

Linux 系统中的 scp（secure copy）命令用于在主机之间安全地复制文件。

scp 命令可在本地主机与远程主机之间，或两台远程主机之间安全地传输文件。

它采用与 Secure Shell（SSH）协议相同的身份验证和安全机制。

可以通过 Windows 终端向同一局域网中的 Linux 系统复制文件。请确保已启用 OpenSSH 客户端，可在“设置”>“应用”>“可选功能”中查看。

如果要从 Linux 系统向 Windows 系统复制文件，还需要启用 OpenSSH 服务器。

image::/picture/bpi_m4_berry_mobaxterm_6.jpg[bpi_m4_berry_mobaxterm_6.jpg]
scp 命令格式如下：
```sh
scp [optionals] file_source file_target
```
. [optionals] 是可选参数，例如 -r 可用于递归复制整个目录。
. file_source：要复制的文件或目录。
. file_target：复制目标路径；如果末尾指定了文件名，还会对文件重命名。

以从 Windows 系统向 Linux 系统复制本地文件为例，在 Windows 终端中输入：
```sh
PS D:\temp\temp_4> scp ".\hello.txt" pi@192.168.3.12:"/home/pi/Downloads/"
```
也可以在 Windows 终端中将 Linux 系统中的文件复制到本地电脑：
```sh
PS D:\temp\temp_4> scp pi@192.168.3.12:"/home/pi/Downloads/hello.txt" "D:\temp\temp_4"
```
- pi@192.168.3.12 中的 pi 是 Linux 系统用户名，192.168.3.12 是 BPI-M4 Zero 在局域网中的 IP 地址。
- “/home/pi/Downloads/hello.txt”是 Linux 系统中的文件路径。
- “D:\temp\temp_4”是 Windows 系统中的路径。
link:https://www.geeksforgeeks.org/scp-command-in-linux-with-examples/[scp 参考文档]
