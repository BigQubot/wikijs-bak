= 简介

Banana Pi BPI-CM7 是一款基于 Allwinner H618 的计算模块，搭配 BPI-CM7IO 载板使用。

TIP: 更多信息：link:/zh/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7 主页]

== 规格参数

* 主控：Allwinner H618，四核 Cortex‑A53，主频最高 1.5GHz
* GPU: ARM Mali G31
* 内存：板载 LPDDR4
* 存储：板载 eMMC
* 无线：K019-CW43-Dw Wi-Fi 5 和蓝牙 5.0
* USB：1 路 USB2.0 OTG，3 路 USB2.0 Host
* 显示：HDMI 输出、CVBS 复合视频输出
* 网口：1 路 10/100M 以太网
* 扩展：microSD 卡槽、2 组 100pin 板对板连接器

= Linux 开发

== 准备
. Linux 镜像支持 SD 卡或 eMMC 两种启动方式；插入 SD 卡时，板子优先从 SD 卡启动。
. SD 卡推荐：容量≥8GB，A1 等级存储卡。
. 若从 SD 卡启动：建议提前格式化 eMMC，清除原有系统。
. 若从 eMMC 启动，SD 卡仅作存储使用：SD 卡需提前格式化，不要写入系统镜像。
. Linux 镜像下载：  link:https://pan.baidu.com/s/1u9LFRcJN0m428XSXyWc47Q?pwd=i7wu[Bananapi-Armbian_24.11.1_Bpi-cm7_jammy_legacy_5.4.125_xfce_desktop.img] 。下载后务必校验 MD5 值，保证镜像完整。
. 镜像烧录工具： link:https://etcher.balena.io/[balenaEtcher] 。
. 默认账号密码： pi/bananapi 或 root/1234。
. 本 Wiki 指南仅适用于 Ubuntu/Debian 类镜像。

== 擦除 eMMC
. 确保 Linux 镜像已烧录到 SD 卡中并插入 SD 卡。插入 SD 卡默认优先 SD 卡启动。
. 终端执行`lsblk`，列出系统中的硬盘、分区等块设备信息。
+
```bash
wangshui@bpi-cm7:~$ lsblk
NAME         MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
mmcblk0      179:0    0  29.3G  0 disk
└─mmcblk0p1  179:1    0  29.3G  0 part
mmcblk0boot0 179:16   0     4M  1 disk
mmcblk0boot1 179:32   0     4M  1 disk
mmcblk1      179:48   0  14.8G  0 disk
└─mmcblk1p1  179:49   0  14.7G  0 part /var/log.hdd #挂载在 `mmcblk1p1` → 系统根分区在 mmcblk1
                                       /
zram0        254:0    0 982.5M  0 disk [SWAP]
zram1        254:1    0    50M  0 disk /var/log
```
. mmcblk0 是 eMMC，mmcblk1 是 SD 卡。在终端中输入以下命令擦除 eMMC。此过程需要二十多分钟且不可逆，请事先备份重要数据。

+
```bash
sudo dd if=/dev/zero of=/dev/mmcblk0 #向 eMMC 全盘持续写入 0，覆盖所有分区与数据
#日志
wangshui@bpi-cm7:~$ sudo dd if=/dev/zero of=/dev/mmcblk0 status=progress
31452194304 bytes (31 GB, 29 GiB) copied, 1498 s, 21.0 MB/s
dd: writing to '/dev/mmcblk0': No space left on device
61472769+0 records in
61472768+0 records out
31474057216 bytes (31 GB, 29 GiB) copied, 1502.02 s, 21.0 MB/s
```

=== scp

SCP 使用 SSH 协议，在 PC 与 BPI-CM7 之间安全复制文件。请先确认 PC 和开发板已连接到同一局域网，且 SSH 可以正常登录。

SCP 命令格式如下：

```bash
scp [options] file_source file_target
```

使用 `-r` 递归复制目录。

将本地文件从 PC 复制到 BPI-CM7：

```bash
scp local-file pi@<board-ip>:/home/pi/
```

将文件从 BPI-CM7 复制到 PC：

```bash
scp pi@<board-ip>:/home/pi/remote-file ./
```

测试结果：

```text
Upload to /tmp: successful
Remote file size and SHA-256 verification: successful
Temporary test file removal: successful
```
