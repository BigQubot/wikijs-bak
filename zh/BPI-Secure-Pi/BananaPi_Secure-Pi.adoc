= 概述

Banana Pi BPI-Secure-Pi SP2302 单板计算机 (SBC) 基于 Secure MPU MH1905 核心板，是一款先进的单板计算机，集成了 Megahunt 的 Secure MPU MH1905 和 Linux 操作系统，专为严苛的工业级应用而设计。与 Raspberry Pi 类似，它配备 40 针扩展接口，支持 100Mbps 以太网、WiFi/BLE 无线网卡，提供多样化的连接方式，以及包括四个 USB 端口和 HDMI 输出在内的多种接口。SP2302 是寻求可靠物联网解决方案平台的开发人员的理想之选，它提供增强的性能和安全性，完美适用于从自动化到工业嵌入式系统的各种应用。

BPI-Secure-Pi 基于 Secure MPU MH1905 的安全基础，旨在为您的工业开发项目提供无与伦比的安全性。MH1905 已通过严格的金融级 PCI PTS 6.X 安全认证，显著降低了高标准应用合规的难度和时间。 BPI-Secure-Pi 通过安全启动技术确保可信启动过程，并提供强大的物理攻击防护，例如差分功耗分析 (DPA) 和简单功耗分析 (SPA)。此外，它还包含先进的硬件加密加速功能，支持包括 AES、DES、SHA、RSA 和 ECC 在内的多种算法。这些特性使 BPI-Secure-Pi 成为一个极其安全的平台，是处理敏感数据和在任何物联网或嵌入式应用中执行安全交易的理想之选。

== 主要特点

* 高性能处理器和内存：

** 处理器：MH1905 处理器，Cortex-A5，最高主频 1.2GHz

** 内存：512MB DDR3L，512MB NAND 闪存

* 增强的连接性和接口选项：

** 网络通信：提供以太网、WiFi 和蓝牙等多种连接方式，满足多样化的连接需求。

** HDMI 接口：支持高清输出。

** MIPI 摄像头接口：支持高级成像解决方案。

* 紧凑坚固的设计：

** 尺寸：120mm x 70mm

** 电源：Type-C USB

** 等级：提供商用级和工业级两种选择

* 主板参数和特性：

** 以太网：10/1000M 接口，实现高速网络连接。

** USB 端口：四个 USB 2.0 端口，可连接多种外设。

**兼容GPIO引脚：兼容树莓派2和3的GPIO引脚

**通信：包含用于串行通信的UART接口。

**无线连接：双频2.4GHz/5GHz WiFi和蓝牙模块。

**扩展：Micro SD卡槽以及多种传感器（电压、毛刺、温度、时钟）。

== 高级安全功能

SP2302 凭借其全面的安全防护功能，为嵌入式系统安全树立了新的标杆：

** PCI PTS 6.X 安全认证：符合金融级安全标准。

** 安全启动和主动屏蔽：确保可信的启动过程并抵御物理攻击。

** 防 DPA/SPA 技术：抵御电源分析攻击。

** 防篡改保护：最多支持 10 个通道，有效防止篡改。

** 硬件加密加速：支持多种算法，包括 AES、DES、SHA、RSA、ECC 等，确保快速、安全的数据加密和认证。

== MH1905 应用

* 门禁系统

* 智能家电

* 人机界面 (HMI)

* 自动售货机

* 支付终端/销售点 (POS) 系统

* 电子阅读器

* 一维/二维条码扫描器/二维码扫描器

* 高性能打印机

* 带支付功能的电动汽车充电器

* 电动两轮车控制器和显示屏

* 物联网网关/集成连接
