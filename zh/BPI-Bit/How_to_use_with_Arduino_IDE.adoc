= 阿迪诺 IDE

== 如何设置和启动
=== 需要做好准备

- BPI-UNO32 1 或 BPI：位 1
- 跳线帽 4
- 微型USB 1

=== 快速入门

. 将四个跳帽分别连接到板子顶部，连接RGB LED 到蜂鸣器。然后使用microUSB线将开发板连接到电脑。
