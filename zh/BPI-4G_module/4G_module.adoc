= 使用方法

NOTE: 为确保蜂窝网络信号正常，请连接与所用模块对应的天线。

. 找到对应的 SIM 卡槽并插入 SIM 卡。卡槽大致分为两种。
+
第一种与 BPI-R4 类似，需要先将 SIM 卡装入卡托，再把卡托插入卡槽。
+
image::/bpi-r4/bpi-r4_4g5g_2.jpg[bpi-r4_4g5g_2.jpg]
+
另一种与 BPI-R3 Mini 类似。
+
image::/picture/bpi-r3_mini_cellular.jpg[bpi-r3_mini_cellular.jpg]

. 系统会自动拨号并获取 IP 地址。

. 如果开发板不支持自动拨号，请运行“quectel-CM &”命令手动拨号。

拨号成功后的输出如下：

**EM05-CN**
