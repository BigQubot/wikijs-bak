= 定制 Banana Pi


如果需要针对特定用途定制 Banana Pi，或希望降低量产成本，我们可以提供完整的定制服务，例如移除或增加排针和连接器、调整元件布局、增减元件以及更改接口等。

image::/bpi-4_0-oem-odm/customizepi.jpg[customizepi.jpg]

= 从零开始（ODM）
如果已有产品创意，却缺少研发和制造能力，我们可利用专业经验提供完整的 ODM 服务，帮助您从零开始，并在 45 天内获得样品。

image::/bpi-4_0-oem-odm/odm.jpg[odm.jpg]

= 已有原型（OEM）
如果已经完成产品设计和原型，但缺少制造能力，我们可以协助量产。凭借 13 年的供应链管理经验和量产设施，我们可帮助控制产品质量和交付。

image::/bpi-4_0-oem-odm/oem.jpg[oem.jpg]
