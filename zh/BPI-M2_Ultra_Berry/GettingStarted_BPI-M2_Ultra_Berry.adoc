= 简介

香蕉派 BPI-M2 Ultra 是一款四核迷你单板计算机，内置 Allwinner R40 SoC。它具有 2GB RAM 和8GB eMMC。它还具有板载 WiFi 和 BT。在端口方面， BPI-M2 Ultra 有 2 USB A 2.0端口，1个 USB OTG端口、1个HDMI端口、1个音频插孔、1个DC电源端口、1个SATA端口。

TIP: 更多信息： link:/en/BPI-M2_Ultra/BananaPi_BPI-M2_Ultra[香蕉派 BPI-M2_Ultra]

香蕉派 BPI-M2 Berry 是一款四核迷你单板计算机，内置 Allwinner V40 SoC。它具有 1GB RAM 。它还具有板载 WiFi 和 BT。在端口方面， BPI-M2 Berry 有 4 个 USB A 2.0端口，1个 USB OTG端口、1个HDMI端口、1个音频插孔、1个DC电源端口、1个SATA端口。

TIP: 更多信息： link:/en/BPI-M2_Berry/BananaPi_BPI-M2_Berry[香蕉派 BPI-M2_Berry]

== 规格参数
=== BPI-M2 Ultra
- 四核 ARM Cortex A7 CPU R40
- 2GB DDR3 内存
- 8GB eMMC 存储
- 无线网络 (AP6212) & 板载蓝牙
- SATA接口

=== BPI-M2 Berry
- 四核 ARM Cortex A7 CPU V40.
- 1GB DDR3 内存。
- 无线网络 (AP6212) & 板载蓝牙。
- SATA接口

== Linux
=== 准备

. Linux 镜像支持SD卡或 EMMC 启动
. 建议使用A1级卡，至少8GB。
. M2 Ultra 和 M2 Berry 兼容 Linux 镜像。
. 安装 bpi-tools 在你的 Linux 电脑(如果使用其他工具刷入镜像，请忽略此步骤)。如果您无法访问此 URL 或出现任何其他安装问题，请转至 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源存储库，手动下载并安装此工具。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认md5校验和正确。
. 默认登录： pi/bananapi 或 root/bananapi

=== 将映像安装到 SD 卡
**Windows 电脑**

使用 Balena Etcher 安装映像。 +
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

. 点击“**从文件闪存**”来选择镜像。 
. 点击“**选择目标**”来选择 USB 设备。 
. 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**有两种方法供您选择。**

. 使用 dd 命令安装镜像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2-ultra-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 安装镜像 bpi-tools 上 Linux，插入SD卡 Linux 电脑并运行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2-ultra-xxx.img.zip /dev/sdX
```

=== 安装镜像到 eMMC

. 准备一张SD卡 Linux 镜像闪存和启动板与此 SD 卡。
. 解压镜像并将其复制到 USB 驱动器，将U盘插入板上并安装。（如果自动安装，请忽略此步骤）
+
```sh
mount /dev/sdx /mnt
```
. 有两种安装方式linux镜像到板上。
- 使用dd命令安装。
+
```sh
sudo dd if=/mnt/xxx.bpi-m2-ultra-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 安装 linux 乌磁盘中的镜像 bpi-tools 命令
+
```sh
 $ sudo bpi-copy xxx-bpi-m2-ultra-xxx.img.zip /dev/mmcblk0
```
. 下载完成后，安全关闭电源并弹出 SD 卡。

=== SATA
. 在 M2U 上安装 SATA
+
image::/picture/m2u_sata.png[m2u_sata.png]
+
插入sata接口后，执行
+
```sh
fdisk -l
```
+
image::/picture/m2u_sata_fdisk_l.png[m2u_sata_fdisk_l.png]
+
然后
+
```sh
mount /dev/sdx /mnt/xxx
```
. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：
+
- 创建新分区
+
```sh
fdisk /dev/sdx
```
设置分区数量和大小，创建分区后，输入“**瓦克**” 保存并退出。
- 格式化SATA
+
```sh
mkfs.ext2 /dev/sdx
```
- 坐骑
+
```sh
mount /dev/sdx /mnt/xxx
```
. 成功插入SATA后，我们可以输入以下命令来测试SATA接口：
- 测试读取速度
+
```sh
time dd if=/dev/xxx of=/dev/null bs=1M count=1000
```
- 测试写入速度
+
```sh
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+
image::/picture/sata_test.png[sata_test.png]
