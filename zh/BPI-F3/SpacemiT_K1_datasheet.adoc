== SpacemiT K1介绍

SpacemiT® Key StoneTM K1 是一款高性能、超低功耗的 cpu 集成了 Octa RISC-V 内核 SpacemiT®道一™AI算力部署。 K1具有以下特点： 

* 整合 SpacemiT®自主创新的X60™RISC-V处理器内核，遵循RISC-V 64GCVB架构和RVA22标准。
* „通过探索RISC-V定制指令实现2.0TOPS AI算力扩展 CPU AI融合算力，支持TensorFlow Lite、TensorFlow、ONNX RunTime等主流AI推理框架。
* 通过实施不同粒度的电源岛和不同级别的电源状态，实现超低功耗，使K1更具竞争力和领先优势。 
* 支持全功能接口，丰富更多创新应用和产品。
* 兼容主流操作系统，满足各种应用场景的需求。
* 符合工业级可靠性标准

== CPU 子系统

=== 概述
的 CPU K1的子系统由以下功能组成： 

* 两个不对称 CPU 包括的集群：Cluster0 集成 Quad RISC-V SpacemiT® X60™ 内核具有 2.0TOPS AI-Power 扩展，而 Cluster1 包括四路 RISC-V SpacemiT® X60™ 内核，不具备 AI 功能
* 每个高性能低功耗 SpacemiT® X60™ CPU 内核遵循 RISC-V 64GCVB 架构和 RVA22 标准
* 支持本地中断控制器CLINT和平台中断控制器PLIC
* 遵循RISC-V Debug V0.13.2标准
* CPU 看门狗复位时拍摄的关键信息快照用于调试
* 电源岛和为每个电源岛设计的两级电源策略 CPU 核心和集群实现超节能 

=== SpacemiT® X60™ RISC-V 内核

X60™ 是一款创新、高效的处理器内核， SpacemiT®道一™人工智能创新部署，遵循RISC-V 64GCVB和RVA22标准。为了满足当前和未来的计算需求，它融合了众多DSA技术和微架构优化，为AI应用、机器学习、SLAM等提供强大的计算能力。 X60™内核具有以下特点： 

image::/bpi-f3/cluster_micro-architecture.png[cluster_micro-architecture.png]

* RISC-V 64GCVB 和 RVA22 标准
* 每个核心具有 32KB L1-I 缓存和 32KB L1-D 缓存
* 每个集群有512KB L2 Cache 
* Cluster0 有 512KB TCM (紧耦合内存) 用于AI扩展
* L1 Cache支持MESI一致性协议，L2 Cache支持MOESI一致性协议
* 矢量扩展：RVV1.0/VLEN 256/128-bit x2 执行宽度
* Cluster0中探索和设计的AI定制指令
* 支持CLINT和PLIC，总共256个中断
* 支持RISC-V性能PMU
* 支持SV39虚拟内存
* 支持 32 个符合 RISC-V 安全框架的 PMP 条目
* 支持RISC-V调试框架


=== 中断
平台中断控制器由PLIC和CLINT组成，由两个集群共享。异常处理 (包括异常和中断) 是处理器的一个重要功能，用于将on-the-fly异常转移到相应的核心进行处理。 这些事件包括硬件错误、指令执行错误、用户程序请求和服务的外部中断等。

X60实现处理器核心本地中断控制器 (克林特)，一个内存地址映射模块，用于处理软件中断和定时器中断。

平台级中断控制器 (普里克) 用于采样、优先仲裁，然后分配外部中断源。 在PLIC模型中，每个核的机器模式和管理模式都是有效的中断目标。 PLIC 支持 256 个外部中断源。每个中断都支持电平和边缘格式。

=== 调试和跟踪

调试接口是软件与处理器交互的通道。 用户可以获取该信息 CPU 寄存器和存储器内容，包括其他片上设备信息，通过调试接口。 另外，还可以通过调试接口进行程序下载等操作。

调试系统由调试软件、调试代理服务、调试器和调试接口组成。 其中，调试软件和调试代理服务程序通过网络互连，调试代理服务程序和调试器通过网络连接。 USB，并且调试器与 CPU 通过JTAG接口。

JTAG 内存评估方法可以是 progbuf 或 sysbus 模式。 progbug 模式是一种普通的 JTAG 方法，通过CPU而sysbus是另一种绕过片上资源访问的方法 CPU 通过小企业管理局 (系统总线访问) 端口。
