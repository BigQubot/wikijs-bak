= 简介

香蕉派 BPI-SM9 16-ENC-A3深度学习计算模块搭载高集成计算技术处理器BM1688 8核ARM CA53 1.6GHz、8GB LPDDR4，32GB eMMC 船上。拥有1个RJ45千兆网口、1个M.2 Key E、1个M.2 Key M、4个USB3.2接口、1个TYPE C (USB3.0) 以及多种功能接口。

== 规格参数
* 支持HDMI 2.0输出；
* 支持双千兆RJ45 Ethernet;
* 支持双层USB3.0接口；
* 支持双层WIFI_蓝牙功能；
* 支持TF卡或M.2 SSD 扩张；
* 支持2路MIPI摄像头输入；
* 支持扩展 GPIO;
* 支持CAN功能；
* 支持 USB-C接口升级 (NVIDVI核心板解决方案);

= 开发

== 准备

* 12V/3A 电源适配器(电压范围在 11 至 13 伏之间。使用 12V 电源适配器是最合适的选择。)

* 使用您的 USB-串行电缆(3.3V TTL,波特率=115200) 连接到调试控制台 BPI-SM9

* 一张TF卡(如果您想使用FT卡启动系统)

* 一根 Type-C 电缆 (用于升级编程)

=== 发送
使用脚本发送
```bash
admin@sophon:~/storage-hot-sda1$ cat uart_send.sh
#!/bin/bash

# 检查传入的参数数量是否正确
if [ $# -ne 2 ]; then
    echo "用法: $0 <串口设备名称> <波特率>"
    echo "示例: $0 /dev/ttyS1 9600"
    exit 1
fi

# 获取传入的串口设备名称和波特率
serial_device=$1
baud_rate=$2

# 配置串口设备
sudo stty -F $serial_device $baud_rate raw

# 要发送的数据
data="hello, hdzk!\r\n"

# 无限循环发送数据
while true; do
    echo -e "$data" | sudo tee $serial_device > /dev/null
    if [ $? -ne 0 ]; then
        echo "数据发送失败。"
        break
    fi
    sleep 1
done
```

== 实时时钟

使用前请在 SM9 中安装 CR1220 纽扣电池。

. 查看当前时钟使用命令： 
+
`sudo hwclock -r --show`

. 设置时钟： 
+
`sudo date -s "20xx-xx-xx 09:09:55"`

. 同步到硬件时钟： 
+
`sudo hwclock --systohc`


. 断电重启，然后检查时钟： 
+
`sudo hwclock -r --show`

. 可以确定显示的时间为RTC时钟。
