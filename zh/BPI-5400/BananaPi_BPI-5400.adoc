= 产品说明

BPI-5400 系列模块用于从传统的
5 类双绞线以太网电缆中获取电力，符合 IEEE 802.3af 和 IEEE 802.3at 以太网供电（PoE）标准。

image::/bpi-poe/banana_pi_poe-5400_5.jpg[banana_pi_poe-5400_5.jpg]

BPI-5400 的特征检测与控制电路可提供 PoE 兼容性特征和
供电设备（PSE）所需的功率等级信息，之后 PSE 才会向
端口提供最高 30 W 的功率。

DC/DC 转换器可在较宽的输入电压范围内工作，并提供稳定的
输出；它还内置输出短路保护。


== 特性

* 符合 IEEE 802.3at 和 IEEE 802.3af 标准
* 最大输出功率 30 W
* 输入电压范围 36～57 V
* 集成高效率 DC/DC 转换器
* 输出纹波和噪声低
* 高性能、低成本
* 短路保护
* 变压器隔离，输入与输出之间隔离电压为 1500 V
* 易于使用，所需外部元件极少

== 应用领域
* IP 摄像头
* 无线接入点
* 安防和报警系统
* VoIP 电话
* 销售点网络终端设备

== 功率等级

RT5400B 的功率等级固定为 Class 4。这意味着 IEEE 802.3at Type 1 或 IEEE 802.3af PSE 会默认将其视为 Class 0；而 IEEE 802.3at PSE 会把 Class 4 识别为 Type 2 PD。
