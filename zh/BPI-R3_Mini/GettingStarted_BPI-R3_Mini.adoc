= 简介

香蕉派 BPI-R3 Mini 路由器板带有 MediaTek MT7986A(Filogic 830) 四核ARM A53芯片设计，2G DDR RAM ,8G eMMC 板载flash，是一款非常高性能的开源路由器开发板，支持Wi-Fi6 2.4G/5G 搭配 MT7976C，支持 2x 2.5GbE ethernet 端口。

TIP: 更多信息： link:/en/BPI-R3_Mini/BananaPi_BPI-R3_Mini[香蕉派 BPI-R3_Mini]

=== MediaTek MT7986(Filogic 830)
MT7986(Filogic 830) 集成了四个高达 2GHz 的 Arm Cortex-A53 内核，具有高达 18,000 DMIP 的处理能力和 6Gbps 的双 4x4 Wi-Fi6 连接。有两个2.5g Ethernet 接口和串行外设接口 (SPI). Filogic 830 的内置硬件加速引擎可实现快速可靠的 Wi-Fi 卸载和无线网络连接。此外，该芯片还支持 Mediatek FastPath™技术，适用于游戏， AR/VR 和其他低延迟应用程序。

Wi-fi 6 相比其前身具有许多优势，包括更低的延迟、更大的带宽容量和更快的传输速率。支持6GHz频段的无线网络设备主要利用160MHz宽信道和6GHz不拥塞带宽提供多千兆传输和低延迟Wi-Fi连接，为流媒体、游戏、 AR/VR 和其他应用程序。

== 规格参数

- MediaTek MT7986A(Filogic 830) 四核 ARM Cortex A53
- 无线网络6 2.4G/5G（MT7976C）
- 2G内存 RAM
- 8G eMMC 闪光
- 128MB Nand 闪光
- 2 个 2.5GbE Ethernet 端口
- 1x M.2 钥匙 B USB 接口
- 1x M.2 钥匙 M PCIe 接口
- 1个USB2.0接口

== Linux
=== 安装镜像到板载 eMMC

WARNING: 注意：当你想更新时 EMMC 设备，首先将启动开关更改为启动 Nand 设备，那么启动后，您需要闪存一个 emmc 镜像进入 EMMC 设备。最后你将 bootstrap 更改为 boot from EMMC.

将镜像刻录到之前 eMMC，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r3mini-EMMC-20230719.img, bl2_emmc-r3mini.img) 例如，步骤如下：

. 复制 EMMC 启动 OpenWrt 镜像(mtk-bpi-r3mini-EMMC-20230719.img, bl2_emmc.img) 到 USB 磁盘。
. 更改启动开关跳线，板子从启动开关 Nand 设备，然后给开发板上电。
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt 
```
将目录更改为安装点，这里是： 
+
```sh
cd /mnt
```

. 执行以下命令以启用并将镜像复制到 EMMC 设备：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc-r3mini.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r3mini-EMMC-20230719.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
```
 . 关闭R3MINI板的电源，拔掉电源线 USB 驱动器，并将启动程序更改为从 emmc 设备。
+
WARNING: 注意：启用 EMMC 设备，引导带来自 EMMC.

=== 安装镜像到板载 Nand

WARNING: 注意：当你想更新时 Nand 设备，首先将启动开关更改为启动 EMMC 设备，那么启动后，您需要闪存一个 nand 镜像进入 nand 设备。最后你将 bootstrap 更改为 boot from Nand 设备。

在将镜像刻录到之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r3mini-NAND-20230719-single-image.bin) 例如，步骤如下：

. 复制 Nand 启动 OpenWrt 镜像(mtk-bpi-r3mini-NAND-20230719-single-image.bin) 到 USB 磁盘。
 . 更改启动开关跳线，板子从启动开关 EMMC 设备，然后给开发板上电。
 . 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt
```
将目录更改为安装点，这里是：
+
```sh
cd /mnt
```
. 执行以下命令即可全部擦除 Nand 闪存并将镜像复制到 nand 设备：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r3mini-NAND-20230719-single-image.bin of=/dev/mtdblock0
```
. 关闭电源 BPI-R3 MINI 主板，删除U盘驱动，更改引导程序以启动 Nand 设备。
+
WARNING: 注意：启用 Nand 设备，引导带来自 Nand.

=== jffs2错误解决办法

烧完后 emmc，切换到emmc开机，但串口一直输出jffs2错误。您可以使用下面的方法来解决。

. 首先，切换回 NAND 启动。执行以下命令将零写入 emmc.
+
```sh
dd if=/dev/zero of=/dev/mmcblk0
```
. 然后重新烧录 emmc 根据 link:/en/BPI-R3_Mini/GettingStarted_BPI-R3_Mini#_install_image_to_onboard_emmc[文件].

== 高级开发
=== GPIO 控制
```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
检查底座 gpio，你可以看到我的是411



例如：如果你想改变 gpio 22 作为高级，你需要输入这样的命令：
```sh
echo 433（22+411） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio433/direction
echo 1 > /sys/class/gpio/gpio433/value
```

=== 串口线
因为UART0_调试口的TXD也是wifi band引脚，上电时需要拉低该引脚，

有些串口线有强上拉，如PL2303，如果在上电前插入，会导致wifi芯片无法识别，导致wifi功能失效。

其他型号包括cp2102、ch340、FDTI均可，串口线电源必须是3.3v TTL标准。

您可以在此处购买串行电缆： https://www.aliexpress.us/item/3256805457599756.html

image::/picture/r3mini-usbc2uart.png[r3mini-usbc2uart.png]

如果您的计算机有 USB TypeC 连接器和支架 PD12V/1.5A (20W) 或以上，也可以直接使用电脑供电 BPI-R3mini.

而且，由于 BPI-R3mini 有内置的 USB 对于串口芯片CH340E，不需要使用额外的串口线。

WARNING: 注意：如果您的计算机不支持 USB PD，那么R3mini很可能会不断重启。

因为R3mini的功耗比较大 (所有外设均已插入，运行时功耗接近20W)
