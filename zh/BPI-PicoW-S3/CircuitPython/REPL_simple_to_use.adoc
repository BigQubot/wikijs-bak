. 确保Mu编辑器中开发板连接正确，参考 [配置环境 (穆编辑)](config_mu-editor.md).
. 通常会出现以下信息 CircuitPython REPL 窗口。外观 `>>>` 符号意味着我们可以开始输入命令与之交互。

. 开始在右侧输入命令 `>>>` 符号，例如： `print("Hello World!")`.
> 请注意，使用英文输入法时，无法识别中文字符。 REPL.
+
```py
>>> print("Hello World!")
Hello World!
>>>
```

== REPL 快捷键

. 复制 `ctrl + shift + c`.
. 粘贴 `ctrl + shift + v`.
    Use the left mouse button to drag and select the command to be copied in the REPL, press the copy shortcut key on the keyboard, and then press the paste shortcut key to copy and paste the command.
. 软复位 `ctrl + d`.
. 中断 `ctrl + c`，中断当前正在执行的程序，但不会重新启动和复位。
