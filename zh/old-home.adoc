== 关于 Banana Pi 开源项目
image::/website.jpg[website.jpg]

link:http://www.banana-pi.org/[Banana Pi] 是由 link:https://wiki.banana-pi.org/About_BPI[广东比派科技有限公司] 主导的开源硬件项目。项目专注于 ARM 与 MCU 系列开源硬件开发板，提供开放的软硬件平台，并打造基础技术开发平台。全系列开源硬件产品可完整集成语音、数据和视频系统平台，开发者能够在此基础上灵活构建各种应用，适用于物联网、人工智能、工业互联网控制、STEAM 教育等领域。另请参阅 link:https://wiki.banana-pi.org/Banana_Pi_open_source_community_ecology_and_Internet_of_things_overall_technical_solutions[Banana Pi 开源社区生态与物联网整体技术解决方案]。

欢迎前往 link:http://forum.banana-pi.org/[Banana Pi 论坛] 自由交流。由于 Google 安全更新，部分旧链接已失效；所需资料和镜像可从新的 link:https://drive.google.com/drive/folders/0B4PAo2nW2Kfndjh6SW9MS2xKSWs?resourcekey=0-qXGFXKmd7AVy0S81OXM1RA&usp=sharing[文档] 与 link:https://drive.google.com/drive/folders/0B_YnvHgh2rwjVjNyS2pheEtWQlk?resourcekey=0-U4TI84zIBdId7bHHjf2qKA[镜像] 链接下载。

可从 link:https://pt.aliexpress.com/store/302756[SinoVoip 速卖通商店] 和 link:https://www.aliexpress.com/store/1101951077[BPI 速卖通商店] 便捷购买样品。

link:https://wiki.banana-pi.org/BPI_4.0_Server[BPI 4.0 服务] 已为全球 200 多个 link:https://wiki.banana-pi.org/Successful_case[成功案例] 提供支持，为客户提供研发、生产、供应链管理和产品认证的一站式服务。
