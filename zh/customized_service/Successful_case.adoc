== 硬件规格

- 尺寸：两层，88x88 毫米
- CPU 芯片组：A20 ARM Cortex™-A7 双核 1 GHz
- GPU 芯片组：ARM Mali400MP2 符合 OpenGL ES 2.0/1.1
- 内存：1 GB DDR3
- 存储插槽：微型SD卡16G字节
- 网络 Ethernet: – 10/100/1000Mbps 广域网 x 1 – 10/100/1000Mbps 局域网×4
- WIFI： – 3x 2.4GHz，支持 IEEE 802.11b/g/n，高达300Mbps – 1x 5GHz，支持IEEE 802.11a/n/ac，高达433Mbps – 外置高增益天线2.4GHz x3，5GHz x1 –WIFI型号MT7632或AP6335
- 4G LTE – SimCom Sim7100C、FDD B3 LTE 1800、 – 型号 SIM7100C – 外部高增益天线 4G x1
- USB: USB 主机2.0×1
- 摄像头：摄像头 x 1，屏幕分辨率高清 1280x720 像素，30 FPS，UVC H.264 编码技术，CSI 连接器
- 音频输入：麦克风 x 1
- 视频输出： HDMI 输出 x 1
- 音频输出：3.5mm 插孔和 HDMI
- 扬声器：BP-5032-44，1x扬声器，直径50mm，深度32mm，功率4w，阻抗4±15%Ω
- 按键： 电源键 x 1 触摸传感器电源按钮 重置键 x 1
- LED：RJ45 LED (上传、下载) 5 个无线网络 LED (2.4G, 5.8G) x 2 电源状态 LED x 1 GPIO LED (4 针 LED) x 1 USB LED x 1 相机 LED x 1 4G LED x 1 音频 LED x1 麦克风 LED x1
- 调试：串行控制台、JTAG
- 预留引脚： GPIO PIN x 26， UART, 12C 总线, SPI 具有两个片选的总线，CAN总线， ADC, PWM, +5V, +3.3V，接地
- 红外接收器：x1
- 电源：微型USB 直流电源 5V/2A
- 电池：锂离子 4400 mAh 3.7V，电池连接器：x1
- 适配器：直流适配器 5V/2A 与微USB 电缆
- 轻松添加zigbee、z-wave、NB-IoT等物联网功能。
