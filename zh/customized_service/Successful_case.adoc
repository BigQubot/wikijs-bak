== 硬件规格

- 尺寸：双层，88 × 88 mm
- CPU 芯片组：A20 ARM Cortex™-A7 双核 1 GHz
- GPU 芯片组：ARM Mali400MP2 符合 OpenGL ES 2.0/1.1
- 内存：1 GB DDR3
- 存储卡槽：microSD 卡，容量 16 GB
- 以太网：1 个 10/100/1000 Mbps WAN 口，4 个 10/100/1000 Mbps LAN 口
- WiFi：3 路 2.4 GHz，支持 IEEE 802.11b/g/n，最高 300 Mbps；1 路 5 GHz，支持 IEEE 802.11a/n/ac，最高 433 Mbps；外置高增益天线为 3 根 2.4 GHz、1 根 5 GHz；WiFi 模块为 MT7632 或 AP6335
- 4G LTE：SimCom SIM7100C，FDD Band 3 LTE 1800；1 根 4G 外置高增益天线
- USB：1 个 USB 2.0 Host 接口
- 摄像头：1 个摄像头，HD 1280 × 720 像素、30 FPS，支持 UVC H.264 编码，采用 CSI 接口
- 音频输入：麦克风 x 1
- 视频输出：1 个 HDMI 输出
- 音频输出：3.5 mm 插孔和 HDMI
- 扬声器：BP-5032-44，1 个；直径 50 mm、深度 32 mm、功率 4 W、阻抗 4 Ω（±15%）
- 按键：1 个触摸感应电源键，1 个复位键
- LED：5 个 RJ45 收发指示灯、2 个 WiFi 指示灯（2.4G、5.8G）、1 个电源状态灯、1 组 GPIO LED（4 引脚）、1 个 USB 指示灯、1 个摄像头指示灯、1 个 4G 指示灯、1 个音频指示灯、1 个麦克风指示灯
- 调试：串行控制台、JTAG
- 预留引脚：26 个 GPIO 引脚，以及 UART、I2C、带两个片选的 SPI、CAN、ADC、PWM、+5V、+3.3V 和 GND
- 红外接收器：1 个
- 电源：Micro-USB，DC 5 V/2 A
- 电池：3.7 V、4400 mAh 锂离子电池，1 个电池连接器
- 适配器：5 V/2 A DC 适配器，配 Micro-USB 线
- 易于扩展 Zigbee、Z-Wave、NB-IoT 等物联网功能。
