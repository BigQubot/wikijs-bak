= 阿迪诺 IDE

== 如何设置和启动
需要准备：

- BPI-UNO32 1 或 BPI：位 1
- 跳线帽 4
- 微型USB 1

快速入门：

. 将四个跳帽分别连接到板子顶部，连接RGB LED 到蜂鸣器。然后使用microUSB线将开发板连接到电脑。

- 端口：
+
image::/picture/uno32_start_0.png[uno32_start_0.png]

- 连接：
+
image::/picture/uno32_start_1.png[uno32_start_1.png]
+
打开 VS 代码 \(你也可以选择其他编译器\) 并打开 BPI-UNO32 以PlatformIO首页的Code工程为例，打开一个测试代码工程文件夹PlatformIO\_VSCode。

- 项目：
+
image::/picture/uno32_start_2.png[uno32_start_2.png]
+
打开VS Code终端控制台，输入 ，编译程序，输入 ，编译并烧录程序。 (如果之前没有编译过，第一次编译可能会比较慢，需要连接，因为他需要获取对应的平台信息).

- 平台运行：
+
image::/picture/uno32_start_3.png[uno32_start_3.png]

- Platformio run --目标上传：
+
image::/picture/uno32_start_4.png[uno32_start_4.png]

. 然后打开串口助手工具，选择 BPI-UNO32 在串口号对应的电脑上，串口设置选择为： 波特率：115200 数据位：8 奇偶校验：无 停止位：

- 串口配置：
+
image::/picture/uno32_start_5.png[uno32_start_5.png]

. 测试内容：

- RGB LED 褪色。
- AD采集与测试6 ADC\_频道1。
- WiFi 扫描测试。
- 蜂鸣器梯度控制测试。
