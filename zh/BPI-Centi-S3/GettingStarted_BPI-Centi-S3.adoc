== 首次使用

使用一根同时支持供电和数据传输的 USB-C 线，将
BPI-Centi-S3 开发板连接到计算机。

首次使用时，开发板上电后屏幕会立即显示
欢迎界面，同时蜂鸣器响两声。

BPI-Centi-S3 出厂时已预烧录 MicroPython 1.19.1 固件，并
集成了 ST7789 C 模块驱动。建议
初学者使用 MicroPython 进行开发和学习。

== 使用 MicroPython 快速入门

. 参见 link:./MicroPython/environment.md[安装并配置
环境]，安装 Python 3、mpremote、mpbridge 和 VS Code
IDE。
. 参见 link:./MicroPython/VScode_mpbridge.md[如何使用 VS Code + mpbridge
工具]，学习如何连接开发板，以及复制、修改和
删除开发板上的文件。
. 参见 link:./MicroPython/REPL_use_case.md[REPL 使用示例]，快速
了解 MicroPython REPL 的常用快捷键，以及
查看模块的方法。

. 完成以上三个步骤后，即可开始开发。

. 学习 Python 和 MicroPython 时，建议先从
link:https://docs.python.org/3.10/tutorial/index.html[Python
教程]开始学习 Python。
+
另外，也可以阅读 link:./MicroPython/What_is_MicroPython[什么是 MicroPython？]

. 将学到的 Python 知识应用起来，并查阅
link:https://docs.micropython.org/en/latest/index.html[MicroPython
文档]，以便快速查找 MicroPython 专用库和
本项目开发所需的 ESP32 移植版专用库。

. 通过以下页面了解二者的部分差异：
link:https://docs.micropython.org/en/latest/genrst/index.html#[Differences
between MicroPython and CPython（MicroPython 与 CPython 的区别）]。

. 在本页下一节中可以找到一些 MicroPython 示例，
它们可能会对你有所帮助。

. ST7789 C 模块驱动来源：
+
link:https://github.com/russhughes/st7789s3_esp_lcd[russhughes/st7789s3_esp_lcd],
采用 MIT License
+
在该 GitHub 仓库中，可以查看 st7789
模块的全部方法及编译方式。感谢 russhughes 的
开源贡献。

. 如果开发过程中出现严重 BUG，导致
开发板无法正常启动，或者因其他原因造成
固件被擦除或损坏，请参阅
link:./MicroPython/Burn_firmware.md[烧录固件]。
