= 简介

Banana Pi BPI-CM7 是一款基于 Allwinner H618 的计算模块，配合 BPI-CM7IO 载板使用。

TIP: 更多信息：link:/zh/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7 主页]

== 规格参数

* Allwinner H618，四核 ARM Cortex™-A53 处理器，高达 1.5 GHz
* ARM Mali G31 GPU
* 板载 LPDDR4 内存
* 板载 eMMC 存储
* K019-CW43-Dw Wi-Fi 5 和蓝牙 5.0 模块
* 1 个 USB 2.0 OTG
* 3 个 USB 2.0 Host
* 1 个 HDMI 输出
* 1x 10/100M Ethernet
* 1 个 microSD 接口
* 2 个 100-pin 板对板连接器

== 准备

使用以下命令确认开发板型号、操作系统、CPU、内存和启动存储设备。

```bash
hostnamectl
tr '\0' '\n' < /proc/device-tree/model
tr '\0' '\n' < /proc/device-tree/compatible
uname -a
lscpu
free -h
lsblk -o NAME,MAJ:MIN,RM,SIZE,RO,TYPE,FSTYPE,MOUNTPOINTS
findmnt -no SOURCE,FSTYPE,SIZE,USED,AVAIL,USE%,TARGET /
```

测试结果：

* 开发板：Banana Pi BPI-CM7 + BPI-CM7IO
* 操作系统：Armbian 24.11.1 Jammy / Ubuntu 22.04.5 LTS
* 内核： Linux 5.4.125-legacy-sunxi64
* 架构：arm64
* CPU：4 个 Cortex-A53，高达 1512 MHz
* 内存：Linux 可用 1.9 GiB
* 启动设备：microSD， `/dev/mmcblk1p1`
* eMMC: `/dev/mmcblk0`, 29.3 GiB
* 用于测试的登录用户： `pi`

== SSH

. 准备好网线和路由器。
. 将 BPI-CM7IO 的以太网口和 PC 接入同一局域网。
. 从路由器管理页面查看开发板的 IP 地址，或在开发板本地终端中执行以下命令。
+
```bash
ip -brief address show eth0
hostname -I
```

. 检查开发板上的 SSH 服务状态。
+
```bash
systemctl is-active ssh
```

. 在 PC 上打开终端并连接开发板，将 `<board-ip>` 替换为路由器实际分配的地址。
+
```bash
ssh pi@<board-ip>
```

. 登录后，使用以下命令确认远程用户名、开发板名称和内核版本。
+
```bash
whoami
hostnamectl --static
uname -r
```

测试结果：

```text
SSH service: active
Remote login: successful
User: pi
Hostname: bpi-cm7
Kernel: 5.4.125-legacy-sunxi64
```

== WiFi

使用 `nmcli` 命令列出网络设备并扫描 Wi-Fi 接入点。

```bash
nmcli device # List devices
nmcli device wifi list # List available Wi-Fi access points
```

```bash
nmcli device wifi connect [SSID] password [PASSWORD]
nmcli connection up [SSID]
nmcli device disconnect [device name]

nmcli device wifi hotspot con-name [NAME] ifname [device name] ssid [SSID] password [PASSWORD]

nmcli connection show
nmcli connection down [NAME]
nmcli connection up [NAME]
nmcli connection delete [SSID]

nmcli radio wifi off
nmcli radio wifi on
```

== 查看硬件温度

使用以下命令识别 4 个 thermal zone。

```bash
cat /sys/class/thermal/thermal_zone0/type
cat /sys/class/thermal/thermal_zone1/type
cat /sys/class/thermal/thermal_zone2/type
cat /sys/class/thermal/thermal_zone3/type
```

使用以下命令读取温度。

```bash
cat /sys/class/thermal/thermal_zone0/temp
cat /sys/class/thermal/thermal_zone1/temp
cat /sys/class/thermal/thermal_zone2/temp
cat /sys/class/thermal/thermal_zone3/temp
```

将每个返回值除以 1000，即可得到摄氏温度。

测试结果：

```text
cpu_thermal_zone: 50.2 °C
ddr_thermal_zone: 51.4 °C
gpu_thermal_zone: 53.4 °C
ve_thermal_zone: 50.8 °C
```

== 传输文件

=== scp

SCP 使用 SSH 协议，在 PC 与 BPI-CM7 之间安全复制文件。请先确认 PC 和开发板已连接到同一局域网，且 SSH 可以正常登录。

SCP 命令格式如下：

```bash
scp [options] file_source file_target
```

使用 `-r` 递归复制目录。

将本地文件从 PC 复制到 BPI-CM7：

```bash
scp local-file pi@<board-ip>:/home/pi/
```

将文件从 BPI-CM7 复制到 PC：

```bash
scp pi@<board-ip>:/home/pi/remote-file ./
```

测试结果：

```text
Upload to /tmp: successful
Remote file size and SHA-256 verification: successful
Temporary test file removal: successful
```
