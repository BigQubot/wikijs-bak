= 简介

Banana Pi R64 是一款采用 64 位芯片的路由器开发板，可运行 OpenWrt、Linux 等多种开源操作系统。它配有 4 个千兆 LAN 端口、1 个千兆 WAN 端口，并支持 802.11ac WiFi AP 功能。

TIP: 更多信息：link:/zh/BPI-R64/BananaPi_BPI-R64[Banana Pi BPI-R64]

== 规格参数

- MediaTek MT7622，1.35 GHz 64 位双核 ARM Cortex-A53
- 1 GB DDR3 SDRAM
- Mini PCIe 接口，支持 4G 模块
- 内置 4×4 802.11n / Bluetooth 5.0 SoC
- 板载 MTK7615 4×4 802.11ac WiFi
- 1 个 SATA 接口
- MicroSD 卡槽，最高支持 256 GB
- 8 GB eMMC 闪存（可选 16/32/64 GB）
- 5 个 10/100/1000 Mb 以太网端口
- 1 个 USB 3.0 接口
- 低速 I/O：ADC、音频放大器、GPIO、I2C、I2S、红外、PMIC I/F、PWM、RTC、SPI、UART
- 支持 PoE 功能

= 开发
== 准备

* 准备一张至少 8 GB 的 TF 卡和一个 USB 转串口适配器
* 使用 USB 转串口适配器（**3.3 V，波特率 115200**）连接 R64 的调试控制台
* LAN 口默认 IP 地址：**192.168.1.1**
* 用户名/密码：**pi/bananapi**、**root/bananapi**。+
也可以使用**无密码**的 root 用户登录。
* WiFi：**OpenWrt**

== Linux
=== 将镜像烧录到 SD 卡
**Windows 电脑**

link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

- 单击“**Flash from file**”选择镜像。 
- 单击“**Select target**”选择目标设备。 
- 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux**

- bpi-copy

. 安装 bpi-tools。如果无法访问该网址或遇到其他问题，请前往 bpi-tools 仓库手动安装该工具。
+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
``` 
. 下载镜像后，将 TF 卡插入 Ubuntu 电脑并执行
+
```sh
bpi-copy xxx.img /dev/sdx
```
以便将镜像烧录到 TF 卡。

- dd
+
如果 SD 卡设备 /dev/sdX 的分区被自动挂载，请先将其卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m5-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```

=== 将镜像烧录到 eMMC
向 eMMC 烧录镜像前，请准备一张已烧录可启动镜像的 SD 卡和一个 U 盘。下面以 OpenWrt 镜像（mtk-bpi-r64-preloader-emmc.bin、2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img）为例。

NOTE: 可以从 GitHub 下载“.bin”文件：https://github.com/BPI-SINOVOIP/BPI-R64-openwrt/tree/master/staging_dir/target-aarch64_cortex-a53_musl/image

. 插入已烧录镜像的 SD 卡，上电启动开发板。（SD 卡中可以是 OpenWrt，也可以是 Ubuntu 等其他 Linux 系统。）
. 将可从 eMMC 启动的 OpenWrt 镜像（mtk-bpi-r64-preloader-emmc.bin、2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img）复制到 U 盘。如果镜像已压缩，请先解压再复制。
. 将 U 盘插入开发板，并按如下方式将其挂载到 /mnt 或其他目录：（如果已自动挂载，可跳过此步）
+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
. 执行以下命令，启用 eMMC 并将镜像写入 eMMC：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img of=/dev/mmcblk0
dd if=mtk-bpi-r64-preloader-emmc.bin of=/dev/mmcblk0boot0
mmc bootpart enable 1 1 /dev/mmcblk0
```
. 关机并取出 SD 卡和 U 盘，然后重新开机，从 eMMC 启动开发板。

==== GPIO 控制
```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
查看 GPIO 基准编号，本例中为 409

image::/picture/r64_gpio_base.jpg[r64_gpio_base.jpg]

例如，如果要将 GPIO 22 配置为高电平输出，需要输入以下命令：
```sh
echo 431（22+409） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio431/direction
echo 1 > /sys/class/gpio/gpio431/value
```
==== PWM 控制
```sh
echo x >/sys/class/pwm/pwmchip0/export
echo 200000 >/sys/class/pwm/pwmchip0/pwmx/period
echo 100000 >/sys/class/pwm/pwmchip0/pwmx/duty_cycle
echo 1 >/sys/class/pwm/pwmchip0/pwmx/enable
```
==== SPI 触摸屏

SPI 面板模块：

2.4 英寸 TFT LCD 触摸屏，采用 SPI 接口，分辨率 240×320（ILI9341 + ADS7843/XPT2046/HR2046）

SPI 面板 <–> BPIR64
```sh
T_DO, T_DIN, T_CLK <–> SPIC_0: MOSI / MISO / CLK
T_CS <–> SPI-CE0
T_IRQ <–> IO-37
SDO, SCK, SDI <–> SPIC_1: MOSI / MISO / CLK
LED <–> PIN-31
DC <–> PIN-11
RESET <–> PIN-13
CS <–> SPI-CE1
GND <–> GND-9
VCC <–> 3.3V-1
```
DTS 修改：
```sh
/ {
       backlight: backlight {
               compatible = "gpio-backlight";
               gpios = <&pio 82 GPIO_ACTIVE_HIGH>;        //PIN31 IO-31 : GPIO82
               default-on;
       };
};
```
```sh
&pio {
       spic0_pins: spic0-pins {
               mux {
                       function = "spi";
                       groups = "spic0_0";
               };
       };

       spic1_pins: spic1-pins {
               mux {
                       function = "spi";
                       groups = "spic1_0";
               };
       };
}
```
```sh
&spi0 {
       pinctrl-names = "default";
       pinctrl-0 = <&spic0_pins>;
       status = "okay";
       touch@0 {
               reg = <0>;                                 //CE0
               compatible = "ti,ads7843";
               interrupt-parent = <&pio>;
               interrupts = <86 0>;                       //PIN37: IO-37 == GPIO86
               pendown-gpio = <&pio 86 0>;
               spi-max-frequency = <1000000>;
               vcc-supply = <&reg_3p3v>;
               wakeup-source;
       };
};
```
```sh
&spi1 {
       pinctrl-names = "default";
       pinctrl-0 = <&spic1_pins>;
       status = "okay";
       display@0{
               compatible = "ilitek,ili9341";
               reg = <0>;                                 //CE0
               spi-max-frequency = <32000000>;
               dc-gpios = <&pio 51 GPIO_ACTIVE_HIGH>;     //PIN11 UART1-TXD : GPIO51
               reset-gpios = <&pio 52 GPIO_ACTIVE_HIGH>;  //PIN13 UART1-RXD : GPIO52
               backlight = <&backlight>;
       };
};
```

=== SATA
- 如需使用 R64 的 SATA 接口，需要将 GPIO90 置为低电平
+
```sh
echo 499 > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio499/direction
echo 0 > /sys/class/gpio/gpio499/value
```
- 使用东芝机械硬盘测得的读写性能如下：

* 磁盘读取：50 MB/s，命令：
+
```sh
dd if=/dev/sda of=/dev/null bs=1M count=1024
```

* 磁盘写入：38 MB/s，命令：
+
```sh
dd if=/dev/zero of=/dev/sda bs=1M count=1024
```
