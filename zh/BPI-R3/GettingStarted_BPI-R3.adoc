= 简介

香蕉派 BPI-R3 Mini 路由器板带有 MediaTek MT7986(Filogic 830) 四核ARM A53芯片设计，2G DDR RAM ,8G eMMC 板载flash，是一款非常高性能的开源路由器开发板，支持Wi-Fi6 2.4G wifi使用MT7975N和5G wifi使用MT7975P，支持2个2.5GbE网络端口。

=== MediaTek MT7986(Filogic 830)
MT7986(Filogic 830) 集成了四个高达 2GHz 的 Arm Cortex-A53 内核，具有高达 18,000 DMIP 的处理能力和 6Gbps 的双 4x4 Wi-Fi6 连接。有两个2.5g Ethernet 接口和串行外设接口 (SPI). Filogic 830 的内置硬件加速引擎可实现快速可靠的 Wi-Fi 卸载和无线网络连接。此外，该芯片还支持 Mediatek FastPath™技术，适用于游戏， AR/VR 和其他低延迟应用程序。

Wi-fi 6 相比其前身具有许多优势，包括更低的延迟、更大的带宽容量和更快的传输速率。支持6GHz频段的无线网络设备主要利用160MHz宽信道和6GHz不拥塞带宽提供多千兆传输和低延迟Wi-Fi连接，为流媒体、游戏、 AR/VR 和其他应用程序。

TIP: 更多信息： link:/en/BPI-R3/BananaPi_BPI-R3[香蕉派 BPI-R3]

== 规格参数

- MediaTek MT7986(Filogic 830) 四核 ARM Cortex A53
- 无线网络6 2.4G/5G（MT7976C）
- 2G内存 RAM
- 8G eMMC 闪光
- 128MB Nand 闪光
- 2 个 2.5GbE 网络端口
- 1x M.2 钥匙 B USB 接口
- 1x M.2 钥匙 M PCIe 接口
- 1个USB2.0接口

== 安装镜像到 NAND

让我们采取 OpenWrt 镜像 (mtk-bpi-r3-SD-WAN1-SFP1-20220619-single-image.img, mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin) 例如，步骤如下：

. 插入闪存的SD卡并通电以启动开发板。(镜像”**mtk-bpi-r3-SD-WAN1-SFP1-20220619-single-image.img**“在SD卡上可以 OpenWrt 或其他 linux 操作系统类似 ubuntu...)
. 复制 Nand 可启动的 OpenWrt 镜像(**mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin**) 到 USB 磁盘，如果镜像被压缩，请在复制到之前解压 USB 磁盘。
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt 
```
将目录更改为安装点，这里是： 
+
```sh
cd /mnt
```
. 执行以下命令以启用并将镜像复制到 nand 闪光：
+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r3-NAND-WAN1-SFP1-20220619-single-image.bin of=/dev/mtdblock0
```
. 拔掉SD卡，更改启动开关 nand 闪存，重新启动板 Nand 闪光。
+
TIP: 启用设备，引导带来自 nand
+
image::/picture/bpi-r3-jumper-flash-nand.png[bpi-r3-jumper-flash-nand.png]

== 安装镜像到 eMMC
WARNING: 注：SD 卡和 EMMC 设备共享一个SOC 接口

NOTE: 将按钮切换到 NAND 然后开始 BPI-R3

. 插入 USB 驾驶与 **bl2_emmc.img** 和 **mtk-bpi-r3-EMMC-xxx.img** 进入 BPI-R3.
. 安装 USB 开车 to/mnt，然后执行以下命令将镜像刻录到 EMMC:
+
```sh
mount -t vfat /dev/sda1 /mnt
cd /mnt
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r3-EMMC-WAN1-SFP1-20220619-single-image.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
```
. 关闭R3板电源，删除U盘驱动，更改引导程序以从 emmc 设备。
+
TIP: 启用 EMMC 设备，引导带来自 EMMC.
+
image::/picture/bpi-r3-jumper-boot-emmc.png[bpi-r3-jumper-boot-emmc.png]

**GPIO 控制**

```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
检查底座 gpio，你可以看到我的是411

image::/picture/bpi-r3-gpio-base.jpg[bpi-r3-gpio-base.jpg]

例如：如果你想改变 gpio 22 作为高级，你需要输入这样的命令：
```sh
echo 433（22+411） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio433/direction
echo 1 > /sys/class/gpio/gpio433/value
```

== 风扇

image::/picture/fan.png[fan.png]

R317 用于 5V 风扇，R318 用于 12V 风扇。

CN23支持 PWM 控制而CN22不支持。

== PWM 风扇控制
```sh
echo 0 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 5000 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm0/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
```

== 4G&5G

BPI-R3 支持4G LTE EC25。

如果你想使用5G BPI-R3:

. 将 5G 适配器插入 USB3.0。
. 连接RG200U-CN至mini PCIe, 连接 SoC 通过USB2.0(限速).
. 制作一块RG200U-CN LGA转接板并将其插入M.2 KEY M。

WARNING: 注：可用性 4G/5G 取决于本地载波频段。

=== 无线网络和串行电缆

如果串口线的芯片类型是pl2303，驱动程序显然无法加载固件，从而导致wifi无法工作。

其他型号包括cp2102、ch340、FDTI均可，串口线电压必须为3.3v LVTTL标准。

串口_TX0 是引导引脚，在上电期间必须保持低电平。
