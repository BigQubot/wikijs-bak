= PlatformIO

== 配置和开始使用
需要准备：

- 1 块 BPI-UNO32 或 1 块 BPI:bit
- 4 个跳线帽
- 1 根 Micro-USB 数据线

快速入门：

. 将四个跳线帽分别安装到开发板顶部，使 RGB LED 和蜂鸣器接入电路。然后用 Micro-USB 数据线将开发板连接到计算机。

- 端口：
+
image::/picture/uno32_start_0.png[uno32_start_0.png]

- 连接：
+
image::/picture/uno32_start_1.png[uno32_start_1.png]
+
打开 VS Code（也可以选择其他编辑器），在 PlatformIO Home 页面打开 BPI-UNO32 代码项目。以测试项目为例，打开 PlatformIO\_VSCode 工程文件夹。

- 项目：
+
image::/picture/uno32_start_2.png[uno32_start_2.png]
+
打开 VS Code 终端，输入相应命令编译程序，再输入上传命令完成编译和烧录。首次编译可能较慢，并且需要联网获取对应的平台信息。

- PlatformIO run：
+
image::/picture/uno32_start_3.png[uno32_start_3.png]

- PlatformIO run --target upload：
+
image::/picture/uno32_start_4.png[uno32_start_4.png]

. 打开串口助手工具，选择计算机上 BPI-UNO32 对应的串口号。串口参数设置为：波特率 115200、数据位 8、无奇偶校验；停止位：

- 串口配置：
+
image::/picture/uno32_start_5.png[uno32_start_5.png]

. 测试内容：

- RGB LED 渐变测试。
- 6 路 ADC\_channel1 的 AD 采集测试。
- Wi-Fi 扫描测试。
- 蜂鸣器渐变控制测试。
