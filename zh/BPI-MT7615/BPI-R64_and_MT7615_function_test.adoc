= 测试环境及软件

MT7615 模块支持 BPI-R2 和 BPI-R64。我们已在实验室测试 MT7615 的各项参数，以获得最佳性能。

使用 OpenWrt 测试 BPI-R64 + MT7615 的 Wi-Fi 功能

== 所需物品清单
. BPI-R64
. BPI-MT7615 模块
. 12 V/2 A 电源适配器
. USB 串口线（3.3V）
. TF 卡
. 5.8 GHz Wi-Fi 天线，1～4 根
. OpenWrt 镜像：https://docs.banana-pi.org/zh/BPI-R64/BananaPi_BPI-R64#_系统镜像

== 环境搭建
在 Windows 中使用 Win32DiskImager 将 BPI-R64 OpenWrt 镜像烧录到 TF 卡，再将卡插入卡槽。把 MT7615 模块插入 BPI-R64 的 mPCIe 接口 CN25，连接 UART 调试线和 Wi-Fi 天线，然后通电启动。

image::/picture/7615_test_1.jpg[7615_test_1.jpg]

== 配置网络
启动完成后，在串口中输入 ifconfig rai0 up 启用 MT7615，再配置 rai0 的 IP 地址，例如：ifconfig rai0 192.168.11.11

= 性能测试
由于测试时只连接一根 Wi-Fi 天线，连接速率为 433 Mb/s。测试期间，笔记本与 MT7615 之间没有墙壁或其他障碍物，并为 MT7615 选择了干扰较少的信道。
