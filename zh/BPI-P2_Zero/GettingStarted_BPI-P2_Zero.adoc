= 简介

Banana Pi BPI-P2 Zero 是一款超紧凑型单板计算机，尺寸仅为 65 mm × 52.5 mm。它采用 Allwinner H2+ 四核 Cortex-A7 处理器（可选 H3 或 H5），配备 512 MB 内存、8 GB eMMC 闪存、百兆以太网和 PoE 功能，适合空间受限的轻量级应用。与其他 Banana Pi 产品一样，它支持 Linux 和 Android 操作系统。

TIP: 更多信息：link:/en/BPI-P2_Zero/BananaPi_BPI-P2_Zero[Banana Pi BPI-P2 Zero]

== 规格参数

- CPU: Allwinner H2+, 四核 Cortex-A7
- 512 MB DDR3 SDRAM
- WiFi（AP6212）及板载蓝牙
- Mini HDMI
- 40 针 GPIO，包含 UART、SPI、I2C、通用 IO 等接口
- 百兆以太网
- 支持符合 IEEE 802.3af 标准的 PoE 模块
- 板载 8 GB eMMC 闪存

== Linux
=== 准备
. Linux 镜像支持从 SD 卡或 eMMC 启动。
. 建议使用 A1 等级、容量至少为 8 GB 的存储卡。
. 在 Linux 电脑上安装 bpi-tools（如果使用其他工具烧录镜像，可跳过此步）。如果无法访问该网址或遇到其他安装问题，请前往 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源码仓库手动下载并安装。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验值正确。
. 默认登录账号：pi/bananapi 或 root/bananapi

=== 将镜像烧录到 SD 卡
**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**可以选择以下两种方法。**

. 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-p2_zero-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 使用 Linux 上的 bpi-tools 烧录镜像。将 SD 卡插入 Linux 电脑并执行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/sdX
```

=== 将镜像烧录到 eMMC

. 准备一张已烧录 Linux 镜像的 SD 卡，并用该卡启动开发板。
. 解压镜像并复制到 U 盘，将 U 盘插入开发板并挂载。（如果已自动挂载，可跳过此步）
+
```sh
mount /dev/sdx /mnt
```
. 可通过以下两种方式将 Linux 镜像安装到开发板。

IMPORTANT: 请确认 eMMC 对应的设备分区。以下命令仅以 mmcblk0 为例，请以实际设备为准。

- 使用 dd 命令烧录。
+
```sh
sudo dd if=/mnt/xxx.bpi-p2_zero-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 使用 bpi-tools 命令烧录 U 盘中的 Linux 镜像
+
```sh
 $ sudo bpi-copy xxx-bpi-p2_zero-xxx.img.zip /dev/mmcblk0
```
. 烧录完成后，安全关机并取出 SD 卡。

== 进阶开发
=== 制作镜像
- 准备一张已安装系统（Ubuntu、Raspbian 等）的 SD 卡
- 使用该 SD 卡启动 P2 Zero。P2 Zero 启动完成后，复制所需文件并配置系统，然后关闭 P2 Zero 电源。[如果不需要配置系统，可跳过此步]
- 将 SD 卡插入运行 Linux 的电脑
+
```sh
cd /media
ln -s <your account> pi
```
- 执行 
+
```sh
bpi-migrate -c bpi-m2z.conf -c ubuntu-mate-from-sd.conf -d /dev/sdx
```
- 完成后即可得到自己的镜像

=== OTG
. 在 P2 Zero 控制台中：
+
执行 
+
```sh
./adbd.sh
ps -ax | grep adbd
```
检查 adbd 是否已启动

. 在电脑终端中：
+
--
如果 adbd 已成功启动，请用 OTG-USB 线连接 P2 Zero 和运行 Ubuntu 的电脑。

执行 
```sh
adb devices
```
检查电脑是否已识别 P2 Zero 的 OTG 设备。

如果已经识别，可以执行
```sh
adb shel
```
此时即可通过 adb 连接 P2 Zero

=== 显示
如何更改显示分辨率
例如，将 P2 Zero 的 HDMI 显示分辨率改为 1080p。

. 执行
+
```sh
mount /dev/mmcblk0p1 /mnt
cd /mnt/bananapi/bpi-m2z/linux
```
找到“**sys_config.fex**”

. 执行
+
```sh
vim sys_config.fex
```
将
+
```sh
screen0_output_mode = 5
```
改为
+
```sh
screen0_output_mode = 10
```
+
image::/picture/display_output.png[display_output.png]

. 保存更改后，使用
+
```sh
fex2bin
```
命令将 sys_config.fex 转换为二进制文件：“**fex2bin sys_config.fex script.bin**”，然后重新启动。
