= 简介

Banana Pi BPI-M2 Ultra 是一款采用 Allwinner R40 SoC 的四核迷你单板计算机，配备 2 GB 内存和 8 GB eMMC，并集成 WiFi 与蓝牙。接口包括两个 USB 2.0 Type-A、一个 USB OTG、一个 HDMI、一个音频插孔、一个直流电源接口和一个 SATA 接口。

TIP: 更多信息：link:/zh/BPI-M2_Ultra/BananaPi_BPI-M2_Ultra[Banana Pi BPI-M2_Ultra]

Banana Pi BPI-M2 Berry 是一款采用 Allwinner V40 SoC 的四核迷你单板计算机，配备 1 GB 内存，并集成 WiFi 与蓝牙。接口包括四个 USB 2.0 Type-A、一个 USB OTG、一个 HDMI、一个音频插孔、一个直流电源接口和一个 SATA 接口。

TIP: 更多信息：link:/zh/BPI-M2_Berry/BananaPi_BPI-M2_Berry[Banana Pi BPI-M2_Berry]

== 规格参数
=== BPI-M2 Ultra
- 四核 ARM Cortex-A7 CPU（R40）
- 2 GB DDR3 SDRAM
- 8 GB eMMC 存储
- WiFi（AP6212）及板载蓝牙
- SATA 接口

=== BPI-M2 Berry
- 四核 ARM Cortex-A7 CPU（V40）
- 1 GB DDR3 SDRAM
- WiFi（AP6212）及板载蓝牙
- SATA 接口

== Linux
=== 准备

. Linux 镜像支持从 SD 卡或 eMMC 启动。
. 建议使用 A1 等级、容量至少为 8 GB 的存储卡。
. M2 Ultra 和 M2 Berry 使用相同的 Linux 镜像。
. 在 Linux 电脑上安装 bpi-tools（如果使用其他工具烧录镜像，可跳过此步）。如果无法访问该网址或遇到其他安装问题，请前往 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源码仓库手动下载并安装。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验值正确。
. 默认登录账号：pi/bananapi 或 root/bananapi

=== 将镜像烧录到 SD 卡
**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**可以选择以下两种方法。**

. 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2-ultra-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 使用 Linux 上的 bpi-tools 烧录镜像。将 SD 卡插入 Linux 电脑并执行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2-ultra-xxx.img.zip /dev/sdX
```

=== 将镜像烧录到 eMMC

. 准备一张已烧录 Linux 镜像的 SD 卡，并用该卡启动开发板。
. 解压镜像并复制到 U 盘，将 U 盘插入开发板并挂载。（如果已自动挂载，可跳过此步）
+
```sh
mount /dev/sdx /mnt
```
. 可通过以下两种方式将 Linux 镜像安装到开发板。
- 使用 dd 命令烧录。
+
```sh
sudo dd if=/mnt/xxx.bpi-m2-ultra-xxx.img of=/dev/mmcblk0 bs=10M status=noxfer
```
- 使用 bpi-tools 命令烧录 U 盘中的 Linux 镜像
+
```sh
 $ sudo bpi-copy xxx-bpi-m2-ultra-xxx.img.zip /dev/mmcblk0
```
. 烧录完成后，安全关机并取出 SD 卡。

=== SATA
. 在 M2U 上挂载 SATA 硬盘
+
image::/picture/m2u_sata.png[m2u_sata.png]
+
连接 SATA 硬盘后，执行
+
```sh
fdisk -l
```
+
image::/picture/m2u_sata_fdisk_l.png[m2u_sata_fdisk_l.png]
+
然后
+
```sh
mount /dev/sdx /mnt/xxx
```
. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：
+
- 创建新分区
+
```sh
fdisk /dev/sdx
```
设置分区数量和大小。创建分区后，输入“**wq**”保存并退出。
- 格式化 SATA 分区
+
```sh
mkfs.ext2 /dev/sdx
```
- 挂载
+
```sh
mount /dev/sdx /mnt/xxx
```
. 成功连接 SATA 硬盘后，可以输入以下命令测试 SATA 接口：
- 测试读取速度
+
```sh
time dd if=/dev/xxx of=/dev/null bs=1M count=1000
```
- 测试写入速度
+
```sh
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+
image::/picture/sata_test.png[sata_test.png]

=== OTG
. 在 M2U 控制台上：
+
执行 
+
```sh
/usr/local/bin/adbd.sh
```
然后执行
+
```sh
ps -ax | grep adbd
```
检查 adbd 是否已启动
+
image::/picture/m2p_adbd.png[m2p_adbd.png]

. 在电脑终端中：
+
- 如果 adbd 已成功启动，请用 OTG-USB 线连接 M2U 和运行 Ubuntu 的电脑。
- 执行 
+
```sh
adb devices
```
检查电脑是否已识别 M2U 的 OTG 设备
- 如果已经识别，可以执行
+
```sh
adb shell
```
此时即可通过 adb 连接 M2U
+
image::/picture/m2p_adbd_shell.png[m2p_adbd_shell.png]

=== WiFi 客户端
可以使用以下两种方法设置 WiFi 客户端

. 使用命令设置 WiFi 客户端
+
```sh
ip link set wlan0 up
iw dev wlan0 scan | grep SSID
nano /etc/wpasupplicant/wpa_supplicant.conf
```
+
```sh
network={    
 ssid="ssid"    
 psk="password"    
 priority=1 
 }
```
+
```sh
wpa_supplicant -iwlan0 -c /etc/wpa_supplicant/wpa_supplicant.conf
```
