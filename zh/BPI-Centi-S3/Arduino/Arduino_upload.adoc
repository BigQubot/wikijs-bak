## 设置固件下载模式

操作方法有两种：

1. 通过 USB 将开发板连接到计算机，按住 BOOT 按钮，再按下并松开 RESET 按钮，最后松开 BOOT 按钮。

2. 在开发板断电状态下按住 BOOT 按钮，再通过 USB 将其连接到计算机，最后松开 BOOT 按钮。

芯片会在复位或重新上电时，通过 BOOT 按钮控制的 GPIO0 选择启动模式。

在设备管理器中确认 COM 端口。固件下载模式和正常模式使用的 COM 端口号通常不同。

在“工具”>“端口”中选择新出现的端口。
