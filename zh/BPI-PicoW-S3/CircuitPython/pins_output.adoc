. `board.LED` 用于控制 BPI-PicoW-S3 上的单色 LED：高电平点亮，低电平熄灭。在 REPL 中输入以下代码：
+
```py
import board
import digitalio
ledpin = digitalio.DigitalInOut(board.LED)
ledpin.direction = digitalio.Direction.OUTPUT
ledpin.value = True
```

. 或者：
+
```py
import board
import digitalio
ledpin = digitalio.DigitalInOut(board.LED)
ledpin.switch_to_output(value=True) # value=1
```

. 使 LED 每 0.5 秒闪烁一次：
```py
import board
import digitalio
import time
ledpin = digitalio.DigitalInOut(board.LED)
while True:
    ledpin.switch_to_output(value=1)
    time.sleep(0.5)
    ledpin.switch_to_output(value=0)
    time.sleep(0.5)

```

. 在 REPL 中按下 KeyboardInterrupt（Ctrl+C）可停止程序运行。

. 在 Mu 编辑器的 REPL 界面中输入 `import board;help(board)`，即可列出所有可控制的引脚。

. `board.GP25` 与 `board.LED` 完全相同。
