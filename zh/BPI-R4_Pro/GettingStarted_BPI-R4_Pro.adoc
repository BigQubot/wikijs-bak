= 概述

香蕉派 BPI-R4Pro 路由器板带有 MediaTek MT7988A (Filogic 880)四核ARM Corex-A73设计，4GB/8GB DDR4 RAM,8GB eMMC,128MB SPI-NAND 板载闪存，还有 2x 10Gbe SFP+, 4x Gbe网口,带USB3.2接口,M.2支持 4G/5G/NVME SSD.2x miniPCIe 插槽，带 PCIe3.0 2lane 接口，用于 Wi-Fi 7 NIC (网络接口卡)。它是一款非常高性能的开源路由器开发板。

TIP: 更多信息： link:https://docs.banana-pi.org/en/BPI-R4_Pro/BananaPi_BPI-R4_Pro[香蕉派 BPI-R4 Pro]

TIP: link:/en/BPI-R4_Pro/TEST-R4_Pro[BPI-R4 Pro 硬件测试]

=== 如何将镜像闪烁到 NAND 闪光灯

NOTE: 工厂形象信息：OpenWrt 24.10-快照架构：aarch64_皮质-a53

将镜像闪烁之前 Nand，请准备一个 USB 磁盘。让我们采取 OpenWrt 镜像 (**BPI-R4Pro-8X-BE14-MT76-OpenWRT24.10-DSA-snand-251120.bin**) 例如，步骤如下：

. 格式化 USB 磁盘到 FAT32。
. 复制 Nand 启动 OpenWrt 镜像(**BPI-R4Pro-8X-BE14-MT76-OpenWRT24.10-DSA-snand-251120.bin**) 到 USB 磁盘。 
. 将引导程序更改为 sd 或 eMMC 启动，然后给开发板上电。
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
. 执行以下命令即可全部擦除 Nand 闪存并将镜像复制到 nand 设备：
+ 

NOTE: 的 BPI-R4Pro's NAND 镜像闪现至 MTD3 (不像 BPI-R4，闪存到 MTD0).

+
```sh
cat /proc/mtd
dev:    size   erasesize  name
mtd0: 00200000 00020000 "bl2"
mtd1: 00400000 00020000 "Factory"
mtd2: 0fa00000 00020000 "ubi"
mtd3: 10000000 00020000 "nand"

mtd erase /dev/mtd3

mtd write BPI-R4Pro-8X-BE14-MT76-OpenWRT24.10-DSA-snand-251120.bin /dev/mtd3

```
. 关闭电源 BPI-R4Po，删除u盘驱动，将bootstrap改为 nand 再次启动并通电。


=== 如何将镜像闪烁到 eMMC
NOTE: 因为SD卡和 EMMC 设备共享一个SOC的控制器，需要切换到 NAND 启动然后刻录 EMMC 镜像进入 EMMC。最后，您将更改启动方式 EMMC.


让我们采取 OpenWrt 镜像 (**bl2_emmc-r4pro.img, mtk-bpi-r4pro-EMMC-20250928.img**) 例如，步骤如下：

. 格式化 USB 磁盘到 FAT32。
. 复制 EMMC 启动 OpenWrt 镜像(**bl2_emmc-r4pro.img, mtk-bpi-r4pro-EMMC-20250928.img**) 到 USB 磁盘, +
如果图像被压缩，请在复制到之前解压缩 USB 磁盘。

. 将引导程序更改为 Nand 启动 R4Pro 并为其供电。
 
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```

. 执行：
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc-r4pro.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4pro-EMMC-20250928.img of=/dev/mmcblk0
 mmc bootpart enable 1 1 /dev/mmcblk0
```
 
. 关闭电源 BPI-R4Pro，删除u盘驱动，将bootstrap改为 emmc 再次启动并通电。
 
 
 
 
== 电源开启

* 上电前设置自举， +
  （If you are using BPI-R4Pro for the first time, it is recommended to set it to NAND boot) +
* 当将电源适配器连接到 DC-IN 连接器时(CN44),绿色 LED “PWR”亮起， +
  And there will be characters similar to the following on the console. +
  This means you have successfully started BPI-R4Pro. +

== 10G Ethernet

TIP: 其中一些板将使用 MxL86252S-ABE-R。 MxL86252S-ABE-R和MxL86252C也兼容，软件通用，无需修改即可使用。

MT7988A 有两个用于 10G 的 USXGMII ethernet，其中USXGMII Port1用作WAN口 (10G SFP+ WAN/10G RJ45广域网)，USXGMII Port0连接交换机MxL86252C的USXGMII0，MxL86252C的USXGMII1用作LAN口 (10G SFP+ LAN/10G RJ45局域网)

的 SFP 串行解串器速度 BPI-R4Pro 固定为 10Gbps，因此仅 SFP 支持这个就可以用了！ +
link:https://docs.banana-pi.org/en/BPI-R4/BananaPi_BPI-R4#_10g_sfp_module[测试10G SFP+ Copper/Fibre 模块] +

==== 10G SFP+ 局域网
当MT7988A的GPIO54输出=低，MxL86252C 的 USXGMII1 切换至 10G SFP+局域网端口。 +
此时，10G SFP+ LAN 可以工作，但 10G RJ45 LAN 将不起作用。 

现在，您可以插入10G SFP+ Copper/Fibre 获得 10G 网络接口的模块。 +
 +



NOTE: 我们的默认图像配置：  + 
插入后 SFP 模块，USXGMII会自动切换到10G SFP+，10G RJ45将无法使用；  +
**因此，如果您想使用10G RJ45，请勿在其上插入任何模块。 SFP+. **


==== 10G RJ45 网卡(仅适用于 8X)

另一方面，当MT7988A的GPIO54输出=高，MxL86252C 的 USXGMII1 切换到 10G RJ45 WAN 端口。 +
您需要加载10G PHY AS21010P的驱动程序才能使10G RJ45 LAN工作。 +
此时，10G RJ45 LAN 可以使用，但 10G SFP+ 局域网将无效。  +
 
NOTE: AS21010P的功耗很高，必须使用散热效果好的散热器。 +

== USB 连接器
=== USB3.2连接器
BPI-R4Pro 有一个 USB3.2 Type-A 连接器，可用于连接 USB 闪存驱动器或其他 USB 设备。 +
USB3.2连接器的电源输出 (CN11) 是 5V/1300mA，可以通过“PCA_A_IO1_3/VBUS_AB_PDN” 输出低。 +


=== USB2.0连接器
BPI-R4Pro 有一个 USB2.0 Type-A 连接器，可用于连接 USB 闪存驱动器或其他 USB 设备。 +
USB2.0连接器的电源输出 (CN12) 是 5V/1300mA，可以通过“PCA_A_IO1_3/VBUS_AB_PDN” 输出低。 +

== USB TypC 调试控制台连接器
的 BPI-R4Pro 机载有 USB-到-UART 芯片(HT42B534-2)，连接到MT7988A的调试 UART. +
连接时 USB Type-c连接器(CN41) 到 PC，一个 USB就会出现-to-serial设备，可以用来调试。 +
终端设置：波特率=115200，数据位：8位，奇偶校验：无，停止位：1位，流控制：无， +

image::/bpi-r4_pro/bpi-r4pro-usb_serial.png[bpi-r4pro-usb_serial.png,width=200]

== MicroSD卡
的 BPI-R4Pro 有一个 Micro SD (安全数字) 卡槽，可用于启动和存储。 +

然而，MT7988A只有一个MSDC控制器，它输出两个pinmux端口用于SD 4.5和 eMMC 5.1, +
所以你只能在 SD 和 eMMC 功能。


== 风扇
的 BPI-R4Pro有两个风扇连接器，引脚分配与 4 线兼容 PWM- Intel PC 主板上的受控风扇。 +

它采用 12V 电源电压运行，并支持 PWM 速度控制，但缺少用于速度检测的感测引脚。

image::/bpi-r4_pro/bpi-r4pro-fan3.png[bpi-r4pro-fan3.png,width=500]

这两个 FAN 连接器由同一个控制 PWM (GPIO57_脉宽调制D0). +

image::/bpi-r4_pro/bpi-r4pro-fan4.png[bpi-r4pro-fan4.png,width=500]

== 实时时钟
内置一颗RTC时钟芯片，只需安装一节3V CR1220电池即可工作。


== EEPROM
内置1颗EEPROM芯片 (P24C02A)，可用于存储少量数据。

== LED
BPI-R4Pro 有 LED 来指示各种操作状态，包括电源、WiFi、 Ethernet, 4G/5G 细胞, SSD等 +

* 1x 动力绿 LED，PCB上丝印“PWR”，上电时亮起，无法通过软件控制。 +
* 1x 红色状态 LED，PCB上丝印“R”，由控制 GPIO "PCA_A_IO1_7/SYS_LEDR". +
* 1x 蓝色状态 LED，PCB上丝印“B”，由控制 GPIO "PCA_A_IO1_6/SYS_LEDB". +
* 3x WiFi 状态蓝色 LED，丝印“W2G”、“W5G”、“W6G”。 +
	 The specific function depends on the module. Some modules do not have this function (including BPI-BE14 V1.0). +
* 2x SSD 状态蓝色LED，丝印“SSD1”、“SSD2”，控制方式 SSD. +
* 3x 5G 蜂窝状态蓝色 LED，丝印“SIM1”、“SIM2”、“SIM3”，由 5G 模块控制。 +
* 每个 10G/2.5G RJ45有两个LED，每个1G RJ45有一个 LED 以指示网络状态。 +
