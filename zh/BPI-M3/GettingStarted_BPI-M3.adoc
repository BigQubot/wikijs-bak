= 简介

香蕉派 M3 是一款超级强大的单板计算机，配备八核处理器和 2GB 内存 RAM。除了精英处理单元外，它还具有千兆位 Ethernet, 2 USB、SATA、WiFi、蓝牙和 HDMI 连接。它可以在多种操作系统上运行，包括 Android, 卢本图, Ubuntu, Debian和树莓派。 

TIP: 更多信息： link:/en/BPI-M3/BananaPi_BPI-M3[香蕉派 BPI-M3]

== 规格参数

- 八核1.8GHz 强劲CPU
- 2 GB LPDDR3 内存
- 8GB eMMC 存储
- 机载 WiFi 和蓝牙

=== 如何生成M3 Bsp代码
. 准备一台可以运行的PC ubuntu
. 安装 Docker-ce 在你的电脑上，https://docs.docker.com/install/linux/docker-ce/ubuntu/#install-docker-ce (安装 Docker 环境)
. 安装后 Docker, 拉 docker 图像，执行
+
```sh
docker pull sinovoip/bpi-build:ubuntu12.04
```
. 然后你拉取镜像，创建一个端口来登录 docker 图像，执行
+
```sh
docker run --privileged -d -p 2222:22 -v /media:/media sinovoip/bpi-build:ubuntu12.04
```
. 登录 docker 图像
+
```sh
ssh -p 2222 root@127.0.0.1 #default passwd is root
```
. Git克隆M3 bsp代码，执行 
+
```sh
git clone https://github.com/BPI-SINOVOIP/BPI-M3-bsp.git
```
. 构建M3 bsp代码，执行
+
```sh
./build.sh
```
. 构建完成后，打开一个新终端，可以将编译文件复制出来 docker 通过执行图像
+
```sh
docker cp <your container id>:<your project path> <your pc path>
```

=== 将映像安装到 SD 卡

**Windows 电脑**

使用 Balena Etcher 安装映像。 +
link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

. 点击“**从文件闪存**”来选择镜像。 
. 点击“**选择目标**”来选择 USB 设备。 
. 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**有两种方法供您选择。**

. 使用 dd 命令安装镜像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m3-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 安装镜像 bpi-tools 上 Linux，插入SD卡 Linux 电脑并运行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m3-xxx.img.zip /dev/sdX
```

 
=== 安装镜像到 eMMC

. 复制“xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img“给你的 USB 磁盘
. 插入你的 USB M3 中的磁盘
. 执行(如果是自动挂载的则跳过此步骤)
+
```sh
mont /dev/sda1 /mnt
```
. 有两种方法可以将镜像刻录到 eMMC.
- 使用 bpi-copy 用于燃烧。
+
```sh
bpi-copy xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img
```
- 使用dd命令进行刻录。
+
```sh
sudo dd if=/mnt/sda1/xxx-sd-emmc-xxx.img of=/dev/mmcblk0
```

. 然后关闭M3电源，取出TF卡，用以下命令打开M3 EMMC

=== 制作你自己的形象

- 制作一张树莓派镜像

- 准备一张已安装Raspbian系统的SD卡

- 用M3启动你的SD卡，M3启动完成后，复制你的文件并配置你的Raspbian，然后关闭M3

- 插入您的 SD 卡 Linux 电脑
+
```sh
cd /media
ln -s <your account> pi
```

- 执行 
+
```sh
bpi-migrate -c bpi-m3.conf -c raspbian-jessie-from-sd.conf -d /dev/sdx
```

- 那么你现在就可以得到你自己的图像了

=== SATA
. 在M3上安装SATA
+
```sh
fdisk -l
mount /dev/sdx /mnt/xxx
```
+
image::/picture/m3_sata.png[m3_sata.png]

. 如果您在挂载 SATA 时遇到一些错误，请尝试以下命令：
+
```sh
fdisk /dev/sdx
```
创建新分区，设置分区数量和大小，创建分区后，输入“wq”保存并退出。
+
```sh
mkfs.ext2 /dev/sdx
mount /dev/sdx /mnt/xxx
```
. 成功插入SATA后，我们可以输入以下命令来测试SATA接口：

- 测试读取速度
+
```SH
time dd if=/dev/xxx of=/dev/null bs=1M count=1000
```
- 测试写入速度
+
```sh
time dd if=/dev/zero of=/dev/sdx bs=1M count=1000
```
+
