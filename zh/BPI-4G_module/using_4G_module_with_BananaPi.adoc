= 如何使用 BPI-4G LTE 模块具有 BPI-R2

== 开始使用
论坛 pthread 讨论： http://forum.banana-pi.org/t/how-to-use-bpi-4g-lte-module-with-bpi-r2/5223/4

image::/picture/usb_4g_1.jpg[usb_4g_1.jpg]

. 首先使用R2连接LTE模块 USB 或 14 针接头。然后执行命令“lsusb”查看R2是否驱动了模块。红框是4G模块的id。
+
image::/picture/usb_4g_2.png[usb_4g_2.png]
+
看到这个后，执行命令“ls /dev/ttyUSB*“以确保4G模块已被识别为 USB 开发人员。
+
image::/picture/usb_4g_3.png[usb_4g_3.png]

. 执行“./ppp1.sh &"
+
image::/picture/usb_4g_4.png[usb_4g_4.png]
+
然后执行命令“ifconfig -a”，你会看到ppp0
+
image::/picture/usb_4g_5.jpg[usb_4g_5.jpg]

. 执行命令“wget -O speedtest-cli https://raw.githubusercontent.com/sivel/speedtest-cli/master/speedtest.py” 下载速度测试工具。
+
image::/picture/usb_4g_6.png[usb_4g_6.png]

. 执行命令“chmod +x speedtest-cli”，然后执行“./speedtest-cli"
+
image::/picture/usb_4g_7.png[usb_4g_7.png]
+
ppp1_success_log.txt ： http://forum.banana-pi.org/uploads/default/original/2X/e/eb7d46a0971c25f6337116d60e76590ce298b676.txt

= FAQ
. 你可以获得 ppp1.sh 从这里开始： https://pan.baidu.com/s/1yu0nTNQKPNPzprVPjhOPUA

. **Q：如果遇到这个“期望”，我该怎么办？ (好的) ^M报警失败”**
+
image::/picture/usb_4g_8.png[usb_4g_8.png]
+
**A**：根本原因是Modem.service使用了usbserial模块，所以4G模块无法使用usbserial；我们可以使用命令“systemctldisableModemManager.service”或“systemctlstopModemManager.service”来解决问题

. Q：如何测试SIM卡与4G模块的通讯情况？
+
A:使用minicom，”minicom -D /dev/ttyUSB2”，然后使用AT命令测试，如“at”，“at+csq”，“在+ccid”，如果得到响应且没有错误，则说明通讯正常。

. **问：如何安装libqmi？**
+
答：从这里下载： http://www.linuxfromscratch.org/blfs/view/cvs/general/libqmi.html ;然后进行 make 和 make install。
+
如果你遇到这样的情况：
+
image::/picture/usb_4g_9.png[usb_4g_9.png]
+
你需要安装libgudev-1.0-dev，然后再次make并make install。

. *Q：如何使用qmi-wwan？*
+
A：使用方法很简单，我把quectel-CM放在root的home路径下，执行“./quectel-CM &”，然后执行“dhclient wwan0”，至此配置完成。

. Openwrt 支持：

A. 从此链接克隆源代码： BPI-R2 OpenWrt(发光二极体) 源代码 : 2018-04-11

B. 将 qmi-wwan 驱动程序添加到该项目中：

- 执行“./scripts/feeds/ install minicom” 将 minicom 安装到 openwrt 项目
- 执行“./scripts/feeds/ 安装 python”来安装 python 到 openwrt 项目
- 执行“make menuconfig”
- 添加 minicom “实用程序 —> 终端 —> minicom”
- 添加 python “语言—> Python”
- 添加驱动程序“网络 —> wwan ...Genetic OpenWrt 3G/4G 原型处理程序”
- 添加“内核模块—> USB 支持—>
- kmod-usb-核心
- kmod-usb-net —> kmod-usb-net-qmi-wwan
- kmod-usb-ohci
- kmod-usb-串行 —> kmod-usb-串行选项，kmod-usb-串行-wwan
- kmod-usb-uhci
- kmod-usb2-*
- 使用这些源文件替换您的 openwrt 项目源文件(“build_dir/target-arm_cortex-a7+neon-vfpv4_musl_eabi/linux-mediatek_32/linux-4.9.44/drivers/usb(或网)/…”) :

. 如果您使用 mPCIE 接口 4G 模块通过 14 排针连接 R2，请使用这些命令来启用 4G 模块，完成这些步骤后，USB0 端口将被禁用。
+
```sh
cd /sys/class/gpio/
echo 266 > export 【# 266(gpio_offset) = 232(base) + 34(GPIO_34)】
cd gpio266/
echo out > direction
echo 1 > value
```
