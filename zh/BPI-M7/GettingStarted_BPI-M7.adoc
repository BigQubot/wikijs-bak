= 简介

Banana Pi BPI-M7 用户手册介绍 BPI-M7 的基本使用方法和准备工作。

BPI-M7 的型号和硬件版本印在开发板上，收到产品后即可查看。

本文尽可能详细地向您概述产品信息。

TIP: 更多信息： link:/en/BPI-M7/BananaPi_BPI-M7[香蕉派 BPI-M7]

= 准备 

== 工具准备

* BPI-M7 主板
* 电源：USB Type-C PD
** 支持 9 V/2 A、12 V/2 A、15 V/2 A
* 系统安装介质（任选一种）
** MicroSD/TF 卡启动
*** 一张 Class 10 或更高等级、容量至少为 8 GB 的 MicroSD/TF（SDHC）卡，以及一个读卡器
*** 以下高速 TF 卡已经 ArmSoM 团队测试：
**** SanDisk 32 GB TF（MicroSD）卡（推荐开发使用）
**** SanDisk 32 GB TF（MicroSD）行车记录仪/监控摄像机存储卡（推荐长期运行使用）
**** 闪迪 TF 8G Class10 microSD
**** 闪迪 TF 128G Class10 microSD XC TF 128G 48MB/S：
** 板载 eMMC 启动
*** 一根 USB Type-C 数据线，用于通过 BPI-M7 的 Type-C 接口将镜像写入 eMMC；使用时连接 BPI-M7 与电脑。

== 可选配件

* USB 键盘和鼠标
* HDMI 显示器和 HDMI 线缆
** BPI-M7 具有全尺寸 HDMI 端口，最高支持 8K@60 显示
** 系统通过 HDMI EDID 确定最佳显示分辨率。支持 1080p（或 4K/8K）的显示器和电视会选择相应分辨率；如果不支持 1080p，则选择下一个可用分辨率。
* 以太网线
** BPI-M7 支持 2.5GbE
** 网线用于将 BPI-M7 连接到本地网络和互联网
* 摄像头模组
** BPI-M7 支持摄像头功能
** 推荐使用 IMX415 或 OV13850 模块，可通过 Banana Pi 淘宝店或 AliExpress 购买 
* LCD 显示屏
** BPI-M7 支持 LCD 显示
** 推荐使用 Display 10.1 HD，可通过 Banana Pi 淘宝店或 AliExpress 购买 
* 音频线
** 适用于 0.8 mm 立式插座
* USB-A 转 USB-C 数据线

== 调试接口
BPI-M7 没有独立的 3 针调试接口；使用 TTL 串口线调试时，需要连接 40 针排针。

连接 40 针排针的第 6、8 和 10 号引脚。


image::/bpi-m7/bpi-m7_debug_interface_diagram.png[bpi-m7_debug_interface_diagram.png]

串口波特率为 **1500000**，**请勿选择错误的波特率。**

Rockchip 产品启动后，可通过以下三种方式查看 IP 地址：

** 连接 HDMI 显示器并登录系统，在终端中输入 ip a 查看 IP 地址。
** 使用调试串口终端登录，输入 ip a 查看 IP 地址。
** 如果没有调试串口或 HDMI 显示器，可通过路由器管理界面查看 ArmSoM-SigeX 以太网接口的 IP 地址。但路由器有时可能不显示该地址；遇到这种情况时，请按以下步骤排查：
*** 确认 Linux 系统已正常启动。ArmSoM-SigeX 的绿灯常亮时通常表示启动正常；如果只有红灯亮，则系统未正常启动。
*** 检查网线是否连接牢固，或更换一根网线。
尝试使用不同的路由器。路由器的常见问题包括无法分配 IP 地址或正确分配 IP 地址但未在路由器界面中显示它们。
*** 如果没有其他路由器可用，请使用 HDMI 显示器或调试串口查看 IP 地址。

TIP: Rockchip 产品通过 DHCP 自动获取 IP 地址，无需额外配置。

== WiFi

Banana Pi 采用 Rockchip 平台的产品配有板载 WiFi 模块，无需外接无线网卡，并使用标准第四代天线。

=== 在服务器版镜像中通过命令行连接 WiFi

1. 首先登录 Linux 系统，可使用以下方式之一：

* 开发板已连接网线时，可通过 SSH 远程登录。
* 开发板已连接调试串口时，可通过串口终端登录 Linux 系统。
* 开发板已连接 HDMI 显示器时，可使用屏幕上显示的终端登录 Linux 系统。

2. 使用 nmcli dev wifi 命令扫描可用的 WiFi 热点：
```sh
# 1. Enable WIFI
armsom@armsom-sige:/# nmcli r wifi on
# 2. Scan for WIFI
armsom@armsom-sige:/# nmcli dev wifi
# 3. Connect to a WIFI network
armsom@armsom-sige:/# nmcli dev wifi connect "wifi_name" password "wifi_password"
```
image::/bpi-m5pro/wifi_1.png[wifi_1.png]

3. 使用 nmcli 命令连接扫描到的 WiFi 网络：

* 将 wifi_name 替换为要连接的 WiFi 热点名称。
* 将 wifi_password 替换为该热点的密码。
```sh
armsom@armsom-sige7:~$ nmcli dev wifi connect "ydtx_5G" password "ydtx123456"
Device 'wlan0' successfully activated with "wlan0b6d10bba-e1d5-4b6d-a17f-7d5ab44bbb6f".
```
4. 使用 ip addr show wlan0 命令查看 WiFi 连接的 IP 地址：
```sh
armsom@armsom-sige7:~$ ip addr show wlan0
4: wlan0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fast state UP group default qlen 1000

    inet 192.168.10.9/24 brd 192.168.10.255 scope global dynamic noprefixroute wlan0
       valid_lft 86321sec preferred_lft 86321sec
    inet6 fe80::850d:3119:e0:afa3/64 scope link noprefixroute
       valid_lft forever preferred_lft forever
```

== HDMI

BPI-M5 Pro 配有一个 HDMI 输出接口，支持 CEC 和 HDMI 2.1，最高分辨率为 4Kp120。

[options="header",cols="1,1,1,1"]
|====
|型号	|BPI-M7	|BPI-M5 Pro	|BPI-M1 Pro

使用 HDMI 线缆将开发板连接到 HDMI 显示器。

Linux 系统启动后，如果 HDMI 显示器能正常显示画面，则 HDMI 接口工作正常。

NOTE: 许多笔记本电脑虽有 HDMI 接口，但通常只支持输出，不支持 HDMI 输入，因此不能直接显示开发板输出的画面。连接前请确认笔记本电脑支持 HDMI 输入。如果没有画面，还应确认使用的是桌面版系统；服务器版可能只显示终端。

=== 测试 USB 鼠标或键盘

* 1. 将 USB 键盘或鼠标插入开发板的 USB 接口。
* 2. 将开发板连接到 HDMI 显示器。
* 3. 如果键盘或鼠标能正常操作系统，则 USB 接口工作正常（鼠标仅适用于桌面版系统）。

=== 测试 USB 存储设备

* 1. 将 U 盘或 USB 移动硬盘插入 ArmSoM-Sige 产品的 USB 接口。
* 2. 运行以下命令；如果输出中出现 sdX 设备，则表示 USB 存储设备已被识别：
```sh
armsom@armsom-sige7:/# cat /proc/partitions | grep "sd*"
major minor  #blocks  name
   8        0  122880000 sda
```
* 3. 使用 mount 命令将 USB 存储设备挂载到 /mnt，然后即可查看其中的文件：
```sh
armsom@armsom-sige7:/# sudo mount /dev/sda1 /test/
```

* 4. 挂载后，使用 df -h 命令查看设备容量使用情况和挂载点：
```sh
armsom@armsom-sige7:/test# df -h | grep "sd"
/dev/sda        4.7G  4.7G     0  100% /test
```
=== USB 摄像头

* 1. 准备一个支持 UVC 协议的 USB 摄像头，并将其连接到开发板的 USB 接口。

* 2. 使用 v4l2-ctl 命令查看 USB 摄像头的设备节点信息，通常为 /dev/video0：

```sh
armsom@armsom-sige7:/# v4l2-ctl --list-devices
Logitech HD Webcam C93 (usb-xhci-hcd.5.auto-1):
        /dev/video40
        /dev/video41
        /dev/media4
```

* 3. 在桌面版系统中，可使用 Cheese/V4L2 Test Bench 直接打开 USB 摄像头。

image::/bpi-m5pro/usb-camera.jpg[usb-camera.jpg]

也可使用终端命令预览摄像头：
```sh
armsom@armsom-sige7:/# gst-launch-1.0 v4l2src device=/dev/video0 io-mode=4 ! videoconvert ! video/x-raw,format=NV12,width=1920,height=1080 ! xvimagesink;
```

要拍摄照片：
```sh
armsom@armsom-sige7:/# gst-launch-1.0 v4l2src device=/dev/video0 io-mode=4 ! videoconvert ! video/x-raw,format=NV12,width=1920,height=1080 ! jpegenc ! multifilesink location=/home/armsom/test.jpg;
```

录制视频：

```sh
gst-launch-1.0 v4l2src num-buffers=512 device=/dev/video0 io-mode=4 ! videoconvert ! video/x-raw, format=NV12, width=1920, height=1080, framerate=30/1 ! tee name=t ! queue ! mpph264enc ! queue ! h264parse ! mpegtsmux ! filesink location=/home/armsom/test.mp4
```

== 实时时钟

* BPI-M5 Pro 配备 LK8563S RTC 芯片。
* 首先通过 2 针 0.8 mm 接口连接 RTC 电池，为 RTC 芯片供电。

NOTE: RTC 电池应保持连接，并确认系统已经创建 LK8563S RTC 设备。
```sh
armsom@armsom-sige5:/# dmesg | grep rtc  
[ 6.407133] rtc-hym8563 6-0051: rtc information is valid  
[ 6.412731] rtc-hym8563 6-0051: registered as rtc0  
[ 6.413779] rtc-hym8563 6-0051: setting system clock to 2022-06-22T01:22:26 UTC (1655860946)  
```

* 找到 rtc0 后，使用以下命令设置系统时间并同步到 rtc0：
```sh
armsom@armsom-sige5:/# hwclock -r  
2023-11-03 10:32:40.461910+00:00  
armsom@armsom-sige5:/# date  
Fri 3rd Nov 10:33:12 UTC 2023
armsom@armsom-sige5:/# hwclock -w  
armsom@armsom-sige5:/# hwclock -r  
armsom@armsom-sige5:/# poweroff  
```

* 取出 RTC 电池，等待至少 10 分钟后重新装入并启动 Sige5，检查 RTC 时间是否与系统时钟同步：
```sh
armsom@armsom-sige5:/# hwclock -r  
2023-11-03 10:35:40.461910+00:00  
armsom@armsom-sige5:/# date
Fri 3rd Nov 10:36:01 UTC 2023
```

= 注意事项

NOTE: 静电保护

. 在搬运设备之前，请确保佩戴防静电腕带或采取静电泄放措施，以免损坏开发板。 

. 组装应在静电安全环境中进行，避免在干燥和低湿度条件下操作。

. 不使用时，请将设备存放在防静电袋中，并将其保存在适当温度控制、低湿度的环境中，以防止静电积聚。

. 搬运设备时，应避免摩擦或碰撞，以免产生静电而造成损坏。 

. 握持设备时，尽量避免直接接触主板上的芯片，防止静电损坏。

. 设备运行时请勿插拔电线或其他设备，以免电涌造成损坏。

. 连接或断开 GPIO/MIPI 扩展接口时，请务必关闭电源并拔下电源线，避免带电操作造成损坏。

NOTE: 热量管理

- 如果没有有效的散热措施，主芯片的表面温度可能会超过60度。处理设备时，请避免直接接触设备 SoC 和周围的功率电感器，以防止烧伤。确保操作期间环境通风良好，以防止局部热量积聚，从而导致过热。此外，请勿将设备放置在阳光直射的地方。建议根据具体使用情况选择官方散热风扇、散热器或第三方散热套件，以确保最佳的散热性能。
