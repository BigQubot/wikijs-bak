= 简介

香蕉派 M2M 是另一个 ARM SoC 供电开发板以超便携的外形提供出色的计算性能。这是一个 51mm 的正方形， Allwinner A33 四核 A7 SoC 和 512MB DDR3 RAM.

TIP: 更多信息： link:/en/BPI-M2_Magic/BananaPi_BPI-M2_Magic[香蕉派 BPI-M2_Magic]

== 规格参数

- 四核 ARM Cortex A7 CPU. R16
- 512MB DDR3内存
- 无线网络 (AP6212) & 板载蓝牙

== Linux
=== 准备

. 准备 8G/above TF卡、 USB-串行电缆。
. 连接 USB-串行至 40 针接头 uart2，用于内核控制台调试。
+
NOTE: 注：uart0旁边的三个排针 usb 端口未调试 uart 对于 bpi 发布映像，因为 SDcard 和 uart0 是复用引脚，并且默认 bpi 映像同时支持 SD 和 eMMC。如果你想启动 emmc 仅启用uart0作为调试端口，不支持SD卡，请参阅启用 link:/en/BPI-M2_Magic/GettingStarted_BPI-M2_Magic#_enable_uart0_for_emmc_only_image_debug[uart0 调试 emmc 仅有镜像] 部分。
+
image::/picture/m2m_debug_console.jpg[m2m_debug_console.jpg]
image::/picture/m2m_pin_define.png[m2m_pin_define.png]

. 安装 bpi-tools 在你的 **Linux 电脑**，如果您无法访问该网址或有其他问题，请前往 link:https://github.com/BPI-SINOVOIP/bpi-tools[bpi-tools 回购协议] 并手动下载该工具。


**林旭**

有两种方法供您选择。

- 安装镜像 bpi-tools 上 Linux，将您的 SD 卡插入 Linux 电脑
+
```sh
$ sudo bpi-copy  xxx-bpi-m2m-xxx.img.zip /dev/sdX
```
- 使用 dd 命令安装映像 Linux,卸载SD卡设备 /dev/sdX 如果自动安装分区，实际上 bpi-copy 与此 dd 命令相同。
+
```sh
$ sudo apt-get install pv
$ sudo unzip -p xxx-bpi-m2m-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```

=== 安装镜像 eMMC

. 准备一张SD卡 Linux 镜像闪烁并用此 SD 卡启动主板。
. 复制 emmc 镜像到udisk，将udisk插入主板并安装。
. 安装与 bpi-tools 命令
+
```sh
$ sudo bpi-copy xxx-bpi-m2m-xxx.img.zip /dev/mmcblk1
```
. 或者用dd命令安装，如果自动挂载则umount mmcblk1p1和mmcblk1p2分区，实际上 bpi-copy 与此 dd 命令相同
+
```sh
   $ sudo apt-get install pv
   $ sudo unzip -p xxxb-bpi-m2m-xxx.img.zip | pv | dd of=/dev/mmcblk1 bs=10M status=noxfer
```
. 刷写完成后，安全关闭电源并弹出 SD 卡。

== 先进开发
=== 启用 uart0 emmc 仅镜像调试
. 启用 uart0 节点并禁用 sdc0 节点 sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex.
+
```sh
    --- a/sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex
    +++ b/sunxi-pack/sun8iw5p1/configs/BPI-M2M-LCD7/sys_config.fex
   @@ -262,7 +262,7 @@ twi_sda         = port:PE13<3><default><default><default>
    ;uart_type       = 2:2 wire,4:4 wire,8:8 wire, full function
    ;----------------------------------------------------------------------------------
    [uart0]
   -uart_used       = 0
   +uart_used       = 1
    uart_port       = 0
    uart_type       = 2
    uart_tx         = port:PF02<3><1><default><default>
   @@ -803,7 +803,7 @@ led3_active_low             = 1
    ;     that supports SD3.0 cards and eMMC4.4+ flashes
    ;-------------------------------------------------------------------------------
    [mmc0_para]
   -sdc_used          = 1
   +sdc_used          = 0
    sdc_detmode       = 3
    sdc_buswidth      = 4
    sdc_d1            = port:PF00<2><1><2><default>
```

. 构建 bsp 源代码。
. 复制引导加载程序文件 SD/bpi-m2m/100MB/BPI-M2M-LCD7-8k.img.gz 到优盘。 bpi 还提供 link:https://download.banana-pi.dev/d/ca025d76afd448aabc63/files/?p=%2FImages%2FBPI-M2M%2FUbuntu16.04%2FBPI-M2M-LCD7-eMMC-only-uart0-debug-8k.img.gz[预构建引导加载程序] 对于这个要求。
. 从以下位置启动 m2m 板emmc，插入udisk并挂载它。
. 将引导加载程序刷新到 emmc
+
```sh
   $ sudo bpi-bootsel BPI-M2M-LCD7-8k.img.gz /dev/mmcblk0
```
或
+
```sh
   $ sudo gunzip -c BPI-M2M-LCD7-8k.img.gz | dd of=/dev/mmcblk0 bs=1024 seek=8
   $ sync
   $ sudo umount /dev/sda1
```
. Mout 启动分区并设置内核调试控制台 uEnv.txt
+
```sh
   $ sudo mount -t vfat /dev/mmcblk0p1 /mnt
```
更改“控制台=ttyS2,115200”到“控制台=ttyS0,115200”中 /mnt/bananapi/bpi-m2m/linux/lcd7/uEnv.txt
+
```sh
   $ sudo umount /dev/mmcblk0p1
```
. 安全关闭开发板电源并连接调试 uart 到 uart0 三针接头。
