= BPI-M7 Display 10 HD 显示屏

image::/bpi-m7/banana_pi_bpi-m7_touch_screen_5.jpg[banana_pi_bpi-m7_touch_screen_5.jpg]

TIP: 更多信息：link:/en/BPI-M7/BananaPi_BPI-M7[Banana Pi BPI-M7]

Banana Pi Display 10 HD1 是一款全视角 TFT LCD（薄膜晶体管液晶显示器）模块，由 TFT LCD 面板、驱动电路和背光组成。其有效显示区域对角线尺寸为 10.1 英寸，采用条纹式像素排列，FHD 分辨率为水平 1200 × 垂直 1920 像素。通过 8 位 R.G.B 信号输入可显示 1670 万种颜色。

image::/bpi-m7/banana_pi_bpi-m7_touch_screen_4.jpg[banana_pi_bpi-m7_touch_screen_4.jpg]

== 基本规格

* 外形尺寸：143 × 228.70 × 2.25 mm（典型值）
* 显示区域：135.36（H）× 216.58（V）mm
* 像素数：1200RGB(H)×1920(V) 像素
* 像素间距：0.1128（H）× 0.1128（V）mm
* 像素排列：RGB 垂直条纹
* 显示模式：IPS
* 表面处理：AG
* 背光：白色 LED
* 系统接口：4 通道 MIPI
* NTSC：72%（典型值）
* 可视方向：全视角
* 功耗：待定（TBD）mW

= 启用显示设备树 Overlay

== 在 Ubuntu 22.04 镜像中启用显示 Overlay
使用 nano 打开 /boot/firmware/ubuntuEnv.txt 文件：

```sh
sudo nano /boot/firmware/ubuntuEnv.txt
```
在文件中找到 “overlays=” 关键字，并添加以下内容：

```sh
overlays=armsom-sige7-display-10hd
```
快捷键：Ctrl + S 保存，Ctrl + X 退出

编辑完成后重启设备，使 Overlay 设置生效并支持 Display 10 HD。

== 在 Armbian 镜像中启用显示 Overlay

使用 nano 打开 /boot/armbianEnv.txt 文件：

```sh
sudo nano /boot/armbianEnv.txt
```

在文件中查找或添加 “overlays=” 关键字。

```sh
overlays=armsom-sige7-display-10hd
```

快捷键：Ctrl + S 保存，Ctrl + X 退出

编辑完成后重启设备，使 Overlay 设置生效并支持 Display 10 HD。
