= 如何供电 BPI-Bit 董事会
板子一共有三个电源，可以任选其一

. USB 有线供电，位板设计有Micro USB 接口，在日常生活中线材是比较常见的，使用起来还是比较方便的。
+
image::/picture/bpi-bit_power_1.jpg[bpi-bit_power_1.jpg]

. 通过2Pin电池插座供电，可通过锂电池、电池组等方式给板子供电，接口有防呆设计，无需担心电源反接问题
+
image::/picture/bpi-bit_power_2.jpg[bpi-bit_power_2.jpg]

. 通过金手指供电，金手指板子下端包含了电源接口，同时兼有输入输出功能，兼容性非常高。
+
image::/picture/bpi-bit_power_3.jpg[bpi-bit_power_3.jpg]

= Webduino固件编程
== 如何烧录webduino固件
BPI-Bit 已默认烧写Webduino固件。只有当您使用其他固件重新编程Flash时，才需要再次编程Webduino固件。

如何： link:https://wiki.banana-pi.org/Webduino_firmware_programming[Webduino固件编程]

== Webduino OTA云升级
BPI-Bit 由于webduino支持OTA云升级，可以很方便地使用此功能更新最新版本。

开机位，白灯闪烁时按A键，绿灯亮时松开A键，开始更新。

image::/picture/bpi-bit_webduino_ota.jpg[bpi-bit_webduino_ota.jpg]
