= 开发
== 准备

. 准备一根 USB 转串口线和一个 5 V/3 A Type-C 电源适配器。串口线用于控制台调试，Type-C 数据线用于下载 Android 镜像和 ADB 调试。
. Linux 开发需要一张至少 8 GB 的 SD 卡；Android 仅支持从 eMMC 启动。
. SoC ROM 首先尝试从 eMMC 启动。因此，只要 eMMC 中存在可启动镜像，开发板就无法从 SD 卡启动。更多信息请参阅“启动顺序”一节。
. 仅 A311D 版本的开发板支持摄像头、MIPI 显示屏和 NPU。

=== 准备

. Linux 镜像支持从 SD 卡或 eMMC 启动。

. 在 Linux PC 上安装 bpi-tools（如果使用其他工具写入镜像，可跳过此步）。如果无法访问该地址或安装时遇到问题，请前往 link:https://github.com/bpi-sinovoip/bpi-tools[bpi-tools] 源码仓库手动下载并安装。
+
```sh
 $ apt-get install pv
 $ curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
. 下载最新的 Linux 镜像，并确认 MD5 校验值正确。
. 默认登录： pi/bananapi 或 root/bananapi
. 本 Wiki 指南仅适用于 Banana Pi 4.9 BSP Ubuntu/Debian 镜像。

=== 将镜像写入 SD 卡
> 使用 Balena Etcher 写入镜像，支持 Windows、Linux 和 macOS。

link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化镜像写入工具，可将操作系统镜像写入 SD 卡或 U 盘。

单击“Flash from file”选择镜像，单击“Select target”选择目标设备，再单击“Flash!”开始写入。

image::/picture/etcher.jpg[etcher.jpg]

> 使用 Balena CLI 写入镜像，支持 Windows、Linux 和 macOS。

link:https://github.com/balena-io/balena-cli[Balena CLI] 是 balenaCloud/openBalena 的命令行工具，可用于写入 Linux 镜像。从 link:https://github.com/balena-io/balena-cli/releases[balena-io Releases]下载安装程序或独立软件包，并按照 link:https://github.com/balena-io/balena-cli/blob/master/INSTALL.md[安装说明]正确安装到 PC。随后可使用 Balena 的“link:https://docs.balena.io/reference/balena-cli/#local-flash-image[local flash]”命令将 Linux 镜像写入 SD 卡或 U 盘。
```sh
 $ sudo balena local flash path/to/xxx-bpi-m2s-xxx.img.zip
 $ sudo balena local flash path/to/xxx-bpi-m2s-xxx.img.zip --drive /dev/disk2
 $ sudo balena local flash path/to/xxx-bpi-m2s-xxx.img.zip --drive /dev/disk2 --yes
```

> 在 Linux 中使用 dd 命令写入镜像

如果 SD 卡设备 /dev/sdX 的分区已自动挂载，请先将其卸载。bpi-copy 的实际写入方式与此 dd 命令相同。
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2s-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
> 在 Linux 中使用 bpi-tools 写入镜像 

将 SD 卡插入 Linux PC，然后运行：
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2s-xxx.img.zip /dev/sdX
```

=== 安装镜像到 eMMC

. 准备一张已写入 Linux 镜像的 SD 卡，并用该 SD 卡启动开发板。
. 将 Linux 镜像复制到 U 盘，把 U 盘插入开发板并挂载。
. 可通过以下两种方式将 Linux 镜像安装到开发板。
- 使用 dd 命令安装，如果自动安装，则 umount mmcblk0p1 和 mmcblk0p2 分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2s-xxx.img.zip | pv | dd of=/dev/mmcblk0 bs=10M status=noxfer
```
- 使用 bpi-tools 命令安装 U 盘中的 Linux 镜像
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2s-xxx.img.zip /dev/mmcblk0
```
. 下载完成后，安全关闭电源并弹出 SD 卡。

=== DTB Overlay
. DTB Overlay 用于配置 40 针 GPIO 的复用功能，文件安装在 VFAT 启动分区中。可以使用 mount 命令查看挂载点。
+
```sh
 root@bananapi:~# ls /boot/overlays/
 custom_ir.dtbo      pwm_b-backlight.dtbo  spi0.dtbo
 ds3231.dtbo         pwm_c-beeper.dtbo     uart1_cts_rts.dtbo
 hifi_pcm5102a.dtbo  pwm_cd-c.dtbo         uart1.dtbo
 hifi_pcm5122.dtbo   pwm_cd.dtbo           uart2.dtbo
 i2c1.dtbo           pwm_ef.dtbo           waveshare_tft24_lcd.dtbo
 i2c2.dtbo           pwm_ef-f.dtbo         waveshare_tft35c_lcd.dtbo
 pwm_ab.dtbo         sdio.dtbo             waveshare_tft35c_rtp.dtbo
```
. 更新 VFAT 分区中 /boot/env.txt 的 Overlay 环境变量，启用所需功能。
+
```sh
 # Device Tree Overlays
 #   uart1           -- Enable UART1 (uart_A, GPIO Header PIN8 & PIN10)
 #   pwm_c           -- Enable PWM_C (GPIO Header PIN7)
 #   i2c2            -- Enable i2c2 (GPIO Header PIN3 & PIN5)
 #   spi0            -- Enable SPI0 (GPIO Header PIN19 & PIN21 & PIN23 & PIN24)
 overlays="i2c2 spi0 uart1"
```
. 必须重新启动开发板才能加载 DTB Overlay。

=== 启用摄像头
Linux 发布镜像默认禁用摄像头，可按以下步骤启用。

. 更新 /boot/env.txt 中的 link:/zh/BPI-M2_Super/GettingStarted_BPI-M2_Super#_dtb_overlay[DTB Overlay] 环境变量，启用摄像头 DTBO。
+
```sh
 overlays="os08a10"
```
. 将摄像头模块添加到 /etc/modules：
+
```sh
 iv009_isp_iq
 iv009_isp_lens
 iv009_isp_sensor
 iv009_isp
```
. 创建 /etc/modprobe.d/os08a10.conf，并添加摄像头模块选项：
+
```sh
 #choose camera calibration parameters
 options iv009_isp_iq cali_name=0
 #choose isp register sequence
 options iv009_isp_sensor isp_seq_num=0
``` 
. 启用摄像头 ISP systemd 服务：
+
```sh
 $ sudo systemctl enable camera_isp_3a_server.service
```
重新启动后，摄像头设备为 /dev/video0。

=== 切换 MIPI 显示屏
由于硬件在启动时无法自动识别不同的 MIPI 显示屏，默认 Linux 发布镜像一次只支持一种显示屏。系统默认启用 800x1280 BPI 显示屏，也可以在 /boot/lcd_env.txt 中将默认显示屏改为 [1200x1920 BPI panel]。
```sh
 # Mipi panel type
 #    Symbol    | Resolution
 # ----------------------+-------------
 #    "lcd_0"   | 10" 800x1280 panel
 #    "lcd_1"   | 10" 1200x1920 panel
 panel_type=lcd_0
```
WARNING: 注意：Linux 不支持双屏显示，因此使用 MIPI 显示屏时请断开 HDMI 线。

=== 面板旋转
两款 10 英寸 MIPI 显示屏在硬件上均为竖屏，因此默认发布镜像采用竖屏模式，也可以将其旋转 90/180/270 度。 +
对于桌面镜像，创建 Xorg 配置文件 /usr/share/X11/xorg.conf.d/10-fbdev-rotate.conf，内容如下：
```sh
 Section "Device"
     Identifier "Configured Video Device"
     # Rotate off
 #   Option "Rotate" "off"
     # Rotate Right / clockwise, 90 degrees
     Option "Rotate" "CW"
```

=== 启用 rc-local
发布镜像中已包含 systemd 服务 rc-local.service，但其单元文件中没有 [Install] 部分，因此 systemd 无法启用该服务。首先需要更新此文件。
```sh
 $ sudo nano /lib/systemd/system/rc-local.service
```
```sh
 [Unit]
 Description=/etc/rc.local Compatibility
 Documentation=man:systemd-rc-local-generator(8)
 ConditionFileIsExecutable=/etc/rc.local
 After=network.target
 
 [Service]
 Type=forking
 ExecStart=/etc/rc.local start
 TimeoutSec=0
 RemainAfterExit=yes
 GuessMainPID=no
 
 [Install]
 WantedBy=multi-user.target
 Alias=rc-local.service
```
创建 /etc/rc.local 文件。
```sh
 sudo nano /etc/rc.local
 #!/bin/sh
 #
 # rc.local
 #
 # This script is executed at the end of each multiuser runlevel.
 # Make sure that the script will "exit 0" on success or any other
 # value on error.
 #
 # In order to enable or disable this script just change the execution
 # bits.
 #
 # By default this script does nothing.
 
 exit 0
```
为 /etc/rc.local 添加可执行权限：
```sh
 $ sudo chmod +x /etc/rc.local
```
启用 rc-local.service 并重新启动：
```sh
 $ sudo systemctl enable rc-local.service
 $ sudo reboot
```

更新 apt 软件包索引并安装软件包以允许 apt 通过 HTTPS 使用存储库：
+
```sh
 $ sudo apt-get update
 $ sudo apt-get install apt-transport-https ca-certificates curl gnupg lsb-release
```
添加 Docker 官方 GPG 密钥：
+
```sh
 $ curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
```
设置稳定存储库
+
```sh
 $  echo \
    "deb [arch=arm64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu \
    $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```
. 安装 Docker Engine
+
```sh
 $ sudo apt-get update
 $ sudo apt-get install docker-ce docker-ce-cli containerd.io
```
. 运行 hello-world 镜像，验证 Docker Engine 是否正确安装。
+
```sh
 $ sudo docker run hello-world
```
