= 简介

香蕉派 BPI-M7 用户手册帮助用户了解基本使用方法和所需的准备工作 BPI-M7

拿到后可以在板上找到它的型号和硬件版本 BPI-M7.

本文尽可能详细地向您概述产品信息。

TIP: 更多信息： link:/en/BPI-M7/BananaPi_BPI-M7[香蕉派 BPI-M7]

= 准备 

== 工具准备

* BPI-M7 主板
* 电源： USB Type-C PD
** 支持 9V/2A, 12V/2A, 15V/2A
* 系统安装 (选择一个)
** 微型SD卡 /TF 卡启动
*** 微型SD卡 card/TF, Class 10 或以上，至少 8GB SDHC 和读卡器
*** 经ArmSoM团队测试的高速TF卡：
**** 闪迪 32GB TF (微型SD卡) (开发商推荐)
**** 闪迪 32GB TF (微型SD卡) 行车记录仪和安全摄像头存储卡 (建议长期运行)
**** 闪迪 TF 8G Class10 microSD
**** 闪迪 TF 128G Class10 microSD XC TF 128G 48MB/S：
** 机上 eMMC 启动
*** USBType-C 数据线，用于从 Type-C 端口写入镜像 BPI-M7 到 eMMC。您需要连接 BPI-M7 使用 Type-C 电缆连接至 PC。

== 可选配件

* USB 键盘和鼠标
* HDMI 显示器和 HDMI 电缆
** BPI-M7 具有全尺寸 HDMI 端口，最高支持 8K@60 显示
** HDMI EDID 用于确定最佳显示分辨率。 1080p (或 4K/8K) 将在支持它的显示器和电视上选择。如果不支持 1080p，EDID 将查找下一个可用的分辨率。
* Ethernet 电缆
** BPI-M7 支持2.5Gb Ethernet
** 网线用于连接 BPI-M7 到本地网络和互联网
* 摄像头模组
** BPI-M7 支持拍照功能
** 我们推荐使用imx415模块或ov13850，可通过香蕉派淘宝店或速卖通购买 
* LCD 显示
** BPI-M7 支持 LCD 显示
** 我们推荐 Display 10.1 HD，可通过 香蕉派 淘宝店或速卖通购买 
* 音频线
** 适用于 0.8mm 垂直插座
* USB-A 至 USB-C数据线

可以通过三种方式查看IP地址 Rockchip 启动后的产品：

** 连接 HDMI 显示器，登录系统，使用终端命令 ip a 查看 IP 地址。
** 使用debug串口终端输入ip a命令查看IP地址。
** 如果调试串口和HDMI监视器均不可用，您可以检查ArmSoM-SigeX的IP地址 Ethernet 通过路由器的管理接口端口。但是，此方法有时可能无法显示 ArmSoM-SigeX IP 地址。如果看不到它，请尝试以下故障排除步骤：
*** 检查是否 Linux 系统已正常启动。如果ArmSoM-SigeX上的绿灯常亮，一般说明系统已正确启动；如果只有红灯亮，则系统尚未正常启动。
*** 确保网络电缆连接牢固，或尝试使用其他电缆。
尝试使用不同的路由器。路由器的常见问题包括无法分配 IP 地址或正确分配 IP 地址但未在路由器界面中显示它们。
*** 如果没有可用的替代路由器，请使用 HDMI 监视器或调试串行端口检查 IP 地址。

TIP: 请注意，DHCP 会自动为您分配 IP 地址 Rockchip 产品无需额外配置。

== 无线网络

香蕉派 设计 Rockchip 系列产品板载WIFI模块，无需外接网络设备。他们使用标准的第四代天线。

=== 通过服务器映像上的命令行连接到 WIFI

1.首先，登录 Linux 系统使用以下方法之一：

* 如果板子连接了网线，则可以通过SSH远程登录。
* 如果开发板是通过调试串口连接的，则使用串口终端登录开发板 Linux 系统。
* 如果开发板连接了 HDMI 显示器，您可以登录 Linux 系统通过 HDMI 显示器。

2.使用 nmcli dev wifi 命令扫描可用的 WIFI 热点：
```sh
# 1. Enable WIFI
armsom@armsom-sige:/# nmcli r wifi on
# 2. Scan for WIFI
armsom@armsom-sige:/# nmcli dev wifi
# 3. Connect to a WIFI network
armsom@armsom-sige:/# nmcli dev wifi connect "wifi_name" password "wifi_password"
```
image::/bpi-m5pro/wifi_1.png[wifi_1.png]

3.使用nmcli命令连接扫描到的WIFI：

* 更换无线网络_name 为您要连接的 WIFI 热点的名称。
* 更换无线网络_密码为WIFI热点密码。
```sh
armsom@armsom-sige7:~$ nmcli dev wifi connect "ydtx_5G" password "ydtx123456"
Device 'wlan0' successfully activated with "wlan0b6d10bba-e1d5-4b6d-a17f-7d5ab44bbb6f".
```
4.使用ip addr show wlan0命令查看WIFI IP地址：

=== 测试 USB 鼠标或键盘

* 1.插入一个 USB 键盘插入主板的 USB 端口。
* 2.将开发板连接到 HDMI 显示器。
* 3.如果鼠标或键盘操作系统正常， USB 界面工作正常 (鼠标仅适用于桌面版本的系统).

=== 测试 USB 存储设备

* 1.插入一个 USB 闪存驱动器或 USB 将外部硬盘驱动器插入 ArmSoM-Sige 产品的 USB 端口。
* 2.运行以下命令；如果您看到 sdX 输出，则 USB 驱动器识别成功：
```sh
armsom@armsom-sige7:/# cat /proc/partitions | grep "sd*"
major minor  #blocks  name
   8        0  122880000 sda
```
* 3.使用mount命令挂载 USB 开车去 /mnt 并查看文件 USB 驱动器：
```sh
armsom@armsom-sige7:/# sudo mount /dev/sda1 /test/
```

* 4.挂载后使用df -h命令查看 USB 驱动器的容量使用情况和安装点：
```sh
armsom@armsom-sige7:/test# df -h | grep "sd"
/dev/sda        4.7G  4.7G     0  100% /test
```

```sh
Logitech HD Webcam C93 (usb-xhci-hcd.5.auto-1):
        /dev/video40
```

* 3.在桌面系统上，您可以使用 Cheese/V4L2 测试台打开 USB 直接相机。

== 实时时钟

* 的 BPI-M5 Pro 采用 LK8563S RTC 芯片。
* 首先，使用 2 针 0.8mm 接头插入 RTC 电池，为 RTC IC 供电。


= 注释

NOTE: 静电保护

. 在搬运设备之前，请确保佩戴防静电腕带或采取静电泄放措施，以免损坏开发板。 

. 组装应在静电安全环境中进行，避免在干燥和低湿度条件下操作。

. 不使用时，请将设备存放在防静电袋中，并将其保存在适当温度控制、低湿度的环境中，以防止静电积聚。

. 搬运设备时，应避免摩擦或碰撞，以免产生静电而造成损坏。 

. 握持设备时，尽量避免直接接触主板上的芯片，防止静电损坏。

. 设备运行时请勿插拔电线或其他设备，以免电涌造成损坏。

. 连接或断开连接时 GPIO/MIPI扩展接口时，请务必关闭电源并拔下电源线，以免电流损坏。

NOTE: 热量管理

- 如果没有有效的散热措施，主芯片的表面温度可能会超过60度。处理设备时，请避免直接接触设备 SoC 和周围的功率电感器，以防止烧伤。确保操作期间环境通风良好，以防止局部热量积聚，从而导致过热。此外，请勿将设备放置在阳光直射的地方。建议根据具体使用情况选择官方散热风扇、散热器或第三方散热套件，以确保最佳的散热性能。
