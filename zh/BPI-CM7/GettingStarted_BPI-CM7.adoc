= 简介

Banana Pi BPI-CM7 是一款基于 Allwinner H618 的计算模块，搭配 BPI-CM7IO 载板使用。

TIP: 更多信息：link:/zh/BPI-CM7/BananaPi_BPI-CM7[Banana Pi BPI-CM7 主页]

== 规格参数

* 主控：Allwinner H618，四核 Cortex‑A53，主频最高 1.5GHz
* GPU: ARM Mali G31
* 内存：板载 LPDDR4
* 存储：板载 eMMC
* 无线：K019-CW43-Dw Wi-Fi 5 和蓝牙 5.0
* USB：1 路 USB2.0 OTG，3 路 USB2.0 Host
* 显示：HDMI 输出、CVBS 复合视频输出
* 网口：1 路 10/100M 以太网
* 扩展：microSD 卡槽、2 组 100pin 板对板连接器

= Linux 开发

. Linux 镜像支持 SD 卡或 eMMC 两种启动方式；插入 SD 卡时，板子优先从 SD 卡启动。
. SD 卡推荐：容量≥8GB，A1 等级存储卡。
. 若从 SD 卡启动：建议提前格式化 eMMC，清除原有系统。
. 若从 eMMC 启动，SD 卡仅作存储使用：SD 卡需提前格式化，不要写入系统镜像。

== 擦除 eMMC
. 确保 Linux 镜像已烧录到 SD 卡中并插入 SD 卡。插入 SD 卡默认优先 SD 卡启动。
. 终端执行下列命令，列出系统中的硬盘、分区等块设备信息。
+
```bash
lsblk
```

. mmcblk0 是 eMMC，mmcblk1 是 SD 卡。在终端中输入以下命令擦除 eMMC。此过程需要二十多分钟且不可逆，请事先备份重要数据。
+
```bash
sudo dd if=/dev/zero of=/dev/mmcblk0  #向 eMMC 全盘持续写入 0，覆盖所有分区与数据
```

== 查看 BPI-CM7 开发板硬件与系统信息
这一组命令用来**一次性读取开发板的系统版本、硬件型号、CPU、内存、存储分区、根文件系统挂载信息**，方便确认板子硬件、内核、启动介质（SD 卡 /eMMC）。
```bash
hostnamectl                                  # 查看操作系统版本、主机名、内核版本、架构
tr '\0' '\n' < /proc/device-tree/model       # 读取设备树里的硬件型号，输出**板子型号**
tr '\0' '\n' < /proc/device-tree/compatible  # 查看设备树兼容型号，用于确认芯片平台
uname -a                                     # 查看完整内核信息、架构、编译时间
lscpu                                        # 查看CPU 核心数、架构、频率等处理器信息
free -h  # 查看内存与 swap 大小，`-h` 自动用 GB/MB 友好单位展示
lsblk    # **列出块存储设备**（eMMC、SD 卡、U 盘等）
findmnt -no SOURCE,FSTYPE,SIZE,USED,AVAIL,USE%,TARGET /  # 查看**根分区 /**：磁盘来源、文件系统、总容量、已用 / 剩余空间、占用率
```

== 无线网络

=== WiFi 连接
```bash
nmcli device                                           # 查看网口硬件状态
nmcli device wifi list                                 # 列出可用的无线网络接入点
nmcli device wifi connection R4Pro-5G password ******  # 连接 WiFi
nmcli device disconnect wlan0                          # 断开WiFi
```

=== 创建 AP 热点
. 建立 AP
+
```bash
nmcli device wifi hotspot con-name AP1 ifname wlan0 ssid Annick password 88888888
```

. 确认主机热点转发与 NAT 规则。
+
```bash
ip a show wlan0                          # 查看 wlan0 的地址（10.42.0.1）
cat /proc/sys/net/ipv4/ip_forward        # 确认 IP 转发开启（如果是0，临时开启 sudo sysctl -w net.ipv4.ip_forward=1）
sudo iptables -t nat -L POSTROUTING -nv  # 查看 nat 表中 POSTROUTING 链的规则
```

. 连接热点 Annick，把手机的 ipv4 地址配置为固定 IP：10.42.0.100（网段：10.42.0.x），还要配置 DNS：223.5.5.5
+
```bash
ip neigh show dev wlan0  # 确认是否连接上热点
```

. 连通性验证
+
（1）手机 ping 网关：ping 10.42.0.1，能通代表手机到板子 WiFi 链路正常。

+
（2）手机 ping 外网：ping 223.5.5.5，通则上网正常。

. 断开创建的 AP 热点
+
```bash
nmcli connection down AP1  # 停止热点
nmcli connection show      # 查看当前所有连接（-- 代表已经停止）
```

. 如果想重新启动 AP1
+
```bash
nmcli connection up AP1
```

. 彻底删除 AP1 的配置（一定要先停止 AP1 再删除 AP1 的配置，否则直接删除 AP1 的配置会连同 wlan0 一起删除！）
+
```bash
nmcli connection delete AP1
```

=== WiFi 射频模块开关
. 关闭 WiFi 射频模块，wlan0 直接断电，创建的 AP 热点立刻消失，所有 WiFi 功能全部停用，如果没删除 AP1 的配置文件，就还保留在系统里。
+
```bash
nmcli radio wifi off
nmcli radio # 查看无线射频开关
```

. 打开 WiFi 射频模块，WiFi 硬件恢复供电
+
```bash
nmcli radio wifi on
nmcli radio  # 查看无线射频开关
```

== 设置静态 IP 和 DNS
设置静态 IP 前，需要先建立并保持相应的网络连接，以设置以太网静态 IP 为例。
```bash
nmcli connection show                       # 显示所有连接
nmcli connection show "Wired connection 1"  # 显示指定连接的全部属性
nmcli connection modify "Wired connection 1" ipv4.addresses 10.0.35.4/24  # 设置静态 ip 和子网掩码
nmcli connection modify "Wired connection 1" ipv4.dns8.8.8.8              # 设置 dns
```
测试连通性。

. ping 网关：板子和路由器之间物理 / 内网链路正常，IP 配置没问题。
+
```bash
ping 10.35.0.1
```

. ping 公网 IP：内网正常，路由器已经可以访问互联网，路由没问题。
+
```bash
ping 223.5.5.5
```

. ping 域名：DNS 解析工作正常。
+
```bash
ping baidu.com
```

```bash
cat /sys/class/thermal/thermal_zone0/temp
cat /sys/class/thermal/thermal_zone1/temp
cat /sys/class/thermal/thermal_zone2/temp
cat /sys/class/thermal/thermal_zone3/temp
```

将每个返回值除以 1000，即可得到摄氏温度。

测试结果：

```text

gpu_thermal_zone: 53.4 °C
ve_thermal_zone: 50.8 °C
```

=== scp

SCP 使用 SSH 协议，在 PC 与 BPI-CM7 之间安全复制文件。请先确认 PC 和开发板已连接到同一局域网，且 SSH 可以正常登录。

SCP 命令格式如下：

```bash
scp [options] file_source file_target
```

使用 `-r` 递归复制目录。

将本地文件从 PC 复制到 BPI-CM7：

```bash
scp local-file pi@<board-ip>:/home/pi/
```

将文件从 BPI-CM7 复制到 PC：

```bash
scp pi@<board-ip>:/home/pi/remote-file ./
```

测试结果：

```text
Upload to /tmp: successful
Remote file size and SHA-256 verification: successful
Temporary test file removal: successful
```
