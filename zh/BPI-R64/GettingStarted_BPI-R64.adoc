= 简介

香蕉派 R64 是一款基于路由器的开发板，可以在多种开源操作系统上运行，包括 OpenWrt,Linux。拥有4个千兆LAN口、1个千兆WAN口、AC wifi AP功能。采用64位芯片设计。

TIP: 更多信息： link:/en/BPI-R64/BananaPi_BPI-R64[香蕉派 BPI-R64]

== 规格参数

- MediaTek MT7622,1.35GHZ 64位双核ARM Cortex-A53
- 1G DDR3内存
- 迷你型 PCIE 接口支持4G模块
- 内置 4x4n 802.11n/Bluetooth 5.0片上系统
- MTK7615 4x4ac 板载 wifi
- 支持1个SATA接口
- MicroSD插槽支持最大256GB扩展
- 8G eMMC 闪光 (选项 16/32/64G)
- 5端口 10/100/1000 MB Ethernet 端口
- 1 个端口 USB 3.0
- 慢 I/O:ADC, 音频放大器, GPIO, I2C, I2S, IR, PMIC I/F, PWM, 实时时钟, SPI, UART
- POE 功能支持

=== 将映像安装到 SD 卡
**Windows 电脑**

link:https://balena.io/etcher[巴莱纳蚀刻机] 是 Balena 的开源 GUI 闪存工具，可将操作系统映像闪存到 SD 卡或 USB 开车。

- 点击“**从文件闪存**”来选择镜像。 
- 点击“**选择目标**”来选择 USB 设备。 
- 点击“**快闪！**“开始燃烧。

image::/picture/etcher.jpg[etcher.jpg]

**Linux**

- bpi-copy

. 安装 bpi-tools。如果您无法访问此网址或有任何其他问题，请访问 bpi-tools 存储库并手动安装此工具。
+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
``` 
. 下载镜像后，将TF卡插入电脑Ubuntu.执行
+
```sh
bpi-copy xxx.img /dev/sdx
```
将镜像安装到您的 TF 卡上

- dd
+
挂载SD卡设备 /dev/sdX 如果自动安装则分区。其实 bpi-copy 与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m5-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```

=== 安装镜像到 eMMC
将镜像刻录到之前 eMMC，请准备一张包含闪存启动映像的 SD 卡和 USB 磁盘。让我们采取 OpenWrt 镜像 (mtk-bpi-r64-preloader-emmc.bin,2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img) 例如。

NOTE: 注意：您可以从以下位置下载“.bin”文件 github: https://github.com/BPI-SINOVOIP/BPI-R64-openwrt/tree/master/staging_dir/target-aarch64_cortex-a53_musl/image

. 插入闪存的SD卡并通电以启动开发板。(SD 卡上的镜像可以 OpenWrt 或其他 linux 操作系统类似 ubuntu...)
. 复制 eMMC 可启动的 OpenWrt 镜像(mtk-bpi-r64-preloader-emmc.bin,2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img) 到 USB 磁盘，如果镜像被压缩，请在复制到之前解压 USB 磁盘。
. 插入 USB 磁盘到板上，并安装 USB 到 /mnt 或其他目录如下： (如果自动安装则可以跳过安装)
+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
. 执行以下命令以启用并将镜像复制到 eMMC:
+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=2020-04-09-OpenWRT-mtk-bpi-r64-EMMC.img of=/dev/mmcblk0
dd if=mtk-bpi-r64-preloader-emmc.bin of=/dev/mmcblk0boot0
mmc bootpart enable 1 1 /dev/mmcblk0
```
. 关机，取出SD卡 USB 磁盘，然后重新启动板 eMMC.

==== GPIO 控制
```sh
echo xxx > /sys/class/gpio/export
echo in/out > /sys/class/gpio/gpioxxx/direction
echo 0/1 > /sys/class/gpio/gpioxxx/value
```
检查底座 gpio，你可以看到我的是409

image::/picture/r64_gpio_base.jpg[r64_gpio_base.jpg]

例如：如果你想改变 gpio 22 作为高级，您需要输入如下命令：
```sh
echo 431（22+409） > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio431/direction
echo 1 > /sys/class/gpio/gpio431/value
```
==== PWM 控制

```sh
&pio {
       spic0_pins: spic0-pins {

                       function = "spi";

               };

       spic1_pins: spic1-pins {
               mux {
                       function = "spi";
                       groups = "spic1_0";
```

```sh
               vcc-supply = <&reg_3p3v>;
```

+
```sh
echo 499 > /sys/class/gpio/export
```
