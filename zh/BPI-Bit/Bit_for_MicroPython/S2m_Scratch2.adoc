= 关于 Scratch 2
为了帮助人们更快地理解计算机语言并让孩子创作自己的作品，麻省理工学院媒体实验室的专家开发了面向儿童的编程语言 Scratch。使用 Scratch 不需要记忆复杂的语法和语句，程序可以像搭积木一样通过拖放来编写，因此更直观、易于操作，学生也能轻松创作自己的作品。

image::/bpi-bit/scratch2_1.png[scratch2_1.png]

= 在 BPI:bit 上使用 Scratch 2
下面介绍如何在 Banana Pi M64 等 Linux ARM 硬件上运行 Scratch 2，并用于 BPI:bit 开发。


= 硬件前提条件
首先阅读 link:/zh/BPI-Bit/Bit_for_MicroPython/Try_burning_the_board[开发板烧录教程]，然后烧录 s2mb_firmware.bin 固件。

Note: 必须将固件重命名为 firmware.bin，否则硬件无法被识别。

烧录完成后无需拔下开发板，此时硬件已准备就绪。

= 安装 Scratch 2
== 在 Windows 系统中安装 Scratch 2
打开 link:https://scratch.mit.edu/download/scratch2[Scratch 2.0 编辑器]下载页面，先安装 Adobe AIR，再安装 Scratch Offline Editor。

image::/bpi-bit/bit-scratch2_install.png[bit-scratch2_install.png]

然后使用 Scratch 2 打开 link:https://raw.githubusercontent.com/junhuanchen/s2m/master/s2m/scratch_files/projects/s2m-bpi-bit.sb2[s2m-bpi-bit.sb2] 文件。

image::/bpi-bit/open_project.png[open_project.png]

现在可以看到更多积木块：

image::/bpi-bit/more_.png[more_.png]

红点表示设备尚未连接。此时需要下载 link:https://github.com/BPI-STEAM/BPI-BIT-MicroPython/releases/download/Firmware1230/s2m-windows.exe[s2m-windows.exe] 软件，可从 link:https://github.com/BPI-STEAM/BPI-BIT-MicroPython/releases/tag/s2mb[s2mb 发布页面]获取。

请确认已经烧录 link:https://github.com/BPI-STEAM/BPI-BIT-MicroPython/releases/download/Firmware1230/s2mb_firmware.bin[s2mb_firmware.bin] 固件。具体步骤请参阅 link:/zh/BPI-Bit/Bit_for_MicroPython/Try_burning_the_board[开发板烧录教程]。

确认运行正常：

打开 s2m-windows.exe，看到绿灯亮起后即可开始使用。

image::/bpi-bit/running_scratch.png[running_scratch.png]

如果未连接开发板，软件会显示提示。

image::/bpi-bit/bit-scratch2_scratch_error.png[bit-scratch2_scratch_error.png]

== 在 Linux 中安装 Scratch
先确认已经安装 Python 3 和 pip3，然后在 Shell 中输入：
```sh
pip3 install git+https://github.com/junhuanchen/s2m 
```
确认安装已完成。

image::/bpi-bit/try_use.png[try_use.png]

== 开始使用
安装完成后，在 Shell 中输入 s2m。程序会自动查找串口并启动服务，因此请确保开发板已经连接。

由于不同环境中的 Scratch 2 安装方式可能不同，建议直接下载并打开项目文件。可下载 s2m-link:https://raw.githubusercontent.com/junhuanchen/s2m/master/s2m/scratch_files/projects/s2m-bpi-bit.sb2[bpi-bit.sb2] 项目；项目也位于 link:https://github.com/junhuanchen/s2m/tree/master/s2m/scratch_files/projects[此目录]（即 s2m 目录）中。

使用 Scratch 2 加载项目文件。顶部栏出现绿点时，表示 s2m 已正常工作，并可从硬件获取数据。此后即可在 Scratch 2 中使用 BPI:bit 学习编程。如需增加其他功能，可用 ZIP 工具打开项目文件并编辑其中的 project.json，以添加更多积木块；相应功能还需要同步修改 s2m 和 s2mb 源代码。
