我们编写了这份入门指南来帮助您开始使用
BPI-Centi-S3 开发板快。

== 第一件事

使用一个 USB-C 电缆具有电源和数据功能，用于连接
BPI-Centi-S3 开发板连接到您的计算机。

第一次使用时，屏幕会立即显示
开机后进入欢迎界面，蜂鸣器响两声。

BPI-Centi-S3 已编程为 MicroPython 1.19.1 固件和
出厂时已集成ST7789 C模块驱动。它是
推荐初学者使用 MicroPython 发展和学习。

== 使用 MicroPython 快速开始

. 参见 link:./MicroPython/environment.md[安装并配置
环境]，安装 Python 3、mpremote工具、mpbridge工具、VScode
IDE.
. 参见 link:./MicroPython/VScode_mpbridge.md[如何使用VScode + MP桥
工具] 学习如何连接开发板、复制、修改、
并删除开发板上的文件。
. 参见 link:./MicroPython/REPL_use_case.md[REPL 使用案例] 快点
了解常用快捷键 MicroPython REPL 和方法
查看模块。

. 经过以上三步，就可以开始开发了。

. 用于学习 Python 和 MicroPython，我们建议开始使用
Python 在 link:https://docs.python.org/3.10/tutorial/index.html[Python
教程]. 
+
另外，尝试了解 link:./MicroPython/What_is_MicroPython[什么是 MicroPython?]

. 应用您所学到的知识 Python，然后看看
link:https://docs.micropython.org/en/latest/index.html[MicroPython
文档]，您可以快速参考 MicroPython的专门图书馆，
供我们开发的ESP32端口专用库。

. 在页面上了解两者之间的一些区别
link:https://docs.micropython.org/en/latest/genrst/index.html#[Differences
之间 MicroPython 和 CPython].

. 在本页的下一部分中，您可以找到一些 MicroPython 例子
这可能对你有帮助。

. ST7789 C模块驱动来自：
+
link:https://github.com/russhughes/st7789s3_esp_lcd[russhughes/st7789s3_esp_lcd],
麻省理工学院许可证
+
在这个 GitHub 存储库，您可以查看st7789的所有方法
模块，以及编译的方法，感谢 russhughes 的帮助
开源贡献。

. 如果您在开发过程中遇到意想不到的恶性BUG导致无法
开发板无法正常启动，或其他原因导致
固件被擦除或损坏，请参阅
link:./MicroPython/Burn_firmware.md[烧录固件].
