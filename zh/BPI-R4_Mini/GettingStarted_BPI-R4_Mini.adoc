= 概述

Banana Pi BPI-R4 Mini 是一款基于 MediaTek MT7987A 四核 Arm Cortex-A53 处理器设计的 Wi-Fi 7 智能路由器开发板，支持 2 GB DDR4 内存和板载 8 GB eMMC 闪存，配有两个 2.5G RJ45 网口和板载 Wi-Fi 7，尺寸小巧。 

= 开发
== 准备工作
* U 盘 +
* USB Type-C 数据线 +
* CAT6A/Cat5e 以太网线 +
* 12 V/5 A 电源适配器（未连接任何外设和网线时，BPI-R4Mini 主板功耗约为 10 W，因此 12 V/2 A 电源也可工作。
请根据实际使用的配件判断是否需要更高功率的电源适配器，建议使用 12 V/5 A） +
* Windows/Ubuntu 系统 +
* link:https://docs.banana-pi.org/zh/BPI-R4_Mini/BananaPi_BPI-R4_Mini[BPI-R4Mini 镜像] +
* link:https://docs.banana-pi.org/zh/BPI-R4_Mini/BananaPi_BPI-R4_Mini[BPI-R4Mini 源代码] +

== 写入镜像
=== 将镜像写入 NAND 闪存
TIP: 工厂镜像信息：OpenWrt 24.10-SNAPSHOT；架构：aarch64_cortex-a53


将镜像写入 NAND 前，请先准备一个 U 盘。以下以 OpenWrt 镜像（mtk-bpi-r4mini-NAND-20260721.img）为例：

1.	将 U 盘格式化为 FAT32。

2.	将 NAND 启动用 OpenWrt 镜像（mtk-bpi-r4mini-NAND-20260721.img）复制到 U 盘。
3.	将启动模式切换为 eMMC 启动，然后给开发板上电。
4.	将 U 盘插入开发板，并按如下方式挂载到 /mnt 或其他目录（如果系统已自动挂载，可跳过此步）：
+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt
```
5.	执行以下命令擦除整个 NAND 闪存，并将镜像写入 NAND 设备：
注意：R4Mini 的 NAND 镜像写入 MTD0。

2.	将 eMMC 启动用 OpenWrt 镜像（bl2_emmc-r4mini.img、mtk-bpi-r4mini-EMMC-20260721）复制到 U 盘。

== 开机
• 使用 USB Type-C 数据线连接 BPI-R4Mini 上的调试控制台接口（CN3）。
• 安装终端模拟器，或使用熟悉的串口终端软件。
• 串口参数设置如下：波特率 115200、数据位 8 位、无校验、停止位 1 位、无流控。
• 接通电源前先设置启动模式。
（首次使用 BPI-R4Mini 时，建议设置为 NAND 启动。）
• 将电源适配器连接到 DC-IN 接口（CN6）后，绿色“PWR”LED 点亮，控制台中会显示类似以下内容，表示 BPI-R4Mini 已成功启动。

== 读写 EEPROM
WARNING:  注意：我们发布的镜像文件每次启动时都会使用随机 MAC 地址，并不使用 EEPROM。如需使用 EEPROM，必须自行编写脚本读取数据并更新端口。

=== 读取 EEPROM +

```sh

hexdump -C /sys/bus/i2c/devices/0-0057/eeprom 
```


=== 向 EEPROM 写入内容

```sh
printf '\x01\x02\x03\x04\x05\x06' | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=32 conv=notrunc
```

"**\x01\x02\x03\x04\x05\x06**" 是准备写入的内容，可以是 MAC 地址、序列号或其他信息。 +
"**bs=1**" 表示块大小为 1。 +
"**seek=32**" 表示偏移量（即跳过的块数）。 +
**"bs=1 seek=32**" 表示跳过 32 字节，即跳过 0x00 至 0x1F，从 0x20 开始写入内容。 +
"**conv=notrunc**" 表示不截断 EEPROM，保留原有数据。

例如，要分别向地址 **0x20** 和 **0x30** 写入两组 MAC 地址：

```
printf '\x12\x41\x89\x7F\x64\xD3' | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=32 conv=notrunc
printf '\x7E\xF5\x56\x36\x4C\xD1'  | dd of=/sys/bus/i2c/devices/0-0057/eeprom bs=1 seek=48 conv=notrunc
```

WARNING:  **注意：由于 V1.2 版本的后续批次计划向 EEPROM 写入数据，因此必须避开 0x00 至 0x1F 的地址范围。**

== M.2 Key（B+M）插槽（用于 4G/5G 模块或 NVMe SSD）

=== 4G/5G 模块
BPI-R4Pro 设有一个 M.2 B-Key 插槽，可用于安装 4G/5G 蜂窝通信模块。

该插槽支持一组 USB 2.0 和 USB 3.0 信号，两者均通过 USB 3.0 Hub 扩展。

此外，CN8h 还提供一路 PCIe 3.0 单通道信号。

image::/bpi-r4_mini_en/m.2_key_b_slot.png[m.2_key_b_slot.png]

=== NVMe SSD

M.2 Key 插槽一次只能安装一种 M.2 模块。

因此，4G/5G 模块与 NVMe SSD 只能二选一安装。


== Nano SIM 卡槽
SIM1 可以使用板载 Nano SIM 卡槽。

== FPC 连接器
这是一个 16 针连接器。

通常用于连接 SPI LCD 或 I2C 电容触摸屏。

image::/bpi-r4_mini_en/fpc.png[fpc.png]


== 调试 UART 
BPI-R4Mini 板载 USB 转 UART 芯片（HT42B534-2），连接到 MT7988A 的调试 UART。

将 USB Type-C 接口（CN41）连接到 PC 后，系统中会出现一个 USB 串口设备，可用于调试。

终端参数：波特率 115200、数据位 8 位、无校验、停止位 1 位、无流控。

== eSIM
M.2 B-Key 插槽的 42/44/46/48 号引脚为第二组 SIM 卡信号。

NOTE: 此功能需要所用模块提供支持，并且需要额外安装 eSIM 模块。

image::/bpi-r4_mini_en/esim.png[esim.png]

== EEPROM
板载一颗 EEPROM 芯片（P24C02A），可用于存储少量数据。

== 按钮
=== 重置
TIP: 短按 RST 可重新启动系统，长按可重置系统。

GPIO0连接有复位按钮，用于新设备快速连接路由器。

== LED
BPI-R4Mini 配有多组 LED，用于指示电源、Wi-Fi、以太网、4G/5G 蜂窝网络等工作状态。

* 1 个绿色电源 LED，PCB 丝印为“PWR”；上电后点亮，不能由软件控制。
* 1 个蓝色状态 LED，PCB 丝印为“B”，由 GPIO“PCA_A_IO1_6/SYS_LEDB”控制。
* 2 个蓝色 Wi-Fi 状态 LED，PCB 丝印分别为“W2G”和“W5G”。
* 1 个蓝色 5G 蜂窝网络状态 LED，PCB 丝印标识。 
* 每个 2.5G RJ45 接口有两个 LED，每个 1G RJ45 接口有一个 LED，用于指示网络状态。

== DCIN
BPI-R4Pro 使用单路 +12 V 供电，并支持直流电源适配器、USB PD、PoE 等多种供电方式。

供电电压范围为 9～24 V，建议使用 12 V 或 20 V；电压超过 25.3 V 时会自动关机。

=== DCIN(5521)
可以将 12 V/5 A 电源适配器接入 CN44 为开发板供电。
如果同时接入其他电源，系统会切换到其他供电输入。

== USB Type-C PD
USB Type-C PD 接口连接到 CH224Q 芯片，用于与 USB 电源适配器通信，使适配器输出 20 V 电压。 +
建议使用支持 20 V 输出且功率不低于 65 W 的 PD 电源。 

== USB 2.0 接口
BPI-R4Mini 配有一个 USB 2.0 Type-A 接口，可连接 U 盘或其他 USB 设备。 +
USB 2.0 接口（CN12）的电源输出为 5 V/1300 mA；将“PCA_A_IO1_3/VBUS_AB_PDN”输出低电平可关闭供电。 +

== 散热片

以下是 MTK OpenWrt MP4.0 的 PWM 风扇控制参考脚本。
```bash
root@OpenWrt:~# cat /sbin/fan-speed 
#!/bin/sh /etc/rc.common

if [ ! -f /sys/class/pwm/pwmchip0/export ]; then
        exit 0
fi

### enable fan ###
echo 2 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm2/period
echo 7000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm2/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm2/enable

while :
do
        sleep 20
        result=`cat /sys/class/thermal/thermal_zone0/temp`

        temperature=$((result))
        #echo $temperature
        if [ ${temperature} -ge 53000 ]; then
                echo 7000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -ge 62000 ]; then
                echo 10000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -le 4800 ]; then
                echo 5000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi

        if [ ${temperature} -le 4000 ]; then
                echo 3000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle
        fi
done
root@OpenWrt:~#
```
