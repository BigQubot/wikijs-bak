在上一节的基础上，我们可以更进一步，写一个循环来自动改变灯珠的颜色。

```py
from machine import Pin
from neopixel import NeoPixel
import time

def rainbow(num=1,level=25,delay=100):
     def write_all(num,delay,red,green,blue):
         for j in range (num):
             np[j] = (red,green,blue)
         np. write()
         time. sleep_ms(delay)
    
     red,green,blue = level,0,0
    
     rainbow_step_list2 = [(0,1,0),(-1,0,0),(0,0,1),(0,-1,0),(1,0,0),(0,0, -1)]
    
     for step in rainbow_step_list2:
         for i in range (level):
             red+=step[0]
             green+=step[1]
             blue+=step[2]
             write_all(num,delay,red,green,blue)
            


np = NeoPixel(Pin(48, Pin.OUT), 1,bpp=3, timing=1)

while True:
     rainbow(num=1,level=25,delay=10)

```
本例程适用于任意长度的 WS2812 灯带。

将 `NeoPixel(Pin(48, Pin.OUT), 1,bpp=3, timing=1)` 的第一个参数改为需要串接灯带的任意 GPIO 引脚。

将 `rainbow(num=1,level=25,delay=100)` 中的 num 参数改为灯带上对应的 LED 数量。

也可以根据需要使用 for 或 while 循环，实现自定义的颜色变化效果。
