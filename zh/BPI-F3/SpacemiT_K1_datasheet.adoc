== SpacemiT K1 简介

SpacemiT® Key StoneTM K1 是一款高性能、超低功耗 CPU，集成八个 RISC-V 核心和 SpacemiT® Daoyi™ AI 算力扩展。K1 具有以下特点： 

* 集成 SpacemiT® 自主创新的 X60™ RISC-V 处理器核心，符合 RISC-V 64GCVB 架构和 RVA22 标准。
* 通过 RISC-V 自定义指令扩展 2.0 TOPS AI 算力，实现 CPU 与 AI 融合计算，并支持 TensorFlow Lite、TensorFlow、ONNX Runtime 等主流 AI 推理框架。
* 通过不同粒度的电源岛和多级电源状态实现超低功耗，提升 K1 的能效与竞争力。 
* 提供功能完整的接口，支持更丰富的创新应用和产品。
* 兼容主流操作系统，满足各种应用场景的需求。
* 符合工业级可靠性标准

== CPU 子系统

=== 概述
K1 的 CPU 子系统具有以下特性： 

* 包含两个非对称 CPU 集群：Cluster0 集成四个带 2.0 TOPS AI 算力扩展的 RISC-V SpacemiT® X60™ 核心；Cluster1 集成四个不带 AI 功能的 RISC-V SpacemiT® X60™ 核心
* 每个高性能、低功耗 SpacemiT® X60™ CPU 核心均符合 RISC-V 64GCVB 架构和 RVA22 标准
* 支持核心本地中断控制器 CLINT 和平台级中断控制器 PLIC
* 符合 RISC-V Debug V0.13.2 标准
* 看门狗复位时保存 CPU 关键信息快照，供调试使用
* 针对各 CPU 核心和集群设计电源岛与两级电源策略，实现超低功耗 

=== SpacemiT® X60™ RISC-V 内核

X60™ 是一款创新、高效的处理器核心，集成 SpacemiT® Daoyi™ AI 创新扩展，符合 RISC-V 64GCVB 和 RVA22 标准。为满足当前与未来的计算需求，它采用多种 DSA 技术和微架构优化，为 AI 应用、机器学习、SLAM 等提供强大算力。X60™ 核心具有以下特点： 

image::/bpi-f3/cluster_micro-architecture.png[cluster_micro-architecture.png]

* RISC-V 64GCVB 和 RVA22 标准
* 每个核心具有 32KB L1-I Cache 和 32KB L1-D Cache
* 每个集群具有 512KB L2 Cache 
* Cluster0 具有 512KB TCM（紧耦合内存），用于 AI 扩展
* L1 Cache 支持 MESI 一致性协议，L2 Cache 支持 MOESI 一致性协议
* 矢量扩展：RVV1.0/VLEN 256/128-bit x2 执行宽度
* Cluster0 中集成自主设计的 AI 自定义指令
* 支持 CLINT 和 PLIC，共 256 个中断
* 支持 RISC-V 性能 PMU
* 支持 SV39 虚拟内存
* 支持 32 个符合 RISC-V 安全框架的 PMP 条目
* 支持 RISC-V 调试框架


=== 中断
平台中断控制器由 PLIC 和 CLINT 组成，由两个集群共享。异常处理（包括异常和中断）是处理器的重要功能，可把运行时事件转交给相应核心处理。这些事件包括硬件错误、指令执行错误、用户程序请求及服务产生的外部中断等。

X60 实现了处理器核心本地中断控制器（CLINT），它是一个内存地址映射模块，用于处理软件中断和定时器中断。

平台级中断控制器（PLIC）负责采样外部中断源、进行优先级仲裁并分配中断。在 PLIC 模型中，每个核心的机器模式与监管者模式都可作为中断目标。PLIC 支持 256 个外部中断源，每个中断均支持电平和边沿触发。

=== 调试和跟踪

调试接口是软件与处理器交互的通道。用户可通过它读取 CPU 寄存器、内存内容及其他片上设备信息，也可执行程序下载等操作。

调试系统由调试软件、调试代理服务、调试器和调试接口组成。调试软件与调试代理服务通过网络互连，调试代理服务与调试器通过 USB 连接，调试器则通过 JTAG 接口与 CPU 通信。

JTAG 内存访问可采用 progbuf 或 sysbus 模式。progbuf 是通过 CPU 访问的常规 JTAG 方式；sysbus 则通过 SBA（System Bus Access）端口绕过 CPU，直接访问片上资源。
