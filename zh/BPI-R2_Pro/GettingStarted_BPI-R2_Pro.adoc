= 简介

Banana Pi BPI-R2 Pro 是 Banana Pi 于 2021 年推出的新一代智能路由器开发板，搭载 Rockchip RK3568 处理器、2 GB LPDDR4 内存和 16 GB eMMC 存储。开发板提供 2 个 USB 3.0 接口、5 个千兆网口、M.2 Key E 和 Mini PCIe 接口、2 个 MIPI DSI 接口（其中一个可通过软件切换为 LVDS）、1 个 CSI 摄像头接口和 1 个 HDMI 输出。

TIP: 更多信息：link:/en/BPI-R2_Pro/BananaPi_BPI-R2_Pro[Banana Pi BPI-R2_Pro]

= Android 开发
== 准备

. 一根双公头 USB 数据线，用于下载镜像或通过 adb 调试。
. 如需查看串口调试信息，准备一根 Micro-USB 线或 USB 转 TTL（**3.3V**）串口线；默认波特率为 **1500000**。
. 一台 Windows 或 Linux PC。
. 下载最新 Android 镜像，并在烧录前确认 MD5 校验和正确。
. LAN 口默认 IP 地址：**192.168.1.1**
. 用户名/密码：**pi/bananapi ,root/bananapi**。 +
也可能使用 root 用户且无密码。

=== 切换 USB OTG 模式
顶部 USB 端口是 USB 3.0 OTG 端口，但未连接硬件 ID 引脚，因此只能通过软件选择 Host 或 Peripheral 模式。发布镜像默认为 Host 模式，可在 Settings 中更改。

. 平板版镜像 +
进入 Settings -> Connected devices -> USB Connect to PC；开关打开时为 Peripheral 模式，关闭时为 Host 模式。
+
image::/picture/otg_mode.png[otg_mode.png]

. 电视盒版镜像 +
进入 Settings -> Device Preferences -> About，连续点击“Build”七次以启用 Developer options。然后返回 Settings -> Device Preferences -> Developer options；开关打开时为 Peripheral 模式，关闭时为 Host 模式。
+
image::/picture/box_otg_mode.png[box_otg_mode.png]

== 触摸屏
R2 Pro 硬件仅提供一组触摸屏 I/O，CN7、CN8 和 CN9 均连接到该组信号，因此同一时间只能使用其中一个触摸屏接口。可在 DTB 中启用或禁用相应接口。
```sh
 &i2c1 {
         status = "okay"
 }
```

== 定制 Android 开机标志
. 准备两个 BMP 文件：logo.bmp 用作 U-Boot Logo，logo_kernel.bmp 用作内核 Logo。
. 可通过以下两种方式替换 Logo。
a. 使用 adb 工具创建并替换 Logo +
link:/en/BPI-R2_Pro/GettingStarted_BPI-R2_Pro#_usb_otg_mode_switch[切换 OTG 端口]以启用 adb，然后将 Logo 文件推送到 /sdcard/ 目录。
+
```sh
 $ adb push logo_kernel.bmp /sdcard/
 $ adb push logo.bmp /sdcard/
 $ adb root
 $ adb shell
```
创建 logo.img
+
```sh
 bananapi_r2pro:/ # cd /sdcard/
 bananapi_r2pro:/sdcard # cat logo.bmp > logo.img && truncate -s %512 
logo.img && cat logo_kernel.bmp >> logo.img
```
将 logo.img 烧录到 logo 分区
+
```sh
 bananapi_r2pro:/sdcard # dd if=logo.img  of=/dev/block/by-name/logo
 24301+1 records in
 24301+1 records out
 12442166 bytes (12 M) copied, 1.104449 s, 11 M/s
```
重新启动 Android
+
```sh
 bananapi_r2pro:/sdcard # reboot
```
b. 在 Linux 上创建 Logo，并通过 RKDevTool 替换 +
在 Linux 上创建 logo.img
+
```sh
 $ cat logo.bmp > logo.img && truncate -s %512 logo.img && cat logo_kernel.bmp >> logo.img
```
打开 RKDevTool.exe，切换到“Download Image”页面，并按下图修改各项。按住 REC/LOADER 按钮并为开发板上电或复位，使其进入 Loader 下载模式，然后单击 Run，将 logo.img 烧录到 logo 分区。
+
image::/picture/flash_logo.png[flash_logo.png]
