= 简介

Banana Pi M2+ 是一款迷你开发板，在小巧便携的外形中提供了出色的计算性能。板体尺寸为 65 mm × 65 mm，采用 Allwinner H 系列芯片。产品有多个版本，但各版本使用相同的接口。

TIP: 更多信息：link:/en/BPI-M2_Plus/BananaPi_BPI-M2_Plus[Banana Pi BPI-M2 Plus]

== 规格参数

- 四核 1.2 GHz Cortex-A7 H3
- 1 GB DDR3
- 板载 8 GB eMMC
- 板载 WiFi 和蓝牙
- 10/100/1000 Mbps 以太网端口

== Linux
=== 准备

. 准备一张至少 8 GB 的 TF 卡和一个 USB 转串口适配器。
. 使用 USB 转串口适配器连接 M2P 的调试控制台。
. 登录用户名/密码：pi/bananapi 或 root/bananapi。

=== 将镜像烧录到 SD 卡

**Windows 电脑**

使用 Balena Etcher 烧录镜像。+
link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化烧录工具，可将操作系统镜像写入 SD 卡或 USB 存储设备。

. 单击“**Flash from file**”选择镜像。 
. 单击“**Select target**”选择目标设备。 
. 单击“**Flash!**”开始烧录。

image::/picture/etcher.jpg[etcher.jpg]

**Linux 电脑**

**可以选择以下两种方法。**

. 使用 Linux 的 dd 命令烧录镜像。如果 /dev/sdX 的分区被自动挂载，请先卸载。bpi-copy 实际执行的操作与此 dd 命令相同。
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo unzip -p xxx-bpi-m2_plus-xxx.img.zip | pv | dd of=/dev/sdX bs=10M status=noxfer
```
. 使用 Linux 上的 bpi-tools 烧录镜像。将 SD 卡插入 Linux 电脑并执行
+
```sh
 $ sudo apt-get install pv unzip
 $ sudo bpi-copy xxx-bpi-m2_plus-xxx.img.zip /dev/sdX
```

 
=== 将镜像烧录到 eMMC

. 将“xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img”复制到 U 盘。
. 将 U 盘插入 M2P。
. 执行以下命令（如果已自动挂载，可跳过此步）
+
```sh
mont /dev/sda1 /mnt
```
. 可以使用以下两种方法将镜像烧录到 eMMC。
- 使用 bpi-copy 烧录。
+
```sh
bpi-copy xxx-sd-emmc-xxx.img.zip / xxx-sd-emmc-xxx.img
```
- 使用 dd 命令烧录。
+
```sh
sudo dd if=/mnt/sda1/xxx-sd-emmc-xxx.img of=/dev/mmcblk0
```

. 关闭 M2P 电源，取出 TF 卡，再次上电后从 eMMC 启动。

=== 更新镜像
例如，将现有镜像更新为支持新版 eMMC 5.1。
```sh
  * 执行“bpi-tools”，更新 bpi-tools；
  * 执行“bpi-update -c bpi-m2p.conf”，下载新驱动并更新镜像
  * 执行“file *.tgz”，检查下载文件的类型是否为压缩数据
  * 执行“bpi-bootsel”，查看引导加载程序路径：“/usr/lib/u-boot/bananapi/bpi-m2p/BPI_M2P_720P.img.gz”
  * 执行“bpi-bootsel /usr/lib/u-boot/bananapi/bpi-m2p/BPI_M2P_720P.img.gz”，更新引导加载程序
  * 重新启动
```

=== 制作镜像
. 准备一张已安装系统（Ubuntu、Raspbian 等）的 SD 卡。
. 使用该 SD 卡启动 M2P。M2P 启动完成后，复制所需文件并配置系统，然后关闭 M2P。[如果不需要配置系统，可跳过此步]
. 将 SD 卡插入运行 Linux 的电脑。
+
```sh
cd /media
ln -s <your account> pi
```
. 执行
+
```sh
bpi-migrate -c bpi-m2p.conf -c ubuntu-mate-from-sd.conf -d /dev/sdx
```
. 完成后即可得到自己的镜像。

=== GPIO 控制
- 要访问 GPIO 引脚，首先需要使用以下命令将其导出
+
```sh
 echo XX > /sys/class/gpio/export
```
- XX 是目标引脚的编号。要得到正确编号，需要根据引脚名称（如 PH18）进行计算。
+
（字母在字母表中的序号 - 1）× 32 + 引脚号
+
以 PH18 为例：（8 - 1）× 32 + 18 = 224 + 18 = 242，因为 h 是第 8 个字母。
+
```sh  
echo "out/in" > /sys/class/gpio/gpio*NUMBER*/direction
 echo "0/1" > /sys/class/gpio/gpio*NUMBER*/value
```

=== OTG
. 在 M2P 控制台上：
+
执行 
+
```sh
./adbd.sh
ps -ax | grep adbd
```
检查 adbd 是否已启动

. 在电脑终端中：

- 如果 adbd 已成功启动，请用 OTG-USB 线连接 M2P 和运行 Ubuntu 的电脑。

- 执行
+
```sh
adb devices
```
检查电脑是否已识别 M2P 的 OTG 设备。
+
- 如果已经识别，可以执行
+
```sh
adb shell
```
此时即可通过 adb 连接 M2P。
