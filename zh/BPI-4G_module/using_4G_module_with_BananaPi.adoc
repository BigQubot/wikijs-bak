= 如何在 BPI-R2 上使用 BPI-4G LTE 模块

== 开始使用
论坛讨论帖：http://forum.banana-pi.org/t/how-to-use-bpi-4g-lte-module-with-bpi-r2/5223/4

image::/picture/usb_4g_1.jpg[usb_4g_1.jpg]

. 首先通过 USB 或 14 针排针将 R2 连接到 LTE 模块，然后执行 “lsusb” 命令，检查 R2 是否已驱动该模块。红框中显示的是 4G 模块 ID。
+
image::/picture/usb_4g_2.png[usb_4g_2.png]
+
看到该设备后，执行 “ls /dev/ttyUSB*” 命令，确认 4G 模块已被识别为 USB 设备。
+
image::/picture/usb_4g_3.png[usb_4g_3.png]

. 执行 “./ppp1.sh &”。
+
image::/picture/usb_4g_4.png[usb_4g_4.png]
+
然后执行 “ifconfig -a” 命令，应能看到 ppp0 接口。
+
image::/picture/usb_4g_5.jpg[usb_4g_5.jpg]

. 执行 “wget -O speedtest-cli https://raw.githubusercontent.com/sivel/speedtest-cli/master/speedtest.py” 命令，下载网速测试工具。
+
image::/picture/usb_4g_6.png[usb_4g_6.png]

. 执行 “chmod +x speedtest-cli”，然后运行 “./speedtest-cli”。
+
image::/picture/usb_4g_7.png[usb_4g_7.png]
+
ppp1_success_log.txt ： http://forum.banana-pi.org/uploads/default/original/2X/e/eb7d46a0971c25f6337116d60e76590ce298b676.txt

= FAQ

. **Q：遇到 “expect (OK) ^M alarm Failed” 错误时该怎么办？**
+
image::/picture/usb_4g_8.png[usb_4g_8.png]
+
**A**：根本原因是 ModemManager.service 占用了 usbserial，因此 4G 模块无法使用 usbserial。可以执行 “systemctl disable ModemManager.service” 或 “systemctl stop ModemManager.service” 解决。

. Q：如何测试 SIM 卡与 4G 模块之间的通信？
+
A：使用 minicom，执行 “minicom -D /dev/ttyUSB2”，然后用 AT 命令测试，例如 “at”“at+csq”“at+ccid”。如果收到响应且没有报错，说明通信正常。

. **Q：如何安装 libqmi？**
+
A：从此处下载：http://www.linuxfromscratch.org/blfs/view/cvs/general/libqmi.html ；然后执行 make 和 make install。
+
如果遇到下图所示错误：
+
image::/picture/usb_4g_9.png[usb_4g_9.png]
+
需要安装 libgudev-1.0-dev，然后再次执行 make 和 make install。

. *Q：如何使用 qmi-wwan？*
+
A：使用方法很简单。将 quectel-CM 放在 root 的主目录中，执行 “./quectel-CM &”，再执行 “dhclient wwan0”，即可完成配置。

. OpenWrt 支持：

A. 从以下链接克隆源代码：BPI-R2 OpenWrt（LEDE）源代码：2018-04-11

B. 将 qmi-wwan 驱动程序添加到该项目中：

- 执行 “./scripts/feeds/ install minicom”，将 minicom 安装到 OpenWrt 项目
- 执行 “./scripts/feeds/ install python”，将 Python 安装到 OpenWrt 项目
- 执行 “make menuconfig”
- 添加 minicom：“Utilities —> Terminal —> minicom”
- 添加 Python：“Languages —> Python”
- 添加驱动：“Network —> wwan ... Generic OpenWrt 3G/4G proto handler”
- 添加 “Kernel modules —> USB Support —>
- kmod-usb-core
- kmod-usb-net —> kmod-usb-net-qmi-wwan
- kmod-usb-ohci
- kmod-usb-serial —> kmod-usb-serial-option、kmod-usb-serial-wwan
- kmod-usb-uhci
- kmod-usb2-*
- 使用这些源文件替换 OpenWrt 项目中的源文件（“build_dir/target-arm_cortex-a7+neon-vfpv4_musl_eabi/linux-mediatek_32/linux-4.9.44/drivers/usb(or net)/…”）：

. 如果通过 14 针排针将 mPCIe 接口的 4G 模块连接到 R2，请使用以下命令启用模块。完成这些步骤后，USB0 接口将被禁用。
+
```sh
cd /sys/class/gpio/
echo 266 > export 【# 266(gpio_offset) = 232(base) + 34(GPIO_34)】
cd gpio266/
echo out > direction
echo 1 > value
```
