= 简介

Banana Pi BPI-R4 Lite 是一款基于 MediaTek MT7987A 四核 Arm Cortex-A53 处理器设计的高性能开源路由器开发板。板载 2 GB DDR4、8 GB eMMC、256 MB SPI NAND、32 MB SPI NOR 和 MicroSD 卡槽；配有一个 2.5G SFP LAN、一个 2.5G RJ45 WAN、四个 1G RJ45 LAN 和一个 USB 3.0 接口。扩展接口包括一个支持 USB 3.0 的 M.2 Key B 插槽（用于 5G 模块）、一个支持 PCIe 3.0 双通道的 miniPCIe 插槽（用于 Wi-Fi 7 网卡；也可选配两个 PCIe 3.0 单通道 miniPCIe 插槽）、一个支持 USB 2.0 的 miniPCIe 插槽，以及一个 USB Type-C 调试控制台。

SW3_A 和 SW3_B 控制 MT7987 芯片输出的选择信号：

“00”表示从 SD 卡启动。

“01”表示从 NOR 启动。

“10”表示从 NAND 启动。

“11”表示从 eMMC 启动。

SW3_C 通过 U24 在 NAND 与 NOR 之间选择：
SW3_C 为 1 时，开关在物理上连接到 NOR。
SW3_C 为 0 时，开关在物理上连接到 NAND。

SW3_D 用于在 SD 卡与 eMMC 之间选择：
SW3_D 为 1 时，开关在物理上连接到 eMMC。
SW3_D 为 0 时，开关在物理上连接到 SD 卡。

== 镜像
下图为示例：

image::/bpi-r4_lite/image.png[image.png]

请参照上面的启动跳线示意图：

对于 mtk-bpi-r4lite-EMMC-NAND-MP4_2-2PCIe-1L.img：启动程序从 NAND 加载，该镜像写入 eMMC。跳线应设置为 1001；写入 eMMC 时还需要 bl2.emmc.img 文件。

对于 mtk-bpi-r4lite-EMMC-NOR-MP4_2-2PCIe-1L.img：启动程序从 NOR 加载，该镜像写入 eMMC。跳线应设置为 0111；写入 eMMC 时还需要 bl2.emmc.img 文件。

对于 mtk-bpi-r4lite-NAND-MP4_2-2PCIe-1L.img：启动程序从 SD 卡加载，该镜像写入 NAND。跳线应设置为 0000。

对于 mtk-bpi-r4lite-NOR-MP4_2-2PCIe-1L.img：启动程序从 SD 卡加载，该镜像写入 NOR。跳线应设置为 0010。

对于 mtk-bpi-r4lite-SD-NOR-MP4_2-2PCIe-1L.img：此 SD 卡镜像支持 NOR 闪存，但不支持 NAND 闪存。如果从 SD 卡启动后需要向 NOR 写入其他镜像，应使用这个专用镜像。

对于 mtk-bpi-r4lite-SD-NAND-MP4_2-2PCIe-1L.img：此 SD 卡镜像支持 NAND 闪存，但不支持 NOR 闪存。如果从 SD 卡启动后需要向 NAND 写入其他镜像，应使用这个专用镜像。



=== 将镜像写入 SD 卡

-  Windows PC：将 SD 卡插入读卡器，再将读卡器连接到电脑。格式化 SD 卡时不要选择“快速格式化”。


- Linux PC：可以使用“**mksf**”命令格式化，或使用“**dd**”命令写零。

**在 Windows 电脑上将镜像写入 SD 卡**

link:https://balena.io/etcher[Balena Etcher] 是 Balena 提供的开源图形化镜像写入工具，可将操作系统镜像写入 SD 卡或 U 盘。

- 单击“**Flash from file**”选择镜像。 
- 单击“**Select target**”选择目标设备。 
- 单击“**Flash!**”开始写入。

image::/bpi-r4_lite/r4_lite_flash1.png[r4_lite_flash1.png]      

**在 Linux 电脑上将镜像写入 SD 卡**

1. 从我们的论坛下载最新镜像。     
2. 在 Ubuntu 中安装 bpi-tools。如果无法访问该地址或遇到其他问题，请前往 bpi-tools 仓库手动安装。

+
```sh
apt-get install pv
curl -sL https://github.com/BPI-SINOVOIP/bpi-tools/raw/master/bpi-tools | sudo -E bash
```
3. 下载镜像后，将 TF 卡插入 Ubuntu 电脑并执行：

+
```sh
bpi-copy xxx.img /dev/sdx
```
该命令会将镜像写入 TF 卡。

4. 完成步骤 3 后，将 TF 卡插入 R4_Lite，然后按电源键启动开发板。
 
**将启动跳线更改为从 SD 启动，启用 SD 卡设备。**

=== 将镜像写入板载 NOR
NOTE: 更新 NOR 时，先将启动开关切换到从 SD 卡启动，并插入写有 SD 启动镜像的 SD 卡。系统启动后，将 NOR 镜像写入 NOR，最后再把启动模式切换为从 NOR 启动。

写入 NOR 镜像前，请先准备一个 U 盘。以下以 OpenWrt 镜像（mtk-bpi-r4lite-NOR.img）为例：

1. 将 NOR 启动用 OpenWrt 镜像（**mtk-bpi-r4lite-NOR.img**）复制到 U 盘。 
2. 调整启动跳线，使开发板从 SD 卡启动，然后上电。
3. 将 U 盘插入开发板，并按如下方式挂载到 /mnt 或其他目录（如果系统已自动挂载，可跳过此步）：

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```
4. 执行以下命令擦除整个 NOR 闪存，并将镜像写入 NOR 设备：

+
```sh
mtd erase /dev/mtd0
dd if=mtk-bpi-r4lite-NOR.img of=/dev/mtdblock0
```
5. 关闭 BPI-R4_Lite 的电源，拔出 U 盘，将启动模式切换为从 NOR 启动。

=== 将镜像写入板载 NAND
> **NAND 在出厂时已写入镜像。如需使用，只需切换到对应的启动模式，然后上电启动。**



NOTE: 更新 NAND 时，先将启动开关切换到从 SD 卡启动，并插入写有 SD 启动镜像的 SD 卡。系统启动后，将 NAND 镜像写入 NAND，最后再把启动模式切换为从 NAND 启动。



写入 NAND 镜像前，请先准备一个 U 盘。以下以 OpenWrt 镜像（mtk-bpi-r4lite-NAND-0611.img）为例：

1. 将 NAND 启动用 OpenWrt 镜像（**mtk-bpi-r4lite-NAND-0611.img**）复制到 U 盘。 
2. 调整启动跳线，使开发板从 SD 卡启动，然后上电。
3. 将 U 盘插入开发板，并按如下方式挂载到 /mnt 或其他目录（如果系统已自动挂载，可跳过此步）：

+
```SH
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```
4. 执行以下命令擦除整个 NAND 闪存，并将镜像写入 NAND 设备：

+
```sh
mtd erase /dev/mtd0
mtd write mtk-bpi-r4lite-NAND-0611.img /dev/mtd0
```
5. 关闭 BPI-R4_Lite 的电源，拔出 U 盘，将启动模式切换为从 NAND 启动。


=== 将镜像写入板载 eMMC
NOTE: SD 卡和 eMMC 共用同一个 SoC 控制器，因此必须先从 NAND 启动，再将 eMMC 镜像写入 eMMC；完成后把启动模式切换为从 eMMC 启动。



写入 eMMC 镜像前，请先准备一个 U 盘。以下以 OpenWrt 镜像（bl2_emmc.img、mtk-bpi-r4lite-EMMC-NAND.img）为例：

1. 将 eMMC 启动用 OpenWrt 镜像（**bl2_emmc.img**、**mtk-bpi-r4lite-EMMC-NAND.img**）复制到 U 盘；如果镜像已压缩，请先解压再复制。

2. 将启动跳线切换到 NAND，使主板从 NAND 启动。
 
3. 将 U 盘插入开发板，并按如下方式挂载到 /mnt 或其他目录（如果系统已自动挂载，可跳过此步）：

+
```sh
mount -t vfat /dev/sda1 /mnt 
cd /mnt/sda1
```

4. 执行：

+
```sh
echo 0 > /sys/block/mmcblk0boot0/force_ro
dd if=bl2_emmc.img of=/dev/mmcblk0boot0
dd if=mtk-bpi-r4lite-EMMC-NAND.img of=/dev/mmcblk0
mmc bootpart enable 1 1 /dev/mmcblk0
sync
sync
```
 
5. 关闭 R4_Lite 的电源，拔出 U 盘，将启动模式切换为从 eMMC 启动。

=== M.2 4G/5G 模块（USB 接口）
BPI-R4_Lite 支持采用 M.2 USB 接口的 4G LTE/5G 模块：**Quectel EM05、RM500U-CN、RM500Q-GL 和 RM520N-GL**。 

如需在 BPI-R4_Lite 上使用 M.2 蜂窝通信模块，请执行以下步骤：

1. 将 4G/5G 蜂窝通信模块安装到 CN9 插槽（M.2 Key B）。
2. 将 Nano SIM 卡插入 SIM 卡槽（SIM1），注意安装方向。
3. 在模块上安装天线。
4. 开机后系统会自动拨号。

NOTE:  4G/5G 功能是否可用取决于当地运营商使用的频段。

== 散热片
以下是 MTK OpenWrt 的 PWM 风扇控制参考脚本。

查看风扇脚本设置：

```bash
root@OpenWrt:/# cat /sbin/fan-speed 
#!/bin/sh /etc/rc.common

if [ ! -f /sys/class/pwm/pwmchip0/export ]; then
        exit 0
fi

### enable fan ###
echo 0 > /sys/class/pwm/pwmchip0/export
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/period
echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
echo normal > /sys/class/pwm/pwmchip0/pwm0/polarity
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable

while :
do
        sleep 20
        result=`cat /sys/class/thermal/thermal_zone0/temp`

        temperature=$((result))
        #echo $temperature
        if [ ${temperature} -ge 53000 ]; then
                echo 5000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -ge 62000 ]; then
                echo 1000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4800 ]; then
                echo 7000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi

        if [ ${temperature} -le 4000 ]; then
                echo 10000 >  /sys/class/pwm/pwmchip0/pwm0/duty_cycle
        fi
done
```

=== 如何调节风扇速度

禁用后台运行的脚本（该脚本会在开机时自动启动，请先停止 fan-speed 进程）：


```bash
root@OpenWrt:/# ps w | grep fan
 7167 root      1324 S    /bin/sh /etc/rc.common /sbin/fan-speed
 7435 root      1244 R    grep fan
root@OpenWrt:/# kill -9 7167
root@OpenWrt:/# ps w | grep fan
 7503 root      1244 S    grep fan
```

手动设置 PWM2 输出；duty_cycle 控制风扇转速，数值越大，转速越高。

```bash
root@OpenWrt:/# echo 2 > /sys/class/pwm/pwmchip0/export
root@OpenWrt:/# echo 10000 > /sys/class/pwm/pwmchip0/pwm2/period
root@OpenWrt:/# echo 5000 >  /sys/class/pwm/pwmchip0/pwm2/duty_cycle 
root@OpenWrt:/# echo normal > /sys/class/pwm/pwmchip0/pwm2/polarity
root@OpenWrt:/# echo 1 > /sys/class/pwm/pwmchip0/pwm2/enable
root@OpenWrt:/# 
```
