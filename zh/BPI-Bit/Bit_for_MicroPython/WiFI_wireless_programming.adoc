= 了解无线编程

采用有线连接板的方式是上个世纪的特点，所以我们在后来的开发过程中，就是要支持，并且尽可能往无线控制的方向开发，对于各种简单的物联网设备来说是没有专门预留有线接口给你连接到电脑控制的，比如说灯光的智能控制。

那么此时无线就投入使用了，可以看到，在板子连接上互联网后，我们就可以不用插入电脑来帮助板子直接上网了 (link:/en/BPI-Bit/Bit_for_MicroPython/WiFI_wireless_connection#_connect_wifi_by_mobile[上一节的手机分销网络模型])，所以这就是无线编程的基础，通过简单的方式让板子进入你的网络，你就可以控制它了。

= 远程连接 BPI:bit
的 MicroPython 接口使用 Python REPL，这意味着它本身就是一个可以重用的操作系统环境。与之前不同 Linux 系统，其特点是简单易用

REPL 是有线时常用的交互界面，而无线时， link:http://micropython.org/webrepl/[网络REPL] 介绍一下，顾名思义，就是一朵云 REPL，如下图所示：

image::/bpi-bit/webrepl_ftp.png[webrepl_ftp.png]

可以看到它可以直接操作板子，和过去有线连接一样，响应速度很快，和有线的感觉没有太大区别。

不过这显然还不够，因为这个编辑器只能用，但是不好用，所以我特地在mpfshell中适配了webrepl。也就是说基于mpfshell的pycharm插件也支持无线编程，所以所有认为有用的功能都用上了，如下图所示。

image::/bpi-bit/pycharm.png[pycharm.png]

程序运行良好且响应速度更快 (毕竟是专门为此目的而设计的)，但需要注意的是，路径并不完全相同。

- webrepl标准路径是ws：//192.168.30.116:8266.
- mpfshell的路径是ws:192.168.30.116和1234，区别在于后者允许绕过密码，从而消除连接认证。

此时，您就可以像以前使用有线一样使用它了，如果这期间出现任何问题，只需重新启动板子即可，它将自动给网络加电并打开Webrepl支持服务

未来它将由电池供电，无需电脑电源，因此您可以完全无线控制它。请注意，必要时需要将频率降低至80Mhz，否则很快就会断电。

== MDns反向域名解析服务
如果无法使用主机名来代替IP内存，除了请求云服务商注册DNS域名解析外，还有一个办法，就是反转注册的DNS，DNS是服务器特有的管理服务，客户端是无法再次更改的，所以，我们会使用主动申请的DNS为其特定的域名。

换句话说，将IP变成自定义的网络路径，例如hostname.local。

如下所示，这也需要相对较新的路由器支持。只要不是上世纪的路由器，基本都支持这个服务，但是不否认10年前生产的路由器可能没有这个MDns服务，包括电脑也可能不支持

Windows 需要额外安装 Bonjour 打印服务，可以 link:https://support.apple.com/kb/DL999[在这里下载].

现在我使用以下代码来配置板子进行Mdns注册 (所有操作均基于互联网)

```sh
try:
   import network
   mdns = network.mDNS()
   mdns.start("bpibit", "MicroPython with mDNS")
   _ = mdns.addService('_ftp', '_tcp', 21, "MicroPython",
                       {"board": "ESP32", "service": "bpibit FTP File transfer", "passive": "True"})
   _ = mdns.addService('_telnet', '_tcp', 23, "MicroPython", {"board": "ESP32", "service": "bpibit Telnet REPL"})
   _ = mdns.addService('_http', '_tcp', 80, "MicroPython", {"board": "ESP32", "service": "bpibit Web server"})
   print("mDNS started")
except Exception as e:
   print("mDNS not started")
```
您可以在计算机上使用bpibit.local代替IP地址来访问它，如下图所示。您还可以更改 mdns.start 的名称(“bpi比特”，“MicroPython 与MDNS“) 在你的代码中
