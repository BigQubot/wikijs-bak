= 简介

BananaPi BPI-F3 采用K1内核，SPM8821 PMIC+外部DCDC供电方案。存储采用LPDDR4X， eMMC。有外围设备，例如 PCIe 2.0 2车道M.2 KEY M， PCIe 2.0 1车道MINI PCIe, 4xUSB3.0 TYPE-A, WIFI/BT、TF卡、HDMI TX、MIPI DSI、MIPI CSI、TYPE-C、2xRJ45等集成，集成稳定且可扩展的解决方案。

TIP: 更多信息： link:/en/BPI-F3/BananaPi_BPI-F3[香蕉派 BPI-F3 主页]

= 开发
== 准备
. 准备一条TTL线，一个12V PD电源， USB 数据线和至少8G的TF卡。
. 请 link:/en/BPI-F3/BananaPi_BPI-F3#_system_image[下载] 标准差和 EMMC 要刻录的镜像。

== 安装镜像到 eMMC 2
WARNING: 的 **阿姆比安** 镜像目前仅支持SD卡启动。

NOTE: 除了使用titantools之外，还可以使用dd命令将镜像刻录到 emmc.
 
采取 **bianbu-23.10-nas-k1-v1.0rc1-release-20240429192450.img**.
解压缩“**bianbu-k1-xxx.img.zip**” 到 USB 驱动器，然后复制“**fsbl.bin**” 和 “**bootinfo_emmc.bin**“在”**bianbu-k1-xxx.zip**” 将其复制到 USB 开车。

. 首先将已经烧录镜像的SD卡插入F3中并上电启动。
. 插入复制的 USB 驶入F3。

. 启动后使用“lsblk”命令查看。
+
```sh
pi@k1:~$ lsblk
NAME        MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda           8:0    1 14.8G  0 disk
└─sda1        8:1    1 14.8G  0 part
mmcblk0     179:8    0 14.8G  0 disk
├─mmcblk0p1 179:9    0  256K  0 part
├─mmcblk0p2 179:10   0  128K  0 part
├─mmcblk0p3 179:11   0  384K  0 part
├─mmcblk0p4 179:12   0    2M  0 part
├─mmcblk0p5 179:13   0  256M  0 part
└─mmcblk0p6 179:14   0    8G  0 part /
mmcblk2     179:8    0 14.6G  0 disk
```
“sda1”指的是 USB 驱动器，“mmcblk0”指的是 SD 卡，“mmcblk2”指的是 EMMC.
. 安装 USB 先开车去mnt。
+
```sh
sudo mount /dev/sda1 /mnt
cd /mnt
```
. 然后使用dd命令将镜像刻录到 emmc
+
```sh
sudo dd if=bianbu-23.10-nas-k1-v1.0rc1-release-20240429192450.img of=/dev/mmcblk2 bs=10M
```
NOTE: 如果您输入 **LSBLK** 命令，可以看到 **启动**。您可以直接进入步骤9。

. 接下来，更新boot0分区 EMMC。但有些镜像启动分区默认是隐藏的，所以需要修改cmdline。挂载bootfs：
+
```shs
sudo mount /dev/mmcblk0p5 /boot
sudo nano /boot/env_k1-x.txt
```
找到 Commonargs 并添加“recovery=1” 最后。
+
```sh
commonargs=setenv bootargs earlycon=${earlycon} earlyprintk console=tty1 console=${console} ${loglevel} clk_ignore_unused rdinit=${init} recovery=1
```
保存并重新启动。
+
```sh
sudo reboot
```
. 重启完成后，使用lsblk命令可以看到BOOT分区。
+
```sh
pi@k1:~$ lsblk
NAME         MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda            8:0    1 14.8G  0 disk
└─sda1         8:1    1 14.8G  0 part
mmcblk0      179:0    0 14.8G  0 disk
├─mmcblk0p1  179:1    0  256K  0 part
├─mmcblk0p2  179:2    0  128K  0 part
├─mmcblk0p3  179:3    0  384K  0 part
├─mmcblk0p4  179:4    0    2M  0 part
├─mmcblk0p5  179:5    0  256M  0 part
└─mmcblk0p6  179:6    0    8G  0 part /
mmcblk2      179:8    0 14.6G  0 disk
├─mmcblk2p1  179:9    0  256K  0 part
├─mmcblk2p2  179:10   0   64K  0 part
├─mmcblk2p3  179:11   0    1M  0 part
├─mmcblk2p4  179:12   0    2M  0 part
├─mmcblk2p5  179:13   0  256M  0 part
└─mmcblk2p6  179:14   0    2G  0 part
mmcblk2boot0 179:16   0    4M  1 disk
mmcblk2boot1 179:24   0    4M  1 disk
```
. 安装一个 USB 开车
+
```sh
sudo mount /dev/sda1 /mnt
cd /mnt
```
. 执行以下命令：
+
```sh
echo 0 | sudo tee /sys/block/mmcblk2boot0/force_ro
sudo dd if=bootinfo_emmc.bin of=/dev/mmcblk2boot0
sudo dd if=FSBL.bin of=/dev/mmcblk2boot0 seek=512 bs=1
sync
```
. 等待刻录完成后，断开电源并取出SD卡并 USB 开车。再次通电即可从 EMMC.

== WiFi/BT
**您有两种设置 WiFi 的方法**

. 使用UI界面设置WiFi

. 使用命令设置 WiFi
+
```sh
sudo nmcli dev
sudo nmcli r wifi on
sudo nmcli dev wifi
sudo nmcli dev wifi connect "SSID" password "PASSWORD" ifname wlan0
```

**您有两种设置 BT 的方法**

. 使用UI界面设置BT

. 使用命令设置BT
+
```sh
hciconfig
sudo hciconfig hci0 up
hciconfig hci0 noauth
hcitool scan
sudo rfcomm bind /dev/rfcomm0 xx:xx:xx:xx
sudo cat >/dev/rfcomm0
```

```sh
git clone git@github.com:BPI-SINOVOIP/armbian-build.git -b v24.04.30 v24.04.30

./compile.sh build BOARD=bananapif3 BRANCH=legacy BUILD_DESKTOP=yes BUILD_MINIMAL=no DESKTOP_APPGROUPS_SELECTED= DESKTOP_ENVIRONMENT=gnome DESKTOP_ENVIRONMENT_CONFIG_NAME=config_base KERNEL_CONFIGURE=no RELEASE=mantic
```

== 实时时钟
NOTE: 系统上电后，RTC会自动同步系统时间。您可以使用命令查询系统时间和RTC时间。这里的系统时间是CST时间，而RTC显示的是UTC时间。 8小时的差异属于正常范围。

image::/bpi-f3/banana_pi_bpi-f3_rtc1.jpg[banana_pi_bpi-f3_rtc1.jpg]
. 将电池连接至F3的RTC接口，然后连接F3的电源 BPI-F3 并打开电源启动设备。连接网络获取实时时间。
+
```sh
root@k1:~# date
2025年 10月 11日 星期六 14:25:47 CST
root@k1:~# cat /sys/class/rtc/rtc0/{date,time}
2025-10-11
06:25:59
```

. 关闭电源并断开网络电缆。稍等一下。再次上电后，确认RTC时间运行正常，但由于网线断开导致系统时间无法同步。
+
```sh
root@k1:~# date
2025年 10月 11日 星期六 14:02:48 CST
root@k1:~# cat /sys/class/rtc/rtc0/{date,time}
2025-10-11
06:38:37
```
